## API 变化

### 新增 API

| 方法 | 路径 | Auth | 说明 |
|------|------|------|------|
| `GET` | `/inquiries/mine` | `JwtAuthGuard` | 查询当前用户所属 organization 的 inquiry 列表，支持分页 (`page`, `pageSize`) |
| `GET` | `/inquiries/:id` | `JwtAuthGuard` | 查询指定 inquiry 详情，需同 organization 权限 |

### 已有 API（保持不变）

| 方法 | 路径 | Auth | 说明 |
|------|------|------|------|
| `POST` | `/inquiries` | Public | 创建产品 inquiry（无需登录） |

所有 API 返回统一 `ApiResponse<T>` 格式：

{
  "success": true,
  "data": { ... },
  "message": "OK",
  "timestamp": "2026-08-03T..."

  "data": {
    "data": [...],

## 权限验证

| 验证项 | 实现方式 | 状态 |
|--------|----------|------|
| **JwtAuthGuard** | `@UseGuards(JwtAuthGuard)` 应用于 `GET /inquiries/mine` 和 `GET /inquiries/:id` | ✅ |
| **Organization Scope** | Service 层查询条件：`user: { organizationId: user.organizationId }`，仅返回当前用户所属组织的 inquiry | ✅ |
| **Unauthorized Access** | `getInquiryById` 中跨组织访问返回 `ForbiddenException`（403） | ✅ |
| **无组织用户** | `getMyInquiries` 中 `organizationId` 为空时返回空列表 | ✅ |
| **POST 公开** | `POST /inquiries` 保持 Public（无 Guard），游客可提交 inquiry | ✅ |
