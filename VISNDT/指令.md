------

# 846 Core Frontend Page Design Specification

> Version: **V1.0**
>
> Status: **DESIGN SPECIFICATION / FROZEN FOR IMPLEMENTATION**
>
> Scope: VISNDT Public Core Frontend
>
> Principle:
>
> **Freeze the Business. Free the Experience.**
>
> Purpose:
>
> 建立 VISNDT 第一套统一、专业、可实施的 Industrial B2B Discovery Platform 前端页面设计体系，为下一阶段实施提供唯一 UX / IA / Layout / Component 基准。

------

# 1. Design Objective

VISNDT 前端不再以：

```text
Corporate Website
+
Marketing Homepage
+
Product Showcase
```

作为主要心智。

正式目标：

```text
Industrial B2B Discovery Platform
```

用户进入平台后的核心路径：

```text
Discover
→ Search
→ Understand
→ Compare
→ Validate
→ Find Supplier
→ Submit Requirement
→ Procure
```

------

# 2. Global Page Mental Model

每个页面只允许拥有一个主要任务。

| 页面               | Primary Mental Model         |
| ------------------ | ---------------------------- |
| Home               | Discover                     |
| Search             | Find                         |
| Product List       | Browse                       |
| Product Detail     | Evaluate                     |
| Compare            | Compare                      |
| Knowledge List     | Learn                        |
| Knowledge Detail   | Understand                   |
| Solution List      | Solve                        |
| Solution Detail    | Solve / Apply                |
| Supplier Detail    | Validate Supplier Capability |
| Buyer Workspace    | Procure                      |
| Supplier Workspace | Manage Supply                |
| Admin              | Govern                       |

禁止一个页面同时承担：

```text
Discover + Marketing + Education + Procurement
```

除非这些内容存在明确的信息层级关系。

------

# 3. Global Information Architecture

正式主导航：

```text

连接

└─ 产品对比

方案
├─ 解决方案
└─ 知识中心

连接

```

但用户端显示语言优先采用：

```text

方案

```

而不是大量：

```text

```

内部 Domain 可以保持原语义。

1280px

1480px

### Content
