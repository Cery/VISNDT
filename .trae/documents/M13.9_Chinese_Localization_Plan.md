# M13.9 中文国际化计划

## 摘要

将 VISNDT Web 前台和 Admin 后台的所有硬编码英文字符串替换为中文，实现全中文显示。同时为 Admin 后台集成 Ant Design 中文语言包。

**策略**: 直接替换每个组件中的硬编码英文字符串为中文，不创建独立的 locale 文件系统。这是最简单、最可靠且风险最低的方案。

**约束**: 
- 仅修改 `apps/web` 和 `apps/admin` 目录
- 不修改 `apps/api`、`database`、`packages`
- 不改变任何业务逻辑、API 调用、组件结构
- `pnpm build` 后 Exit Code 必须为 0

---

## 当前状态分析

- `apps/web/src/app/layout.tsx` 中 `<html lang="zh-CN">` 已设置
- `apps/admin/src/providers/AppProvider.tsx` 中 `ConfigProvider` 未设置 `locale` 属性
- 所有组件均为硬编码英文字符串，无国际化支持
- 项目处于 M13.9 V1.0 Release 阶段，仅允许低风险文本级修改

## 假设与决策

1. **不做国际化框架**: 不使用 i18n 库或 locale 文件系统，直接替换硬编码字符串。项目没有多语言切换需求，中文是唯一目标语言。
2. **Admin 列表页模式一致**: 所有 Admin 列表页（ProductList、UserList、OrganizationList 等）遵循相同的 Ant Design Table 模式，翻译策略一致。
3. **不修改 API 返回数据**: API 返回的 status 枚举值（如 ACTIVE、DRAFT）保持英文，仅前端展示翻译。
