# 能力分类与参数级联及产品分级展示实现计划

## 背景与目标

当前 Admin 端在能力（Product）创建、能力产品管理、参数组/参数定义管理中存在以下问题：

1. **能力创建页**的“分类”与“能力参数”没有级联：表单一次性加载全部分类与全部参数定义，选择分类后参数区不会联动过滤。
2. **能力产品管理页**（`/products`）的分类筛选是扁平下拉，无法按分类层级（父分类 → 子分类）查看产品。
3. **参数组/参数定义列表**也是扁平表格，无法按“分类 → 参数组 → 参数定义”的层级关系展示。

本计划通过最小 Schema 改动，将 `ParameterGroup` 归属到 `ProductCategory`，从而建立“分类 → 参数组 → 参数定义”的层级，并据此改造 Admin 前端级联与列表展示。

## 核心决策

- **需要改 Schema**。当前 `ParameterGroup`/`ParameterDefinition` 与 `ProductCategory` 无关联，无法做级联。
- **最小改动方案**：在 `ParameterGroup` 上新增 `categoryId`，`ParameterDefinition` 通过已有的 `parameterGroupId` 间接归属分类。
- **权衡**：一个参数组只属于一个分类，实现最简单；若未来需要跨分类复用，可再迁移为多对多关系。

## 阶段一：数据库迁移与数据回填

1. 在 `database/prisma/schema.prisma` 中：
   - `ParameterGroup` 新增 `categoryId` 字段与 `ProductCategory` 关系。
   - `ProductCategory` 新增反向关系 `parameterGroups`。
   - `ParameterGroup` 新增 `@@index([categoryId])`。
2. 生成并执行迁移：
   - `npx prisma migrate dev --name add_category_to_parameter_group`
   - `npx prisma generate`
3. 数据回填（migration 或一次性脚本）：
   - 对已有 `ParameterGroup`，通过其下 `ParameterDefinition → ProductParameterValue → Product.categoryId` 推断最常用分类。
   - 无法推断的挂到一个“通用/未分类”分类下，避免前端空值。

## 阶段二：后端 API 改造

### 参数组
- `apps/api/src/parameter-groups/dto/create-parameter-group.dto.ts`
- `apps/api/src/parameter-groups/dto/update-parameter-group.dto.ts`
  - DTO 增加 `categoryId?: string`。
- `apps/api/src/parameter-groups/parameter-groups.service.ts`
  - `findAll` 增加 `categoryId` 过滤。
  - 返回时 `include: { category: true }`。
- `apps/api/src/parameter-groups/parameter-groups.controller.ts`
  - `findAll` 透传 `categoryId` 查询参数。

### 参数定义
- `apps/api/src/parameter-definitions/dto/create-parameter-definition.dto.ts`
- `apps/api/src/parameter-definitions/parameter-definitions.service.ts`
  - `findAll` 增加 `categoryId` 过滤（通过 `group.categoryId`）与 `parameterGroupId` 过滤。
  - 返回时 `include: { group: { include: { category: true } }, options: true }`。
- `apps/api/src/parameter-definitions/parameter-definitions.controller.ts`
  - `findAll` 透传 `categoryId`、`parameterGroupId`。

### 产品查询
- `apps/api/src/products/products.service.ts`
  - 当传入 `categoryId` 时，支持可选 `includeSubcategories=true`，递归包含所有子分类下的产品。
  - 用于产品管理页点击父分类时展示整棵分类树下的产品。

## 阶段三：Admin 前端 API 层

- `apps/admin/src/api/categories.service.ts`
  - 已有 `getList()` 返回扁平列表，可复用；如需后端树可后续新增 `getTree()`，当前先用前端构建树。
- `apps/admin/src/api/parameter-group.service.ts`
  - `getList(params)` 支持 `categoryId`。
- `apps/admin/src/api/parameter-definition.service.ts`
  - `getList(params)` 支持 `categoryId`、`parameterGroupId`。
- `apps/admin/src/api/product.service.ts`
  - `getList(params)` 支持 `includeSubcategories`。

## 阶段四：前端页面与组件改造

### 通用工具

- 新增或复用分类树构建工具（如 `buildCategoryTree(categories)`），将扁平 `ProductCategory[]` 转换为层级结构。
- 分类选择控件优先使用 Ant Design `TreeSelect` 或 `Cascader`，显示完整路径。

### 1. 能力创建页 `apps/admin/src/components/product/ProductForm.tsx`

- 分类 `Select` 改为 `TreeSelect`/`Cascader`，支持层级选择。
- 初始不再加载所有参数定义；仅加载分类列表。
- 监听 `categoryId` 变化：
  - 清空此前已填写的参数值（避免误保存到不相关分类）。
  - 调用 `parameterDefinitionService.getList({ categoryId, pageSize: 100 })`。
  - 按 `def.group?.name` 分组渲染参数配置卡片。
- 编辑模式：回显 `initialValues.categoryId` 后加载对应分类参数定义并回填已有值。

### 2. 能力产品管理页 `apps/admin/src/pages/ProductList.tsx`

- 左侧新增 `Tree` 分类树面板，展示层级与每个节点下的产品数量。
- 点击树节点时：
  - 设置 `categoryId` 查询参数。
  - 设置 `includeSubcategories=true`，右侧表格展示该分类及其子分类下的产品。
- 表格“分类”列显示完整路径（如 `工业检测 / 内窥镜`），而非仅当前分类名。
- 顶部原有扁平 `categoryId` 下拉可替换为 `TreeSelect`，或与左侧树联动。

### 3. 参数组列表页 `apps/admin/src/pages/parameter/ParameterGroupList.tsx`

- 增加分类筛选 `TreeSelect`。
- 列表增加“所属分类”列。
- 按分类排序/分组展示（可用 Table 的 `rowSpan` 或按分类折叠的卡片组）。
- 创建/编辑参数组时强制选择分类。

### 4. 参数定义列表页 `apps/admin/src/pages/parameter/ParameterDefinitionList.tsx`

- 增加分类筛选、参数组筛选。
- 列表增加“所属分类”、“所属参数组”列。
- 按 `category → group → definition` 层级排序或分组展示。
- “分级”体现在分类列的层级路径或缩进中。

## 阶段五：数据与 Seed

- 确认 `ProductCategory` 中存在可用根分类；若无，新增“通用参数”占位分类。
- Seed 脚本（如有）中新增参数组/定义时，必须写入 `categoryId`。

## 阶段六：验证

1. **构建与类型检查**
   - `npx prisma generate`
   - `npm run build --workspace=apps/api`
   - `npm run build --workspace=apps/admin`
2. **数据库**
   - 确认迁移文件生成并执行成功。
   - 确认 `parameter_group.category_id` 列已回填。
3. **运行时验证**
   - 登录 Admin（`http://localhost:3001`）。
   - 进入“能力创建”：
     - 选择分类后，参数配置区仅出现该分类下的参数组/定义。
     - 切换分类后参数区刷新。
   - 进入“能力产品管理”：
     - 左侧分类树可展开/折叠。
     - 点击父分类，右侧展示该分类树下的全部产品。
   - 进入“参数组管理”与“参数定义管理”：
     - 列表按分类、分组、层级展示。
     - 分类筛选有效。
4. **截图**

   - 产品管理页左侧树+右侧表格截图。
