# M9.3 Admin Product Management — 实施计划

## Context

M9.2 Dashboard V1 已完成并冻结。按照交接文档，下一步是 M9.3 Admin Product Management，目标是将 `/products` 路由的 Placeholder 替换为功能完整的 Product List 页面。

## 目标

实现 Product List 页面，支持：
- 关键词搜索（name, model, description）
- 状态筛选（DRAFT, ACTIVE, INACTIVE）
- 排序（name, createdAt, updatedAt）
- 分页（复用 Ant Design Table 内置分页）
- 三种状态：loading → error（可重试）→ success（含 empty 处理）

## 新建文件

### 1. `apps/admin/src/types/product.types.ts`

```typescript
// Product 实体（匹配 API 返回结构）
export interface Product {
  id: string;
  categoryId: string;
  name: string;
  model?: string;
  description?: string;
  status: 'DRAFT' | 'ACTIVE' | 'INACTIVE';
  createdAt: string;
  updatedAt: string;
  category?: {
    id: string;
    name: string;
    slug: string;
  };
}

// 分页列表响应
export interface ProductListResponse {
  data: Product[];
  total: number;
  page: number;
  pageSize: number;
  totalPages: number;
}

// 搜索参数
export interface SearchProductParams {
  keyword?: string;
  categoryId?: string;
  status?: string;
  sortBy?: 'createdAt' | 'updatedAt' | 'name';
  sortOrder?: 'asc' | 'desc';
  page?: number;
  pageSize?: number;
}
```

### 2. `apps/admin/src/api/product.service.ts`

```typescript
import { apiClient } from './client';
import type { Product, ProductListResponse, SearchProductParams } from '../types/product.types';

// 后端 ApiResponse 包装类型
interface ApiResponseWrapper<T> {
  success: boolean;
  data: T;
  message: string;
  timestamp: string;
}

export const productService = {
  async getList(params?: SearchProductParams): Promise<ProductListResponse> {
    const response = (await apiClient.get('/products', { params })) as unknown as ApiResponseWrapper<ProductListResponse>;
    return response.data;
  },

  async getById(id: string): Promise<Product> {
    const response = (await apiClient.get(`/products/${id}`)) as unknown as ApiResponseWrapper<Product>;
    return response.data;
  },

  async create(data: { categoryId: string; name: string; model?: string; description?: string }): Promise<Product> {
    const response = (await apiClient.post('/products', data)) as unknown as ApiResponseWrapper<Product>;
    return response.data;
  },

  async update(id: string, data: { categoryId?: string; name?: string; model?: string; description?: string; status?: string }): Promise<Product> {
    const response = (await apiClient.patch(`/products/${id}`, data)) as unknown as ApiResponseWrapper<Product>;
    return response.data;
  },
};
```

### 3. `apps/admin/src/pages/ProductList.tsx`

页面结构：
- **状态管理**: discriminated union `PageState` (loading | error | success)
- **搜索栏**: Input.Search + Select(status) + Button(Reset)
- **表格**: Ant Design Table
  - columns: Name, Model, Category, Status (Tag), Created At
  - pagination: 服务端分页，pageSizeOptions: [10, 20, 50]
  - onChange: 处理 sort + pagination 变化
- **状态处理**:
  - loading → Spin 居中
  - error → Alert + Retry 按钮
  - success (empty) → Table 内置 empty
  - success (data) → Table 渲染

## 关键设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 状态管理 | discriminated union | 与 Dashboard 模式一致 |
| 分页 | 服务端 | 产品数量可能很大，前端分页不可行 |
| 搜索 | 防抖 Input.Search | 减少 API 调用 |
| 排序 | Table onChange | 复用 Ant Design 内置排序 |
| Status 标签颜色 | ACTIVE=green, DRAFT=default, INACTIVE=red | 语义化配色 |
| 样式 | inline styles | 与现有 Home.tsx 保持一致 |
