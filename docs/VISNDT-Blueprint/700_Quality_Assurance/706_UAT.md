定义 VISNDT 用户验收测试（UAT）规范。

目标：

确认：

- 平台满足业务需求；
- 用户操作流程完整；
- 核心场景符合预期；

| Supplier Flow | Organization Flow | Business Object |
| Submit Requirement | Submit Demand | Business Object |
| Receive Requirement | Receive Demand | Business Object |
| Review Requirement | Review Demand | Business Object |
| Requirement Submission | Demand Submission | Business Object |
| Matching Process | RFQ Process | Business Object |
| Supplier Response | Organization Response | Business Object |
| Solution Response | Organization Response | Business Object |
| Matching | RFQ | Business Object |
| Fill Requirement | Fill Demand | Business Object |
| Requirement Available | Demand Available | Business Object |
| Business Requirement | Business Requirement | QA Process (unchanged) |

## Test Object Alignment

VISNDT Blueprint v1.0 统一测试对象：

| Test Object | UAT Role |
|-------------|----------|
| Identity | Visitor / Buyer |
| Organization | Organization Side |
| Standard Product | Product Discovery |
| Product Parameter | Search / Filter |
| Offer | Offer Management |
| Demand | Demand Creation / Tracking |
| RFQ | RFQ Tracking / Response |
| Workflow | Status Flow |
| Notification | User Notification |

## Technology Baseline Reference

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js + TypeScript |

## Migration Notes

1. 所有业务对象术语已统一为 Canonical Naming Specification 标准。
2. QA 流程术语（Business Requirement）保持不变。
3. UAT 用户流程已收敛：
   - Buyer Side: `Demand Creation` → `RFQ Tracking`
   - Organization Side: `Offer Management` → `RFQ Response`
4. 测试对象覆盖范围已对齐 Blueprint v1.0 的 9 个核心业务对象。
