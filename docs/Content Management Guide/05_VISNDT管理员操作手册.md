## 1. 管理后台登录

### 1.1 访问地址

```
http://localhost:3001
```

### 1.2 测试账号

| 字段 | 值 |
|------|-----|
| 账号 | `admin` |
| 密码 | `admin888` |

> ⚠️ **重要提示**: 以上为测试环境默认账号密码。生产环境必须修改为强密码。

### 1.3 登录步骤

1. 浏览器访问 `http://localhost:3001`
2. 输入账号和密码
3. 点击「登录」按钮
4. 登录成功后进入管理后台首页

### 1.4 常见问题

| 问题 | 解决方案 |
|------|---------|
| 无法访问 | 确认 Admin 服务已启动 (`pnpm dev`) |
| 登录失败 | 确认账号密码正确；确认 API 服务已启动 |
| 页面空白 | 清除浏览器缓存后重试 |

## 3. 用户管理

### 3.1 功能说明

管理平台所有注册用户，包括查看、创建、编辑用户信息。

### 3.2 用户列表

**功能**: 查看所有注册用户

**操作流程:**

1. 点击左侧菜单「用户管理」→「用户列表」
2. 查看用户列表（包含邮箱、姓名、状态、组织、注册时间）
3. 可搜索、筛选用户

**注意事项:**
- 用户状态：ACTIVE（正常）、INACTIVE（未激活）、SUSPENDED（已停用）
- 修改用户状态需谨慎，SUSPENDED 用户将无法登录

### 3.3 创建用户

**操作流程:**

1. 点击「创建用户」按钮
2. 填写用户信息：
   - 邮箱（必填）
   - 密码（必填）
   - 姓名（可选）
   - 组织（可选）
3. 点击「保存」

**注意事项:**
- 邮箱必须唯一，不可重复
- 创建后用户状态默认为 ACTIVE

### 3.4 用户详情

**操作流程:**

1. 在用户列表点击某用户
2. 查看用户详细信息
3. 可编辑用户信息
4. 可修改用户状态

## 5. 产品管理

### 5.1 功能说明

这是平台**最核心**的管理模块。管理所有产品信息，包括产品分类、参数、媒体。

### 5.2 产品列表

**功能**: 查看所有产品

**操作流程:**

1. 点击「产品管理」→「产品列表」
2. 查看产品列表（名称、分类、状态、创建时间）
3. 可搜索、筛选、排序

**产品状态说明:**

| 状态 | 说明 |
|------|------|
| DRAFT | 草稿，仅管理员可见 |
| ACTIVE | 已发布，前端可见 |
| INACTIVE | 已下架，前端不可见 |

### 5.3 创建产品

**操作流程:**

1. 点击「创建产品」
2. 填写基本信息：
   - 产品名称（必填）
   - 型号（可选）
   - 描述（可选）
   - 分类（必选）
3. 设置产品状态
4. 点击「保存」
5. **保存后需要配置参数和媒体**（见下方）

**注意事项:**
- 产品名称建议规范：品牌 + 型号 + 产品类型
- 分类选择影响前端展示和搜索匹配
- 新建产品默认为 DRAFT 状态，需手动发布

### 5.4 产品详情

**功能**: 查看产品完整信息，编辑产品

**操作流程:**

1. 在产品列表点击某产品
2. 查看产品基本信息
3. 可编辑产品信息
4. **配置产品参数**（见参数管理）
5. **添加产品媒体**（见媒体管理）

### 5.5 产品编辑

**操作流程:**

1. 在产品详情页点击「编辑」
2. 修改产品信息
3. 点击「保存」

## 7. 参数管理

### 7.1 功能说明

这是平台**技术核心**模块。管理产品的标准化参数体系，包括参数组、参数定义、参数选项。

### 7.2 参数体系结构

```
参数组 (Parameter Group)
  └── 参数定义 (Parameter Definition)
        ├── 参数选项 (Parameter Option)  [仅 ENUM 类型]
        └── 产品参数值 (Product Parameter Value)
```

### 7.3 参数组管理

**功能**: 创建和管理参数分组

**操作流程:**

1. 点击「参数管理」→「参数组」
2. 点击「创建参数组」
3. 填写：
   - 名称（如：工业内窥镜参数）
   - 代码（如：industrial_endoscope）
   - 描述（可选）
4. 点击「保存」

**注意事项:**
- 参数组代码必须唯一
- 建议按产品类型创建参数组

### 7.4 参数定义管理

**功能**: 创建具体参数定义

**操作流程:**

1. 点击「参数管理」→「参数定义」
2. 点击「创建参数定义」
3. 填写：
   - 参数组（选择所属参数组）
   - 名称（如：管线直径）
   - 代码（如：probe_diameter）
   - 数据类型：STRING / NUMBER / BOOLEAN / ENUM
   - 单位（如：mm）
   - 是否必填
4. 点击「保存」

**数据类型说明:**

| 类型 | 适用场景 | 示例 |
|------|---------|------|
| STRING | 文本参数 | 品牌、主机屏幕 |
| NUMBER | 数值参数 | 直径、像素、角度 |
| BOOLEAN | 布尔参数 | 是否防水 |
| ENUM | 枚举参数 | 光源类型、视向 |

**注意事项:**
- ENUM 类型参数需要额外创建参数选项
- NUMBER 类型参数需要在产品中填写数值
- 参数代码必须唯一

### 7.5 参数选项管理

**仅在 ENUM 类型参数时需要**

**操作流程:**

1. 在参数定义列表中，找到 ENUM 类型参数
2. 进入参数选项管理
3. 点击「添加选项」
4. 填写：
   - 值（如：LED）
   - 标签（如：LED 光源）
   - 排序
5. 点击「保存」

### 7.6 为产品配置参数值

**操作流程:**

1. 进入产品详情页
2. 找到参数配置区域
3. 为每个参数定义填写值：
   - STRING 类型：输入文本
   - NUMBER 类型：输入数值
   - ENUM 类型：选择选项
   - BOOLEAN 类型：选择是/否
4. 点击「保存」

## 8. 媒体管理

### 8.1 功能说明

管理产品相关的图片、文档、证书等媒体文件。

### 8.2 添加产品媒体

**操作流程:**

1. 进入产品详情页
2. 点击「添加媒体」
3. 选择媒体类型：IMAGE / DOCUMENT / CERTIFICATE / OTHER
4. 上传文件
5. 填写标题和描述
6. 设置是否为主图（is_primary）
7. 设置显示顺序（display_order）
8. 点击「保存」

**媒体类型说明:**

| 类型 | 说明 |
|------|------|
| IMAGE | 产品图片 |
| DOCUMENT | 技术文档 |
| CERTIFICATE | 认证证书 |
| OTHER | 其他文件 |

**注意事项:**
- 建议至少上传 1 张主图
- 主图在前端产品列表中优先展示
- 图片建议尺寸：800×600 或 4:3 比例

### 8.3 媒体编辑

1. 在媒体列表点击某媒体
2. 修改标题、描述、主图设置、排序
3. 点击「保存」

## 14. 常见运维操作

### 14.1 新用户入驻流程

```
1. 用户注册 → 自动创建账号
2. 管理员在「用户管理」查看新用户
3. 如需，管理员在「组织管理」创建组织
4. 将用户关联到组织
5. 用户可正常使用平台功能
```

### 14.2 新产品上架流程

```
1. 管理员在「分类管理」确认分类存在
2. 管理员在「参数管理」确认参数体系完整
3. 管理员在「产品管理」创建产品
4. 填写产品基本信息
5. 配置产品参数值
6. 上传产品图片（媒体管理）
7. 将产品状态设为 ACTIVE
8. 前端即可看到该产品
```

### 14.3 数据备份

- 数据库备份：定期执行 PostgreSQL 备份
- 文件备份：定期备份 S3 存储文件
- 建议备份频率：每日增量 + 每周全量

## 15. 故障排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 产品不显示 | 产品状态为 DRAFT | 改为 ACTIVE |
| 搜索不到产品 | 产品名称/分类不匹配 | 检查产品信息 |
| 匹配不准确 | 参数值不完整 | 完善产品参数值 |
| 图片不显示 | 文件上传失败 | 重新上传 |
| 用户无法登录 | 账号被 SUSPENDED | 改为 ACTIVE |
