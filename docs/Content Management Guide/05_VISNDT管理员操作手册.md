## 1. 系统概述

VISNDT 定位为**工业检测能力发现平台**，核心业务对象为：

- **能力（Capability / Product）**：平台级标准能力目录（Global Catalog），由管理员统一维护；
- **需求（Demand）**：采购方发布的检测能力采购需求；
- **匹配（Match）**：需求参数与能力参数的确定性匹配结果（Demand → Match → RFQ）；
- **询价请求（RFQ）**：基于需求发起的询价单，供应商可响应；
- **报价（Offer）**：供应商提供的供应能力报价；
- **能力型号（Capability Model / Supplier Product）**：供应商供应能力的型号表达，由平台审核后发布。

> ⚠️ 术语规范：本平台不使用 "Supplier Store / Marketplace / 商品商城" 等表述。供应商 = **能力提供方（Capability Provider）**。请勿新增供应商店铺、交易等概念。

## 2. 登录与账号体系

### 2.1 访问地址

| 环境 | 地址 |
|------|------|
| 开发环境（本地） | `http://localhost:3001` |
| 生产环境 | 按部署域名访问（Admin 独立子域） |

### 2.2 登录步骤

1. 浏览器访问管理后台地址；
2. 输入账号（邮箱）与密码；
3. 点击「登录」；
4. 登录成功后进入后台首页（`/home`）。

### 2.3 账号与角色

| 角色 | 代码 | 中文名 | 说明 |
|------|------|--------|------|
| 超级管理员 | `SUPER_ADMIN` | 超级管理员 | 全部权限，含系统管理、用户/组织管理 |
| 管理员 | `ADMIN` | 管理员 | 产品/内容/业务/用户/组织管理，审计查看 |
| 运营人员 | `OPERATOR` | 运营人员 | 产品/内容管理，用户/组织查看 |
| 查看者 | `VIEWER` | 查看者 | 只读查看，无任何写操作权限 |

> ⚠️ 测试环境存在默认管理员账号，**生产环境必须修改为强密码**，并严格控制角色分配。

### 2.4 常见登录问题

| 问题 | 解决方案 |
|------|---------|
| 无法访问页面 | 确认 Admin 服务已启动（`pnpm dev`）且网络可达 |
| 登录失败 | 确认账号密码正确；确认 API（后端）服务已启动 |
| 页面空白 | 清除浏览器缓存后重试；确认后端接口可用 |
| 无权限操作 | 当前账号角色权限不足，联系 SUPER_ADMIN 调整 |

## 5. 能力中心

### 5.1 能力管理（/products）

平台标准能力目录（Global Catalog），由管理员统一维护。能力（Capability，即原「产品 Product」）是采购方发现与匹配的核心对象。

**能力状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 草稿 | `DRAFT` | 仅后台可见，前端不展示 |
| 已上架 | `ACTIVE` | 前端可见、可被搜索与匹配 |
| 已下架 | `INACTIVE` | 前端不可见 |

**功能与操作**：

1. **能力列表**：查看全部能力，支持关键字搜索、按状态筛选（草稿/已上架/已下架）、按分类筛选、分页浏览；列表显示状态统计数量。
2. **创建能力**：填写能力名称、型号、描述、选择分类，设置状态（默认 `DRAFT`）。保存后可继续配置参数值与媒体。
3. **能力详情 / 编辑**：查看并修改能力信息。
4. **批量操作**：支持勾选多行后批量变更状态（如批量上架、批量下架）。

**注意事项**：
- 能力名称建议采用「品牌 + 型号 + 能力类型」规范；
- 分类选择影响前端展示与匹配；请先确保分类与参数体系已维护；
- 新建能力默认为 `DRAFT`，需手动上架（`ACTIVE`）后前端才可见；
- 已被能力型号（SupplierProduct）绑定引用的能力受保护，无法删除（Prisma 约束保护）。

### 5.2 能力型号审核（/supplier-products）

平台级治理池，用于管理**能力型号（Capability Model / Supplier Product）**的生命周期。**当前能力型号的创建与状态流转均由平台管理员在此完成**；供应商端「运行时能力」为只读视图（供应商自助创建/提交为未来项 `self-service=Future`，冻结设计）。

**审核状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 草稿 | `DRAFT` | 尚未进入审核 |
| 已提交 | `SUBMITTED` | 已提交，待审核 |
| 审核中 | `REVIEWING` | 已开始审核 |
| 已通过 | `APPROVED` | 审核通过（待发布） |
| 已发布 | `PUBLISHED` | 正式发布，前端/匹配可见 |
| 已拒绝 | `REJECTED` | 审核拒绝（需填写拒绝原因） |

**治理操作流程**：

1. 进入「能力型号审核」，创建能力型号（关联平台能力 / 填写品牌、系列、型号、能力参数）；
2. 按状态筛选（重点查看 `SUBMITTED` 待审核项）；
3. 点击某型号进入详情页，核对供应商提交的能力信息与能力参数；
4. 执行「开始审核」（`SUBMITTED → REVIEWING`）；
5. 审核通过则「通过」（`REVIEWING → APPROVED`），再「发布」（`APPROVED → PUBLISHED`）；
6. 如不符合要求则「拒绝」（`REVIEWING → REJECTED`），**必须填写拒绝原因（reviewedNote）**。

> 审核历史（提交时间、审核时间、审核人、拒绝原因、发布时间）可在详情页「审核状态与历史」中查看。
> 生命周期状态迁移（submit → review → approve → reject → publish）由专用动作接口驱动，无通用 PATCH/DELETE 路由（设计内）。

### 5.3 能力分类（/product-categories）

管理能力分类树形结构（多级分类）。

**操作**：
- 创建分类：填写名称、选择父分类（留空为顶级分类）；
- 编辑分类名称；
- 删除/停用不再使用的分类。

**注意事项**：
- 创建分类前先规划好分类体系；
- 能力关联分类后，删除分类需谨慎；存在关联能力的分类无法直接删除（约束保护），需先解除关联。

### 5.4 参数体系

参数体系是匹配能力的**技术核心**。结构如下：

```
参数组 (Parameter Group)
  └── 参数定义 (Parameter Definition)
        ├── 参数选项 (Parameter Option)   [仅 ENUM 类型]
        └── 产品参数值 (Product Parameter Value)
```

#### 5.4.1 参数组（/parameter-groups）

- 创建参数组：填写名称（如「工业内窥镜参数」）、代码（如 `industrial_endoscope`，必须唯一）、描述；
- 建议按产品类型建立参数组。

#### 5.4.2 参数定义（/parameter-definitions）

- 创建参数定义：选择所属参数组、名称、代码（唯一）、数据类型、单位、是否必填；
- 数据类型说明：

| 类型 | 适用场景 | 示例 |
|------|---------|------|
| STRING | 文本参数 | 品牌、主机屏幕 |
| NUMBER | 数值参数 | 管线直径、像素 |
| BOOLEAN | 布尔参数 | 是否防水 |
| ENUM | 枚举参数 | 光源类型、视向 |

- `ENUM` 类型参数需额外维护参数选项（值 + 标签 + 排序）；
- 为能力配置参数值时，不同类型采用不同录入方式（文本/数值/下拉/开关）。

## 6. 业务中心

### 6.1 需求管理（/demands）

查看采购方提交的需求。

**需求状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 草稿 | `DRAFT` | 采购方保存未发布 |
| 已发布 | `PUBLISHED` | 已发布，可进入匹配 |
| 已提交 | `SUBMITTED` | 已进入匹配流程 |
| 处理中 | `PROCESSING` | 匹配/RFQ 处理中 |
| 已关闭 | `CLOSED` | 流程已结束 |
| 已取消 | `CANCELLED` | 采购方取消 |

**操作**：
- 需求列表：按状态筛选、关键字搜索、分页；
- 需求详情：查看基本信息（标题、描述、预算、数量、单位、预计交付日期）、需求参数、匹配结果、关联 RFQ。

### 6.2 RFQ 管理（/rfqs）

管理询价单（RFQ）。

**RFQ 状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 草稿 | `DRAFT` | 已创建未发布 |
| 开放 | `OPEN` | 已发布，供应商可响应 |
| 响应中 | `RESPONDING` | 已收到响应，处理中 |
| 已关闭 | `CLOSED` | 已关闭 |
| 已取消 | `CANCELLED` | 已取消 |

**操作**：
- RFQ 列表：按状态筛选、查看关联需求；
- 创建 RFQ：选择关联需求后创建；
- RFQ 详情：查看需求上下文、供应商响应列表及响应状态。

### 6.3 报价管理（/offers）

管理供应商提交的报价（Offer）。

**报价状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 草稿 | `DRAFT` | 供应商保存未提交 |
| 有效 | `ACTIVE` | 正常有效的报价 |
| 无效 | `INACTIVE` | 已停用 |
| 已提交 | `SUBMITTED` | 已提交 |
| 已接受 | `ACCEPTED` | 采购方已接受 |
| 已拒绝 | `REJECTED` | 已拒绝 |
| 已撤回 | `WITHDRAWN` | 供应商撤回 |

**操作**：报价列表、报价详情查看（关联产品、价格、货币）。

### 6.4 能力询价（/inquiries）

管理能力详情页的询价记录（Inquiry）。

**询价状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 新询价 | `NEW` | 收到询价 |
| 处理中 | `PROCESSING` | 处理中 |
| 已回复 | `REPLIED` | 已回复 |
| 已关闭 | `CLOSED` | 已关闭 |

### 6.5 匹配管理（/matching）

查看需求与产品的确定性匹配结果（Matching Monitor）。

**匹配状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 待处理 | `PENDING` | 匹配完成，待处理 |
| 已匹配 | `MATCHED` | 已生成匹配 |
| 已查看 | `REVIEWED` | 采购方已查看 |
| 已接受 | `ACCEPTED` | 采购方已接受 |
| 已拒绝 | `REJECTED` | 采购方已拒绝 |
| 已过期 | `EXPIRED` | 已过期 |

**操作**：匹配列表（按状态/分数筛选）、匹配详情（匹配分数与匹配依据）。

> 匹配逻辑为确定性规则：Demand 参数 → Product 参数 → 分数 → 匹配。请勿将其理解为 AI/语义替代。

## 7. 用户与供应商

### 7.1 用户管理（/users）

管理平台所有注册用户。

**用户状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 正常 | `ACTIVE` | 可正常登录使用 |
| 未激活 | `INACTIVE` | 尚未激活 |
| 已停用 | `SUSPENDED` | 已停用，无法登录 |

**操作**：
- 用户列表：搜索、筛选（状态）、查看（邮箱、姓名、状态、组织、注册时间）；
- 创建用户：邮箱（必填，唯一）、密码（必填）、姓名（选填）、组织（选填）；创建后默认 `ACTIVE`；
- 用户详情/编辑：修改用户信息、修改状态。

> ⚠️ 将用户置为 `SUSPENDED` 后该用户将无法登录，操作前请确认。

### 7.2 企业管理（/organizations）

管理平台上的企业/组织（Organization）。

**组织状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 正常 | `ACTIVE` | 正常运营 |
| 停用 | `INACTIVE` | 已停用 |
| 暂停 | `SUSPENDED` | 已暂停 |

**操作**：
- 组织列表：搜索、筛选（名称、类型、状态、成员数）；
- 创建组织：名称（必填）、组织类型（决定平台角色）、状态；
- 组织详情/编辑：修改信息、管理组织成员。

> 组织类型决定该组织的平台角色（采购方/供应商等）。请保持术语一致：本平台使用 **Organization**，不使用 "Supplier Store"。

## 8. 内容中心

### 8.1 内容管理（/content）

管理前台内容（文章/知识/解决方案/洞察）。

**内容类型**：`ARTICLE`（文章）、`KNOWLEDGE`（知识）、`SOLUTION`（解决方案）、`INSIGHT`（洞察）。

**内容状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 草稿 | `DRAFT` | 仅后台可见 |
| 待审核 | `REVIEW` | 提交审核中 |
| 已发布 | `PUBLISHED` | 前台可见 |
| 已归档 | `ARCHIVED` | 已归档，前台不展示 |

**操作**：
- 内容列表：按类型/状态筛选、查看 SEO 健康度指标；
- 创建/编辑内容：填写标题、正文、分类、标签、封面等；
- 发布流程：草稿 → 审核 → 发布 / 归档。

### 8.2 知识库

- **知识条目**（/knowledge/entries）：管理知识条目；
- **知识领域**（/knowledge/domains）：管理知识领域；
- **知识分类**（/knowledge/categories）：管理知识分类；
- **知识分类映射**（/product-category-knowledge-mappings）：维护能力分类 ↔ 知识分类的确定性映射。

> 重要：产品与知识关联必须走**确定性映射**（Product → ProductCategory → Mapping → KnowledgeCategory → KnowledgeEntry），禁止使用 AI/关键词猜测。

### 8.3 标签管理（/content/tags）

管理内容标签：创建、编辑、删除标签。

## 9. 媒体中心

### 9.1 媒体管理（/media）

按 FileAsset 的 entityType/entityId 归属展示和管理平台所有媒体文件（图片、文档、证书、规格书、插图等）。

**媒体类型**：`IMAGE`（图片）、`DOCUMENT`（文档）、`CERTIFICATE`（证书）、`SPEC_SHEET`（规格书）、`ILLUSTRATION`（插图）、`OTHER`（其他）。

**操作**：
- 媒体列表：按归属实体查看；
- 上传/编辑媒体：设置标题、描述、主图标识、排序；
- 清理孤儿文件（无关联的文件）。

**注意事项**：
- 产品建议至少 1 张主图，主图在产品列表中优先展示；
- 图片建议 4:3（如 800×600）比例；
- 孤儿文件清理不可逆，清理前请确认文件确实无关联。

## 10. 数据与分析

### 10.1 数据分析（/analytics）

## 12. 核心业务流程

### 12.1 新能力上架流程

```
1. 在「能力分类」确认/创建分类
2. 在「参数体系」确认/创建参数组与参数定义
3. 在「能力管理」创建能力（默认 DRAFT）
4. 填写能力基本信息（名称/型号/描述/分类）
5. 配置能力参数值
6. 在「媒体中心」上传能力图片（≥1 张主图）
7. 将能力状态改为 已上架（ACTIVE）
8. 前端能力目录即可展示，并参与搜索与匹配
```

### 12.2 能力型号治理流程

能力型号（Capability Model / Supplier Product）的创建与状态流转当前由平台管理员完成（供应商端「运行时能力」为只读；供应商自助创建为未来项）。

```
管理员创建/录入能力型号（DRAFT）
  → 提交（SUBMITTED）
  → 管理员「开始审核」（REVIEWING）
      ├→ 「通过」（APPROVED）→「发布」（PUBLISHED）  前端可见
      └→ 「拒绝」（REJECTED，填写原因）→ 修正后重新提交
```

### 12.3 内容发布流程

```
内容 草稿（DRAFT）→ 提交审核（REVIEW）→ 发布（PUBLISHED）/ 归档（ARCHIVED）
```

### 12.4 业务闭环总览

```
采购方创建需求（Demand）
  → 系统确定性匹配（Match）
  → 采购方基于需求发起 RFQ
  → 供应商响应 RFQ（RFQ Response）
  → 采购方决策（接受/拒绝响应）
  → 需求/询价关闭（CLOSED）
```

管理员在整个流程中负责：监控匹配质量、治理能力型号、管理需求/RFQ/报价/询价数据、保障内容与媒体规范。

## 14. 常见问题与故障排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 能力在前端不显示 | 能力状态为 DRAFT / INACTIVE | 改为已上架（ACTIVE） |
| 搜索不到能力 | 名称/分类/参数不匹配 | 检查能力信息与参数值 |
| 匹配不准确 | 参数值缺失或不规范 | 完善能力参数值 |
| 图片不显示 | 上传失败或文件被清理 | 重新上传；确认媒体归属 |
| 用户无法登录 | 账号为 SUSPENDED | 改为 ACTIVE |
| 能力型号审核后仍不可见 | 仅 APPROVED 未 PUBLISHED | 执行「发布」（→ PUBLISHED） |
| 内容前台不显示 | 状态为 DRAFT / REVIEW | 发布（→ PUBLISHED） |
| 供应商反馈看不到询价机会 | RFQ 状态非 OPEN | 检查 RFQ 是否已发布开放 |
