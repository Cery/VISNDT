## 产品参数体系说明

平台工业内窥镜参数体系包含以下标准字段：

| 参数代码 | 参数名称 | 数据类型 | 单位 |
|---------|---------|---------|------|
| screen_size | 主机屏幕 | STRING | — |
| probe_diameter | 管线直径 | NUMBER | mm |
| lens_pixel | 镜头像素 | NUMBER | 万像素 |
| lens_direction | 镜头视向 | ENUM | — |
| depth_of_field | 景深 | STRING | — |
| field_of_view | 视场角 | NUMBER | ° |
| light_source | 光源 | ENUM | — |
| lens_guidance | 镜头导向 | ENUM | — |
| probe_material | 管线材质 | ENUM | — |

### 枚举值说明

| 参数 | 可选值 |
|------|--------|
| 镜头视向 | 前视、侧视、双视向 |
| 光源 | LED、光纤、激光、红外 |
| 镜头导向 | 360°全方位、两方向、四方向、固定 |
| 管线材质 | 不锈钢编织、钨丝编织、聚氨酯、PVC |

## 数据录入说明

### 在 Admin 后台录入步骤

1. 登录 Admin 后台 (`http://localhost:3001`)
2. 进入「产品管理」→「产品列表」
3. 点击「创建产品」
4. 填写基本信息（品牌、型号、名称、分类）
5. 进入「参数管理」配置参数值
6. 进入「媒体管理」上传产品图片
7. 保存并发布

### 参数体系配置

在录入产品前，需要先在 Admin 后台配置参数体系：

1. 参数组管理 → 创建「工业内窥镜」参数组
2. 参数定义管理 → 创建 9 个标准参数定义
3. 参数选项管理 → 为枚举类型参数创建选项值
