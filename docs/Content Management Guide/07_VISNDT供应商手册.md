## 1. 供应商角色说明

在 VISNDT 平台中，**供应商 = 能力提供方（Capability Provider）**，不是店铺/卖家。您的职责是：

- 维护并展示您的**供应能力（Capability）**；
- 创建与管理**能力报价（Offer）**；
- 响应采购方的**询价请求（RFQ）**；
- 通过**能力型号（Supplier Product / Capability Model）**（由平台管理员治理并发布）让您的检测能力被采购方发现。

> ⚠️ 术语提醒：本平台不使用 "Store / Marketplace / 商品商城" 等概念，请勿将供应商理解为交易卖家。

### 1.1 供应商业务闭环

```
完善企业资料 → 创建报价 Offer → 查看 RFQ 机会 / 商机 → 响应 RFQ → 跟踪响应状态
  → 通过「能力展示」向采购方呈现能力
  → 通过「运行时能力」（只读）查看自身能力型号状态与买方兴趣
```

> 能力型号的录入/提交/审核/发布由平台管理员在后台「能力型号审核」统一完成。当前版本供应商无法自助创建或提交能力型号。

## 2. 注册与登录

### 2.1 注册

- 公共网站右上角「注册」；
- 填写姓名（选填）、邮箱（必填、唯一）、密码（必填），如有邀请码可填写；
- 注册成功后自动登录。

### 2.2 登录

- 公共网站右上角「登录」→ 输入邮箱与密码；
- 登录成功后，右上角下拉菜单进入「工作台」或「工作区」。

### 2.3 供应商工作区入口

进入 `/workspace` 后，系统按您的角色（`SUPPLIER`）展示供应商侧导航：

```
仪表盘 (/dashboard/supplier)
RFQ 机会 (/workspace/supplier/rfqs)
我的响应 (/workspace/supplier/responses)
我的报价 (/workspace/supplier/offers)
商机 (/workspace/supplier/opportunities)
运行时能力 (/workspace/supplier/runtime)
企业资料 (/workspace/supplier/profile)
通知中心 (/workspace/notifications)
能力展示 (/workspace/supplier/display)
```

> 若提示「当前账号未映射到可用工作区」，说明您的账号尚未具备有效的工作区身份，请联系平台管理员。

## 3. 企业资料

**入口**：左侧菜单「企业资料」（`/workspace/supplier/profile`）。

- 查看并编辑组织的**基础信息**（企业名称、类型、状态等）；
- 维护企业身份与公开资料，作为采购方了解您企业的窗口；
- 企业资料完整、准确有助于提升您的能力被采购方采纳的概率。

> 组织状态：`ACTIVE`（正常）/ `INACTIVE`（停用）/ `SUSPENDED`（暂停）。异常状态请联系平台管理员。

## 4. 供应商工作台

**入口**：`/dashboard/supplier`。

### 4.1 业务概览（六项统计卡）

| 卡片 | 说明 |
|------|------|
| 待处理 RFQ | 定向询价总数与状态分布 |
| 已提交响应 | 响应总数与状态分布 |
| 匹配机会 | 系统匹配机会数 |
| 公开 RFQ | 可参与响应的公开询价数 |
| 我的 Offer | 供应能力报价总数 |
| 未读通知 | 未读消息数 |

### 4.2 快捷操作

提供「查看 RFQ」「商机中心」「我的响应」「我的 Offer」「企业资料」「展示管理」「通知中心」快捷入口，一键直达。

### 4.3 定向询价快照

展示当前与您相关的定向 RFQ 列表（状态、创建时间、采购方组织），点击可进入详情。

### 4.4 响应跟踪

- 按「已提交 / 处理中 / 已接受」汇总您的响应状态；
- 展示最近响应记录（响应状态、关联 RFQ、关联需求、采购方组织）。

### 4.5 最近活动

展示最近的 RFQ 与响应动态，快速掌握业务进展。

## 5. 运行时能力（能力型号查看 · 只读）

**入口**：左侧菜单「运行时能力」（`/workspace/supplier/runtime`）。

这里是您的**能力型号（Supplier Product / Capability Model）**只读视图——即与您相关的、由平台治理的检测能力型号清单。**供应商自助创建/提交能力型号为未来项**，当前版本此页面仅提供查看与买方兴趣分析，**不提供创建或编辑入口**。

### 5.1 能力概览（统计卡）

| 卡片 | 说明 |
|------|------|
| 能力型号 | 与您相关的 SupplierProduct 总数 |
| 已发布 | 已发布（PUBLISHED），可供公开发现 |
| 有效 Offer | 商用层有效报价汇总 |
| 审核中 | 待平台治理确认的型号数 |

### 5.2 能力型号状态列表

支持：
- **关键字搜索**：按品牌 / 系列 / 型号 / 能力名称搜索；
- **状态筛选**：按状态过滤（草稿 / 已提交 / 审核中 / 已批准 / 已发布 / 已拒绝）；
- **系列筛选**：按系列过滤；
- **分页浏览**：翻页查看；
- 每条记录展示：品牌 + 系列 + 型号、能力锚点（关联的平台能力 Platform Product）、状态标签、商用 Offer 汇总、价格区间、创建时间。

### 5.3 能力型号状态说明

| 状态 | 代码 | 说明 |
|------|------|------|
| 草稿 | `DRAFT` | 尚未进入审核 |
| 已提交 | `SUBMITTED` | 已提交平台审核 |
| 审核中 | `REVIEWING` | 平台审核中 |
| 已批准 | `APPROVED` | 审核通过（待发布） |
| 已发布 | `PUBLISHED` | 正式发布，采购方可发现 |
| 已拒绝 | `REJECTED` | 审核被拒 |

### 5.4 买方兴趣快照

- 平台将买方 **Inquiry（询价）** 在能力层（Platform Product）聚合呈现；
- 点击型号卡片中的「查看买方兴趣」按钮，进入该能力型号的 **Inquiry 上下文**（只读列表），了解采购方对该能力的关注情况。

> 如需新增/修改能力型号，请联系平台管理员，由其在后台「能力型号审核」统一录入与治理。

## 6. 报价（Offer）管理

**入口**：左侧菜单「我的报价」（`/workspace/supplier/offers`）。

报价（Offer）是您为某平台产品提供的**供应能力报价**。

### 6.1 创建报价（/workspace/supplier/offers/new）

**操作步骤**：

1. 点击「创建报价」；
2. **选择产品**：搜索并选择要关联的平台产品（Global Catalog 产品），点击产品名即可选中；
3. 填写报价信息：

| 字段 | 必填 | 说明 |
|------|:---:|------|
| 报价标题 | ✅ | 如「高端工业相机供应方案」（选择产品后会自动带入产品名） |
| 描述 | 选填 | 供应能力、服务范围、交付方式等 |
| 价格 | 选填 | 数值，如 1999.99 |
| 货币 | 选填 | CNY（人民币）/ USD / EUR / JPY |

4. 点击「创建报价」；
5. 创建成功后自动跳转到该报价的**编辑页**，可继续完善。

**校验规则**：未选择产品或标题为空时，会提示「请选择产品并填写报价标题」。

### 6.2 报价列表与状态

**报价状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 草稿 | `DRAFT` | 已保存未提交 |
| 有效 | `ACTIVE` | 正常有效 |
| 无效 | `INACTIVE` | 已停用 |
| 已提交 | `SUBMITTED` | 已提交 |
| 已接受 | `ACCEPTED` | 采购方已接受 |
| 已拒绝 | `REJECTED` | 已拒绝 |
| 已撤回 | `WITHDRAWN` | 已撤回 |

### 6.3 编辑报价

在报价列表/创建页进入对应报价的编辑页（`/workspace/supplier/offers/[id]/edit`），修改报价信息并保存。

## 7. RFQ 机会与响应

### 7.1 查看 RFQ 机会（/workspace/supplier/rfqs）

- 展示当前**可响应的 RFQ** 列表（状态、需求标题、需求描述、发布时间、创建时间）；
- 每条 RFQ 卡片提供「查看详情」入口；
- 分页浏览。

> 页面说明：「查看当前可响应的 RFQ 列表」——用于发现询价机会并查看详情。

### 7.2 RFQ 详情与响应（/workspace/supplier/rfqs/[id]）

在 RFQ 详情页可查看：

- RFQ 状态（开放 OPEN 时才可响应）；
- 关联需求上下文（标题、描述、参数等）；
- 采购方组织信息。

**提交响应**：

1. 确认 RFQ 处于**开放（OPEN）**状态；
2. 选择您要关联的**报价（Offer）**（需属于您所在组织）；
3. 提交响应（RFQ Response）；
4. 响应提交后进入跟踪流程。

**常见提示**：

| 提示 | 含义 |
|------|------|
| 「当前 RFQ 未开放响应，请等待发布后再试」 | RFQ 非 OPEN 状态，无法响应 |
| 「所选 Offer 非法或不属于您的组织」 | 请选择本组织名下的 Offer |
| 「您不是有效组织成员，无法提交 RFQ 响应」 | 账号/组织身份异常，联系管理员 |
| 「您已对此 RFQ 提交过响应，请勿重复提交」 | 同一 RFQ 仅可提交一次响应 |

### 7.3 我的响应（/workspace/supplier/responses）

- 查看您已提交的**响应记录**（状态、关联 RFQ、关联需求、采购方组织、提交/更新时间）；
- 按状态跟踪：`SUBMITTED`（已提交）→ `VIEWED`（已查看）→ `ACCEPTED`（已接受）/ `REJECTED`（已拒绝）。

## 8. 商机中心

**入口**：左侧菜单「商机」（`/workspace/supplier/opportunities`）。

集中发现业务机会：

- **公开 RFQ 机会**：平台开放的、可参与响应的询价；
- **匹配机会**：系统基于您的能力生成的匹配机会；
- **定向询价**：直接面向您的询价。

把握商机 → 进入对应 RFQ 详情 → 提交响应。

---

## 9. 能力展示

**入口**：左侧菜单「能力展示」（`/workspace/supplier/display`）。

管理您对外**公开展示**的能力内容，包括：

- 企业身份信息；
- 产品能力展示；
- 供应管理展示。

确保展示内容完整、准确，有助于采购方更好地发现并信任您的能力。

---

## 10. 通知中心

**入口**：`/workspace/notifications`（左侧菜单「通知中心」）。

- 接收系统通知、需求更新、RFQ 更新、响应更新等消息；
- 通知分为未读 / 已读，可标记阅读；
- 工作台顶部展示未读通知数量。

> 建议及时查看通知，掌握 RFQ 机会、审核结果与响应反馈。

## 11. 常见问题

| 问题 | 解决方案 |
|------|---------|
| 无法进入工作区 | 账号未映射到有效工作区，联系平台管理员 |
| 「运行时能力」没有新建/编辑入口 | 设计如此：能力型号由平台管理员统一治理，供应商端为只读；如需新增/修改请联系管理员 |
| 能力型号状态长期为「审核中」 | 审核由平台管理员执行，请耐心等待或联系管理员 |
| 能力型号被拒绝 | 联系平台管理员了解拒绝原因并修正后重新提交 |
| 无法创建报价 | 需先选择平台能力并填写报价标题 |
| 无法响应 RFQ | 确认 RFQ 为 OPEN 状态；选择本组织名下的 Offer |
| 提示重复提交响应 | 同一 RFQ 已提交过，无法再次响应 |
| 供应商身份显示异常 | 检查企业资料与组织状态，异常时联系管理员 |
