## 1. 测试环境准备

### 1.1 前端启动

**Web 端 (Buyer):**

```bash
cd apps/web
pnpm dev
# 访问 http://localhost:3000
```

**Admin 端:**

```bash
cd apps/admin
pnpm dev
# 访问 http://localhost:3001
```

### 1.2 后端启动

```bash
cd apps/api
pnpm dev
# API 运行在默认端口
```

### 1.3 数据准备

| 数据 | 说明 |
|------|------|
| 测试账号 | 需要注册新账号或使用已有测试账号 |
| 产品数据 | 需要管理员在 Admin 后台录入产品 |
| 分类数据 | 需要管理员在 Admin 后台配置分类 |
| 参数体系 | 需要管理员在 Admin 后台配置参数 |

> ⚠️ **注意**: 如果产品数据为空，部分功能（如产品浏览、匹配）将无法完整测试。请先使用 Admin 后台录入测试数据。
