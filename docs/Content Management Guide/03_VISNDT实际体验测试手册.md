### 1.1 系统架构概览

| 服务 | 技术栈 | 端口 | 访问地址 |
|------|--------|------|---------|
| API 服务 | NestJS | 4000 | http://localhost:4000/api/v1 |
| Web 前台 | Next.js | 3000 | http://localhost:3000 |
| Admin 后台 | React (Vite) | 3001 | http://localhost:3001 |
| 数据库 | PostgreSQL | 5432 | localhost:5432 |

**认证机制**: JWT HttpOnly Cookie + CSRF Double Submit Cookie

### 1.3 Step 2: 启动 API 服务

| 项目 | 内容 |
|------|------|
| **测试目标** | 验证 NestJS API 服务正常启动 |
| **前置条件** | 数据库已启动，环境变量已配置 |

**操作步骤:**

1. 进入 API 目录并启动:
   ```bash
   cd apps/api
   pnpm dev
   ```
2. 等待控制台输出启动成功日志
3. 验证健康检查接口:
   ```bash
   curl http://localhost:4000/api/v1/health
   ```
4. 验证 API 文档（如有 Swagger）:
   ```bash
   curl http://localhost:4000/api/v1/docs -o /dev/null -w "%{http_code}"
   ```

**预期结果:**

- [ ] 控制台输出 "Nest application successfully started"
- [ ] 健康检查接口返回 200 OK
- [ ] API 日志无报错信息
- [ ] 端口 4000 未被占用

**常见问题与解决:**

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 端口 4000 被占用 | 其他进程占用 | `netstat -ano \| findstr :4000` 查看并终止进程 |
| 数据库连接失败 | 数据库未启动或配置错误 | 检查 .env 中数据库连接字符串 |
| 模块加载失败 | 依赖未安装 | 运行 `pnpm install` |
| JWT 密钥缺失 | 环境变量未配置 | 检查 .env 中 JWT_SECRET |

### 1.6 服务启动一键检查脚本

在项目根目录执行以下 PowerShell 命令进行一键验证:

```powershell
# 检查各端口占用情况
Write-Host "=== 端口检查 ===" -ForegroundColor Cyan
@(3000, 3001, 4000, 5432) | ForEach-Object {
    $conn = Get-NetTCPConnection -LocalPort $_ -ErrorAction SilentlyContinue
    if ($conn) { Write-Host "端口 $_ : 已占用 (PID: $($conn.OwningProcess))" -ForegroundColor Green }
    else { Write-Host "端口 $_ : 未占用" -ForegroundColor Red }
}

# 检查 API 健康
Write-Host "`n=== API 健康检查 ===" -ForegroundColor Cyan
try {
    $res = Invoke-WebRequest -Uri "http://localhost:4000/api/v1/health" -UseBasicParsing -TimeoutSec 5
    Write-Host "API 状态: $($res.StatusCode)" -ForegroundColor Green
} catch {
    Write-Host "API 不可达: $_" -ForegroundColor Red
}

# 检查 Web 前台
Write-Host "`n=== Web 前台检查 ===" -ForegroundColor Cyan
try {
    $res = Invoke-WebRequest -Uri "http://localhost:3000" -UseBasicParsing -TimeoutSec 5
    Write-Host "Web 状态: $($res.StatusCode)" -ForegroundColor Green
} catch {
    Write-Host "Web 不可达: $_" -ForegroundColor Red
}

# 检查 Admin 后台
Write-Host "`n=== Admin 后台检查 ===" -ForegroundColor Cyan
try {
    $res = Invoke-WebRequest -Uri "http://localhost:3001" -UseBasicParsing -TimeoutSec 5
    Write-Host "Admin 状态: $($res.StatusCode)" -ForegroundColor Green
} catch {
    Write-Host "Admin 不可达: $_" -ForegroundColor Red
}
```
