## 3. 业务闭环验证

### 3.1 产品-供应商关联模型

```
Product (标准产品) ← Offer (供应商报价) → Organization (供应商)
     ↓                                        ↓
  ProductParameterValue                  OrganizationMember
     ↓                                        ↓
  ParameterDefinition                        User (业务员)
```

### 3.2 完整业务流程

```
1. Admin 创建产品分类 (ProductCategory)
2. Admin 创建参数组 + 参数定义 (ParameterGroup → ParameterDefinition)
3. Admin 创建标准产品 (Product) + 关联参数值
4. Admin 创建供应商组织 (Organization) + 业务员用户 (User)
5. 供应商创建 Offer (关联 Product + Organization)
6. Offer 状态流转: DRAFT → ACTIVE → SUBMITTED → ACCEPTED/REJECTED
7. 买家注册 → 浏览产品 → 查看Offer → 发起询价
8. 买家发布需求 (Demand) → 系统匹配 (Match) → 创建 RFQ
```
