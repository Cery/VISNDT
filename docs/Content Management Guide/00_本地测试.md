## 本地测试需要启动的服务

需要 **4 个终端/窗口**，按顺序启动：

### 1. 数据库 + MinIO（Docker）

PowerShell



```powershell
# 在项目根目录下
cd F:\Desktop\VISNDT\VISNDT
docker compose -f docker\docker-compose.yml up -d
```

启动后验证：

PowerShell



```powershell
docker ps --filter "name=visndt"
```

应看到 `visndt-postgres` 和 `visndt-minio` 两个容器都在运行。

### 2. 后端 API（NestJS，端口 4000）

PowerShell



```powershell
cd F:\Desktop\VISNDT\VISNDT\apps\api
npm run dev
```

`apps/api/.env` 已配置好，直接启动即可。API 会自动连接 PostgreSQL 并执行 Prisma 迁移。

### 3. 前台网站（Next.js，端口 3000）

PowerShell



```powershell
cd F:\Desktop\VISNDT\VISNDT\apps\web
npm run dev
```

### 4. 后台管理（Vite + React，端口 3001）

PowerShell



```powershell
cd F:\Desktop\VISNDT\VISNDT\apps\admin
npm run dev
```

Vite 的 `vite.config.ts` 已配置 `/api` 代理到 `http://localhost:4000` ，所以 Admin 在开发时 API 请求是自动转发的，不需要额外配置 CORS。

------

### 测试地址

| 服务         | 地址                                            | 说明                           |
| :----------- | :---------------------------------------------- | :----------------------------- |
| 前台网站     | [http://localhost:3000](http://localhost:3000/) | 产品展示、需求发布等           |
| 后台管理     | [http://localhost:3001](http://localhost:3001/) | 管理员管理后台                 |
| API Swagger  | http://localhost:4000/api/v1/docs               | API 文档（如果配置了 Swagger） |
| MinIO 控制台 | [http://localhost:9001](http://localhost:9001/) | 文件存储管理                   |

### 简化启动（一次性脚本）

如果你想用一个命令启动所有服务，每个服务需要单独开一个终端窗口，因为 `npm run dev` 是前台进程。建议按顺序：**Docker → API → Web → Admin**。
