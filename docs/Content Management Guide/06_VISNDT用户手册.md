## 1. 平台简介

VISNDT 是**工业检测能力发现平台**。作为采购方（BUYER），您可以：

- 浏览平台上的工业检测**能力（Capability / Product）**目录与解决方案；
- 使用**能力搜索**发现符合需求的检测能力；
- 发布采购**需求（Demand）**；
- 查看系统基于需求参数生成的**匹配结果（Match）**；
- 基于需求发起**询价请求（RFQ）**，接收供应商响应并做出决策。

### 1.1 业务流程总览

```
发现能力（搜索/浏览）
  → 创建需求（Demand）
  → 系统确定性匹配（Match）
  → 基于需求发起 RFQ
  → 供应商响应 RFQ
  → 您决策（接受/拒绝）
  → 流程关闭
```

## 2. 注册与登录

### 2.1 注册

**入口**：公共网站右上角「注册」。

**注册表单**：

| 字段 | 必填 | 说明 |
|------|:---:|------|
| 姓名 | 选填 | 您的姓名 |
| 邮箱 | 必填 | 注册账号（需唯一） |
| 密码 | 必填 | 登录密码 |
| 邀请码 | 选填 | 如收到邀请链接/邀请码可填写 |

**操作步骤**：

1. 填写姓名（选填）、邮箱、密码；
2. 如有邀请码请填写；
3. 点击提交；
4. 注册成功后自动登录并进入工作区。

**提示**：
- 邮箱已被注册时会提示「该邮箱已注册，请使用其他邮箱或登录」；
- 操作过于频繁会触发频率限制提示，请稍后重试。

### 2.2 登录

**入口**：公共网站右上角「登录」。

1. 输入邮箱和密码；
2. 点击「登录」；
3. 登录成功后右上角显示您的头像与姓名。

**登录后下拉菜单**：可进入「工作台」（Dashboard）、「工作区」（Workspace），或「退出登录」。

### 2.3 退出登录

在右上角头像下拉中点击「退出登录」，退出后返回公共首页。

## 4. 能力搜索

### 4.1 搜索入口

- 顶栏全局搜索框（Global Search Bar）；
- 独立搜索页 `/search`（含能力发现首页 Hero 搜索）。

### 4.2 搜索内容

搜索结果为**能力发现**导向，覆盖 4 类结果：**能力（Product）**、**知识（Knowledge）**、**解决方案（Solution）**、**能力型号（Supplier Product）**，按能力相关度排序展示；可在搜索页按类型（全部 / 能力 / 知识 / 解决方案 / 能力型号）切换筛选。

> 提示：本平台搜索定位为「工业检测能力发现」，不提供商品/店铺/卖家搜索。

### 4.3 搜索增强功能

- **筛选（Filter）**：按参数/维度过滤结果；
- **分页**：结果列表分页浏览；
- **URL 状态还原**：筛选与翻页状态会同步到 URL，刷新/分享后可还原。

### 4.4 能力询价（Inquiry）

在能力详情页可提交「能力询价」，填写您的询价信息后提交，管理员/供应方会收到询价并可回复。

## 6. 我的需求

### 6.1 需求列表（/workspace/demands）

查看您创建的全部需求，含状态、标题、时间等信息，可进入详情。

**需求状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 草稿 | `DRAFT` | 已保存未发布 |
| 已发布 | `PUBLISHED` | 已发布，可进入匹配 |
| 已提交 | `SUBMITTED` | 已进入匹配流程 |
| 处理中 | `PROCESSING` | 匹配/RFQ 处理中 |
| 已关闭 | `CLOSED` | 流程已结束 |
| 已取消 | `CANCELLED` | 已取消 |

### 6.2 创建需求（/workspace/demands/create）

**操作步骤**：

1. 进入「我的需求」→「创建需求」；
2. 填写需求信息：

| 字段 | 必填 | 说明/示例 |
|------|:---:|------|
| 标题 | ✅ | 如「需要100台工业内窥镜」 |
| 描述 | 选填 | 详细描述您的需求 |
| 预算范围 | 选填 | 如「10000-50000」 |
| 数量 | 选填 | 必须为正数，如 100 |
| 单位 | 选填 | 如 pcs / sets / 台 |
| 预计交付日期 | 选填 | 选择日期 |

3. 点击「创建需求」；
4. 创建成功后返回需求列表。

**校验规则**：标题不能为空；数量必须为数字且大于 0，否则表单会提示错误。

### 6.3 需求详情 / 编辑

- 在需求列表点击某需求查看详情（基本信息、需求参数、匹配结果、关联 RFQ）；
- 草稿/可编辑状态下可修改需求信息。

## 7. 匹配结果

### 7.1 匹配列表（/workspace/matches）

查看您各需求对应的产品匹配结果。

**功能**：
- 按需求标题关键字搜索（输入后自动过滤）；
- 分页浏览；
- 查看每个匹配的匹配分数与匹配依据。

**匹配状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 待处理 | `PENDING` | 匹配完成待处理 |
| 已匹配 | `MATCHED` | 已生成匹配 |
| 已查看 | `REVIEWED` | 您已查看 |
| 已接受 | `ACCEPTED` | 您已接受 |
| 已拒绝 | `REJECTED` | 您已拒绝 |
| 已过期 | `EXPIRED` | 已过期 |

### 7.2 操作

- **更新匹配状态**：对匹配结果执行接受/拒绝等状态更新；
- **重新匹配**：对需求重新执行匹配以获取最新结果。

> 匹配由系统按「需求参数 → 产品参数 → 分数」确定性规则生成。

## 8. 我的询价请求（RFQ）

### 8.1 询价列表（/workspace/rfqs）

查看您发起的全部 RFQ 及供应商响应情况。

**RFQ 状态说明**：

| 状态 | 代码 | 说明 |
|------|------|------|
| 草稿 | `DRAFT` | 已创建未发布 |
| 开放 | `OPEN` | 已发布，供应商可响应 |
| 响应中 | `RESPONDING` | 已收到响应，处理中 |
| 已关闭 | `CLOSED` | 已关闭 |
| 已取消 | `CANCELLED` | 已取消 |

### 8.2 创建询价（/workspace/rfqs/create）

**操作步骤**：

1. 进入「我的询价请求」→「创建询价」；
2. 在需求列表中选择一个已有需求（**必须选择**，否则提示「请选择一个需求」）；
3. 点击「创建」；
4. 创建成功后返回询价列表。

> RFQ 是基于需求的询价单，请先创建需求再发起询价。

### 8.3 询价详情与决策

- 在询价详情页查看需求上下文、供应商响应列表；
- 对每条供应商响应执行**接受 / 拒绝**决策；
- 处理完成后询价进入关闭流程。

## 11. 常见问题

| 问题 | 解决方案 |
|------|---------|
| 登录后看不到工作台 | 确认账号角色为 BUYER；右上角下拉进入「工作台」 |
| 创建需求失败 | 标题必填；数量为正数 |
| 没有匹配结果 | 需求需为已发布/已提交状态；完善需求描述与参数后重新匹配 |
| 无法创建询价 | 需先创建需求；询价创建时选择需求 |
| 收不到通知 | 检查「通知中心」未读/已读；确认系统是否生成相关通知 |
| 忘记密码 | 联系平台管理员重置（当前版本） |
