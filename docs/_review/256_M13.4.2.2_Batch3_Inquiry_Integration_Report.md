## 3. API

### POST /inquiries

| 属性 | 值 |
|------|-----|
| 端点 | `POST /inquiries` |
| 认证 | Public (无需 JWT) |
| 调用链 | `InquiryForm` → `inquiry.service.ts` → `lib/api/inquiries.ts` → `apiClient` |

### Request Body (CreateInquiryDto)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `productId` | UUID | ✅ | 产品 ID |
| `offerId` | UUID | ✅ | 报价 ID |
| `organizationId` | UUID | ✅ | 接收企业 ID |
| `name` | string | ✅ | 访客姓名 (max 100) |
| `email` | email | ✅ | 访客邮箱 |
| `phone` | string | ❌ | 访客电话 (max 30) |
| `message` | string | ✅ | 咨询内容 (max 2000) |

### Response (InquiryResponse)

```typescript
{
  inquiry: {
    productId: string;
    productName: string;
    organizationId: string;
    organizationName: string;
    visitorName: string;
    visitorEmail: string;
  };
  notificationsSent: number;
}
```

### Backend Flow

```
POST /inquiries
  → 验证 Product 存在
  → 验证 Offer 存在且属于该 Product
  → 验证 Organization 匹配 Offer
  → 查找 Organization Members
  → 创建 Notification (SYSTEM type) 给所有 Members
  → 返回 InquiryResponse
```

## 4. Components

### InquiryForm

| 属性 | 值 |
|------|------|
| 类型 | Client Component |
| Props | `productId`, `productName`, `offerId`, `organizationId` |
| 状态 | Idle → Submitting → Success / Error |

**表单字段：**
- Name (required, max 100)
- Email (required, type email)
- Phone (optional, max 30)
- Message (required, max 2000, textarea)

**状态处理：**
- `idle`: 显示空表单
- `submitting`: 所有字段 disabled + spinner 按钮
- `success`: 绿色成功卡片 + "Thank you. Your inquiry has been submitted." + 重新提交按钮
- `error`: 红色错误横幅 + 错误信息

**禁止字段：**
- ❌ supplierId
- ❌ sellerId
- ❌ storeId
- ❌ Price / Stock / Cart

### InquirySection

| 属性 | 值 |
|------|------|
| 类型 | Client Component |
| Props | `productId`, `productName`, `offerId?`, `organizationId?` |

**逻辑：**
- 如果 `productId && offerId && organizationId` 全部存在 → 渲染 `InquiryForm`
- 如果缺少任一必填字段 → 显示 "Inquiry Unavailable" 提示

**当前状态：** Product Detail API 不返回 `offerId`/`organizationId`，因此显示 "Inquiry Unavailable"。Form 组件已就绪，待后端提供数据后即可激活。
