## 二、修复问题记录

### 2.1 Prisma Schema 恢复
- **问题**: `prisma db pull` 覆盖了 schema.prisma，导致 218 个 TypeScript 编译错误（camelCase → snake_case）
- **修复**: `git restore -- database/prisma/schema.prisma` + `npx prisma generate`
- **结果**: 编译错误 0

### 2.2 refresh_token 表缺失
- **问题**: RefreshToken 模型存在但数据库无对应表，导致登录 500 错误 (P2021)
- **修复**: `npx prisma migrate dev --name add_refresh_token` 创建迁移
- **结果**: 迁移成功应用，表已创建

### 2.3 API 路由前缀
- **问题**: Web 前端 `API_BASE_URL` 未包含 `/api/v1` 前缀
- **修复**: 更新 `constants.ts` 中 `API_BASE_URL` 为 `http://localhost:4000/api/v1`
- **结果**: API 请求正常
