## 2. Multi-Stage Build Architecture

```
Stage 1: deps (node:20-alpine)
  ├── corepack enable pnpm@9
  ├── pnpm install --frozen-lockfile --prod
  └── Output: production node_modules

Stage 2: prisma (node:20-alpine)
  ├── pnpm install (all deps)
  ├── pnpm db:generate
  └── Output: Prisma Client generated files

Stage 3: build (node:20-alpine)
  ├── pnpm install (all deps)
  ├── COPY Prisma Client
  ├── COPY source code
  ├── pnpm --filter @visndt/api build
  └── Output: dist/

Stage 4: production (node:20-alpine)
  ├── COPY production deps
  ├── COPY Prisma Client
  ├── COPY build output
  ├── EXPOSE 4000
  ├── HEALTHCHECK /api/v1/health
  └── CMD node apps/api/dist/main
```

---

## 3. Key Design Decisions

| 决策 | 理由 |
|------|------|
| `node:20-alpine` | 最小化镜像大小，匹配项目 `>=20.0.0` |
| `corepack enable pnpm@9` | pnpm 9 版本锁定 |
| 多阶段构建 | 分离构建依赖和运行时依赖，减小镜像 |
| `--frozen-lockfile` | 确保 CI/生产一致性 |
| `HEALTHCHECK /api/v1/health` | 容器健康监控 |
| 不包含数据库初始化 | 迁移由外部执行 (`prisma migrate deploy`) |
