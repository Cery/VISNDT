## 5. workspaceRole null行为变化

修改前：

1. `workspaceRole = null` 的已登录用户可进入 `/workspace`
2. `workspaceRole = null` 的已登录用户可进入 `/workspace/settings`
3. 页面主体仍会继续渲染，设置页还可继续显示账户编辑 UI

修改后：

1. `workspaceRole = null` 时，`RoleGuard` 在页面入口直接拒绝通过
2. `/workspace` 与 `/workspace/settings` 都不会继续渲染原页面主体
3. 未引入 `workspaceRole ?? 'BUYER'`、`workspaceRole || 'SUPPLIER'` 或任何默认角色补偿

说明：

1. 本次复用现有 `RoleGuard`，未修改其实现
2. `BUYER` 与 `SUPPLIER` 仍为允许角色
3. UI 主体对有效角色保持不变
