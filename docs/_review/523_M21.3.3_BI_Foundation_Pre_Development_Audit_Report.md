## 5. Query Architecture Decision

### 5.1 Options Analysis

| Option | Description | Pros | Cons |
|--------|-------------|------|------|
| **A: Direct Query** | Controller 直接调用 Prisma raw query | 最简单，零新增依赖 | 无封装，重复代码，无缓存 |
| **B: Analytics Query Service** | 新增 AnalyticsReadService，封装聚合查询 | 封装良好，可测试，可扩展 | 需要新增 Service + DTO |
| **C: Aggregation Tables** | 定时任务预计算聚合表 | 查询极快，适合大数据量 | 复杂度高，数据延迟，需要 Migration |

### 5.2 Recommendation: **Option B — Analytics Query Service**

**Rationale:**
1. Current data volume is small (M21.3.2 just deployed), no need for aggregation tables yet
2. AnalyticsReadService can be added within existing AnalyticsModule without new dependencies
3. Prisma's `groupBy` + `count` + `orderBy` covers all Easy/Medium queries
4. Option C (Aggregation Tables) can be deferred to M21.3.4 Data-Driven Optimization

**Proposed Module Structure:**

```
apps/api/src/analytics/
├── analytics.module.ts
├── analytics.controller.ts          — POST /events (existing)
├── analytics.service.ts             — createMany() (existing)
├── analytics-read.controller.ts     — GET /dashboard, GET /statistics (NEW)
├── analytics-read.service.ts        — Query aggregation logic (NEW)
├── dto/
│   ├── create-analytics-events.dto.ts   — Request DTO (existing)
│   ├── analytics-query.dto.ts           — Query params DTO (NEW)
│   └── analytics-response.dto.ts        — Response DTO (NEW)
```

## 9. Architecture Decision

### 9.1 Module Architecture

```
Decision: Keep single AnalyticsModule with Write + Read separation

Rationale:
  - Current module is small (3 files)
  - Write and Read share PrismaService dependency
  - Splitting into analytics-event / analytics-query is premature
  - Future: Split when module exceeds 10 files or query complexity grows
```

### 9.2 Database Architecture

```
Decision: No schema changes for M21.3.3

Rationale:
  - ConversionEvent model + 7 indexes are sufficient for BI queries
  - No aggregation tables needed at current data scale
  - No materialized views (PostgreSQL dependency)
  - No partition yet (data volume is small)
```
