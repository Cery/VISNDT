## 3. Current Workspace Capability

### 3.1 Workspace Role System

**Auth Architecture** ([auth.service.ts](file:///f:/Desktop/VISNDT/VISNDT/apps/api/src/auth/auth.service.ts#L245-L263))：

| Organization Type | WorkspaceRole |
| --- | --- |
| `SUPPLIER` / `MANUFACTURER` / `DISTRIBUTOR` | `SUPPLIER` |
| `BUYER` | `BUYER` |
| Other / null | `null` |

**Key Insight**: workspaceRole 由 `organization.type` 派生，非 OrganizationMember.role 字段。User 模型无 workspaceRole 字段。

### 3.2 Supplier Workspace API

| Endpoint | Auth | Function |
| --- | --- | --- |
| `GET /workspace/status` | JWT | Module readiness check |
| `GET /workspace/supplier/overview` | JWT + SUPPLIER | RFQ/Response/Match 统计 |
| `GET /workspace/supplier/rfqs` | JWT + SUPPLIER | 定向 RFQ 列表 |
| `GET /workspace/supplier/responses` | JWT + SUPPLIER | RFQ 响应列表 |

**Key Insight**: Workspace API 全部为 RFQ/Response 协作导向，无 Offer 管理、无 Organization Profile 管理、无 Supplier Display 配置 API。

### 3.3 Organization API

| Endpoint | Auth | Function |
| --- | --- | --- |
| `GET /organizations/:id` | Public | 读取公开信息（id/name/type/status/createdAt/updatedAt） |
| `PATCH /organizations/:id` | ADMIN | 更新 Organization |
| `GET /organizations` | ADMIN | 列表 |

**Key Insight**: `PATCH /organizations/:id` 仅 ADMIN 角色可用，Supplier 无法自助更新 Profile。

### 3.4 Offer API

| Endpoint | Auth | Function |
| --- | --- | --- |
| `GET /offers` | Public | 列表（支持 organizationId 过滤） |
| `GET /offers/:id` | Public | 详情 |
| `PATCH /offers/:id` | JWT (org-scoped) | 更新 Offer（authenticated, org-scoped） |
| `POST /offers` | JWT | 创建 Offer |

**Key Insight**: `PATCH /offers/:id` 已支持 org-scoped 更新，Supplier 可更新自有 Offer。

### 3.5 Supplier Workspace Frontend

## 5. API Capability Assessment

### 5.1 Existing API — Supplier Display Management 可用性

| API | Supplier Display Management 用途 | 是否满足 |
| --- | --- | --- |
| `GET /workspace/supplier/overview` | Supplier 工作台概览 | ✅ 可直接复用 |
| `GET /workspace/supplier/rfqs` | RFQ 管理 | ❌ 不相关 |
| `GET /workspace/supplier/responses` | Response 管理 | ❌ 不相关 |
| `GET /organizations/:id` | Profile 读取 | ✅ 读取自身 Profile |
| `GET /offers?organizationId=` | 自有 Offer 列表 | ✅ 读取自有 Offer |
| `PATCH /offers/:id` | 更新 Offer 状态/描述 | ✅ org-scoped 更新 |
| `PATCH /organizations/:id` | 更新 Profile | ❌ ADMIN only |

### 5.2 Missing API for Supplier Display Management

| 缺失 API | 说明 | 影响 |
| --- | --- | --- |
| `PATCH /organizations/:id` (Supplier self-service) | Supplier 无法自助更新 Profile | M19.2.3 仅能做只读展示 |
| `GET /workspace/supplier/offers` | 无 Supplier 自有 Offer 管理 API | 可用 `GET /offers?organizationId=` 替代 |
| Supplier Configuration API | 无 Display 配置端点 | M19.2.3 不可做配置编辑 |

### 5.3 API Decision

**结论：M19.2.3 可基于现有 API 实现「只读展示管理」，不可实现「编辑配置」**。

- ✅ 读取 Supplier Profile：`GET /organizations/:id`
- ✅ 读取自有 Offers：`GET /offers?organizationId=`
- ✅ 更新 Offer 状态/描述：`PATCH /offers/:id`
- ❌ 更新 Organization Profile：需要 ADMIN 权限
- ❌ Display 配置：无对应 API
