## 6. Authentication Review

### Auth Flow

```
Login/Register Page
    ↓
POST /auth/login or /auth/register
    ↓
Receive JWT (accessToken) + User
    ↓
localStorage: visndt_token, visndt_user
    ↓
AuthProvider Context (React Context)
    ↓
AuthGuard wraps protected routes
```

### Auth Architecture

| Component | File | Role |
|-----------|------|------|
| AuthProvider | `auth/AuthProvider.tsx` | React Context: token, user, login, logout, register, isLoading |
| AuthGuard | `auth/AuthGuard.tsx` | Route protection: redirects to /login if unauthenticated |
| RoleGuard | `auth/RoleGuard.tsx` | Role-based access (BUYER/SUPPLIER/ADMIN) — partial implementation |
| auth.ts | `lib/auth.ts` | localStorage helpers: getToken, setToken, removeToken, getCurrentUser |
| api-client.ts | `lib/api-client.ts` | Auto-injects `Authorization: Bearer {token}` |
