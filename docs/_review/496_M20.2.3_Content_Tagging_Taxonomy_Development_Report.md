## 2. Schema Change Summary

### 2.1 New Enum: ContentTagType

```prisma
enum ContentTagType {
  TOPIC
  INDUSTRY
  APPLICATION
  TECHNOLOGY
}
```

Four types only, no `OTHER`/`MISC`/`CUSTOM` — per design freeze.

### 2.2 New Model: ContentTag

| Field | Type | Constraint |
|-------|------|------------|
| `id` | UUID | PK, @default(uuid()) |
| `name` | String | NOT NULL |
| `slug` | String | @unique, NOT NULL |
| `type` | ContentTagType | NOT NULL |
| `description` | String? | nullable |
| `createdAt` | DateTime | @default(now()) |
| `updatedAt` | DateTime | @updatedAt |

Mapped to `content_tag` table.

### 2.3 New Model: ContentTagRelation

| Field | Type | Constraint |
|-------|------|------------|
| `id` | UUID | PK, @default(uuid()) |
| `contentId` | UUID | FK → Content, onDelete: Cascade |
| `tagId` | UUID | FK → ContentTag, onDelete: Cascade |
| `createdAt` | DateTime | @default(now()) |

Indexes: `@@unique([contentId, tagId])`, `@@index([tagId])`, `@@index([contentId])`

Mapped to `content_tag_relation` table.

### 2.4 Content Model Extension

Added reverse relation:
```prisma
tags ContentTagRelation[]
```

No other Content model fields changed.

## 5. API Verification

### 5.1 Tag CRUD (Admin)

- `POST /content/tags` — create tag with name/slug/type/description
- `PATCH /content/tags/:id` — update tag, slug uniqueness check
- `DELETE /content/tags/:id` — delete tag (cascade removes relations)

### 5.2 Content Tag Assignment (Admin)

- `POST /content/:id/tags` — upsert tag relation (idempotent)
- `DELETE /content/:id/tags/:tagId` — remove relation
- `GET /content/:id/tags` — list tags with tag details

### 5.3 Public Query

- `GET /content/tags` — returns all tags
- `GET /content/tags/:slug` — returns single tag by slug

### 5.4 Content Filter

- `GET /content/public?tag={slug}` — filter content by tag
- `GET /content/public?keyword=test&tag=test` — combined filter
- `GET /content/public?type=KNOWLEDGE&tag=test` — type + tag filter
