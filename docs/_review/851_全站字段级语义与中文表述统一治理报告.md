## 1. 目标与边界

治理目标：实现 **内部领域值（Internal Domain Value ≠ 用户可见标签 User-facing Label）** 的分离，统一全站（Web 用户端、Admin 后台、Workspace、Search、Detail、Filter、Table、Form、Dialog、Toast、Status、Role、Enum、SEO、Metadata）的中文表述，使其自然、专业、符合工业检测业务理解。

**核心原则（已固化）**
- 禁止向用户暴露内部英文枚举（`ACTIVE` / `PENDING` / `SUPPLIER` / `SUPPLIER_PRODUCT` 等）。
- Supplier 语义：`organization.type ∈ {ADMIN, SUPPLIER}`，无制造/贸易细分量 → **一律「供应商」**，不臆断为「制造商」。
- fallback 型展示不得回退到英文原值，应回退到中文占位（「未知状态」「未知类型」等）。

边界：本次为**展示层语义治理**，不修改数据库 Schema、API、权限、业务逻辑。
