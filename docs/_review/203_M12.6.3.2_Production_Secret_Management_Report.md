## 3. Security Impact

### JWT_SECRET

| Before | After |
|--------|-------|
| `JWT_SECRET:-visndt-smoke-test-jwt-secret-2026` | `JWT_SECRET` (no fallback) |
| 🔴 若未设置环境变量，使用已知 smoke-test 值 | 🟢 若未设置，Docker 启动失败 |
| Any JWT can be forged with known secret | JWT only valid with user-provided secret |

### POSTGRES_PASSWORD

| Before | After |
|--------|-------|
| `POSTGRES_PASSWORD:-visndt_dev` | `POSTGRES_PASSWORD` (no fallback) |
| 🔴 若未设置环境变量，使用开发密码 `visndt_dev` | 🟢 若未设置，Docker 启动失败 |
| Database accessible with known dev password | Database only accessible with user-provided password |

### Fail-Fast Design

修改后，若部署时未设置 `JWT_SECRET` 或 `POSTGRES_PASSWORD` 环境变量，`docker compose up` 将直接失败并报错，而非静默使用默认值。这是生产环境的最佳实践。

## 4. Configuration Changes

### Before (docker-compose.yml)

```yaml
# PostgreSQL
environment:
  POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-visndt_dev}   # ← 硬编码默认值

# API
environment:
  DATABASE_URL: postgresql://...:${POSTGRES_PASSWORD:-visndt_dev}@...  # ← 连锁引用
  JWT_SECRET: ${JWT_SECRET:-visndt-smoke-test-jwt-secret-2026}         # ← 硬编码 smoke-test
```

### After (docker-compose.yml)

```yaml
# PostgreSQL
environment:
  POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}   # ← 无默认值，必须由环境变量提供

# API
environment:
  DATABASE_URL: postgresql://...:${POSTGRES_PASSWORD}@...  # ← 引用环境变量
  JWT_SECRET: ${JWT_SECRET}                                 # ← 无默认值，必须由环境变量提供
```

### After (.env.example)

```env
# --- Docker Deployment Secrets (REQUIRED for production) ---
# Generate with: openssl rand -hex 32
POSTGRES_PASSWORD=<generate-production-password>

# --- Authentication (JWT) ---
# Generate with: openssl rand -hex 64
JWT_SECRET=<generate-production-jwt-secret>
```
