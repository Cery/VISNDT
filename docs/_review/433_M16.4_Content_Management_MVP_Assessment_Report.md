## 4. MVP Scope Definition (为 M17 准备的实现范围)

依据 `CONTENT_MANAGEMENT_PLAN.md` Phase 1，内容管理 M17 的最小闭环应包含：

| 层次 | 最小范围 |
| --- | --- |
| 数据模型 | `Knowledge` / `Article`（含 slug、状态）+ `SeoMetadata`（可并入 Article 或独立） |
| 后端 API | 内容列表 / 详情 / 发布 / 下线；SEO metadata 管理 |
| Admin 后台 | 内容管理入口 + 文章/知识中心列表/详情/编辑 |
| Web 前台 | `/knowledge/[slug]`、`/solutions/[slug]` 详情页 + 动态 SEO metadata |
| 发布流 | 内容状态（DRAFT/PUBLISHED）与审核流（可复用 M15 WorkflowEvent 基础） |

明确**不纳入** M17 首版：参数解释(Parameter Explanation)、Insight 内容体系、内容搜索/标签体系、运营看板与质量指标。
