## 3. Event Tracking Foundation Assessment

### 3.1 Three-Layer Event Architecture

| Layer | Source | Persistence | Coverage |
|-------|--------|-------------|----------|
| **L1: Frontend Conversion** | 519 Conversion Events | **None**（console.log only） | 5 events: page_view, product_view, cta_click, inquiry_start, inquiry_submit |
| **L2: Business Workflow** | WorkflowEvent | PostgreSQL | 9 actions: CREATED→SUBMITTED→OPENED→RESPONDED→ACCEPTED→REJECTED→CLOSED→WITHDRAWN→REVIEWED |
| **L3: Data Audit** | AuditLog | PostgreSQL | 5 actions: CREATE→UPDATE→DELETE→STATUS_CHANGE→LOGIN |

### 3.2 Event Coverage Analysis

| Event | L1 Frontend | L2 Workflow | L3 Audit | 完整度 |
|-------|:-----------:|:-----------:|:--------:|:------:|
| 页面访问 | page_view | — | — | 前端 Only |
| 产品查看 | product_view | — | — | 前端 Only |
| CTA 点击 | cta_click | — | — | 前端 Only |
| 咨询开始 | inquiry_start | — | — | 前端 Only |
| 咨询提交 | inquiry_submit | CREATED | CREATE | 前后端双覆盖 |
| 需求创建 | — | CREATED | CREATE | 后端双覆盖 |
| 需求匹配 | — | — | — | **缺失** |
| RFQ 发送 | — | SUBMITTED | CREATE | 后端双覆盖 |
| RFQ 响应 | — | RESPONDED | CREATE | 后端双覆盖 |

### 3.3 Key Gap

**L1 Frontend Events 无持久化存储**。519 建立的 5 个 Conversion Event 仅在 dev 环境 console.log 输出，生产环境无数据落地。这是 M21.3 首要解决的基础设施问题。

### 4.3 M21.3.2 Analytics Event Persistence（Detail）

**核心问题**: 519 建立的 5 个 Conversion Event 无持久化存储。

**建议方案**:

```typescript
// 新增 Model: ConversionEvent
model ConversionEvent {
  id        String   @id @default(uuid()) @db.Uuid
  event     String   // page_view | product_view | cta_click | inquiry_start | inquiry_submit
  source    String?  // 触发来源
  targetId  String?  // 目标实体 ID
  metadata  Json?    @db.JsonB
  sessionId String?  // 会话标识
  userId    String?  @db.Uuid
  createdAt DateTime @default(now())
}
```

**禁止**: 接入 Google Analytics、Mixpanel、Amplitude 等第三方服务（M21.3 阶段仅自建）。
