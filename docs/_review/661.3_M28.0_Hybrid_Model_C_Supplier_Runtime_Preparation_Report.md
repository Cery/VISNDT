## 4. Runtime Boundary Verification

**Supplier Runtime** 在本任务中定义为：

> **Supplier Capability Operation Boundary**（供应商能力操作边界）

Supplier Runtime **不是**：

- ❌ Supplier Store
- ❌ Marketplace
- ❌ Seller Center

Supplier Runtime **仅负责**：

- 查看自身 SupplierProduct
- 查看 Buyer Interest
- 查看 Inquiry Context
- 准备商业响应入口

Supplier Runtime **不负责**：

- ❌ 订单处理
- ❌ 支付
- ❌ 合同
- ❌ 库存、物流、交易闭环

本任务实现符合上述边界：前端展示 Supplier Capability Overview、Supplier Product Status、Buyer Interest Snapshot；后端仅提供只读聚合查询，无任何订单/支付/合同/库存功能。

**Permission Boundary**：`Role.ADMIN → Governance` 保持原有。新增 `Role.SUPPLIER` 仅作为 Supplier Runtime 标记，未扩大任何现有权限范围（未在任何管理/治理端点放宽 `@Roles(Role.ADMIN)` 约束）。
