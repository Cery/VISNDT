## 3. Media Status Presentation Contract

建立 `MediaStatusPresentationContract`（`packages/design-system/src/media/media-presentation.ts`），参考 642 `StatusPresentationContract`。

### 3.1 Contract Output

```typescript
type MediaStatusPresentation = {
  label: string;        // UI 展示标签
  tone: SemanticTone;   // 语义色调（复用 640）
  description: string;  // 状态说明
  governanceHint: string; // 治理提示
}
```

### 3.2 Governance State 映射

| 情况 | UI Governance State | tone | governanceHint |
| --- | --- | --- | --- |
| 已被产品/内容引用 | **Active** 正常引用 | success | 无需处理 |
| 未被任何对象引用 | **Unused** 未引用 | warning | 建议确认无引用后清理或补挂引用 |
| 文件元信息不完整 | **Incomplete** 缺少信息 | info | 建议补充文件信息以提升可管理性 |
| 已归档/逻辑删除 | **Legacy** 历史资源 | neutral | 仅归档可见，可评估归档迁移或清理 |

- **Important Boundary**：以上为 **UI Governance State**，**不是 Database Enum**。
- `deriveMediaGovernanceState(input)` 仅由既有字段状态确定性派生：
  1. `status === 'ARCHIVED' || deletedAt` → `legacy`
  2. 元信息不完整（`!fileName || !mimeType || !fileSize`）→ `incomplete`
  3. `productRefCount + contentRefCount === 0` → `unused`
  4. 否则 → `active`
- 语义色调复用 640 `SemanticTone`，**未新增颜色体系、未写库**。
