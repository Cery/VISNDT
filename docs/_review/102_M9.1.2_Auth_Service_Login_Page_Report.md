## 4. Login Flow Architecture

### 4.1 Flow Diagram

```
Login Page
  └── useAuth().login(email, password)
        └── auth.service.ts: login()
              └── apiClient.post('/auth/login', { email, password })
                    └── Backend: POST /api/v1/auth/login
                          └── Response: { success, data: { accessToken, user } }
        └── authStore.setAuth(accessToken, user)
              └── accessToken: "<jwt>"
              └── user: AuthUser
              └── isAuthenticated: true
  └── navigate('/home')
```

### 4.2 Auth Service (`src/auth/auth.service.ts`)

```typescript
// login(): calls backend, stores token + user in authStore
export async function login(email: string, password: string): Promise<void>

// logout(): clears authStore
export function logout(): void
```

**Backend Response Mapping:**

| Backend Field | Frontend Field | Mapping |
|---------------|---------------|---------|
| `data.accessToken` | `accessToken` | Direct |
| `data.user.id` | `user.id` | Direct |
| `data.user.email` | `user.email` | Direct |
| `data.user.name` | `user.name` | `null → undefined` |
| (not returned) | `user.role` | Default `'ADMIN'` |
| `data.user.organizationId` | `user.organizationId` | `null → undefined` |

### 4.3 useAuth Hook (`src/hooks/useAuth.ts`)

```typescript
function useAuth() {
  return {
    user: AuthUser | null,
    accessToken: string | null,
    isAuthenticated: boolean,
    login: (email: string, password: string) => Promise<void>,
    logout: () => void,
  };
}
```

## 7. State Management Impact

### 7.1 Auth Store State Transitions

```
Initial:  { accessToken: null, user: null, isAuthenticated: false }
  │
  ├── login() success → setAuth(token, user)
  │     { accessToken: "<jwt>", user: {...}, isAuthenticated: true }
  │
  └── logout() → clearAuth()
        { accessToken: null, user: null, isAuthenticated: false }
```

### 7.2 Store Usage

| Store | Consumer | Method |
|-------|----------|--------|
| `authStore` | `auth.service.ts` | `getState().setAuth()` / `getState().clearAuth()` |
| `authStore` | `useAuth.ts` | `useStore(authStore)` — reactive |
