## 4. 权限流程图

```
Client Request
     │
     ▼
┌─────────────────┐
│  JwtAuthGuard    │  ← 身份认证（Passport JWT Strategy）
│  Bearer Token?   │
└────────┬────────┘
         │ ✅ Valid Token
         ▼
  request.user = { id, email, name, organizationId }
         │
         ▼
┌─────────────────┐
│  RolesGuard      │  ← 权限控制
│  @Roles()?       │
└────────┬────────┘
         │
    ┌────┴────┐
    │         │
  No @Roles  Has @Roles(Role.ADMIN)
    │         │
    ▼         ▼
  PASS    ┌──────────────────────┐
          │ Query OrganizationMember │
          │ WHERE orgId + userId      │
          └──────────┬───────────────┘
                     │
              ┌──────┴──────┐
              │             │
          role=ADMIN    role=MEMBER
              │             │
              ▼             ▼
           200 OK      403 Forbidden
```

## 5. API 测试验证
