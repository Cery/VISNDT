## 3. clearCookie Fix

### Before (M13.5.1)

```typescript
private clearAuthCookies(res: Response) {
  res.clearCookie('access_token', { path: '/' });
  res.clearCookie('refresh_token', { path: '/' });
}
```

**Issue:** Missing `httpOnly`, `secure`, `sameSite` attributes. Browser may not match the cookie to clear.

### After (M13.5.2.2)

```typescript
private clearAuthCookies(res: Response) {
  const isProduction = this.configService.get<string>('NODE_ENV') === 'production';

  const cookieOptions = {
    httpOnly: true,
    secure: isProduction,
    sameSite: 'lax' as const,
    path: '/',
  };

  res.clearCookie('access_token', cookieOptions);
  res.clearCookie('refresh_token', cookieOptions);
}
```

### Attribute Match Verification

| Attribute | setCookie | clearCookie | Match |
|-----------|-----------|-------------|-------|
| `httpOnly` | `true` | `true` | ✅ |
| `secure` | `isProduction` | `isProduction` | ✅ |
| `sameSite` | `'lax'` | `'lax'` | ✅ |
| `path` | `'/'` | `'/'` | ✅ |

**Fix verified:** ✅ All attributes now match between `setCookie` and `clearCookie`.

## 5. CSRF Implementation

### 5.1 Architecture: Double Submit Cookie Pattern

```
┌──────────────────────────────────────────────────────────────┐
│                   CSRF DOUBLE SUBMIT PATTERN                   │
├──────────────────────────────────────────────────────────────┤
│                                                               │
│  1. GET /auth/csrf                                            │
│     ┌──────────┐                                              │
│     │  Browser  │ ──── GET /auth/csrf ────▶ ┌──────────────┐ │
│     └──────────┘                            │   Backend     │ │
│          │                                  │               │ │
│          │  Response: { csrfToken: "xxx" }  │  generateToken()│
│          │  Set-Cookie: csrf_token=xxx       │  crypto.randomBytes(32)│
│          │◀─────────────────────────────────│               │ │
│          │                                  └──────────────┘ │
│          ▼                                                    │
│  2. POST /rfq                                                 │
│     ┌──────────┐                                              │
│     │  Browser  │ ──── POST /rfq ───▶ ┌──────────────┐       │
│     │          │     Header:           │   Backend     │       │
│     │          │     X-CSRF-Token: xxx │               │       │
│     │          │     Cookie:           │  verifyToken()│       │
│     │          │     csrf_token=xxx    │  timingSafeEqual│     │
│     └──────────┘                      └──────────────┘       │
│                                                               │
│  ✅ No session required                                       │
│  ✅ crypto.randomBytes() for token generation                  │
│  ✅ crypto.timingSafeEqual() for comparison                    │
└──────────────────────────────────────────────────────────────┘
```

### 5.2 File Structure

```
apps/api/src/common/security/
├── csrf/
│   ├── csrf.module.ts       # NestJS module

```

### 5.3 CsrfService

| Method | Algorithm | Purpose |
|--------|-----------|---------|
| `generateToken()` | `crypto.randomBytes(32)` → hex | Generate 64-char hex token |
| `hashToken()` | `crypto.createHash('sha256')` | Hash for storage (unused) |
| `verifyToken()` | `crypto.timingSafeEqual()` | Timing-safe comparison |

### 5.4 CSRF Middleware Whitelist

| Method | Path | CSRF Check | Reason |
|--------|------|-----------|--------|
| POST | `/api/v1/auth/login` | ❌ Skipped | Sets auth cookies |
| POST | `/api/v1/auth/register` | ❌ Skipped | Sets auth cookies |
| POST | `/api/v1/auth/refresh` | ❌ Skipped | Sets auth cookies |
| POST | `/api/v1/auth/csrf` | ❌ Skipped | GET method |
| GET, HEAD, OPTIONS | `*` | ❌ Skipped | Safe methods |
| POST, PUT, PATCH, DELETE | `*` (all others) | ✅ Validated | State-changing |

### 5.5 csrf_token Cookie

| Attribute | Value | Reason |
|-----------|-------|--------|
| `httpOnly` | `false` | Frontend must read token for X-CSRF-Token header |
| `secure` | `isProduction` | HTTPS only in production |
| `sameSite` | `lax` | CSRF protection |
| `path` | `/` | Global scope |

### 5.6 Middleware Registration Order

```
main.ts bootstrap():
  helmet()           ← Security headers
  cookieParser()     ← Parse cookies
  CSRF middleware    ← Validate CSRF tokens
  GlobalPrefix       ← /api/v1
  CORS               ← Origin validation
  ValidationPipe     ← DTO validation
  Routes             ← Controller handlers
```
