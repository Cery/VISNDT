## 4. Fixed Issues

### Issue C: 401 Interceptor Caught Login API Errors

**Problem:**
The 401 response interceptor in `api/client.ts` treated ALL 401 responses identically — clearing auth and redirecting to `/login`. When the login form submitted invalid credentials, the backend returned 401, but the interceptor redirected the page before the Login component could show the error message.

**Root Cause:**
```typescript
// BEFORE (bug): all 401s trigger redirect
if (error.response?.status === 401) {
  authStore.getState().clearAuth();
  window.location.href = '/login';  // kills Login page error display
}
```

**Fix:**
Exclude `/auth/login` endpoint from 401 redirect handling:

```typescript
// AFTER: login endpoint 401s are passed through to caller
if (error.response?.status === 401) {
  const isLoginRequest = error.config?.url === '/auth/login';
  if (!isLoginRequest) {
    authStore.getState().clearAuth();
    window.location.href = '/login';
  }
}
```

**Impact:**
- Login page now correctly displays "Invalid email or password" error
- All other 401 responses (expired token, unauthorized API access) still trigger auto-logout
- No change to backend, no new dependencies

## 6. Login Flow Verification

```
1. User visits /products (unauthenticated)
   → RequireAuth: isAuthenticated=false
   → Navigate to /login (state.from = "/products")

2. User submits login form
   → useAuth().login(email, password)
   → auth.service.ts: apiClient.post('/auth/login', ...)
   → Request interceptor: (no token, skip)
   → Backend returns 200: { accessToken, user }
   → Response interceptor: unwrap response.data
   → authStore.setAuth(token, user)
   → Login page: navigate(state.from ?? '/home')
   → User arrives at /products ✓

3. User submits wrong credentials
   → Backend returns 401
   → Response interceptor: isLoginRequest=true → skip redirect
   → Promise.reject(error) → Login page catch block
   → Alert "Invalid email or password" ✓

4. Token expires, user navigates
   → API returns 401
   → Response interceptor: isLoginRequest=false → clearAuth() + redirect
   → window.location.href = '/login' ✓
```
