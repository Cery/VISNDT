# 6. GET /search Filter Contract

`UnifiedSearchDto` 新增两个可选字段（[unified-search.dto.ts](f:/Desktop/VISNDT/VISNDT/apps/api/src/search/dto/unified-search.dto.ts)）：

| 字段 | 语义 |
|-|-|
| `category` | 选中分类 `ProductCategory.id`（= `selectedCategoryTab`） |
| `filters` | 参数筛选 wire format：`parameterId:value1,value2;parameterId2:value3` |

`filters` 语义：同一 `parameterId` 多值 = OR；不同 `parameterId` = AND（服务端处理）。

- `category` 缺省 → 不施加分类过滤
- `filters` 缺省 → 不施加参数过滤（与修改前语义完全兼容，回归通过）

# 7. Backend Filter Implementation

[search.service.ts](f:/Desktop/VISNDT/VISNDT/apps/api/src/search/search.service.ts)：

| 能力 | 实现 |
|-|-|
| `parseFilters(raw)` | 解析 `parameterId:val1,val2;...` → `ProductFilter[]` |
| 同一参数 OR | `parameterValues.some({ parameterDefinitionId, value: { in: values } })` |
| 不同参数 AND | 所有 filter 作为 `where.AND` 数组元素 |
| Category 过滤 | `where.categoryId = category` |
| Filter-before-Pagination | filter 并入同一 `where`，`findMany(skip/take)` 与 `count(where)` 同源，分页基于过滤后候选集 |

产品结果 DTO 保持轻量（`id/name/model/slug/description/category`），不强制返回全部 `ProductParameterValue`。

**Backend Filtering: PASS（服务端筛选，非前端当前页过滤）**
