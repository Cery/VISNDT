### 4.2 PageState Pattern

All three pages implement the PageState discriminated union pattern:

- **ParameterGroupList**: `{loading} | {error; message} | {empty} | {success; data; total}`
- **ParameterGroupCreate**: `{idle} | {submitting} | {error; message}`
- **ParameterGroupEdit**: `{loading} | {error; message} | {ready} | {submitting}`

### 4.3 Route Structure

```
/parameter-groups          → ParameterGroupList   (RequireAuth → AdminLayout)
/parameter-groups/create   → ParameterGroupCreate  (RequireAuth → AdminLayout)
/parameter-groups/:id/edit → ParameterGroupEdit    (RequireAuth → AdminLayout)
```

Create route is placed before `:id/edit` to avoid dynamic parameter conflict.
