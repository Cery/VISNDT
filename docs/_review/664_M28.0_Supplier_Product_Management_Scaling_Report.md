## 3. P2-A Supplier Runtime Scaling

- **唯一入口保持**：`GET /workspace/supplier/runtime/products`（未新增 Pool API，未建新 domain）。
- **契约扩展**：可选 query 参数 `page`（1-based）、`pageSize`（默认 20）、`q`（统一搜索串）、`status`（多值 in 过滤）、`series`（contains 过滤）；响应 DTO 增加 `data/total/page/pageSize`。
- **实现**：`workspace.service.ts getSupplierProducts` 以 `skip/take + count` 分页；`q` 对 brand/series/modelNumber/capability 名称模糊检索；`status` 多值过滤；`series` contains 过滤；全部保持既有 `organizationId` 归属边界。状态模型六档（DRAFT/SUBMITTED/REVIEWING/APPROVED/PUBLISHED/REJECTED）未改。
- **运行时实测**：
  - `page=1&pageSize=5` → items=5、total=11；`page=2&pageSize=5` → items=5、page=2；`page=3&pageSize=5` → items=1、total=11（分页切页正确）。
  - `status=PUBLISHED` → total=2、allPublished=true。
  - `q=3DSC` → total=2、matched=true。
  - `series=精密扫描系列` → total=2、allMatch=true。
  - `status=PUBLISHED&series=精密扫描系列` → total=1、allMatch=true。
  - `pageSize=100` 全量取回正常。
