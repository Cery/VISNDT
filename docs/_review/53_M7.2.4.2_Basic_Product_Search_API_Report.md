## 4. Search Logic

### Keyword Search
- 使用 Prisma `contains` 操作符，对 `name`、`model`、`description` 三个字段执行 OR 查询
- 与其它过滤条件（categoryId、status）通过 AND 组合

```typescript
where: {
  AND: [
    { OR: [{ name: { contains: keyword } }, { model: { contains: keyword } }, { description: { contains: keyword } }] },
    // categoryId + status
  ]
}
```

### Category Filter
- 直接使用 `where.categoryId` 精确匹配

### Status Filter
- 直接使用 `where.status` 精确匹配

### Sort
- 白名单机制：`ALLOWED_SORT_FIELDS = new Set(['createdAt', 'updatedAt', 'name'])`
- 非法字段自动回退为 `createdAt desc`
- 使用 Prisma `orderBy` 实现

### Pagination
- 保持现有 offset pagination
- 使用 `page`/`pageSize`/`skip`/`take`
- 返回 `{ data, total, page, pageSize, totalPages }`
