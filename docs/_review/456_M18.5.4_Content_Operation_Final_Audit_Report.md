## 3. Content Architecture Audit
- **Content 实体** ✅：`type` / `title` / `slug(unique)` / `summary` / `content` / `coverImageId` / `status(DRAFT|REVIEW|PUBLISHED|ARCHIVED)` / `authorId` / `publishedAt?` / `archivedAt?` / `scheduledPublishAt?` / `seoTitle?` / `seoDescription?` / `seoKeywords?`，字段完整且与文档一致。
- **WorkflowEvent（职责：Business Timeline）** ✅：`entityType=CONTENT`、`action ∈ {CREATED, SUBMITTED, REVIEWED, OPENED, CLOSED}`、`metadata` 仅含 `{to, scheduled, scheduledAt}`；**不保存内容快照、不保存 oldValue/newValue、不替代 AuditLog**。`WorkflowEventsService.create()` 对 CONTENT 豁免 `organizationId` 校验（M18.4.1），`emitEvent()` 无静默吞错（失败即上抛）。
- **AuditLog（职责：System Audit）** ✅：`CREATE`（newValue 含 auditPayload）、`UPDATE`（oldValue/newValue 含 title/status/seo/coverImageId）、`STATUS_CHANGE`（oldValue/newValue 含 status + scheduled 标记），含 `operatorId`/`action`/`oldValue`/`newValue`；**不作为 Timeline 数据来源**（Timeline 仅来自 WorkflowEvent.findContentTimeline）。
- **ContentRevision（职责：Content Snapshot History）** ✅：保存 `title/summary/content/seoTitle/seoDescription/seoKeywords/coverImageId`（`revisionPayload` 显式投影）；**不保存 workflow 状态、不保存 approval timeline**；`contentId` 1:N + `onDelete: Cascade` + `version = max(version)+1` 策略（create→v1，update→v(n+1)）；快照写入失败会使 Content 变更回滚（数据完整性优先）。
- **边界结论** ✅：三层职责无混用，完全符合 448 冻结设计。

## 5. Workflow Reliability Audit
- **Lifecycle** ✅：Create（DRAFT 内容 + Revision v1 原子事务 → `emitEvent(CREATED)` → AuditLog CREATE）；Update（仅 DRAFT/REVIEW → Revision v(n+1) 原子事务 → AuditLog UPDATE）；Transition（`updateMany where {id, status: from}` 原子条件更新保证幂等 → `emitEvent` → AuditLog STATUS_CHANGE）。
- **Revision** ✅：版本快照 v1/v(n+1) 策略正确，快照字段与业务/审计隔离。
- **Scheduler** ✅：`ContentSchedulerService`——仅扫描 `status=REVIEW AND scheduledPublishAt<=now()`；`running` 标志防重入；复用 `ContentService.publish()`（不复制逻辑）；`updateMany` 原子条件更新保证并发/重复 tick 仅一次 OPENED + 一次 STATUS_CHANGE（**无重复发布风险**）；单条失败 catch 记录日志、不阻塞其他、下轮重试、不修改 scheduledPublishAt；发布成功自动清空 `scheduledPublishAt`；`ensureSystemUser()` 幂等创建 `system@visndt.com` 系统身份保量可追踪。
- **Timeline** ✅：`WorkflowEventsService.findContentTimeline(contentId)`——`entityType=CONTENT`、`entityId=contentId`、`createdAt asc`，投影 `id/action/operator(id,name)/metadata/createdAt`，仅来自 WorkflowEvent。
