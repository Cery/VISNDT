## 4. Search Domain Analysis

### 4.1 Search Positioning

VISNDT Search 定位为 **Industrial Inspection Capability Discovery（工业检测能力发现）**，不等于普通电商搜索。

**禁止定位**：
- ❌ 商品商城搜索
- ❌ 店铺搜索
- ❌ 卖家搜索

**正确定位**：
- ✅ 工业检测设备发现
- ✅ 供应商能力发现
- ✅ 工业内容检索
- ✅ 需求匹配撮合

---

### 4.2 Product Search (A)

**目标**：寻找检测设备。

**数据来源**：Product / ProductCategory / ProductParameter

**现有能力**：

| Dimension | Capability | Status |
|-----------|-----------|--------|
| Keyword Search | name, model, description (contains) | ✅ Existing |
| Category Filter | categoryId | ✅ Existing |
| Parameter Filter | parameterFilters (AND logic, exact match or numeric range, NUMBER/ENUM/STRING/BOOLEAN) | ✅ Existing |
| Sort | createdAt, updatedAt, name (asc/desc) | ✅ Existing |
| Pagination | page, pageSize (max 100) | ✅ Existing |
| Product Detail Navigation | `/products/[slug]` | ✅ Existing |

**Backend API**: `GET /products` (`SearchProductDto` — keyword, categoryId, status, parameterFilters, sortBy, sortOrder, page, pageSize)

**Frontend**: `/products` page — SearchBar + ProductFilter (categories + ParameterFilterPanel + sort) + ProductGrid (result count + empty state) + Pagination

**Assessment**: **Capability = Existing**. M19.3 only needs UX enhancement (search suggestions, keyword highlighting, filter state persistence, URL sync, loading skeleton).

---

### 4.3 Supplier Capability Search (B)

**目标**：寻找供应能力。

**数据来源**：Offer / Organization / Supplier Public Profile

**约束**：Supplier = Capability Provider（禁止 Supplier Store Search）

**现有能力**：

| Dimension | Capability | Status |
|-----------|-----------|--------|
| Organization Lookup | GET /organizations/:id (public, name/type/status) | ✅ Existing |
| Offer Search | GET /offers?organizationId=&keyword= (title/description) | ✅ Existing |
| Supplier Public Profile | `/suppliers/[id]` (SupplierPublicProfile + SupplierOfferList) | ✅ Existing |
| Supplier Discovery | Only via Product Detail → Supplier Public Profile | ⚠️ Partial |
| Supplier Listing Page | None | ❌ Missing |

**Assessment**: **Capability = Partial**. No supplier listing/search page. Supplier discovery is indirect (Product Detail → ManufacturerInfo/SupplierCapabilityList → /suppliers/[id]). M19.3 can add Supplier Discovery Entry (product search page supplier entry + `/suppliers` listing page).

## 9. Search Engine Decision

| Option | Decision | Rationale |
|--------|----------|-----------|
| Elasticsearch | ❌ Not Adopted | Over-engineering for current data scale |
| Algolia | ❌ Not Adopted | External dependency, cost |
| Meilisearch | ❌ Not Adopted | Additional infrastructure |
| **Database Query** | ✅ **Adopted** | Current data scale sufficient; `GET /products` already supports keyword + category + parameterFilters + sort + pagination |

**Decision**: **Database Query First** — Introduce search engine only when data scale justifies it (M20+ evaluation).
