## 5. API Impact

### 5.1 Rate Limit Policy

| Endpoint | Method | Limit | TTL | Reason |
|----------|--------|-------|-----|--------|
| `/auth/login` | POST | 5 | 60s | 防暴力破解 |
| `/auth/register` | POST | 5 | 60s | 防接口滥用 |
| `/auth/invitations` | POST | 20 | 60s | Admin only |
| `/demands/:id/rematch` | POST | 10 | 60s | 计算资源消耗 |
| `/workflow-events` | POST | 60 | 60s | 一般写入 |
| ALL other | * | 100 | 60s | Global default |

### 5.2 Error Response

限流触发时返回:
```
HTTP 429 Too Many Requests
```

### 5.3 Response Format

API Response 格式不变。`ApiResponse.ok()` 不受影响。

## 6. Code Refactor

### Before (AppModule)

```typescript
@Module({
  imports: [
    ConfigModule.forRoot({ isGlobal: true }),
    PrismaModule,
    ...
  ],
})
```

### After (AppModule)

```typescript
@Module({
  imports: [
    ConfigModule.forRoot({ isGlobal: true }),
    ThrottlerModule.forRoot([{ ttl: 60000, limit: 100 }]),
    PrismaModule,
    ...
  ],
  providers: [
    { provide: APP_GUARD, useClass: ThrottlerGuard },
  ],
})
```

### Before (Controller)

```typescript
@Post('login')
@ApiOperation({ summary: 'Login with email and password' })
async login(@Body() dto: LoginDto) { ... }
```

### After (Controller)

```typescript
@Post('login')
@Throttle({ default: { limit: 5, ttl: 60000 } })
@ApiOperation({ summary: 'Login with email and password' })
@SwaggerResponse({ status: 429, description: 'Too many requests' })
async login(@Body() dto: LoginDto) { ... }
```
