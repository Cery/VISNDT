## Security Impact

- **Route Protection**: Route `/organizations/:id` is inside `<RequireAuth>` wrapper
- **JWT Injection**: apiClient interceptor automatically injects Bearer token
- **Backend Authorization**: `checkOrganizationAccess` enforces org-ownership or ADMIN role
- **No client-controlled organizationId**: Page reads `id` from URL params only
- **No sensitive data exposure**: Members table shows User ID (not email) and Role
