## 7. Recommendations

### Critical (部署前必须)
1. **JWT_SECRET**: 生成强随机密钥并注入环境变量
2. **CORS_ORIGIN**: 配置为实际生产域名
3. **NODE_ENV**: 生产环境必须设为 `production`
4. **S3 凭证**: 替换为实际 S3 Access Key / Secret Key
5. **DATABASE_URL**: 替换为生产 PostgreSQL 连接字符串

### Medium (建议)
1. **Swagger**: 生产环境禁用 Swagger UI
2. **Helmet**: 添加 HTTP 安全头中间件
3. **Source Map**: 生产构建关闭 sourceMap

### Low (优化)
1. **Compression**: 添加响应压缩中间件
2. **noImplicitAny**: 后端 TypeScript 启用 strict 模式
