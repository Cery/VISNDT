## 4. Architecture Impact

### Frontend

- 已统一为 `Page → Service → API Wrapper → Backend API`。
- 迁移后页面层运行时无直接业务 API 调用；剩余 `import type { ... } from '@/lib/api/*'` 为纯类型导入（编译期，非运行时调用），以及 `ApiError` 来自 API Wrapper 错误处理类，均属合理保留。
- 未替换 UI 框架、未替换状态管理方案、未引入新请求库、未大规模改页面结构。

### Backend

- **保持不变**。本任务完全未修改 `apps/api`。
