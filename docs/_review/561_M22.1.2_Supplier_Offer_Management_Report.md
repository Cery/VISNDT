## Implementation Details

### Offer List Page

**Route**: `/workspace/supplier/offers`

**Capabilities**:
- 查看自身组织 Offer 列表（通过 organizationId 过滤）
- 状态筛选（DRAFT / SUBMITTED / ACCEPTED / REJECTED / WITHDRAWN）
- Offer 卡片展示：标题、描述、价格（货币+金额）、状态徽章、创建时间
- 分页导航
- 创建 Offer 入口按钮

**API Used**: `GET /offers?organizationId=X&status=X&page=X&pageSize=X`

### Offer Create Page

**Route**: `/workspace/supplier/offers/new`

**Capabilities**:
- 产品搜索与选择（Global Catalog 产品列表）
- Offer 信息表单：标题（必填）、描述、价格、货币（CNY/USD/EUR/JPY）
- 创建成功自动跳转至编辑页

**API Used**: `POST /offers` (CreateOfferDto: productId, title, description, price, currency)

### Offer Edit Page

**Route**: `/workspace/supplier/offers/[id]/edit`

**Capabilities**:
- Offer 概览信息：Product ID、Organization、创建时间、更新时间
- 编辑表单（仅 DRAFT 状态可编辑）：标题、描述、价格、货币
- 提交 Offer（DRAFT → SUBMITTED）
- 撤回 Offer（SUBMITTED → WITHDRAWN）
- 所有权验证：仅自己组织的 Offer 可编辑

**API Used**: `GET /offers/:id`, `PATCH /offers/:id`, `POST /offers/:id/submit`, `POST /offers/:id/withdraw`

### Dashboard Integration

**Added to `/dashboard/supplier`**:
- 统计卡片：新增"我的 Offer"卡片（显示 Offer 总数）
- 快捷操作：新增"我的 Offer"入口（显示 Offer 数量）
- 业务导航：新增"我的 Offer"导航项

### Navigation Integration

**SUPPLIER Sidebar updated**:
```
Dashboard → RFQs → Responses → Offers → Notifications → Display
```
