## 3. Event Implementation

### 3.1 Event Summary

| Event | Name | Trigger | Notify Target | Type | Method |
|:---:|------|---------|---------------|:---:|--------|
| **E1** | RFQ Created | `rfqs.service.ts:create()` | Demand 创建者 | `RFQ_UPDATE` | `create()` |
| **E2** | RFQ Status Changed | `rfqs.service.ts:update()` | RFQ 创建者 | `RFQ_UPDATE` | `create()` |
| **E3** | RFQ Response Submitted | `rfq-responses.service.ts:create()` | RFQ 创建者 | `RESPONSE_UPDATE` | `create()` |
| **E4** | Response Accepted | `rfq-responses.service.ts:update()` | Response 组织管理员 | `RESPONSE_UPDATE` | `createForOrganization()` |
| **E5** | Response Rejected | `rfq-responses.service.ts:update()` | Response 组织管理员 | `RESPONSE_UPDATE` | `createForOrganization()` |

### 3.2 E1: RFQ Created

```
create() → prisma.rFQ.create()
         → fetch demand.createdBy
         → notificationsService.create({
             userId: demand.createdBy,
             type: RFQ_UPDATE,
             title: "New RFQ Created",
             message: "RFQ for demand '{title}' has been created",
             referenceType: "RFQ",
             referenceId: rfq.id
           })
```

### 3.3 E2: RFQ Status Changed

```
update() → prisma.rFQ.update()
         → if (dto.status)
         → notificationsService.create({
             userId: rfq.createdBy,
             type: RFQ_UPDATE,
             title: "RFQ Status Updated",
             message: "RFQ status changed to '{status}'",
             referenceType: "RFQ",
             referenceId: rfq.id
           })
```

### 3.4 E3: RFQ Response Submitted

```
create() → prisma.rFQResponse.create()
         → fetch rfq.createdBy
         → notificationsService.create({
             userId: rfq.createdBy,
             type: RESPONSE_UPDATE,
             title: "New RFQ Response",
             message: "A supplier has submitted a response to your RFQ",
             referenceType: "RFQ_RESPONSE",
             referenceId: response.id
           })
```

### 3.5 E4/E5: Response Accepted/Rejected

```
update() → prisma.rFQResponse.update()
         → if (status === ACCEPTED || REJECTED)
         → notificationsService.createForOrganization(
             response.organizationId,
             { type: RESPONSE_UPDATE, title: "Response Accepted/Rejected", ... }
           )
```
