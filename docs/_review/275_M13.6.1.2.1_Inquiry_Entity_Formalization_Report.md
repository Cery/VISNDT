## 数据模型变化

### Before (M13.6.1.2)

```
POST /inquiries
    |
    ↓
Notification Table (referenceType='INQUIRY')
    |
    ↓ (no persistent inquiry entity)
```

### After (M13.6.1.2.1)

```
POST /inquiries
    |
    ↓
Inquiry Entity (new table)
    |
    ├── Notification (referenceType='INQUIRY', referenceId=inquiry.id)
    └── (未来) WorkflowEvent
```

### 新增 Prisma 模型

**InquiryStatus 枚举：**
```prisma
enum InquiryStatus {
  NEW
  PROCESSING
  REPLIED
  CLOSED
}
```

**Inquiry 模型：**
```prisma
model Inquiry {
  id             String        @id @default(uuid()) @db.Uuid
  productId      String?       @map("product_id") @db.Uuid
  organizationId String?       @map("organization_id") @db.Uuid
  createdById    String?       @map("created_by_id") @db.Uuid
  contactName    String?       @map("contact_name")
  contactEmail   String?       @map("contact_email")
  contactPhone   String?       @map("contact_phone")
  message        String
  status         InquiryStatus @default(NEW)
  createdAt      DateTime      @default(now())
  updatedAt      DateTime      @updatedAt

  product      Product?      @relation(...)
  organization Organization? @relation(...)
  createdBy    User?         @relation(...)
}
```

### 关键变更

1. **`create()`**: 先保存 `Inquiry` 实体，再创建通知（`referenceId` 从 `productId` 改为 `inquiry.id`）
2. **`getMyInquiries()`**: 从 Notification 去重查询 → 直接查询 Inquiry 表（`organizationId` 过滤 + Prisma 分页）
3. **`getInquiryById()`**: 从 Notification ID 查询 → 直接查询 Inquiry 表（`id` + `organizationId` 权限验证）
4. **`mapToInquiryResponse()`**: 映射对象从 Notification → Inquiry 实体（完整字段：`id`, `productId`, `organizationId`, `createdById`, `contactName`, `contactEmail`, `contactPhone`, `message`, `status`, `createdAt`, `updatedAt`）
