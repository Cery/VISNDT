## Match State Machine

```
                    match()
                      │
                      ↓
                  PENDING
                      │
                  review()
                      │
                      ↓
                  REVIEWED
                   ┌──┴──┐
              accept()  reject()
                   │       │
                   ↓       ↓
               ACCEPTED  REJECTED
```

### 状态转换规则

| 方法 | 源状态 | 目标状态 | 权限 | WorkflowEvent |
|------|--------|----------|------|---------------|
| `match()` | — | `PENDING` | (内部调用) | — |
| `review()` | `PENDING` | `REVIEWED` | demand 同组织 | `MATCH → REVIEWED` |
| `accept()` | `REVIEWED` | `ACCEPTED` | demand 同组织 | `MATCH → ACCEPTED` |
| `reject()` | `REVIEWED` | `REJECTED` | demand 同组织 | `MATCH → REJECTED` |

### 非法状态转换 → BadRequestException

| 场景 | 返回 |
|------|------|
| 对非 PENDING 状态调用 `review()` | `BadRequestException` |
| 对非 REVIEWED 状态调用 `accept()` / `reject()` | `BadRequestException` |
| 跨组织操作 | `BadRequestException` |

## Matching Algorithm Changes

### weighted_v1 保留

完全保留现有 `weighted_v1` 算法，不做任何修改。

### 变化 1: matchStatus → PENDING

```
Before:  matchStatus = DemandMatchStatus.MATCHED
After:   matchStatus = DemandMatchStatus.PENDING
```

### 变化 2: matchDetails 增强 explanation

```json
// Before
{
  "algorithm": "weighted_v1",
  "totalParameters": 5,
  "matchedParameters": 3,
  "matchRate": 0.6,
  "hardFail": false,
  "failReason": null,
  "parameterScores": [...]
}

// After — 新增 explanation
{
  "algorithm": "weighted_v1",
  "explanation": {
    "score": 85,
    "factors": [
      { "name": "diameter", "code": "diameter", "matched": true, "weight": 20, "score": 100, "required": true, "type": "range" },
      { "name": "pixel", "code": "pixel", "matched": true, "weight": 15, "score": 100, "required": false, "type": "exact" },
      { "name": "voltage", "code": "voltage", "matched": false, "weight": 10, "score": 0, "required": false, "type": "enum" }
    ]
  },
  "totalParameters": 5,
  "matchedParameters": 3,
  "matchRate": 0.6,
  "hardFail": false,
  "failReason": null,
  "parameterScores": [...]
}
```

## Match Explanation Design

`explanation` 字段嵌入在 `matchDetails` (Json) 中，包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| `score` | number | 匹配总分 |
| `factors` | array | 匹配因素明细 |
| `factors[].name` | string | 参数名称 |
| `factors[].code` | string | 参数代码 |
| `factors[].matched` | boolean | 是否匹配 |
| `factors[].weight` | number | 权重 |
| `factors[].score` | number | 该因素得分 |
| `factors[].required` | boolean | 是否必选 |
| `factors[].type` | string | 匹配类型 (exact/enum/range) |
