## 4. New API Documentation

### 4.1 POST /files/upload

```
POST /api/v1/files/upload
Content-Type: multipart/form-data
Authorization: Bearer <JWT>
```

**Request**:
| Field | Type | Required | Description |
|-------|------|:---:|-------------|
| `file` | File (binary) | ✅ | File to upload (max 10MB) |

**Response** (200):
```json
{
  "status": "ok",
  "message": "File uploaded",
  "data": {
    "id": "uuid",
    "entityType": "PRODUCT",
    "entityId": "00000000-0000-0000-0000-000000000000",
    "fileType": "IMAGE|DOCUMENT|CERTIFICATE|OTHER",
    "fileName": "original-name.jpg",
    "storageKey": "uploads/2026-07-28T09-30-25-000Z-uuid.ext",
    "mimeType": "image/jpeg",
    "fileSize": 123456,
    "uploadedBy": "uuid",
    "createdAt": "2026-07-28T09:30:25.000Z",
    "updatedAt": "2026-07-28T09:30:25.000Z"
  }
}
```

**Security**: `@UseGuards(JwtAuthGuard, RolesGuard)` + `@Roles(Role.ADMIN)`

**Rate Limit**: Inherits global 100 req/min (can be overridden to 10 req/min in future)

**Multer Config**: `FileInterceptor('file')` — single file, field name `file`

### 4.2 GET /files/:id/download

```
GET /api/v1/files/:id/download
```

**Response** (302 Found):
```
Location: https://s3-host/bucket/key?X-Amz-... (signed URL)
Content-Type: image/jpeg
Content-Disposition: attachment; filename="original-name.jpg"
```

**Flow**:
```
1. GET /files/:id/download
2. FileAssetService.download(id)
3. prisma.fileAsset.findUnique({ where: { id } })
4. StorageService.getSignedUrl(storageKey, 900s)
5. 302 redirect to signed URL
```

**Security**: Public access (no auth required). Signed URL expires in 15 minutes.

---

### 4.3 DELETE /files/:id

```
DELETE /api/v1/files/:id
Authorization: Bearer <JWT>
```

**Response** (200):
```json
{
  "status": "ok",
  "message": "File deleted",
  "data": null
}
```

**Flow**:
```
1. DELETE /files/:id
2. FileAssetService.delete(id)
3. prisma.fileAsset.findUnique({ where: { id } })
4. StorageService.deleteObject(storageKey)
5. prisma.fileAsset.delete({ where: { id } })
```

**Security**: `@UseGuards(JwtAuthGuard, RolesGuard)` + `@Roles(Role.ADMIN)`

## 6. Security Controls

### 6.1 File Validation (`validateFile`)

| Check | Rule | Error |
|-------|------|-------|
| File exists | `file` must not be null/undefined | "No file provided" |
| File size | `≤ 10MB (10 * 1024 * 1024 bytes)` | "File too large. Maximum size is 10MB" |
| MIME type | See whitelist below | "Unsupported file type: {mimeType}" |

### 6.2 MIME Type Whitelist

| Category | MIME Types |
|----------|-----------|
| **Images** | `image/png`, `image/jpeg`, `image/webp`, `image/gif` |
| **Documents** | `application/pdf`, `application/msword`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
| **Spreadsheets** | `application/vnd.ms-excel`, `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` |
| **Presentations** | `application/vnd.ms-powerpoint`, `application/vnd.openxmlformats-officedocument.presentationml.presentation` |
| **Text** | `text/plain`, `text/csv` |

**Blocked**: Executables, scripts, archives, HTML, SVG, and other potentially dangerous formats.

### 6.3 Permission Model

| Endpoint | Auth | Role | Rate Limit |
|----------|:---:|:---:|:---:|
| `POST /files/upload` | JWT | ADMIN | 100/min (global) |
| `GET /files/:id/download` | None | None | 100/min (global) |
| `DELETE /files/:id` | JWT | ADMIN | 100/min (global) |

### 6.4 Storage Key Security

- Format: `uploads/{ISO-timestamp}-{randomUUID}.{ext}`
- No user-controlled input in key
- No predictable naming
- FileAsset entityId is set to placeholder UUID — actual linking happens via ProductMedia

## 7. Storage Integration

### 7.1 StorageService Dependency

```
FileAssetService
  ├── PrismaService (database)
  └── StorageService (S3/MinIO)
       ├── upload(buffer, key, mimeType) → PutObjectCommand
       ├── getSignedUrl(key, 900s)       → getSignedUrl()
       └── deleteObject(key)            → DeleteObjectCommand
```

### 7.2 File Lifecycle

```
CREATE:  upload → S3.PutObject → DB.Insert
READ:    download → DB.Find → S3.GetSignedUrl → 302 redirect
DELETE:  delete → DB.Find → S3.DeleteObject → DB.Delete
```
