## Architecture Impact

- **数据流**: `DemandDetail.tsx` → `demandService.getById(id)` → `apiClient.get('/demands/:id')` → Backend
- **依赖**: 复用 `apiClient` 和 `demandService`，无新增依赖
- **模式**: 遵循 ProductDetail 模板: loading → error (Retry + Back) → success
- **类型**: `Demand` 新增 `parameters?: DemandParameter[]`，`DemandParameter` 独立接口

---

## Security Impact

- **无影响** — 路由在 `RequireAuth` 守卫下
- Backend `GET /demands/:id` 为 Public 端点，contact info 由 Backend 根据 `contactVisible` 保护
- 认证链路完整: RequireAuth → JWT Token → Backend

---

## API Changes

- **无新增 Backend API** — 复用 `GET /api/v1/demands/:id` (Public)
- Frontend `demandService.getById()` 返回类型已支持 `parameters` 字段

## Demand Detail 页面功能

### 状态管理

| 状态 | UI |
|---|---|
| Loading | 居中 Spin |
| Error | Alert + description + Retry + Back to List |
| Success | 完整 Detail 展示 |

### UI 区域

| 区域 | 组件 | 内容 |
|---|---|---|
| 基础信息 | `Descriptions` (bordered) | Title, Status (Tag), Category, Organization, Budget Range, Quantity, Expected Delivery |
| 描述 | `Card` (conditional) | description (仅当存在时显示) |
| 参数 | `Table` (small) | Name, Code, Value, Unit |
| 时间线 | `Descriptions` (bordered) | Created At, Updated At, Published At, Closed At |

### Status Tag 颜色

| 状态 | 颜色 |
|---|---|
| DRAFT | orange |
| PUBLISHED | green |
| SUBMITTED | cyan |
| PROCESSING | blue |
| CLOSED | default |
| CANCELLED | red |

### 参数值渲染

| 数据 | 显示 |
|---|---|
| `value` (string) | 直接显示 |
| `valueMin` + `valueMax` | `{min} - {max}` |
| `valueMin` only | `≥ {min}` |
| `valueMax` only | `≤ {max}` |
| 无值 | `-` |

### 导航

- 顶部 "Back to List" 按钮 → `/demands`
- 底部 "Back to List" 按钮 → `/demands`
