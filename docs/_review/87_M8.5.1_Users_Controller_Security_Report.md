## 1. Phase Overview

解决 Project Reality Audit 中发现的 Users Controller 安全缺口：

> "Users Controller 所有端点无 JWT Guard，允许未认证用户进行 CRUD 操作"

**Before**: 4 个端点全部 public，无任何认证保护。

**After**: JWT 认证 + 所有权校验 + 角色权限控制。

## 3. API Impact

### 3.1 Before vs After

| Endpoint | Before | After |
|----------|--------|-------|
| `GET /users` | Public | JWT + ADMIN |
| `GET /users/:id` | Public | JWT (self or ADMIN) |
| `POST /users` | Public | JWT + ADMIN |
| `PATCH /users/:id` | Public | JWT (self or ADMIN) |

### 3.2 Security Rules

| Rule | Implementation |
|------|---------------|
| 所有端点必须 JWT 认证 | `@UseGuards(JwtAuthGuard)` |
| 列表/创建操作仅 ADMIN | `@Roles(Role.ADMIN)` + `RolesGuard` |
| 查看/更新操作仅自己或 ADMIN | `checkOwnershipOrAdmin()` |
| 非 ADMIN 自我更新不能修改 status/organizationId | Service 层字段剥离 |

### 3.3 Response Format

API 响应格式不变。仍然使用 `ApiResponse.ok()` 统一格式。
