## 4. 是否符合 333 冻结

结论：**符合 `333_M14.2.4.4C_WorkspaceRole_Contract_Freeze_Specification` 对前端消费层的冻结要求。**

对齐依据：

1. `workspaceRole` 是工作区业务人格，最终冻结为 `SUPPLIER | BUYER | null`
2. `workspaceRole = null` 表示“未映射 / 不可进入业务工作区”，不得用 Buyer 兜底

5. `WorkspaceSidebar` 遇到 `workspaceRole = null` 时不得渲染 Buyer 默认导航
