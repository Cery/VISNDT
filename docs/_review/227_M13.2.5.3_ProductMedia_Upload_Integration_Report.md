## 4. Upload Flow

### Before (M13.1.4)

```
User → type fileAssetId manually → submit form
                                     ↓
                              POST /products/:id/media (with hardcoded fileAssetId)
```

### After (M13.2.5.3)

```
User → drag/click Upload.Dragger → beforeUpload(file)
                                        ↓
                                 fileAssetService.upload(file)
                                        ↓
                                 POST /files/upload (multipart/form-data)
                                        ↓
                                 StorageService.upload() → S3/MinIO
                                        ↓
                                 prisma.fileAsset.create() → DB
                                        ↓
                                 Return fileAsset.id
                                        ↓
                                 Form stores fileAssetId
                                        ↓
                                 User fills form → submit
                                        ↓
                                 POST /products/:id/media (auto fileAssetId)
```

### PageState Machine

```
idle
 ├── [file selected] → uploading { fileName }
 │    ├── [success] → idle (fileAssetId stored)
 │    └── [failure] → error { message }
 └── [form submit] → submitting
      ├── [success] → navigate to /products/:id/media
      └── [failure] → error { message }
```

## 5. API Integration

### 5.1 fileAssetService.upload()

```typescript
async upload(file: File): Promise<FileAsset> {
  const formData = new FormData();
  formData.append('file', file);

  const response = await apiClient.post<UploadResponse>(
    '/files/upload',
    formData,
    { headers: { 'Content-Type': 'multipart/form-data' } },
  );

  return response.data;
}
```

**Key design decisions**:
- Uses `apiClient` (not raw axios) — inherits JWT interceptor
- Overrides `Content-Type` to `multipart/form-data` per-request (without modifying global default)
- Returns `FileAsset` directly (not raw response wrapper)

### 5.2 Backend Endpoint

| Endpoint | Method | Auth | Purpose |
|----------|--------|:---:|---------|
| `POST /api/v1/files/upload` | multipart | ADMIN | Upload file → FileAsset |
