## Implementation Summary

### 1. Supplier Business Opportunity Center Page

创建页面 `/workspace/supplier/opportunities`，实现三标签展示：

- **公开 RFQ**：通过 `GET /rfqs/available` 展示所有公开 RFQ，支持分页和状态标签
- **定向 RFQ**：通过 `GET /workspace/supplier/rfqs` 展示定向到当前供应商的 RFQ
- **匹配机会**：通过 `GET /workspace/supplier/overview` 的 matchSummary 展示 DemandMatch 匹配机会统计

每个 RFQ 卡片展示标题、状态、发布时间，并提供快速入口进入 RFQ Detail 和 Response 创建。

### 2. DemandMatch Opportunity 展示

复用现有 `DemandMatch`、`Demand`、`Offer`、`Product` 模型，通过 Workspace Overview API 的 `matchSummary` 字段展示匹配机会统计（总数 + 各状态计数），无需新增数据模型。

### 3. Match → RFQ Response 快速入口

Opportunity Center 页面中，每个 RFQ 卡片提供：
- 点击进入 `/workspace/supplier/rfqs/{id}` 查看 RFQ 详情
- 对于已响应 RFQ 的项目，展示已响应状态
- 复用现有 `POST /rfqs/:id/responses` 接口，无需新增 API

### 4. Supplier Opportunity Dashboard Enhancement

增强 `/dashboard/supplier` 页面：

- **新增公开 RFQ 统计卡片**：通过 `GET /rfqs/available` 展示可参与报价的公开 RFQ 数量
- **新增商机中心快捷入口**：Dashboard 快捷操作区域添加「商机中心」入口，直达 `/workspace/supplier/opportunities`
- **业务导航增强**：DOMAIN_NAV_ITEMS 新增「商机中心」导航项

Dashboard 统计卡片阵列为 6 列：待处理 RFQ、已提交响应、匹配机会、公开 RFQ、我的 Offer、未读通知。

### 5. Supplier Opportunity Timeline

在 Opportunity Center 页面底部实现机会时间线，展示：

- 最近定向 RFQ（RFQ Received）
- 已提交响应状态（SUBMITTED / VIEWED / ACCEPTED / REJECTED）

数据来源复用 `WorkflowEvent`、`Notification`、`RFQResponse`，无需新增 Timeline 专用模型。
