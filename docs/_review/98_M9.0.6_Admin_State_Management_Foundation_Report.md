## 5. State Architecture Impact

### 5.1 AppStore Interface

```typescript
interface AppState {
  sidebarCollapsed: boolean;
  setSidebarCollapsed: (collapsed: boolean) => void;
}
```

### 5.2 Store Architecture

```
src/stores/
├── app.store.ts    # Zustand create — AppState
└── index.ts        # Barrel export
```

### 5.3 Hook Architecture

```
src/hooks/
├── useAppStore.ts  # useStore(appStore) wrapper
└── index.ts        # Barrel export
```

### 5.4 Usage Pattern

```typescript
import { useAppStore } from '../hooks';

function MyComponent() {
  const { sidebarCollapsed, setSidebarCollapsed } = useAppStore();
  // ...
}
```

### 5.5 No Provider Required

Zustand does not require a React context provider. The store is accessed directly via the hook. `main.tsx` remains unchanged:

```tsx
<AppProvider>
  <App />
</AppProvider>
```
