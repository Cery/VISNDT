## 1. Phase Overview

解决 M8 Final Architecture Audit 中发现的 TD-4 技术债：

> "Workflow Event API 权限不足，事件创建接口未进行 JWT Guard 与 Organization 权限校验"

**Before**: `POST /workflow-events` 公开，`operatorId` 由客户端传入。

**After**: JWT Guard 保护，`operatorId` 从 JWT 派生，强制 Organization 归属。

## 6. Code Refactor

### Before (Controller)

```typescript
@Post()
async create(@Body() dto: CreateWorkflowEventDto) {
  return ApiResponse.ok(await this.service.create(dto), 'Event created');
}
```

### After (Controller)

```typescript
@Post()
@UseGuards(JwtAuthGuard)
@ApiBearerAuth()
async create(
  @Body() dto: CreateWorkflowEventDto,
  @CurrentUser() user: AuthRequest['user'],
) {
  return ApiResponse.ok(await this.service.create(dto, user), 'Event created');
}
```

### Before (Service)

```typescript
async create(dto: CreateWorkflowEventDto) {
  return this.prisma.workflowEvent.create({
    data: { ...dto, metadata: dto.metadata as Prisma.InputJsonValue },
  });
}
```

### After (Service)

```typescript
async create(dto: CreateWorkflowEventDto, user: WorkflowEventUser) {
  if (!user.organizationId) {
    throw new ForbiddenException('User must belong to an organization');
  }
  return this.prisma.workflowEvent.create({
    data: {
      entityType: dto.entityType,
      entityId: dto.entityId,
      action: dto.action,
      operatorId: user.id,       // ← server-derived
      metadata: dto.metadata as Prisma.InputJsonValue,
    },
  });
}
```
