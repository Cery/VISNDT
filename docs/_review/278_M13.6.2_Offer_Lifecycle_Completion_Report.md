## Offer State Machine

```
                  submit()
DRAFT ────────────────────────→ SUBMITTED
                                    │
                    ┌───────────────┼───────────────┐
                    │               │               │
                accept()        reject()        withdraw()
                    │               │               │
                    ↓               ↓               ↓
                ACCEPTED        REJECTED        WITHDRAWN
```

### 状态转换规则

| 方法 | 源状态 | 目标状态 | 权限 | WorkflowEvent |
|------|--------|----------|------|---------------|
| `submit()` | `DRAFT` | `SUBMITTED` | 同组织 | `OFFER → SUBMITTED` |
| `accept()` | `SUBMITTED` | `ACCEPTED` | 同组织 | `OFFER → ACCEPTED` |
| `reject()` | `SUBMITTED` | `REJECTED` | 同组织 | `OFFER → REJECTED` |
| `withdraw()` | `SUBMITTED` | `WITHDRAWN` | 同组织 | `OFFER → WITHDRAWN` |

### 非法状态转换 → BadRequestException

| 场景 | 返回 |
|------|------|
| 对非 DRAFT 状态调用 `submit()` | `BadRequestException` |
| 对非 SUBMITTED 状态调用 `accept()` / `reject()` / `withdraw()` | `BadRequestException` |
| 跨组织操作 | `BadRequestException` |
