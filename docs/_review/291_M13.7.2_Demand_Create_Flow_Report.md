## 6. Authentication Handling

| Aspect | Implementation |
|--------|---------------|
| **Page-level guard** | `AuthGuard` wraps the entire page component |
| **Redirect** | `router.replace('/login')` if not authenticated |
| **Loading state** | AuthGuard shows `<Loading />` while checking auth |
| **CSRF token** | Auto-attached by `apiClient` for POST requests |
| **JWT cookie** | `credentials: 'include'` sends HttpOnly cookie |
| **Token refresh** | Auto-retry on 401 via `tryRefreshToken()` |
| **Session expiry** | `ApiError(401, 'Session expired')` thrown on refresh failure |

### AuthGuard Flow

```
Page renders
     │
     ▼
AuthGuard checks useAuth()
     │
     ├── isLoading → <Loading />
     ├── !isAuthenticated → router.replace('/login')
     └── isAuthenticated → render children (DemandCreateContent)
```
