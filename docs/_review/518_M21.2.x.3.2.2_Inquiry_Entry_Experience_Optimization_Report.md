## 1. Task Summary

**Objective**: 在 518.1 Product Inquiry Context Presentation 基础上，继续优化 Product Detail → Inquiry Entry 的完整体验链路，降低用户进入咨询流程的理解成本，强化「产品咨询」而非「交易询价」定位。

**Before**:
```
Product Detail → Suppliers Tab → Select Supplier
  → "询价对象：[Supplier]" → ProductInquiryContext
  → "发送询价" → "向 X 询价 Y" → "提交询价"
  → Success: "感谢您的询价，已成功提交" → "提交另一个询价"
```

**After**:
```
Product Detail → Suppliers Tab → Select Supplier
  → "已选择供应商：[Supplier]" → ProductInquiryContext
  → "请填写以下信息，X 将为您提供 Y 的技术方案与报价建议" → "咨询此设备"
  → Success: "咨询已提交" → "您已成功提交关于 [product] 的咨询" → "继续咨询" / "返回产品详情"
```

**Scope**: Frontend Only — 2 文件修改，零 Schema/API/Migration 变更。

## 5. Experience Changes

### 5.1 术语去交易化

| 交易化术语 | 替换为 |
|-----------|--------|
| 询价对象 | 已选择供应商 |
| 发送询价 | （移除，由 ProductInquiryContext 替代） |
| 向 X 询价 Y | 请填写信息，X 为您提供 Y 的技术方案与报价建议 |
| 提交询价失败 | 提交咨询失败 |
| 感谢您的询价 | 咨询已提交 |
| 提交另一个询价 | 继续咨询 |

### 5.2 体验链路

```
Product Detail
  ↓
产品信息确认（ProductInquiryContext：产品名称 + 型号 + 分类）
  ↓
供应商选择（SupplierCapabilityList）
  ↓
供应商确认（"已选择供应商：[name]"）
  ↓
咨询表单（"填写信息，获取技术方案与报价建议"）
  ↓
咨询提交（成功状态：产品名称 + 后续说明 + 继续咨询/返回产品详情）
```
