## 2. Multi-Stage Build Architecture

```
Stage 1: build (node:20-alpine)
  ├── corepack enable pnpm@9
  ├── pnpm install --frozen-lockfile
  ├── COPY source code
  ├── pnpm --filter @visndt/admin build
  └── Output: apps/admin/dist/

Stage 2: production (nginx:1.27-alpine)
  ├── COPY build output → /usr/share/nginx/html
  ├── COPY nginx.conf → /etc/nginx/conf.d/
  ├── EXPOSE 80
  ├── HEALTHCHECK /
  └── CMD nginx -g "daemon off;"
```

## 3. Nginx Configuration

### 3.1 路由规则

| 路由 | 行为 |
|------|------|
| `/` | SPA fallback → `index.html` |
| `/assets/` | 静态资源 (1年缓存) |
| `/api/` | 反向代理 → `http://api:4000` |

### 3.2 关键配置

```nginx
# SPA 路由
try_files $uri $uri/ /index.html;

# API 代理
proxy_pass http://api:4000;
```

---

## 4. Key Design Decisions

| 决策 | 理由 |
|------|------|
| `nginx:1.27-alpine` | 最小化静态文件服务器 |
| SPA fallback | React Router 需要 |
| API 反向代理 | 避免 CORS 问题，统一入口 |
| `assets/` 长缓存 | 带 hash 的文件名支持 immutable |
| 构建阶段分离 | 最终镜像不含 Node.js |
