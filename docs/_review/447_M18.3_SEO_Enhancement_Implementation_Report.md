## 4. SEO Capability Changes

### OpenGraph
- `/knowledge/[slug]` 与 `/solutions/[slug]` 详情页 `generateMetadata()` 输出：
  - `title`（`seoTitle || title`）
  - `description`（`seoDescription || summary 前 160 字 || SITE_DESCRIPTION`）
  - `images`（优先 `coverImage`，其次 `media` 中首个 IMAGE 的 fileAsset）
  - `url`（基于 `SITE_URL` 的绝对 URL）
- Solution 页 `openGraph.type` 为 `website`；Knowledge 页为 `article`。

### JSON-LD Structured Data
- 新增 `buildContentJsonLd()`（`apps/web/src/lib/seo.ts`）：
  - Knowledge → `@type: Article`
  - Solution → `@type: TechArticle`
- 注入方式：详情页 `<script type="application/ld+json">`。
- 字段：`@context / @type / headline / url / description / image / datePublished / dateModified / author(@type Organization) / publisher(@type Organization)`。
- **无敏感字段**：不含内部 ID、storageKey、author email、status、archivedAt。

### Sitemap
- 新增 `apps/web/src/app/sitemap.ts`（`/sitemap.xml`）：
  - 静态核心路由：`/`、`/knowledge`、`/solutions`、`/products`、`/business`、`/about`
  - 动态内容路由：`/knowledge/:slug`、`/solutions/:slug`（带 `lastModified`）
- **规则**：仅 `status=PUBLISHED`（后端公开 API `GET /content/public` 在 DB 层强制 PUBLISHED）
- **降级**：内容拉取失败时仅返回静态路由，不阻断 sitemap 生成。

### Canonical
- 两个详情页均输出 `alternates.canonical`（基于 `SITE_URL` 的绝对 URL）。
