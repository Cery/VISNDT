## 3. API

### Endpoint

```
POST /inquiries
```

### Auth

```
Public (no JWT required)
```

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `productId` | UUID | ✅ | Target product |
| `offerId` | UUID | ✅ | Product offer source |
| `organizationId` | UUID | ✅ | Receiving enterprise |
| `name` | string | ✅ | Visitor name (max 100) |
| `email` | email | ✅ | Visitor email |
| `phone` | string | ❌ | Visitor phone (max 30) |
| `message` | string | ✅ | Inquiry content (max 2000) |

### Response

```json
{
  "success": true,
  "data": {
    "inquiry": {
      "productId": "...",
      "productName": "Product X",
      "organizationId": "...",
      "organizationName": "Company Y",
      "visitorName": "Zhang Wei",
      "visitorEmail": "zhangwei@example.com"
    },
    "notificationsSent": 3
  },
  "message": "Inquiry submitted"
}
```

### Flow

```
Visitor (POST /inquiries)
  ↓
Validate Product exists
  ↓
Validate Offer exists (linked to product)
  ↓
Validate Organization exists (matches offer)
  ↓
Find OrganizationMember(s) for organization
  ↓
Create Notification for each member
  ↓
Return success
```
