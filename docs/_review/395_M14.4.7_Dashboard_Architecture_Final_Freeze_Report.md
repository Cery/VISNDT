## 4. Auth / RBAC Boundary

确认结果：

- `/dashboard`：使用 `AuthGuard`
- `/dashboard/buyer`：使用 `AuthGuard` + `RoleGuard roles={['BUYER']}`
- `/dashboard/supplier`：使用 `AuthGuard` + `RoleGuard roles={['SUPPLIER']}`
- `/workspace/supplier`：使用 `AuthGuard` + `RoleGuard roles={['SUPPLIER']}`

角色来源：

- `AuthProvider` 通过 `getMe()` 获取当前用户
- `RoleGuard` 使用 `user.workspaceRole` 执行 Buyer / Supplier 角色判断
- `/dashboard` 入口也直接读取 `user.workspaceRole` 完成角色分流

边界结论：

- Dashboard 与 Workspace 入口的认证边界仍由现有 `AuthGuard` / `RoleGuard` 承担
- 角色事实来源为 `workspaceRole`
- 本次冻结确认未触碰 Auth Backend 或 RBAC Backend
