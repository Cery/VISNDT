## Architecture Decision

### Knowledge Base Position

```
Content Asset Layer (M22.2 — CLOSED)
    |
    | publishes information assets
    v
Knowledge Structured Layer (M22.3 — ARCHITECTURE INITIALIZATION)
    |
    | structures reusable knowledge assets
    v
Industrial Inspection Knowledge Capability (Future)
```

### Knowledge = Platform Knowledge Asset

**是：**
- Platform Knowledge Asset（平台知识资产）
- 结构化知识资产（Structured Knowledge Assets）
- 工业检测知识体系基础（Industrial Inspection Knowledge Foundation）

**不是：**
- Supplier Asset（供应商资产）
- Marketplace Asset（市场资产）
- User Generated Content（用户生成内容）

### Content → Knowledge Relationship

```
Content Types (ARTICLE / KNOWLEDGE / SOLUTION / INSIGHT)
    |
    | Knowledge Reference (结构化关联)
    v
Knowledge Domain (分类 / 关联 / 检索)
    |
    | Future Extension
    v
Parameter Knowledge Base / Inspection Experience Base / Industry Knowledge System
```

**允许：** Article / Knowledge / Solution / Insight → Knowledge Reference

**禁止：** Content Ownership By Supplier / Content Marketplace / Content Transaction

### Product-Centric Strategy

```
Product
    ↓
Inspection Scenario
    ↓
Knowledge Explanation
    ↓
Solution Guidance
```

**禁止：** Supplier Article / Supplier Blog / Supplier Knowledge Page / Supplier Ranking Content

### Future Extension Points (Reserved Only)

- Knowledge Classification System
- Knowledge Association Graph
- Knowledge Retrieval Foundation
- Parameter Knowledge Base
- Inspection Experience Base
- Industry Knowledge System

**All marked as FUTURE DESIGN — no implementation in this initialization.**
