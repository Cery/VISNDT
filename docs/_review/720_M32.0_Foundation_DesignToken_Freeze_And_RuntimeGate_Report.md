| Token | Value | 语义定位 |

- `VISNDT_COLOR_SYSTEM.md`（色板 + 状态语义映射 success/info/warning/error/neutral → ACTIVE/OPEN/PENDING/REJECTED...）
- `VISNDT_TYPOGRAPHY.md`
- `VISNDT_SPACING.md`（含 Radius / Elevation / 布局网格）
- `VISNDT_COMPONENT_RULE.md`（CTA hierarchy Primary/Secondary/Tertiary/Danger/Disabled + 状态组件 + 跨 App 一致性）
- `VISNDT_UI_GUIDE.md`（平台定位 / 页面认知顺序 / 核心页面体验基线 / 状态驱动 UX / 技术约束 / M32 停止线）

**Usage Rule（冻结）**：Primary = CTA/Active/Link/Focus；Secondary = 技术高亮/辅助交互；Accent = Warning/Pending/Attention；Neutral = Background/Body/Border/Default UI。**禁止全站染 Blue**；**禁止 Primary/Cyan/Amber 同时作为主视觉竞争色**。

**Cross-App Principle（冻结）**：Same Design Tokens + Same Semantic Language + Same Interaction Principles + **Different Application Theme**。Web Card ≠ AntD Card；「统一品牌」≠「统一组件库」。Web/Admin 各自 manual consumption，不引入跨应用共享组件库。
