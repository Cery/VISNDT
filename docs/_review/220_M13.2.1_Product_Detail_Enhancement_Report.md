## 12. Next Step Recommendation

### Known Issue

**C-01**: ProductDetail Media card always shows "No media attached" because the backend `findOne()` does not include `media` relation. This is a pre-existing bug, not introduced by M13.2.1.

### Recommended Next Step

**M13.2.2 — Backend Minimal Unfreeze: Fix ProductDetail Media Card**

Required change: 1 line in `apps/api/src/products/products.service.ts`:

```typescript
// Before
include: { category: true, parameterValues: { include: { parameterDefinition: true } } }

// After
include: { category: true, parameterValues: { include: { parameterDefinition: true } }, media: true }
```

This is the smallest possible Backend Unfreeze — a single Prisma `include` addition with zero API changes, zero DTO changes, zero migration changes, and zero security impact.
