## 4. Match Explanation Implementation

`MatchExplanationCard` 只解释已有结果，**不修改评分、不重算匹配算法、不加 AI**。

- 展示字段：匹配 ID、关联对象 Business Identity、置信度（`score` → 百分比）、状态（`StatusDisplay`）、匹配依据因子。
- 因子由既有确定性信号派生（`buildMatchFactors`）：
  - 检测类型兼容（依据需求与产品能力分类）
  - 要求参数覆盖（依据确定性参数匹配）
  - 能力供给可用（依据 match.status，REJECTED/EXPIRED 标记不可用）
- **位置约束满足**：解释层不反写任何业务状态，`Visualization ≠ Workflow Engine`。
