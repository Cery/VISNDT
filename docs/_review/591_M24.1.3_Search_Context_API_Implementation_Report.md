# 4. API Contract

## 4.1 Endpoint

```
GET /api/v1/search/context?q={keyword}
```

## 4.2 Request

| 参数 | 类型 | 必填 | 说明 |
|-|-|-|-|
| `q` | string | YES | 搜索关键词 |

不得包含：`page`、`pageSize`、`offset`、`cursor`

## 4.3 Response

```typescript
interface SearchContextResponse {
  query: string;                          // 搜索关键词
  candidateCount: number;                 // 匹配候选产品总数（完整种群）
  relevantCategories: RelevantCategoryContext[];  // 相关产品分类
  commonFilters: ParameterFacet[];        // 公共筛选器（交集）
  categorySpecificFilters: Record<string, ParameterFacet[]>;  // 分类专属筛选器
}

interface RelevantCategoryContext {
  id: string;
  name: string;
  slug: string;
  productCount: number;
}

interface ParameterFacet {
  parameterId: string;
  parameterName: string;
  parameterKey: string;
  parameterType: string;      // STRING / NUMBER / BOOLEAN
  unit: string | null;
  sortOrder: number;
  availableValues: FacetValue[];
}

interface FacetValue {
  value: string;
  label: string;
  count: number;
}
```

# 5. Query-Level Context Logic

## 5.1 Semantic Flow

```
Search Query
    ↓
Query Normalization (trim)
    ↓
Candidate Product Population (full, no pagination)
    ↓
Relevant ProductCategory Context
    ↓
Relevant Parameter Definitions (via ProductParameterDefinition + ProductParameterValue)
    ↓
Common Filter Intersection
    ↓
Category-Specific Filters
    ↓
Facet Metadata (available values from candidate products)
```

## 5.2 Candidate Population

基于以下条件查找所有 ACTIVE 产品（无分页）：

- `name` contains keyword (case-insensitive)
- `model` contains keyword (case-insensitive)
- `description` contains keyword (case-insensitive)

返回完整的候选产品 ID 列表及其所属分类。

## 5.3 Parameter Relevance

参数相关性基于以下确定性计算：

1. 候选产品关联的 `ProductParameterDefinition`（显式参数关联）
2. 候选产品关联的 `ProductParameterValue`（实际参数值）
3. 按分类分组，确定每个分类下有哪些参数被使用

无 AI/LLM/Embedding/Vector 参与。

# 6. Pagination Independence Verification

Search Context 的以下请求：

```
GET /api/v1/search/context?q=内窥镜
```

得到稳定的 Query-Level Context，不依赖以下任何分页请求：

```
GET /api/v1/search?q=内窥镜&page=1&pageSize=10
GET /api/v1/search?q=内窥镜&page=2&pageSize=10
GET /api/v1/search?q=内窥镜&page=3&pageSize=20
```

Search Context 的计算基于完整候选产品种群（Full Matching Candidate Population），而非当前结果页。
