## 4. Service Ownership Changes

### 4.1 create()

| Aspect | Before | After |
|--------|--------|-------|
| Signature | `create(dto)` | `create(dto, user)` |
| orgId source | `dto.organizationId` (client) | `user.organizationId` (JWT) |
| creator source | `dto.createdBy` (client) | `user.id` (JWT) |
| No org | — | `BadRequestException` |

```typescript
// ✅ After
async create(dto: CreateDemandDto, user: { id: string; organizationId?: string | null }) {
  if (!user.organizationId) {
    throw new BadRequestException('User must belong to an organization');
  }
  return this.prisma.demand.create({
    data: {
      title: dto.title,
      description: dto.description,
      parametersJson: dto.parametersJson,
      budgetRange: dto.budgetRange,
      organizationId: user.organizationId,
      createdBy: user.id,
    },
  });
}
```

### 4.2 update()

| Aspect | Before | After |
|--------|--------|-------|
| Signature | `update(id, dto)` | `update(id, dto, user)` |
| Query | `findUnique({ where: { id } })` | `findFirst({ where: { id, organizationId } })` |
| Role | None | ADMIN only (via RolesGuard) |
| Cross-org | Possible | Blocked |

```typescript
// ✅ After
async update(id: string, dto: UpdateDemandDto, user: { organizationId?: string | null }) {
  if (!user.organizationId) {
    throw new BadRequestException('User must belong to an organization');
  }
  const demand = await this.prisma.demand.findFirst({
    where: { id, organizationId: user.organizationId },
  });
  if (!demand) throw new NotFoundException(`Demand ${id} not found`);
  return this.prisma.demand.update({ where: { id }, data: { ...dto } });
}
```

## 7. Security Vulnerability Fixes

| Vulnerability | Severity | Fix |
|--------------|----------|-----|
| Client can impersonate any user | 🔴 High | `createdBy` forced from JWT `user.id` |
| Client can set arbitrary `organizationId` | 🔴 High | `organizationId` forced from JWT |
| Cross-organization Demand modification | 🔴 High | `findFirst({ id, organizationId })` |
| Unauthenticated Demand creation | 🟡 Medium | `JwtAuthGuard` on POST |
| Unauthorized Demand modification | 🟡 Medium | `RolesGuard` + `@Roles(Role.ADMIN)` on PATCH |
