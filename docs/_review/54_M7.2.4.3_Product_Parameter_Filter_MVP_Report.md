## 1. Phase Overview

本阶段在 M7.2.4.2 Basic Product Search API 基础上新增 Product Parameter Filter 能力，支持通过 `parameterFilters` 参数按 ProductParameterValue 筛选产品。多个参数条件之间为 AND 逻辑，与 keyword/categoryId/status 等条件也通过 AND 组合。

### 业务场景
- 镜头直径 = 2.8mm
- 分辨率 = 200万
- 光源类型 = LED

上述条件组合后，返回同时满足所有参数条件的产品。

## 4. Parameter Filter Logic

### 查询逻辑

```typescript
// 每个 parameterFilter 转换为一个 AND 条件
if (parameterFilters && parameterFilters.length > 0) {
  for (const filter of parameterFilters) {
    conditions.push({
      parameterValues: {
        some: {
          parameterDefinitionId: filter.parameterDefinitionId,
          value: filter.value,
        },
      },
    });
  }
}
```

### 组合规则

| 条件组合 | 逻辑 |
|----------|------|
| 多个 parameterFilter 之间 | AND |
| parameterFilter + keyword | AND |
| parameterFilter + categoryId | AND |
| parameterFilter + status | AND |

### 最终 Prisma where 结构

```typescript
where: {
  categoryId: "...",         // 精确过滤
  status: "ACTIVE",          // 精确过滤
  AND: [
    // keyword OR 条件
    { OR: [{ name: { contains: "..." } }, { model: { contains: "..." } }, ...] },
    // 参数筛选 1
    { parameterValues: { some: { parameterDefinitionId: "uuid-1", value: "2.8mm" } } },
    // 参数筛选 2
    { parameterValues: { some: { parameterDefinitionId: "uuid-2", value: "200万" } } },
  ],
}
```

### 匹配方式

- 使用 Prisma `some` 关系过滤：Product 至少存在一个匹配的 ProductParameterValue
- `value` 为精确匹配（等值比较），不支持范围查询（属于后续阶段）

## 5. Prisma Query Design

### 关系链

```
Product
  └── parameterValues: ProductParameterValue[]
        └── parameterDefinition: ParameterDefinition
```

### 查询模式

- 使用 Prisma Relation Filter `some` 在 ProductParameterValue 上过滤
- 避免 N+1 查询：`parameterValues` 条件直接嵌入 `where`
- 查询结果 `include: { category: true }` 保持不变

### 关于 parameterValues include 评估

当前 `findAll` 搜索结果不包含 `parameterValues`，仅 `findOne` 包含。建议保持不变：
- 优点：减少查询负载，避免大结果集时传输冗余参数数据
- 如需前端展示参数值，可调用 `GET /products/:id` 获取详情时附带
- 后续可考虑增加 `includeParameters` 可选参数控制
