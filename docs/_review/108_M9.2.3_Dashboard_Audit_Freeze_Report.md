## 6. Security Review

### Auth Call Chain Audit

```
1. User navigates to /home
2. Router checks: /home is child of RequireAuth > AdminLayout
3. RequireAuth checks: isAuthenticated from authStore
   ├─ Not authenticated → redirect to /login
   └─ Authenticated → checkTokenExpiry() → if expired, clearAuth + redirect
4. AdminLayout renders with Sider + Content
5. Home.tsx mounts → useEffect → fetchStats()
6. dashboardService.getStats() → apiClient.get('/admin/dashboard/stats')
7. Request interceptor injects: Authorization: Bearer {accessToken}
8. Backend validates JWT + ADMIN role
9. On 401: response interceptor → clearAuth() + window.location.href = '/login'
```

| Check | Result | Detail |
|---|---|---|
| RequireAuth effectiveness | PASS | All child routes (including /home) wrapped in RequireAuth |
| Token propagation | PASS | Request interceptor injects Bearer token from authStore |
| 401 handling | PASS | Response interceptor clears auth + redirects to /login |
| No auth bypass | PASS | Dashboard service does not manipulate auth state |
| Data exposure | PASS | Dashboard page only accessible after auth; no sensitive PII |
| Error message safety | PASS | `instanceof Error` guard; no raw error objects leaked to UI |
| localStorage security | PASS | Token stored via Zustand persist; JWT with limited lifetime |
| No new auth surface | PASS | All auth is delegated to M9.1 infrastructure |

### Result: PASS
