## New API Endpoints

| Method | Path | Purpose | Existing Guards |
|--------|------|---------|:---:|
| `GET` | `/admin/dashboard/activities` | Recent platform activities (users, demands, matches, notifications) | JWT + Roles(ADMIN) |

| `GET` | `/admin/dashboard/status` | System health summary + entity counts | JWT + Roles(ADMIN) |

### Endpoint Details

#### 1. GET /admin/dashboard/activities

**Service Method**: `getRecentActivities()`

**Returns**:

```typescript
{
  users: { id, email, name, status, createdAt }[],        // Last 5 registered
  demands: { id, title, status, createdAt }[],             // Last 5 created
  matches: { id, matchScore, matchStatus, createdAt }[],   // Last 5 matches
  notifications: { id, type, title, createdAt }[]          // Last 5 unread
}
```

**Implementation**:

| Query | Model | Where | OrderBy | Take | Select |
|-------|-------|-------|---------|------|--------|
| users | `user` | — | `createdAt: desc` | 5 | id, email, name, status, createdAt |
| demands | `demand` | — | `createdAt: desc` | 5 | id, title, status, createdAt |
| matches | `demandMatch` | — | `createdAt: desc` | 5 | id, matchScore, matchStatus, createdAt |
| notifications | `notification` | `status: UNREAD` | `createdAt: desc` | 5 | id, type, title, createdAt |

**Security**: All `select` blocks exclude `passwordHash`. All 4 queries run in parallel via `Promise.all`.

#### 2. GET /admin/dashboard/pending

**Service Method**: `getPendingItems()`

**Returns**:

```typescript
{
  usersPending: number,        // Users with INACTIVE or SUSPENDED status
  demandsPending: number,      // Demands with DRAFT status
  rfqPending: number,          // RFQs with DRAFT or OPEN status
  unreadNotifications: number  // Notifications with UNREAD status
}
```

**Implementation**:

| Count | Model | Where Filter |
|-------|-------|-------------|
| `usersPending` | `user` | `status IN ['INACTIVE', 'SUSPENDED']` |
| `demandsPending` | `demand` | `status = 'DRAFT'` |
| `rfqPending` | `rFQ` | `status IN ['DRAFT', 'OPEN']` |
| `unreadNotifications` | `notification` | `status = 'UNREAD'` |

All 4 counts run in parallel via `Promise.all`.

#### 3. GET /admin/dashboard/status

**Service Method**: `getSystemStatus()`

**Returns**:

```typescript
{
  database: 'connected',
  api: 'healthy',
  lastUpdated: string,         // ISO timestamp of latest activity
  entityCounts: {
    users: number,
    organizations: number,
    products: number,
    demands: number,
    matches: number
  }
}
```

**Implementation**:

| Field | Source | Method |
|-------|--------|--------|
| `database` | Prisma connection | Static `'connected'` (confirmed by query execution) |
| `api` | NestJS runtime | Static `'healthy'` |
| `lastUpdated` | Max of `user.createdAt` + `demand.createdAt` | `findFirst` + `orderBy: desc` |
| `entityCounts` | 5 parallel `count()` queries | `Promise.all` |
