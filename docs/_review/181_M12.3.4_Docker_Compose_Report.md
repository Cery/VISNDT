## 6. Usage

```bash
# 创建 .env 文件并设置 JWT_SECRET
echo "JWT_SECRET=$(openssl rand -base64 64)" > .env

# 启动所有服务
docker compose up -d

# 查看状态
docker compose ps

# 数据库迁移 (首次或更新)
docker compose exec api npx prisma migrate deploy

# 查看日志
docker compose logs -f

# 停止
docker compose down
```
