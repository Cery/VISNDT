## 5. Design System Expansion Result

### 5.1 状态语义统一（StatusTag 组件扩散）

- 将 **17 个 List/Detail 页** 中误用 `<Tag color={resolveStatusTone(x)}>` 的写法，收敛为语义化 `StatusTag` 组件（该组件通过 `TONE_TO_ANTD_COLOR` 将语义色映射为合法 antd 色值）。
- **清除非法 antd Tag 色问题**：消除了 `'neutral'`、`'primary'`、`'violet'` 等非 antd 合法 Tag 颜色取值。
- **消除潜在运行隐患**：`DemandDetail` 原引用了未定义的 `MATCH_STATUS_COLOR` / `RFQ_STATUS_COLOR`，已收敛为 `StatusTag` 语义化渲染。
- 使用 `StatusTag` 的页面（17 页）：
  - ProductList / ProductDetail
  - DemandList / DemandDetail
  - RfqList / RfqDetail
  - OfferList / OfferDetail
  - OrganizationList / OrganizationDetail
  - UserList / UserDetail
  - InquiryList / InquiryDetail
  - MatchDetail
  - NotificationList / NotificationDetail

### 5.2 硬编码色彩收敛（VISNDT_COLORS）

将散落在管理页面的 antd/默认硬编码色收敛到 `VISNDT_COLORS` 语义 Token：

- `ProductList` 统计卡默认色（#52c41a / #faad14 / #ff4d4f）→ `VISNDT_COLORS.success/warning/error`
- `ProductMediaCreate/Edit`、`DemandDetail`、`MatchDetail`、`MediaList`、`Monitoring`、`TrendChart`、`OverviewCards`、`AuditIntelligence`、`ContentList`、`FileAssetOrphanList` 等默认色 → `VISNDT_COLORS.success/warning/error/primary`

### 5.3 遗留字符串字面量修复

- 将 `AuditIntelligence.tsx` / `BusinessAnalytics.tsx` 中遗留的字符串字面量 `'VISNDT_COLORS.*'`（会被当作无效色值渲染）修复为真实变量引用 `VISNDT_COLORS.*`。
- 收口后全量校验：`apps/admin/src` 下已无 `'VISNDT_COLORS.` 字符串字面量残存（Grep = 0）。

### 5.4 组件与 Token 复用约束

- 优先复用既有设计系统资产（`StatusTag` / `StatCard` / `SectionHeader` / `PlatformHealthBanner` / `EmptyState` / `VISNDT_COLORS` / `CHART_PALETTE`），**未**重复创建 Card 系统 / 状态映射 / 色值 Token。
