### 3.3 Backend Adaptation Note

为支持 Supplier Display 功能，后端进行了最小化适配：

1. **`SearchParamsDto`** 新增 `organizationId` 可选参数 — 非破坏性变更，所有现有调用者不受影响
2. **`OffersService.findAll`** 新增 `organizationId` where 过滤 — 仅当参数传入时生效
3. **`OrganizationsService.findOnePublic`** 扩展返回字段 — 新增 `status`/`createdAt`/`updatedAt`（公开信息，无敏感数据）

上述适配未新增 API 端点、未修改 Schema、未执行 Migration，属于现有 API 的增强。
