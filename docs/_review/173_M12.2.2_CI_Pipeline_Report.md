## 2. Workflow Structure

### 2.1 触发条件

| 事件 | 分支 |
|------|------|
| `push` | `main`, `develop` |
| `pull_request` | `main` |

### 2.2 执行环境

| 配置 | 值 |
|------|-----|
| Runner | `ubuntu-latest` |
| Node.js | `20.x` |
| pnpm | `9` |

### 2.3 Pipeline Steps

```
┌─────────────────────────────────┐
│ 1. Checkout                     │
│    actions/checkout@v4          │
├─────────────────────────────────┤
│ 2. Setup pnpm                   │
│    pnpm/action-setup@v4 (v9)   │
├─────────────────────────────────┤
│ 3. Setup Node.js                │
│    actions/setup-node@v4 (20.x) │
│    cache: 'pnpm'                │
├─────────────────────────────────┤
│ 4. Install dependencies         │
│    pnpm install --frozen-lockfile│
├─────────────────────────────────┤
│ 5. Generate Prisma Client       │
│    pnpm db:generate             │
├─────────────────────────────────┤
│ 6. Lint                         │
│    pnpm lint                    │
├─────────────────────────────────┤
│ 7. Build Backend                │
│    pnpm --filter @visndt/api build│
├─────────────────────────────────┤
│ 8. Build Frontend               │
│    pnpm --filter @visndt/admin build│
└─────────────────────────────────┘
```

## 4. Pipeline 设计原则

| 原则 | 实现 |
|------|------|
| 失败快速 | Step 失败立即终止 |
| 顺序执行 | 依赖链: Install → Lint → Build |
| 不自动部署 | 仅构建验证，不触发生产部署 |
| 分支保护 | 仅 main/develop + PR |
