## 3. Test Cases

### 3.1 Test 1: Basic Matching Flow

**场景：** 完整匹配流程 — 精确匹配 + 数值范围匹配

**测试数据：**
- Product: 镜头视向 = "直视", 管径 = 4mm (ACTIVE + Offer)
- Demand: 镜头视向 = "直视" (required, priority=3), 管径 = 3-6mm (required, priority=2)

**流程：**
```
POST /api/v1/demands/:id/publish
  → MatchingService.match(demandId)
    → 发现候选产品 (ACTIVE + Offer)
    → 精确匹配 镜头视向 = "直视" → score 100
    → 范围匹配 管径 4 ∈ [3, 6] → score 100
    → totalScore = 100
    → 创建 DemandMatch
```

**验证点：**
| # | 验证 | 预期 |
|---|------|------|
| 1 | Demand.status | PUBLISHED |
| 2 | DemandMatch 数量 | > 0 |
| 3 | matchScore | 100 |
| 4 | matchStatus | MATCHED |
| 5 | productId | 正确 |
