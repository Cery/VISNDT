## 4. Prisma Schema Change

新增枚举：

- `ContentType`：ARTICLE / KNOWLEDGE / SOLUTION / INSIGHT（MVP 使用前 3 项，INSIGHT 预留）
- `ContentStatus`：DRAFT / REVIEW / PUBLISHED / ARCHIVED

新增模型 `Content`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | String @id @db.Uuid | UUID 主键 |
| type | ContentType | 类型判别 |
| title | String | 标题 |
| slug | String @unique | 唯一路由/SEO |
| summary | String? | 摘要 |
| content | String | 正文 |
| coverImageId | String? @db.Uuid | 关联 FileAsset |
| status | ContentStatus @default(DRAFT) | 生命周期 |
| authorId | String @db.Uuid | 关联 User |
| publishedAt / archivedAt | DateTime? | 时间戳 |
| seoTitle / seoDescription / seoKeywords | String? | SEO 内联字段 |
| createdAt / updatedAt | DateTime | 审计时间戳 |

关系与索引：

- `author -> User`
- `coverImage -> FileAsset`
- `@@unique([slug])`、`@@index([type, status])`、`@@index([authorId])`、`@@index([status])`

## 6. Backend Module Structure

新增 `apps/api/src/content/`：

```
content/
  content.module.ts      # 模块声明（导入 AuthModule、WorkflowEventsModule）
  content.controller.ts  # Controller Skeleton（Admin 保护）
  content.service.ts     # Service 基础能力（CRUD + 生命周期 + 事件）
  dto/
    create-content.dto.ts
    update-content.dto.ts
    query-content.dto.ts
```

架构遵循：`Controller → Service → Domain Logic → Prisma Persistence → WorkflowEvent`。Controller 不直接访问 Prisma。

Service 能力：

- `findAll`（type/status 过滤 + 分页）
- `findOne` / `findBySlug`
- `create`（DRAFT，唯一 slug 校验）
- `update`（仅 DRAFT/REVIEW 可编辑）
- `submit` / `review` / `publish` / `archive`（状态迁移 + 校验）
- 每次状态操作通过 `WorkflowEventsService` 写入 `WorkflowEvent`（entityType=CONTENT）
