## API Changes

### New Endpoints (5)

| Method | Path | Auth | Purpose |
|--------|------|------|---------|
| `GET` | `/notifications` | JWT | List notifications (paginated, filterable by status/type) |
| `GET` | `/notifications/:id` | JWT | Get single notification |
| `PATCH` | `/notifications/:id/read` | JWT | Mark single notification as read |
| `PATCH` | `/notifications/read-all` | JWT | Mark all notifications as read (scoped) |
| `GET` | `/notifications/unread-count` | JWT | Get unread count (scoped) |

### Endpoint Details

#### GET /notifications

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `page` | number | No | 1 | Page number (1-based) |
| `pageSize` | number | No | 20 | Items per page (1-100) |
| `status` | NotificationStatus | No | — | Filter by READ/UNREAD |
| `type` | NotificationType | No | — | Filter by SYSTEM/DEMAND_UPDATE/RFQ_UPDATE/RESPONSE_UPDATE |

Response: `{ data: Notification[], total, page, pageSize, totalPages }`

#### GET /notifications/unread-count

Response: `{ count: number }`

#### PATCH /notifications/read-all

Response: `{ updatedCount: number }`

## Security Audit

### Authentication

| Check | Implementation |
|-------|---------------|
| JWT Authentication | `@UseGuards(JwtAuthGuard)` on controller class |
| Bearer Token | `@ApiBearerAuth()` on controller class |
| User extraction | `@CurrentUser()` → `AuthRequest['user']` |
| No client-controlled userId | All scoping from JWT payload |

### Authorization Model

| Role | Scope | Implementation |
|------|-------|---------------|
| **ADMIN** | All notifications in user's organization | `Notification.user.organizationId === currentUser.organizationId` |
| **MEMBER** | Own notifications only | `Notification.userId === currentUser.id` |

### Access Control Implementation

```typescript
// Service-level: getAccessScope() determines filter
// ADMIN: { organizationId: requestUser.organizationId }
// MEMBER: { userId: requestUser.id }

// Controller-level: no @Roles() decorator needed
// All access control is in service layer via getAccessScope()
```

### Security Rules Applied

| Rule | Status |
|------|--------|
| `userId` always from JWT | ✅ `@CurrentUser()` decorator |
| No client `userId` in request body/params | ✅ DTOs have no userId field |
| Single notification access validated | ✅ `validateAccess()` checks ownership + org |
| Admin org-scoped, not global | ✅ Filter by `organizationId` |
| No cross-org access | ✅ Service-level where clause |
