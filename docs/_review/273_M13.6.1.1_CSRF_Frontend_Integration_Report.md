## 5. Implementation Details

### 5.1 `apps/web/src/lib/csrf.ts` (NEW)

| Function | Behavior |
|----------|----------|
| `getCsrfToken()` | Returns cached token or fetches from `GET /auth/csrf` |
| `clearCsrfToken()` | Clears memory cache (called on logout) |

**Security properties:**
- ✅ Token stored in **memory only** (closure variable)
- ✅ NOT in `localStorage` — immune to XSS exfiltration
- ✅ NOT in `sessionStorage` — cleaned on tab close
- ✅ Concurrent call deduplication (no double fetch)
- ✅ Error recovery (reset on failure, retry on next call)

### 5.2 `apps/web/src/lib/api-client.ts` Changes

| Addition | Detail |
|----------|--------|
| `CSRF_METHODS` | `Set(['POST', 'PUT', 'PATCH', 'DELETE'])` |
| `CSRF_EXCLUDED_PATHS` | `Set([REFRESH_PATH, '/auth/login', '/auth/register', '/auth/csrf'])` |
| CSRF injection | Before `fetch()`, checks method + endpoint → attaches `X-CSRF-Token` |
| Error handling | CSRF token fetch failure → proceed without token (backend rejects with 403) |

**Preserved features:**
- ✅ `credentials: 'include'` — all 3 fetch calls
- ✅ 401 auto-refresh + retry — untouched
- ✅ Refresh deduplication — untouched
- ✅ `ApiError` handling — untouched
- ✅ `params` serialization — untouched

### 5.3 `apps/web/src/auth/AuthProvider.tsx` Changes

| Change | Detail |
|--------|--------|
| Import | `clearCsrfToken` from `@/lib/csrf` |
| `logout()` | Added `clearCsrfToken()` call before `setUser(null)` |
