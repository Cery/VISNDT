## 5. ErrorState Consolidation Result

目标达成（621 B2 错误态一致性收敛）：

```text
Before:  API 错误直接展示（散落内联错误块）
After:   统一 ErrorState（Error Message + Retry + Navigation）
```

- 增强了 `components/common/ErrorState.tsx`，新增可选 `action` 兜底导航入口（`{ label, href }`），配合 `onRetry` 重试形成「错误提示 + 重试 + 兜底导航」完整链路。
- `/search/SearchPageContent.tsx` 内联错误块收敛为统一 ErrorState：

```tsx
<ErrorState
  message="搜索服务暂不可用，请稍后重试。"
  onRetry={handleRetry}
  action={{ label: '浏览产品分类', href: '/products' }}
/>
```

覆盖：search / workspace / dashboard 均使用统一 `ErrorState` / `Loading` 状态组件。

## 6. Error Boundary Result

目标达成（621 B3 页面级错误边界补齐）：

为以下重点页面新增 Next.js App Router 规范错误边界（`loading.tsx` + `error.tsx`）：

```text
app/login
app/register
app/workspace
app/dashboard（buyer / supplier 共用）
```

规范与复用：

```text
loading.tsx → 统一 Loading 组件
error.tsx   → 共享 PageErrorBoundary 组件
```

- 新增共享 `PageErrorBoundary.tsx`（`'use client'`），统一 error.tsx 排版，满足 Next.js error boundary 规范：
  - **Error Context**（错误上下文：标题 + 错误说明）
  - **Retry Action**（重试按钮 → `reset()`）
  - **Back Navigation**（返回导航 → 首页 / 指定 href）
  - **Brand Consistency**（品牌化按钮渐变 + 工业色）
- **不改变 Auth Flow / RBAC / Route Structure**：login/register/workspace/dashboard 的页面主体、守卫逻辑（AuthGuard / RoleGuard）原样保留。
