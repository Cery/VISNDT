## 1. Task Summary

**Objective**: 增强 Product Detail 页面 Inquiry 入口的上下文展示能力，在用户进入询价流程前明确展示当前咨询对象。

**Before**:
```
Product Detail
  ↓
Suppliers Tab → Select Supplier → InquiryForm（"提交询价"）
```

**After**:
```
Product Detail
  ↓
Suppliers Tab → Select Supplier
  ↓
ProductInquiryContext（您正在咨询：产品名称 + 型号 + 分类 + 引导说明）
  ↓
InquiryForm（"咨询此设备"）
```

**Scope**: Frontend Only — 1 新增组件 + 3 文件修改，零 Schema/API/Migration 变更。

## 3. ProductInquiryContext Component Design

### 3.1 Props

```typescript
interface ProductInquiryContextProps {
  productName: string;
  model?: string | null;
  category?: string | null;
}
```

### 3.2 Display

```
您正在咨询：
[产品名称]
型号：[model]    分类：[category]
我们将根据该设备信息帮助您匹配检测需求。
```

### 3.3 Visual Design

- 渐变背景（primary/5 → primary/0.02）+ 主色边框
- 产品名称使用 `font-semibold` 突出显示
- 型号使用 `font-mono` 等宽字体
- 引导说明使用 `text-xs text-slate-400` 低调展示
