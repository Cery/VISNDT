### 4.2 ProductDetail Page Analysis

The existing ProductDetail page (`ProductDetail.tsx`, 180 lines) contains:

| Card | Content | Data Source |
|------|---------|------------|
| **Basic Information** | Name, Model, Category, Status, Created At, Updated At, Description | `productService.getById()` — `category` relation |
