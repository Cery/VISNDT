## 4. D2 Verification — Product Parameter Edit

## 5. D3 Verification — Product Media Runtime Crash

- **Root Cause**：后端 `GET /products/:productId/media` 经 ApiResponse 返回**原始数组**，前端类型期待分页对象 `{data,total}`，导致 `undefined.length` 运行时崩溃。
- **Fix**：
  - `product-media.types.ts`：`ProductMediaListResponse = ProductMediaItem[]`（一维数组，注释说明非分页）。
  - `product-media.service.ts`：返回类型对齐一维数组。
  - `ProductMediaList.tsx`：用 `result.length` 判空（空态而非报错），`mediaStats` 统计移至分支外（空安全）。
- **Verify**：浏览器进入产品媒体页 → 正常渲染「产品媒体」标题与媒体列表 / 空态，**无 `undefined.length` 崩溃**。
- **禁止范围**：未修改 FileAsset Schema、未新增 Media Model；Media Contract 保持。

**结果：FIXED** ✅
