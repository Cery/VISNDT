## Content Model Implementation Summary

### Schema Changes

| Change | Detail |
| --- | --- |
| Content.estimatedReadTime | `Int?` — Auto-calculated reading time in minutes |
| @@index([status, publishedAt]) | Composite index for efficient public content queries |

**estimatedReadTime Calculation:**
- Blended approach: Chinese characters (~400/min) + English words (~200/min)
- Formula: `max(1, ceil((charCount + wordCount) / 500))`
- Minimum value: 1 minute
- Auto-calculated on create and update (when content body changes)

### Migration Changes

| Migration | Detail |
| --- | --- |
| 012_content_model_enhancement | `ALTER TABLE "content" ADD COLUMN "estimated_read_time" INTEGER` + `CREATE INDEX "content_status_published_at_idx"` |
