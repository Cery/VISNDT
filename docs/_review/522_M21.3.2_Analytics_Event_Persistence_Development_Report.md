### 4.2 ConversionEvent Model

```prisma
model ConversionEvent {
  id             String               @id @default(uuid()) @db.Uuid
  event          ConversionEventType
  userId         String?              @map("user_id") @db.Uuid
  organizationId String?              @map("organization_id") @db.Uuid
  sessionId      String?              @map("session_id")
  entityType     String?              @map("entity_type")
  entityId       String?              @map("entity_id") @db.Uuid
  source         String?
  metadata       Json?                @db.JsonB
  createdAt      DateTime             @default(now()) @map("created_at")

  @@index([event])
  @@index([userId])
  @@index([organizationId])
  @@index([sessionId])
  @@index([entityType, entityId])
  @@index([createdAt])
  @@index([event, createdAt])
  @@map("conversion_event")
}
```

## 5. API Changes

### 5.1 New Endpoint

```
POST /api/analytics/events
```

**Request Format:**
```json
{
  "events": [
    {
      "event": "PAGE_VIEW",
      "userId": "optional-uuid",
      "organizationId": "optional-uuid",
      "sessionId": "optional-string",
      "entityType": "optional-string",
      "entityId": "optional-uuid",
      "source": "optional-string",
      "metadata": {}
    }
  ]
}
```

**Response Format:**
```json
{
  "accepted": 5,
  "rejected": 0
}
```

**Constraints:**
- Anonymous allowed (userId/orgId optional)
- Batch write only (no GET endpoints)
- Fire-and-forget: failed events silently dropped
