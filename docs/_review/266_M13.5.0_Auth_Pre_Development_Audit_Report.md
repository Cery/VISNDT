### 3.2 Login Flow

```
POST /auth/login
    │
    ▼
AuthController.login(LoginDto)
    │
    ▼
AuthService.login(dto)
    │
    ├─ prisma.user.findUnique({ email })
    │   └─ 404 → UnauthorizedException
    │
    ├─ bcrypt.compare(password, passwordHash)
    │   └─ false → UnauthorizedException
    │
    ├─ generateToken(JwtPayload)
    │   └─ jwtService.sign({ sub, email, name, organizationId })
    │
    └─ Response: { accessToken, user: { id, email, name, organizationId } }
```

**Rate Limiting:** 5 requests per 60 seconds (`@Throttle`)

### 3.3 Register Flow

```
POST /auth/register
    │
    ▼
AuthController.register(RegisterDto)
    │
    ▼
AuthService.register(dto)
    │
    ├─ Validate inviteToken (required)
    │   └─ Invalid/expired → UnauthorizedException
    │
    ├─ Verify email matches invitation
    │   └─ Mismatch → UnauthorizedException
    │
    ├─ Check email uniqueness
    │   └─ Duplicate → ConflictException
    │
    ├─ bcrypt.hash(password, 10)
    │
    ├─ prisma.user.create({ email, passwordHash, name, organizationId })
    │
    ├─ prisma.organizationMember.create({ organizationId, userId, role })
    │
    ├─ Consume invitation (mark as USED)
    │
    └─ Response: { accessToken, user: { id, email, name, organizationId } }
```

**Note:** Registration is **invite-only**. No public registration.

|-----------|--------|-------|

| `expiresIn` | `JWT_EXPIRES_IN` env var | **⚠️ NOT DEFINED in `.env`** (default: 86400s = 24h) |

## 9. Security Risk Assessment

### 🔴 Critical

| # | Risk | Detail |
|---|------|--------|
| 1 | **JWT_SECRET missing** | `apps/api/.env` does not define `JWT_SECRET`. Application will fail or use undefined secret. |
| 2 | **XSS → Token theft** | JWT in `localStorage` is readable by any JS on the page. XSS attack = full account takeover. |
| 3 | **No token revocation** | Once issued, JWT is valid for 24h. Cannot revoke compromised tokens. |

### 🟠 High

| # | Risk | Detail |
|---|------|--------|
| 4 | **No RefreshToken** | Long-lived access token (24h). No way to rotate credentials. |
| 5 | **No 401 handling** | Expired tokens cause silent failures. No auto-logout or redirect. |
| 6 | **Logout is client-only** | "Logout" only clears localStorage. Token remains valid on server. |

### 🟡 Medium

| # | Risk | Detail |
|---|------|--------|
| 7 | **No password reset** | Users cannot reset forgotten passwords. |
| 8 | **RoleGuard incomplete** | Frontend RoleGuard hardcoded to `BUYER`. Backend RolesGuard is functional. |
| 9 | **No CSRF protection** | JWT in Bearer header is CSRF-safe, but cookie migration would need CSRF tokens. |

### 🟢 Low

| # | Risk | Detail |
|---|------|--------|
| 10 | **Rate limiting on login** | 5 req/min per endpoint — acceptable but could be more granular. |
| 11 | **Password min length** | 8 chars — acceptable minimum. |
