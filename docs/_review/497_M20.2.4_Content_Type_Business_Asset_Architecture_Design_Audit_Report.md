## 2. Current Content Architecture Review

### 2.1 Content Model (schema.prisma verified)

```
Content {
  id, type (ARTICLE|KNOWLEDGE|SOLUTION|INSIGHT), title, slug (unique),
  summary, content (Markdown), coverImageId (→ FileAsset),
  status (DRAFT|REVIEW|PUBLISHED|ARCHIVED), authorId (→ User),
  publishedAt, archivedAt, scheduledPublishAt,
  seoTitle, seoDescription, seoKeywords,
  createdAt, updatedAt,
  author, coverImage, media (ContentMedia[]), revisions (ContentRevision[]),
  tags (ContentTagRelation[])
}
```

**Indexes:** `@@index([type, status])`, `@@index([authorId])`, `@@index([status])`, `@@index([status, scheduledPublishAt])`

### 2.2 ContentType Enum

| Type | 定义 | 前端路由 | 状态 |
|------|------|----------|------|
| `ARTICLE` | 通用文章 | 无 | 仅定义，无公开页面 |
| `KNOWLEDGE` | 技术知识 | `/knowledge` + `/knowledge/[slug]` | 完整实现 |
| `SOLUTION` | 行业解决方案 | `/solutions` + `/solutions/[slug]` | 完整实现 |
| `INSIGHT` | 参数百科/行业洞察 | 无 | 仅定义，无公开页面 |

### 2.3 ContentTag & ContentTagRelation (M20.2.3)

```
ContentTag {
  id, name, slug (unique), type (TOPIC|INDUSTRY|APPLICATION|TECHNOLOGY),
  description, createdAt, updatedAt,
  relations (ContentTagRelation[])
}

ContentTagRelation {
  id, contentId (→ Content, Cascade), tagId (→ ContentTag, Cascade),
  createdAt,
  @@unique([contentId, tagId])
}
```

**API:**
- Public: `GET /content/tags`, `GET /content/tags/:slug`
- Admin: `POST/PATCH/DELETE /content/tags/:id`, `POST/DELETE /content/:id/tags/:tagId`, `GET /content/:id/tags`
- Content Filter: `GET /content/public?tag={slug}` (combined with `keyword` & `type`)

**Frontend:**
- Admin: 标签管理 CRUD (ContentTagList, ContentTagCreate, ContentTagEdit)
- Web: `/tags/[slug]` 标签聚合页 (dynamic metadata, content list)

### 2.4 Content Supporting Modules

|--------|------|--------|
| Content | `apps/api/src/content/` | Mature (12 ADMIN + 2 Public endpoints) |

## 3. Content Type Capability Analysis

### 3.1 ARTICLE (通用文章)

| 维度 | 评估 |
|------|------|
| **商业目的** | 企业品牌宣传、行业动态、技术趋势、公司新闻 |
| **用户价值** | 了解公司动态、行业趋势、建立信任 |
| **SEO价值** | 高 — 品牌词、行业词、长尾词覆盖 |
| **当前状态** | 类型已定义，无公开路由 (`/articles` 不存在) |
| **当前映射** | 无 — `/business` 和 `/about` 是静态硬编码页面 |
| **建议方向** | 将 `/business` 和 `/about` 迁移至 ARTICLE 类型，动态化管理 |

### 3.2 KNOWLEDGE (技术知识)

| 维度 | 评估 |
|------|------|
| **商业目的** | 技术权威建设、专业能力展示、知识沉淀 |
| **用户价值** | 获取检测技术知识、设备选型参考、行业标准理解 |
| **SEO价值** | 极高 — 技术长尾词、检测方法词、设备参数词 |
| **当前状态** | 完整实现：`/knowledge` 列表 + `/knowledge/[slug]` 详情 |
| **当前能力** | SEO (OpenGraph + JSON-LD Article), Markdown 渲染, MediaGallery (ContentMedia), 标签筛选 |
| **建议方向** | 增加跨内容推荐 (Related Content), 产品关联入口 |

### 3.3 SOLUTION (行业解决方案)

| 维度 | 评估 |
|------|------|
| **商业目的** | 行业场景覆盖、解决方案展示、业务转化 |
| **用户价值** | 了解行业检测方案、对比不同方案、获取业务咨询 |
| **SEO价值** | 高 — 行业场景词、解决方案词、应用场景词 |
| **当前状态** | 完整实现：`/solutions` 列表 + `/solutions/[slug]` 详情 |
| **当前能力** | SEO (OpenGraph + JSON-LD TechArticle), Markdown 渲染, 标签筛选 |
| **建议方向** | 增加产品关联 (检测方案 → 设备), 应用场景关联 |

### 3.4 INSIGHT (参数百科/行业洞察)

| 维度 | 评估 |
|------|------|
| **商业目的** | 深度行业分析、参数解读、数据洞察 |
| **用户价值** | 理解检测参数含义、行业数据参考、深度研究 |
| **SEO价值** | 中等 — 参数词、行业数据词、专业术语 |
| **当前状态** | 类型已定义，无公开路由 (`/insights` 不存在) |
| **当前映射** | 无 — 无任何公开页面 |
| **建议方向** | 新增 `/insights` 列表 + `/insights/[slug]` 详情 (复用 KNOWLEDGE 模板) |

## 4. Business Asset Capability Gap Analysis

### 4.1 Current State: Content → User

```
Content (KNOWLEDGE/SOLUTION) → Static SEO Page → User
/business                       → Static HTML       → User
/about                          → Static HTML       → User
```

**问题：**
- `/business` 和 `/about` 是硬编码静态页面，无法通过 Content 系统管理
- 每次内容更新需要代码修改 → 部署
- 无版本管理、无审核流程、无 SEO 动态控制
- 与 KNOWLEDGE/SOLUTION 的内容管理体系割裂

### 4.2 Gap: Business Asset Not Content-Managed

| 当前页面 | 内容类型 | 管理方式 | 建议 |
|----------|----------|----------|------|
| `/business` | 企业介绍、行业案例、资质展示 | 静态硬编码 | → ARTICLE 类型，动态管理 |
| `/about` | 公司介绍、团队、愿景 | 静态硬编码 | → ARTICLE 类型，动态管理 |
| (无) | 行业洞察、参数百科 | 无 | → INSIGHT 类型，新建路由 |

### 4.3 Gap: Content-to-Entity Relationship Missing

| 关联方向 | 当前状态 | 业务价值 |
|----------|----------|----------|
| Content → Product | 无关联 | 技术文章引用检测设备，提升转化 |
| Content → Category | 无关联 | 行业方案关联产品分类 |
| Content → Application Scenario | 无关联 | 解决方案对应检测场景 |
| Content → Industry | 通过 ContentTag (INDUSTRY) | 已实现 (M20.2.3) |
| Content → Content | 无关联 | 相关文章推荐，增加停留时间 |

### 4.4 Gap: Content Recommendation Missing

| 能力 | 当前状态 | 优先级 |
|------|----------|--------|
| 同类型相关推荐 | 无 | 高 |
| 同标签相关推荐 | 无 | 高 |
| 产品关联推荐 | 无 | 中 |
| AI 智能推荐 | 无 (Future Candidate) | 低 |
