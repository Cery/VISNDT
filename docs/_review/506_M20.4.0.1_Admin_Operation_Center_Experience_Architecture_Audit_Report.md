## 5. Key UX Gaps

### 5.1 Navigation & Layout Gaps (P0)

| Gap | Impact | Fix |
|-----|--------|-----|
| No Breadcrumb | Cannot navigate deeply nested pages | Add Ant Design Breadcrumb to AdminLayout |
| No Multi-tab | Cannot switch between tasks | Add tab-based page management |
| No User Info in Header | Cannot identify logged-in user | Add Avatar + Dropdown (logout) |
| No Global Search | Cannot quickly find entities | Add Command Palette or search bar |
| 15-item Flat Menu | Hard to scan | Group into sections (核心运营/内容管理/系统管理) |

### 5.2 Table Experience Gaps (P0)

| Gap | Impact | Fix |
|-----|--------|-----|
| No Fixed Columns | Actions column scrolls out of view | Set `fixed: 'right'` on actions column |
| No Column Config | Cannot customize visible columns | Add column visibility dropdown |
| No Horizontal Scroll | Wide tables break on smaller screens | Add `scroll={{ x: 'max-content' }}` |
| No Card View Alternative | Tables unusable on mobile | Add Card List view for mobile |

### 5.3 Mobile Experience Gaps (P1)

| Gap | Impact | Fix |
|-----|--------|-----|
| No Mobile Layout | Admin unusable on phone | Responsive layout: auto-collapse sidebar, drawer menu |
| No Mobile Table | Cannot view data on phone | Card List component for mobile lists |
| No Mobile Filters | Filters fill screen | Collapsible filter panel |
| No Mobile Navigation | Cannot navigate | Bottom tab bar or hamburger menu |

### 5.4 Operation Center Gaps (P1)

| Gap | Impact | Fix |
|-----|--------|-----|
| No Charts | Cannot visualize trends | Add chart library (recharts, @ant-design/charts) |
| No Funnel View | Cannot trace commercial pipeline | Add cross-entity aggregation view |
| No Export | Cannot download data | Add Excel export buttons |
| No Real-time Updates | Stale data | Add polling or WebSocket for dashboard |
