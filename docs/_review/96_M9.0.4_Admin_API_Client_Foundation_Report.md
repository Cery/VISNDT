## 4. API Client Architecture

### 4.1 Axios Instance Configuration

```
src/api/client.ts
  ├── baseURL: '/api/v1'
  ├── timeout: 10000ms
  ├── headers: { Content-Type: application/json }
  ├── Response interceptor: unwrap response.data
  └── Request interceptor: reserved placeholder
```

### 4.2 Interceptor Pipeline

```
Request → [request interceptor (reserved)] → Backend → [response interceptor (unwrap)] → Caller
```

| Stage | Handler | Status |
|-------|---------|:---:|
| Request | Placeholder — no Authorization header yet | Reserved |
| Response success | Return `response.data` (unwraps axios envelope) | Active |
| Response error | `Promise.reject(error)` | Active |

### 4.3 API Directory Structure

```
src/api/
├── client.ts    # Axios instance + interceptors
└── index.ts     # Barrel export
```

### 4.4 Type Definitions

```typescript
// src/types/api.ts
export interface ApiResponse<T> {
  data: T;
  message?: string;
}
```

Matches the backend response format:
```json
{
  "success": true,
  "message": "...",
  "data": { ... }
}
```
