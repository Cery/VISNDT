## 3. 测试环境与执行说明

- Web 启动方式：`pnpm.cmd --filter @visndt/web dev`
- Web 访问结果：`http://localhost:3000/login` 可访问，返回 `200`
- API 健康检查：
  - 检查地址：`http://localhost:4000/api/v1/health`
  - 结果：**不可访问**
  - 现象：`无法连接到远程服务器`

浏览器人工验证期间观察到：

- 访问 Supplier 目标路由时，页面模块可命中并开始加载
- 前端会先请求 `GET /auth/me`
- 由于本地 API 不可达，`GET http://localhost:4000/api/v1/auth/me` 返回 `net::ERR_CONNECTION_REFUSED`
- 随后页面回落到 `/login`
- 在登录页提交表单时，`POST http://localhost:4000/api/v1/auth/login` 同样返回 `net::ERR_CONNECTION_REFUSED`

结论：

- 本次环境下，Supplier Workspace 人工主流程被 **本地 API 不可达** 阻断
- 因无法建立有效登录态，后续 Supplier 页面业务请求无法进入正常验证阶段
