**Knowledge Service** (`apps/api/src/knowledge/knowledge.service.ts`):
- `findAllEntries()`: 多条件筛选（domainId/categoryId/status/search）+ 关联查询（domain/category/author/_count）
- `createEntry()`: Slug 唯一性校验 + Domain/Category 存在性校验
- `updateEntry()`: 支持部分更新 + status 转换
- `findAllContentRefs()`: knowledgeId 可选筛选 + 关联查询
- `createContentRef()`: Cascade Delete 支持
- `findAllRelations()`: knowledgeId 可选筛选（source OR target）+ 关联查询
