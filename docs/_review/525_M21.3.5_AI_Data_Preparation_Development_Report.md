## 6. Architecture Decisions

### 6.1 Vector Storage

- **Decision**: PostgreSQL + pgvector (not external Vector DB)
- **Rationale**: Keep infrastructure simple, avoid introducing new services
- **Dimension**: 1536 (OpenAI text-embedding-3-small compatible)

### 6.2 Embedding Provider

- **Decision**: OpenAI text-embedding-3-small (abstracted via interface)
- **Fallback**: If OPENAI_API_KEY not configured, provider reports unavailable; no hardcoded keys
- **Future**: Interface allows swapping to other providers without code changes

### 6.3 Prisma Vector Handling

- **Decision**: Use `Unsupported("vector(1536)")` in schema + `$executeRawUnsafe` for vector operations
- **Rationale**: Prisma does not natively support vector type; raw SQL is the only safe approach

### 6.4 Content Chunking Strategy

- **Decision**: Paragraph-based chunking with max 1000 chars per chunk, merging short paragraphs
- **Rationale**: Simple, deterministic, suitable for RAG preparation; no external NLP dependency
