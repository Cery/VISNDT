## 2. Schema Change Summary

### 2.1 新增 Enum
- **`SupplierProductStatus`**：`DRAFT / SUBMITTED / REVIEWING / APPROVED / PUBLISHED / REJECTED`（SupplierProduct 生命周期）。

### 2.2 扩展 Enum
- **`FileEntityType`**：在现有 `PRODUCT / ORGANIZATION / DEMAND / RFQ / RFQ_RESPONSE / CONTENT` 末尾新增 `SUPPLIER_PRODUCT`（供应商型号 FileAsset 归属）。

### 2.3 新增 Model（3 个）

**`SupplierProduct`（supplier_product）**
- Identity：`id`、`organizationId`、`platformProductId`
- Product Identity：`brand`、`series?`、`modelNumber`、`slug? (unique)`
- Content：`description?`、`technicalDescription?`、`applicationInfo?`
- Governance：`status (SupplierProductStatus default DRAFT)`、`submittedAt?`、`reviewedAt?`、`reviewedBy?`、`reviewedNote?`、`publishedAt?`
- Relations：`organization` / `platformProduct` / `reviewedByUser` / `parameterValues` / `media` / `offers`
- Constraints：`@@unique([organizationId, platformProductId, modelNumber])`
- Indexes：`organizationId`、`platformProductId`、`modelNumber`、`status`
- FK：`platformProductId → Product` **`onDelete: Restrict`**

**`SupplierProductMedia`（supplier_product_media）**
- 关联：`supplierProductId`、`fileAssetId?`
- 字段：`mediaType(FileType)`、`documentType?`、`title?`、`altText?`、`isPrimary(default false)`、`displayOrder(default 0)`
- Relations：`supplierProduct`（Cascade）、`fileAsset?`
- Indexes：`supplierProductId`、`fileAssetId`

**`SupplierProductParameterValue`（supplier_product_parameter_value）**
- 字段：`supplierProductId`、`parameterDefinitionId`、`value`、`valueNumber?`
- Relations：`supplierProduct`（Cascade）、`parameterDefinition`
- Constraint：`@@unique([supplierProductId, parameterDefinitionId])`
- Index：`parameterDefinitionId`

### 2.4 扩展既有 Model — `Offer`
- 新增标量：`supplierProductId String?` @map(supplier_product_id)
- 新增 Relation：`supplierProduct SupplierProduct?` **`onDelete: Restrict`**
- 新增 Index：`@@index([supplierProductId])`
- 保留：`@@unique([organizationId, productId])`、`@@index([productId])`、`@@index([status])`

### 2.5 反向 Relation（纯 Prisma 关系字段，不产生 DB 列）
- `Organization.supplierProducts[]`
- `Product.supplierProducts[]`
- `User.reviewedSupplierProducts[] @relation("SupplierProductReviewer")`
- `FileAsset.supplierProductMedia[]`
- `ParameterDefinition.supplierProductValues[]`

## 4. Relation Map（最终架构）

```
Product (Platform Capability Node)
   1 ───────── N
SupplierProduct (organizationId + platformProductId)
   1 ───────── N
Offer (productId 能力聚合 + supplierProductId? 商业源)
   N ───────── 1
Organization
```

- SupplierProduct → Organization：Organization ownership（SupplierProduct.organizationId FK）
- SupplierProduct → Product：Platform Capability（onDelete Restrict）
- Offer → SupplierProduct：双绑商业源（可空，onDelete Restrict），保留 `@@unique([organizationId, productId])`
- Media：`SupplierProductMedia`（supplierProduct Cascade + FileAsset?）
- Parameter：`SupplierProductParameterValue`（supplierProduct Cascade + parameterDefinition）
