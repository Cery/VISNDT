## 3. Schema Changes

### 3.1 DemandStatus 枚举

```diff
 enum DemandStatus {
   DRAFT
+  PUBLISHED
   SUBMITTED
   PROCESSING
   CLOSED
   CANCELLED
 }
```

**状态流转扩展：**

```
                    ┌─────────────┐
                    │    DRAFT    │  ← 创建初始状态
                    └──────┬──────┘
                           │ publish()
                    ┌──────▼──────┐
                    │  PUBLISHED  │  ← 新增：发布后供应商可见
                    └──────┬──────┘
                           │ createRFQ()
                    ┌──────▼──────┐
                    │  SUBMITTED  │  ← 保留：进入询价流程
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │ PROCESSING  │  ← 询价进行中
                    └──────┬──────┘
                      ╱         ╲
                     ╱           ╲
           ┌──────▼──────┐   ┌────▼──────┐
           │   CLOSED    │   │ CANCELLED  │  ← 终态
           └─────────────┘   └───────────┘
```
