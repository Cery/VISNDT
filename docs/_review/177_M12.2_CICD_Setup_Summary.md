```

├── Trigger: push (main, develop) + pull_request (main)
├── Runner: ubuntu-latest
├── Node.js: 20.x
├── pnpm: 9
└── Steps:
```

## 4. Deployment Preparation

### 4.1 部署流程

```
1. 配置环境变量 (.env)
   ↓
2. pnpm install --frozen-lockfile
   ↓
3. pnpm db:generate
   ↓
4. prisma migrate deploy
   ↓
5. pnpm --filter @visndt/api build
   ↓
6. pnpm --filter @visndt/admin build
   ↓
7. node apps/api/dist/main
   ↓
8. Nginx serve apps/admin/dist/
```

### 4.2 一键部署

```bash
# Windows
scripts\deploy.bat
```
