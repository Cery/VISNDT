## 3. API Changes

### 3.1 端点总览

```
GET    /demands       → findAll()      [Public]    列表所有 Demand
GET    /demands/my    → findMy()       [JWT]       我的组织 Demand
GET    /demands/:id   → findOne()      [Public]    Demand 详情（含联系方式保护）
POST   /demands       → create()       [JWT]       创建 Demand
PATCH  /demands/:id   → update()       [JWT]       更新 Demand（所有者/同组织）
```

### 3.2 POST /demands — 创建

**认证：** JwtAuthGuard (+ @ApiBearerAuth)

**请求体：**

```typescript
{
  title: string;                    // 必填
  description?: string;             // 可选
  budgetRange?: string;             // 可选
  quantity?: number;                // 可选
  quantityUnit?: string;            // 可选
  expectedDeliveryDate?: string;    // 可选 (ISO 8601)
  contactName?: string;             // 可选
  contactPhone?: string;            // 可选
  contactEmail?: string;            // 可选
  contactVisible?: boolean;         // 可选，默认 false
}
```

**禁止客户端提交的字段：**
- `createdBy` → 从 JWT `user.id` 获取
- `organizationId` → 从 JWT `user.organizationId` 获取
- `status` → 默认 `DRAFT`

**安全规则：**
- 用户必须属于一个 Organization
- 无组织用户 → 400 Bad Request

### 3.3 GET /demands/my — 我的列表

**认证：** JwtAuthGuard (+ @ApiBearerAuth)

**查询参数：** `page`, `pageSize`（PaginationDto）

**响应：**

```typescript
{
  data: Demand[];        // 包含 organization, createdByUser, parameters
  total: number;
  page: number;
  pageSize: number;
  totalPages: number;
}
```

**安全规则：**
- 仅返回 `user.organizationId` 的 Demand
- 按 `createdAt` 降序

### 3.4 GET /demands/:id — 详情

**认证：** 无（Public）

**Include：**
- `organization`
- `createdByUser`
- `parameters` + `parameterDefinition`
- `matches` + `product` + `category`

**联系方式保护：**

```typescript
// contactVisible = false 时
{
  contactName: "张三",         // ✅ 可见
  contactPhone: "***",         // 🔒 脱敏
  contactEmail: "***",         // 🔒 脱敏
}

// contactVisible = true 时
{
  contactName: "张三",         // ✅ 可见
  contactPhone: "138xxxx1234", // ✅ 可见
  contactEmail: "a@b.com",    // ✅ 可见
}
```

### 3.5 PATCH /demands/:id — 更新

**认证：** JwtAuthGuard (+ @ApiBearerAuth)

**权限模型变更：**

| | 旧 (M7.4 之前) | 新 (M7.5.1) |
|---|---|---|
| Guard | ADMIN + RolesGuard | JwtAuthGuard |
| 权限范围 | 仅 ADMIN | 创建者 或 同组织成员 |
| 终态阻止 | ❌ 无 | ✅ CLOSED / CANCELLED 禁止修改 |

**安全规则：**
1. 用户必须属于一个 Organization
2. `demand.createdBy === user.id` 或 `demand.organizationId === user.organizationId`
3. `demand.status ∈ {CLOSED, CANCELLED}` → 400 Bad Request

**请求体：**

```typescript
{
  title?: string;
  description?: string;
  status?: DemandStatus;          // 可手动变更状态
  budgetRange?: string;
  quantity?: number;
  quantityUnit?: string;
  expectedDeliveryDate?: string;
  contactName?: string;
  contactPhone?: string;
  contactEmail?: string;
  contactVisible?: boolean;
}
```

## 4. Security Impact

### 4.1 安全改进

| 改进项 | 说明 | 严重程度 |
|--------|------|----------|
| 身份注入防护 | `createdBy` / `organizationId` 从 JWT 提取，客户端不可提交 | 🔴 Critical |
| 所有权验证 | 仅创建者或同组织成员可更新 Demand | 🟡 High |
| 终态阻止 | CLOSED / CANCELLED 状态 Demand 不可修改 | 🟡 High |
| 联系方式保护 | `contactVisible=false` 时手机号/邮箱脱敏为 `***` | 🟡 High |
| 组织隔离 | `GET /my` 仅返回本组织数据 | 🟡 High |
| 写操作认证 | 所有写端点 + `GET /my` 均添加 JwtAuthGuard | 🟡 High |

### 4.2 安全对比

| 检查项 | 旧实现 | 新实现 |

| POST 身份来源 | JWT ✅ | JWT ✅ |
| PATCH 身份来源 | JWT ✅ | JWT ✅ |
| PATCH 权限验证 | ADMIN only | Owner/Org-scoped |
| PATCH 终态阻止 | ❌ | ✅ |
| GET /my 组织隔离 | ❌ 不存在 | ✅ |
| 联系方式保护 | ❌ | ✅ |
