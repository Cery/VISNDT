## 4. Experience Requirement Summary

本章为契约正文，定义 612 / 613 的逐项执行标准。

### 4.1 Web Platform UI Upgrade

目标：`Industrial Product Website → Industrial Capability Discovery Platform`。

**首页（`/`）**：

- **Hero 完全保留（锚点，禁止改动）**：文案「工业检测解决方案平台 / 工业无损检测 产品与技术方案 一站式平台」，CTA「浏览产品 / 探索解决方案 / 提交需求」，双角色入口「我是检测需求方 / 我是能力提供商」。
- Hero 后章节按能力发现叙事重排：

```
Hero → 工业检测能力分类 → 热门检测设备 → 行业解决方案 → 平台撮合流程 → 知识中心入口 → 能力提供商展示 → 需求入口
```

**产品中心（`/products`）**：目标 `Global Capability Catalog`。列表必须包含产品能力、核心参数、分类、应用场景、能力标签；禁止价格、库存、购买按钮等商城元素。

**搜索升级（`/search`）**：升级为一级能力，目标链：

```
Header Search → Search Landing → Multi Entity Result → Facet Filter → Capability Detail
```

修复「顶部搜索过窄」问题，强化：独立搜索区域、搜索建议、类型切换、参数筛选、搜索结果分区。

**Workspace 升级**：统一 `/workspace` 为业务入口，治理 `/dashboard`、`/dashboard/buyer`、`/dashboard/supplier` 遗留。Buyer 覆盖 Dashboard/Demand/RFQ/Match/Notification/Setting；Supplier 覆盖 Capability Display/Offer/Opportunity/RFQ Response/Inquiry Response/Organization。

### 4.2 Admin Console Upgrade

目标：`Industrial Operation Console`（非 Default Ant Design Admin）。

- **Dashboard**：增加核心指标、趋势分析、业务状态。
- **管理模块统一标准**：所有列表页检查字段完整性、操作（查看/编辑/删除/状态管理/批量操作）、过滤（搜索/分类/状态/时间）。
- 覆盖模块：Product / Category / Parameter / Knowledge / Media / Inquiry / Demand / RFQ / Offer / Supplier / User / Organization / Analytics / Audit。

### 4.3 Media Requirement

- 开发环境允许 `https://picsum.photos/` 作为 Placeholder Provider（产品图片 / 卡片图片 / Banner 占位 / 内容图片）。
- 必须实现 `Media Display → Fallback Empty State`，禁止空白布局。
- 生产保持 `FileAsset + S3 Compatible Storage`。

### 4.4 Test Data Preparation Requirement（移交 611）

611 必须建立完整测试闭环数据链：

```
Organization → User → Product → Category → Parameter → Knowledge → Solution → Media → Offer → Demand → RFQ → Response → Notification
```

角色账号规划 `buyer@visndt.com` / `supplier@visndt.com` / `admin@visndt.com`，若运行时不存在必须同步真实 seed 账号。

### 4.5 Agent Validation Requirement（移交 614）

614 必须实现六 Agent 体系：QA Supervisor / Visitor / Buyer / Supplier / Admin / Regression Agent，每个 Agent 输出统一 10 段报告（Current State / Test Scope / Functional Coverage / Interaction Validation / Data Validation / Permission Validation / UX Issue / Architecture Risk / Recommendation / Priority）。
