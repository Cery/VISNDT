## 4. Service Ownership Changes

### 4.1 create()

| Aspect | Before | After |
|--------|--------|-------|
| Signature | `create(dto: CreateOfferDto)` | `create(dto, user)` |
| orgId source | `dto.organizationId` (client) | `user.organizationId` (JWT) |
| No org | — | `BadRequestException` |

```typescript
// ✅ After
async create(dto: CreateOfferDto, user: { id: string; organizationId?: string | null }) {
  if (!user.organizationId) {
    throw new BadRequestException('User must belong to an organization');
  }
  return this.prisma.offer.create({
    data: { ...dto, organizationId: user.organizationId },
  });
}
```

### 4.2 update()

| Aspect | Before | After |
|--------|--------|-------|
| Signature | `update(id, dto)` | `update(id, dto, user)` |
| Query | `findUnique({ where: { id } })` | `findFirst({ where: { id, organizationId } })` |
| Cross-org | Possible (no check) | Blocked |

```typescript
// ✅ After
async update(id: string, dto: UpdateOfferDto, user: { organizationId?: string | null }) {
  if (!user.organizationId) {
    throw new BadRequestException('User must belong to an organization');
  }
  const offer = await this.prisma.offer.findFirst({
    where: { id, organizationId: user.organizationId },
  });
  if (!offer) throw new NotFoundException(`Offer ${id} not found`);
  return this.prisma.offer.update({ where: { id }, data: dto });
}
```
