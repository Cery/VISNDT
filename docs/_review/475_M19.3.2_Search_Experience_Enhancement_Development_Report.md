## 4. Architecture Impact

### 4.1 Product Global Catalog

✅ **保持**——Product 作为标准目录，不引入 `Product.organizationId` / `Product.supplierId` / `ProductFamily` / `ProductModel`。

### 4.2 Offer Supplier Display

✅ **保持**——供应商能力通过 Offer 间接关联，链路为 `Product → Offer → Organization → Supplier Capability`。`/suppliers` 页面通过 `GET /offers` 获取数据，按 `organizationId` 去重。

### 4.3 Supplier Capability Provider

✅ **保持**——Supplier 定位为 Capability Provider（能力提供者），不是 Store Owner / Marketplace Seller / Inventory Owner / Transaction Party。文案使用「供应商能力」「Products Supplier Can Provide」「供应能力」等。

### 4.4 No Marketplace

✅ **禁止**——未引入 Supplier Store / Marketplace / 商品交易 / 订单 / 价格展示。

### 4.5 No Transaction

✅ **禁止**——未新增交易/支付/结算能力。

## 8. Implementation Details

### 8.1 Supplier Discovery Enhancement

#### Supplier List Page (`/suppliers`)

- **数据获取**：通过 `GET /offers` API（status=ACTIVE, pageSize=200）获取所有活跃报价
- **去重逻辑**：按 `organizationId` 去重，统计每个供应商的供应产品数量
- **排序**：按供应产品数量降序排列
- **错误处理**：API 失败时降级显示空状态，不阻塞页面渲染
- **SEO Metadata**：`generateMetadata` 静态生成标题「供应商能力发现 | VISNDT」+ OpenGraph
- **空状态**：暂无供应商时显示引导图标 + 文案 + 返回产品列表链接
- **结果计数**：显示「共 N 个供应商」
- **供应商卡片**：展示首字母头像、名称、类型标签、状态标签、供应产品数量，hover 效果联动

#### Product Page Supplier Entry

- 产品列表页 `/products` 头部右侧新增「浏览供应商能力」Link（SVG 图标 + 文字）
- hover 时 border-color → primary/30，background → primary/5

#### Product Card Supplier Link

- `ProductCard.tsx` 底部「查看供应商能力」改为 `<Link href={/products/${product.id}#suppliers}>`
- 点击跳转至产品详情页的供应商区域（`#suppliers` 锚点）

### 8.2 Search Result UX Enhancement

#### Loading Skeleton

- `ProductGrid.tsx` 新增 `isLoading` prop
- 加载中显示头部骨架屏（`animate-pulse` 灰色占位）+ 6 个产品卡片骨架屏

#### Empty State Enhancement

- **有筛选条件 + 有关键词**：`未找到与「XXX」相关的产品。请尝试调整关键词或清除筛选条件后重新搜索。`
- **有筛选条件 + 无关键词**：`当前筛选条件没有匹配的产品。请尝试调整筛选条件或清除筛选后重新搜索。`
- **无筛选条件**：`产品目录正在建设中，敬请期待更多产品上线。`

#### Result Count Context

- 结果计数区域显示搜索上下文信息（当前页码、筛选状态标记）

#### Pagination Navigation

- `Pagination.tsx` 新增 `<span>{currentPage} / {totalPages}</span>` 页码指示器
