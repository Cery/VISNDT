## 4. 返回结构变化

原结构：

```json
{
  "id": "string",
  "email": "string",
  "name": "string | null",
  "organizationId": "string | null"
}
```

现结构：

```json
{
  "id": "string",
  "email": "string",
  "name": "string | null",
  "organizationId": "string | null",
  "organization": {
    "id": "string",
    "name": "string",
    "type": "string"
  },
  "organizationMember": {
    "role": "string"
  },
  "workspaceRole": "ADMIN | SUPPLIER | BUYER | null"
}
```

空值规则：

- `organization` 不存在时返回 `null`
- `organizationMember` 不存在时返回 `null`
- 当无法从当前认证用户解析到 `organization.type` 时，`workspaceRole` 返回 `null`

`workspaceRole` 映射规则：

1. `organizationMember.role === ADMIN` 时返回 `ADMIN`
2. 否则 `organization.type === SUPPLIER` 时返回 `SUPPLIER`
3. 否则存在组织上下文的已登录组织用户返回 `BUYER`
4. 无法确定组织类型时返回 `null`

说明：

- 当前代码可直接从 `Organization.type` 获取组织类型，因此未使用猜测逻辑
