## 4. M18 Capability Roadmap

### M18 实施优先级总览

| 优先级 | 子阶段 | 能力 | 顺序 |

### M18.1 Markdown Content Enhancement（P1）

- **Markdown Storage**：复用现有 `Content.content`（Text），以 Markdown 语法书写，零数据迁移。
- **Admin Preview**：Admin 端 Markdown 编辑器 + 预览面板。
- **Web Rendering**：Web 端服务端 Markdown → HTML 安全渲染。
- **XSS Protection**：使用安全渲染库（sanitize），禁止原始 HTML 注入。
- **Existing Content Compatibility**：现有纯文本内容天然兼容 Markdown，向后兼容。

| 影响维度 | 评估 |
| --- | --- |
| Schema Impact | 无（复用 `Content.content`） |
| API Impact | 仅传递原文，无契约变更 |
| Admin Impact | 新增 Markdown 编辑器 + 预览 |
| Web Impact | 详情页改 MD → HTML 渲染 |
| Security Impact | XSS 防护（服务端 sanitize） |
| Migration | 无 |
| Freeze | 兼容 |

### M18.2 Content Media Management（P2）

规划模型：

```
Content 1 ── N ContentMedia N ── 1 FileAsset
```

- **图片**：正文内嵌多图
- **附件**：技术文档
- **报告文件**：检测报告下载
- **排序**：sortOrder
- **描述**：caption

| 影响维度 | 评估 |
| --- | --- |
| Schema Impact | 新增 `ContentMedia` 关联模型（M18 实施阶段） |
| API Impact | 明确新增 Content Media 相关读写端点（M18 实施阶段） |
| Admin Impact | 内容编辑页媒体管理（多图/附件/排序/描述） |
| Web Impact | 详情页图文混排 + 附件下载 |
| Security Impact | 沿用 FileAsset 权限边界 |
| Migration | M18 实施阶段新增 Migration |
| Freeze | Schema 需在 M18.2 解冻（专项） |

| Freeze | 兼容 |
