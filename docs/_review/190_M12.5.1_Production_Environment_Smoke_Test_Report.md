## 6. Frontend Verification

### 6.1 Admin Docker Build

| 指标 | 值 |
|------|-----|
| Exit Code | **1** ❌ |
| 错误类型 | TS2307: Cannot find module |
| 缺失模块 | `react-router-dom`, `@ant-design/icons` |

### 6.2 错误详情

```
TS2307: Cannot find module 'react-router-dom' (30 files)
TS2307: Cannot find module '@ant-design/icons' (24 files)
```

**根因**: Dockerfile 中 `pnpm install` 仅安装 `apps/admin/package.json` 的依赖，但 `react-router-dom` 和 `@ant-design/icons` 被 hoisted 到 monorepo root `node_modules`，Docker build 上下文未包含这些依赖。

| Pages | 22 |
| Components | 3 |

| **总计** | **28** |
