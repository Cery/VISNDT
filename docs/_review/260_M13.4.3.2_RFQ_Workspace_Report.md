## 4. API Usage

| 端点 | 方法 | 认证 | 用途 | 调用位置 |
|------|------|------|------|----------|
| `GET /rfqs/mine` | GET | JWT | RFQ 列表 | `rfqs/page.tsx` |
| `GET /rfqs/:id` | GET | Public | RFQ 详情 | `rfqs/[id]/page.tsx` |
| `GET /rfq-responses/mine` | GET | JWT | Response 列表 | `rfqs/[id]/page.tsx` |

### 调用链

```
/workspace/rfqs
  └─ rfq.service.getRfqs()
       └─ lib/api/rfqs.getMyRfqs()
            └─ apiClient → GET /rfqs/mine (JWT)

/workspace/rfqs/[id]
  ├─ rfq.service.getRfq(id)
  │    └─ lib/api/rfqs.getRfq()
  │         └─ apiClient → GET /rfqs/:id
  └─ rfq.service.getRfqResponses()
       └─ lib/api/rfqs.getMyRfqResponses()
            └─ apiClient → GET /rfq-responses/mine (JWT)
```

## 5. Component Structure

### RFQList

```
States:
  loading → 4× skeleton pulse
  empty   → "No RFQs yet" + description
  data    → RFQ cards (title/description/status badge/date)
```

### RFQDetail

```
Sections:
  Header   → Title + StatusBadge + dates
  Demand   → Related demand reference (if available)
  Description → Full description text
  Responses → Response count badge
```

### RFQStatusBadge

| Status | Label | Color |
|--------|-------|-------|
| DRAFT | Draft | slate |
| OPEN | Open | green |
| RESPONDING | Responding | blue |
| CLOSED | Closed | red |
| CANCELLED | Cancelled | red |

### RFQResponseList

```
States:
  loading → 2× skeleton pulse
  empty   → "No responses received yet."
  data    → Response cards (ID/date/status badge)
```
