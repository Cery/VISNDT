## 5. Gap Classification

### Level A — Critical Experience Gap (0 项)

无。所有页面均存在且功能完整，核心业务流程（登录→需求→匹配→RFQ→响应）无断裂，品牌表达在公开页面一致。

### Level B — Premium Experience Gap (3 项)

| # | 差距 | 影响范围 | 优先级 |
| :---: | --- | --- | :---: |
| B1 | **Admin 工业运营中心风格未扩散** — Dashboard（Home.tsx）已升级为 Industrial Console 风格，但其余 26 个管理页面停留于 Ant Design 默认样式，形成"一个升级页面 + 二十多个默认页面"的断层体验。`VISNDT_COLORS`/`CHART_PALETTE`/`resolveStatusTone` 已定义但未普及 | `apps/admin` 全部管理页面 | 高 |
| B2 | **空状态/错误状态一致性** — `knowledge`/`solutions` 页面使用内联 HTML 而非 `EmptyState` 组件；`search` 页面使用内联 HTML 而非 `ErrorState` 组件。已有组件未统一使用 | `apps/web` knowledge, solutions, search | 中 |
| B3 | **客户端页面缺少页面级错误边界** — `login`/`register`/`workspace`/`dashboard/buyer`/`dashboard/supplier` 缺少 Next.js App Router 的 `loading.tsx`/`error.tsx` 文件，API 层面错误无法被优雅捕获 | `apps/web` 客户端路由页面 | 中 |

### Level C — Optimization Gap (4 项)

| # | 差距 | 影响范围 |
| :---: | --- | --- |
| C1 | `SectionHeader` 组件在页面中直接使用率低，品牌叙述分散在各页面内联样式中 | `apps/web` knowledge, solutions, about, business |
| C2 | `knowledge`/`solutions` 列表页缺少分页控件（固定 `pageSize: 50`） | `apps/web` knowledge, solutions |
| C3 | `login`/`register` 缺少客户端表单验证、密码可见性切换、密码强度指示 | `apps/web` login, register |
| C4 | `dashboard/buyer`/`dashboard/supplier` 导航项使用 emoji 而非 SVG 图标，跨平台渲染不一致 | `apps/web` dashboard |

## 7. M24.4 Decision

### 审计结论

经过对 VISNDT 全站 41 个页面（14 Web + 27 Admin）的逐页审计，得出以下结论：

**无 Level A 关键体验差距**：所有页面均存在且功能完整，核心业务流程（登录→需求→匹配→RFQ→响应）无断裂，品牌表达在公开页面一致。

**存在 3 项 Level B 高级体验差距**：
- **B1 (高优先级)**：Admin 工业运营中心风格仅覆盖 Dashboard，其余 26 个管理页面为 Ant Design 默认样式，形成显著体验断层
- **B2 (中优先级)**：Web 端空状态/错误状态组件使用不一致
- **B3 (中优先级)**：客户端页面缺少页面级错误边界

**存在 4 项 Level C 优化差距**：SectionHeader 使用率低、列表分页缺失、登录/注册体验细节、emoji 图标。

### 决策

```
M24.4 FINAL EXPERIENCE CLOSURE REQUIRED
```

**理由**：B1 差距（Admin 工业运营中心风格未扩散）为高优先级 Level B 差距，影响 Admin Console 整体体验一致性。Dashboard（1/27 页面）是工业运营中心，其余 26/27 页面仍是 Ant Design 默认风格，不符合"Industrial Operation Console"定位。

### 建议的 M24.4 Final Closure Upgrade Scope

| 子任务 | 范围 | 目标 |
| --- | --- | --- |
| 622_M24.4.7_Admin_Industrial_Style_Diffusion | `apps/admin` 全部非 Dashboard 页面 | 将 `VISNDT_COLORS`/`CHART_PALETTE`/`resolveStatusTone` 从 Dashboard 扩散到全部管理页面，统一 Industrial Operation Console 视觉风格 |
| 623_M24.4.8_Web_State_Consistency_And_Error_Boundary | `apps/web` knowledge/solutions/search/login/register/workspace/dashboard | 统一使用 `EmptyState`/`ErrorState` 组件，添加缺失的 `loading.tsx`/`error.tsx` |
