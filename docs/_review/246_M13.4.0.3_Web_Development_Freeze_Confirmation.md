## 1. 商业模型最终确认

### 1.1 核心定义

```
VISNDT = 工业检测设备产品信息平台 + 需求撮合平台

产品中心 — 唯一主要公开流量入口
  ├── 产品搜索 + 筛选
  ├── 产品详情 (含制造商信息)
  ├── 分类导航
  ├── 行业方案
  └── 技术知识

统一 Dashboard — Buyer + Supplier Partner 同一入口
  ├── /workspace  (Supplier Partner 功能区)
  ├── /demands     (Buyer 功能区)
  ├── /rfqs        (询价单, 双方共用)
  └── /contacts    (联系记录, 双方共用)

合作入口 — 企业入驻引导
  └── /business    (企业合作, 产品入驻, 采购需求, 撮合机会)
```

### 1.2 角色定义

| 角色 | 定义 | 来源 | 平台 |
|------|------|------|------|
| **Visitor** | 匿名用户 | 无需登录 | Web (公开) |
| **Buyer** | 采购需求方 | User + Organization (可选) | Web (Dashboard) |
| **Supplier Partner** | 产品提供方/合作参与方 | User + Organization (type='supplier') | Web (Dashboard) |
| **Admin** | 平台管理员 | User (role=ADMIN) | apps/admin |

> **注意:** 使用 "Supplier Partner" 而非 "Supplier"，强调合作参与而非卖家身份。"Supplier" 在内部代码中保持不变（数据库字段名、API 路径），前端展示使用 "合作企业" 或 "产品提供方"。

### 1.3 供应商定位

```
Supplier Partner ≠ 店铺主/卖家
Supplier Partner = 产品制造来源 + 合作参与方 + 需求响应方

✅ 供应商是:
  - 产品制造来源 (Product Manufacturer)
  - 合作参与方 (Cooperation Participant)
  - 需求响应方 (Demand Responder)

❌ 供应商不是:
  - 店铺主 (Store Owner)
  - 卖家 (Seller)
  - 产品拥有者 (Product Owner)
  - 独立品牌 (Independent Brand)
```

### 1.4 正确商业流程

```
用户
  ↓
搜索产品 (/products)
  ↓
查看产品详情 (/products/[slug])
  ├── 产品信息
  ├── 技术参数
  ├── 制造商信息 (产品来源)
  ├── [💬 Quick Inquiry]  → 轻量咨询
  └── [📋 Request Quotation] → 正式询盘
  ↓
Quick Inquiry → 企业收到通知 → 建立联系
  ↓
用户注册 → Buyer
  ↓
创建 Demand → 触发 Matching
  ↓
DemandMatch → RFQ → 报价
  ↓
Supplier Partner 在 Dashboard 处理合作机会
```

### 4.6 Inquiry 数据流验证

```

  ✅ Inquiry → Product → Matching → Supplier Partner
  
  数据流:
    1. Visitor 提交 Quick Inquiry → POST /inquiries { productId, name, email, message }
    2. 后端查询产品关联的 Offer → Offer.organizationId
    3. 创建 Notification → 通知企业联系人
    4. Supplier Partner 在 /workspace/contacts 中查看
    5. 线下回复 → 建立联系 → 引导注册 → Demand → Matching

    Inquiry → Supplier Partner 直接交易 (绕过 Product)
```
