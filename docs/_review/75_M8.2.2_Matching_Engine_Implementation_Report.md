## 4. Matching Algorithm Implementation

### 4.1 ScoringService — 四种匹配策略

#### 精确匹配 (exactMatch)

```typescript
// STRING / BOOLEAN 类型
// 大小写不敏感，去除首尾空格
private exactMatch(demandValue: string | null, productValue: string | null): number {
  if (!demandValue || !productValue) return 0;
  return demandValue.toLowerCase().trim() === productValue.toLowerCase().trim()
    ? 100 : 0;
}
```

#### 数值范围匹配 (rangeMatch)

```typescript
// NUMBER 类型
// 检查 productValueNumber ∈ [valueMin, valueMax]
// 不在范围内时计算偏离度部分得分
private rangeMatch(
  valueMin: number | null,
  valueMax: number | null,
  productValue: number | null,
): number {
  if (productValue === null) return 0;
  const min = valueMin ?? -Infinity;
  const max = valueMax ?? Infinity;
  if (productValue >= min && productValue <= max) return 100;
  // 部分得分
  if (productValue < min && min !== -Infinity && min !== 0) {
    return Math.max(0, Math.round((1 - (min - productValue) / min) * 100));
  }
  if (productValue > max && max !== Infinity && max !== 0) {
    return Math.max(0, Math.round((1 - (productValue - max) / max) * 100));
  }
  return 0;
}
```

#### 枚举匹配 (enumMatch)

```typescript
// ENUM 类型 — 本质是精确匹配
private enumMatch(demandValue: string | null, productValue: string | null): number {
  return this.exactMatch(demandValue, productValue);
}
```

### 4.2 加权评分公式

```
totalScore = Σ(parameterScore × priority) / Σ(priority)

if (required parameter scores 0):
    totalScore = 0 (hard fail)
```

## 8. Security Review

### 8.1 数据泄露检查

| 风险 | 分析 | 结论 |
|------|------|------|
| 匹配结果泄露用户联系方式 | `matchDetails` 仅包含参数得分，不包含 `contactEmail`/`contactPhone` | ✅ 安全 |
| 跨组织数据泄露 | 匹配仅在 `publish()` 内部触发，候选产品来自全局 ACTIVE + Offer | ⚠️ 匹配结果可被 Demand 所有者查看（设计如此） |
| 匹配查询泄露敏感字段 | 候选产品查询仅读取 `name` + `parameterValues` + `offers` | ✅ 安全 |
| `matchDetails` 暴露其他组织信息 | 仅包含参数定义名、参数值、得分，不涉及组织/用户 | ✅ 安全 |

### 8.2 权限检查

| 操作 | 权限 | 说明 |

| JWT 权限体系 | ✅ 不影响 | 匹配引擎不涉及认证/授权 |
