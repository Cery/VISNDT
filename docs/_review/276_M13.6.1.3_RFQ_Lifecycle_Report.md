## RFQ 状态机

```
                  publish()
DRAFT ────────────────────→ OPEN ────→ RESPONDING
                               │
                               │ close()
                               ↓
                            CLOSED
```

### 状态转换规则

| 方法 | 源状态 | 目标状态 | 字段更新 | WorkflowEvent |
|------|--------|----------|----------|---------------|
| `publish()` | `DRAFT` | `OPEN` | `publishedAt = now()` | `RFQ → OPENED` |
| `close()` | `OPEN` | `CLOSED` | `closedAt = now()` | `RFQ → CLOSED` |

### 非法状态转换

| 场景 | 返回 |
|------|------|
| 对非 DRAFT 状态调用 `publish()` | `BadRequestException` |
| 对非 OPEN 状态调用 `close()` | `BadRequestException` |
| 跨组织操作 | `BadRequestException` |

---

## 权限验证

| 验证项 | 实现 |
|--------|------|
| **认证** | `@UseGuards(JwtAuthGuard)` + `@ApiBearerAuth()` |
| **创建者** | `rfq.createdBy === user.id` |
| **同组织** | `user.organizationId === rfq.demand.organizationId` |
| **跨组织拦截** | `BadRequestException('You do not have permission to publish/close this RFQ')` |

| 动作 | entityType | action | 触发时机 |
