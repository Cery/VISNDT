## 5. Unified Pagination Verification

### 5.1 Single Pagination State

`SearchPageContent.tsx` 中分页状态**唯一**：

```text
const page = Math.max(1, Number(searchParams.get('page')) || 1);
```

- `page` 由 URL `page` 派生（URL-driven / deep-linkable）。
- `pageSize` 为单一常量 `PAGE_SIZE = 20`。
- **不存在**「SupplierProduct page + Unified Search page」两套状态。

### 5.2 Type Switching

`searchContextKey = ${query}|${type}|${facetKey}|${spBrand}|${spSeries}|${spHasOffer}` 捕获完整搜索上下文：

- 上下文变化（type 切换 / facet 变化 / 新 query）→ 重置 `page=1`。
- 首次挂载（deep-link）→ 保留 URL `page`。
- 纯 `page` 变化（deep-link / refresh / load-more）→ 恢复该页。

### 5.3 Deep Link / 刷新保持

```text
/search?type=supplier-product&page=2&brand=XXX&series=YYY&hasOffer=true
```

刷新后 `type / brand / series / hasOffer / page / query` 全部从 URL 恢复（`searchParams` 单一来源，`sb / ss / sh` 直接派生，`page` 直接派生）。

**Runtime 验证（HTTP）**：`/search?q=内窥镜&type=supplier-product&page=2&sb=TESTBRAND_X&ss=TESTSERIES_Y&sh=true` → 200，页面渲染正常（SSR）。

**Runtime 验证（API 分页）**：

## 6. Unified Facet State Verification

### 6.1 Facet Sources（统一进入 /search）

| Facet | Source | API 参数 |
| --- | --- | --- |
| category（能力分类） | `useFacetFilterState`（URL `category`） | `category` |
| brand | URL `sb` → `searchParams` | `brand` |
| series | URL `ss` → `searchParams` | `series` |
| technical parameters | `useFacetFilterState`（URL `fc` / `f_<catId>`） | `filters` |
| hasOffer | URL `sh` → `searchParams` | `hasOffer` |

全部经 `unifiedSearch()` → `GET /search`（无第二套 Facet 契约）。

### 6.2 State Synchronization（URL = API = Rendered）

用户选择 brand / series / parameter / hasOffer 时：

- `updateSpFacet` / `useFacetFilterState` 同步 **URL Query State**（`router.replace` / `replaceState`）。
- 同一 `searchContextKey` 变化触发 **Search API Request**（`executeSearch` 携带 `spBrand / spSeries / spHasOffer / activeFacet`）。
- 响应 `setResults` + `setSpFacets` 驱动 **Rendered Result State**。

三者同源，不存在「UI 已选但 URL 无 / API 未携带」的撕裂。

**Runtime 验证（API）**：

| Request | Result |
| --- | --- |
| `GET /api/v1/search?q=内窥镜&brand=TESTBRAND_X&series=TESTSERIES_Y` | 200, supplierProducts.total=1（过滤命中） |
| `GET /api/v1/search?q=内窥镜&hasOffer=true` | 200, supplierProducts.total=0（无 Offer 记录被排除） |

### 6.3 Reset Behavior（Clear Facets）

`clearSpFacet()` → `updateSpFacet({ brand: undefined, series: undefined, hasOffer: false })`，同时 `clearAllFilters()` 清除 technical filters / category；URL 删除 `sb / ss / sh / category / fc / f_*`，**保留 `type=supplier-product`**。
