## 11. Test Execution Instructions

从项目根目录运行：

```bash
cd F:\Desktop\VISNDT\VISNDT
pnpm --filter @visndt/api test:e2e
```

或单独运行：

```bash
# Flow test
pnpm --filter @visndt/api exec jest --config ./test/jest-e2e.json test/e2e/demands/demand-flow.e2e-spec.ts --forceExit

# Security test
pnpm --filter @visndt/api exec jest --config ./test/jest-e2e.json test/e2e/demands/demand-security.e2e-spec.ts --forceExit
```

**注意：** E2E 测试会创建临时测试数据（Organization、User、Demand、Product 等），并在 `afterAll()` 中自动清理。测试使用 `E2E_FLOW` / `E2E_SEC` 前缀标识测试数据，不会影响生产数据。每次运行前会执行 pre-cleanup 清除上次残留数据。
