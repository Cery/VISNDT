## 2. Container Structure

### 2.1 Backend (`apps/api/Dockerfile`)

| 阶段 | 用途 | 关键操作 |
|------|------|----------|
| deps | 生产依赖安装 | `pnpm install --prod` |
| prisma | Prisma Client 生成 | `pnpm db:generate` |
| build | TypeScript 编译 | `nest build` |
| production | 运行时 | `node dist/main` |

### 2.2 Frontend (`apps/admin/Dockerfile`)

| 阶段 | 用途 | 关键操作 |
|------|------|----------|
| build | React 构建 | `tsc -b && vite build` |
| production | Nginx 静态服务 | `nginx -g "daemon off;"` |

### 2.3 Nginx 配置 (`apps/admin/nginx.conf`)

| 路由 | 行为 |
|------|------|
| `/` | SPA fallback |
| `/assets/` | 静态资源 (1年缓存) |
| `/api/` | 反向代理 → `http://api:4000` |
