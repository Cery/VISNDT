## 4. Architecture Impact

- **Product Global Catalog 保持**：产品仍为标准平台目录，未引入 `Product.organizationId` / `ProductFamily` / `ProductModel` / `SupplierOffering`。
- **Offer Supplier Display 保持**：供应商能力通过 `Offer.organization` 展示，`SupplierCapabilityList` 消费 `product.offers[]` 已有数据。
- **未新增模型**：`ParameterGroup` 类型仅映射后端已有 `parameter_groups` 表（public endpoint），无新增 Prisma 模型。

## 5. API Impact

- **API Change = None**。
  - `GET /products/:id`：复用已有 `offers`（含 `organization`）和 `parameterValues`（含 `parameterDefinition`）数据。
  - `GET /parameter-groups`：复用已有 public endpoint（后端 `ParameterGroupsController.findAll` 已有 `@Get()` 且无 `@UseGuards`），仅新增前端 API Wrapper 访问，后端无改动。
  - `POST /inquiries`：复用已有 inquiry 提交接口，`offerId`/`organizationId` 由前端 `SupplierInquirySection` 显式传入，不再使用 fallback。
