## 2. Problem Background

### 2.1 passwordHash Exposure

**Affected Endpoints**:
- `GET /api/v1/users` — User list returned `passwordHash` for every user
- `GET /api/v1/users/:id` — User detail returned `passwordHash`

**Root Cause**: `UsersService.findAll()` and `UsersService.findOne()` used Prisma `findMany()` and `findUnique()` without `select`, returning the full User model including the `passwordHash` field.

**Risk**: Sensitive credential data exposed in API responses. While bcrypt hashes are not reversible, exposing them increases the attack surface for offline brute-force attacks.

### 2.2 Admin Container Healthcheck

**Symptom**: `docker compose ps` showed `visndt-admin` as "unhealthy" despite the service being accessible at `http://localhost:80`.

**Root Cause**: The Dockerfile healthcheck used `wget -qO- http://localhost:80`. In the nginx:alpine container, `localhost` may not resolve to `127.0.0.1` due to IPv6 resolution or DNS configuration, causing the healthcheck to fail.

**Risk**: No functional impact — the service was accessible externally. However, `unhealthy` status prevents Docker Compose dependency chains from working correctly and causes false alarms in monitoring.

## 4. passwordHash Fix Details

### 4.1 File: `apps/api/src/users/users.service.ts`

**`findAll()` method** (line 37-67):

Before:
```typescript
const [data, total] = await Promise.all([
  this.prisma.user.findMany({
    skip,
    take: pageSize,
    orderBy: { createdAt: 'desc' },
  }),
  this.prisma.user.count(),
]);
```

After:
```typescript
const userSelect = {
  id: true,
  email: true,
  name: true,
  status: true,
  organizationId: true,
  createdAt: true,
  updatedAt: true,
};

const [data, total] = await Promise.all([
  this.prisma.user.findMany({
    skip,
    take: pageSize,
    orderBy: { createdAt: 'desc' },
    select: userSelect,
  }),
  this.prisma.user.count(),
]);
```

**`findOne()` method** (line 70-87):

Before:
```typescript
const user = await this.prisma.user.findUnique({ where: { id } });
```

After:
```typescript
const user = await this.prisma.user.findUnique({
  where: { id },
  select: {
    id: true,
    email: true,
    name: true,
    status: true,
    organizationId: true,
    createdAt: true,
    updatedAt: true,
  },
});
```

**Excluded field**: `passwordHash`  
**Retained fields**: `id`, `email`, `name`, `status`, `organizationId`, `createdAt`, `updatedAt`

## 5. Healthcheck Fix Details

### 5.1 File: `apps/admin/Dockerfile` (line 45-46)

Before:
```dockerfile
HEALTHCHECK --interval=30s --timeout=5s --retries=3 \
  CMD wget -qO- http://localhost:80 || exit 1
```

After:
