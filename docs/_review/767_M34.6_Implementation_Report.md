## 3. Schema Change（落实 ADR-M34-13 Option B）

`schema.prisma` 新增受控表 `buyer_evaluation`（此前 schema 无任何 Shortlist/Evaluation/Favorite/Watchlist 持久化载体，与 ADR-M34-13、766 §14 ONE Authority 审计一致）：

```prisma
enum EvaluationTargetType { PRODUCT SUPPLIER_PRODUCT }
enum EvaluationState { INTERESTED SHORTLISTED COMPARING CONTACTED }

model BuyerEvaluation {
  id         String                @id @default(uuid()) @db.Uuid
  userId     String                @map("user_id") @db.Uuid
  targetType EvaluationTargetType  @map("target_type")
  targetId   String                @map("target_id") @db.Uuid
  state      EvaluationState       @default(INTERESTED)
  note       String?
  createdAt  DateTime              @default(now()) @map("created_at")
  updatedAt  DateTime              @updatedAt @map("updated_at")
  user User @relation("BuyerEvaluationOwner", fields: [userId], references: [id], onDelete: Cascade)
  @@unique([userId, targetType, targetId])
  @@index([userId])
  @@index([targetType, targetId])
  @@map("buyer_evaluation")
}
```

- **Authority 边界保持**：`buyer_evaluation` 是**买家用户维度的评估断面（snapshot）**，非一级 Domain Authority；Authority 仍归属被引用对象（Product / SupplierProduct / Organization(type=SUPPLIER)），无第二套权威。
- **唯一约束** `@@unique([userId, targetType, targetId])` 保证每个 Buyer × Target 只有一个当前评估（DB 层去重）。

### 5.2 Key Behaviors（service）

- **目标校验 `resolveTarget`**：PRODUCT→存在性 404；SUPPLIER_PRODUCT→存在性 404 + 仅 `PUBLISHED` 可评估（Draft/Reviewing 拒绝，BadRequest）。
- **去重**：`buyerEvaluation.create` 捕获 Prisma `P2002` → `ConflictException`（同 Buyer+Target 已存在，须 PATCH）。
- **权限隔离**：`getById/update/remove/connectionContext` 均校验 `evaluation.userId === user.id`，越权→403。
- **Connection 复用**：PRODUCT→`product.offers[0]` 取组织（无 Offer 则 orgId=null）；SUPPLIER_PRODUCT→`platformProductId + organizationId`。**不新建询价权威**，沿用既有 Inquiry。
