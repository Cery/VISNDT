## 3. Admin Positioning Audit

### 3.1 Definition

**Admin = Platform Governance Center**

| Responsibility | Scope |
|---------------|-------|
| Data Governance | Platform-wide data integrity and consistency |
| Product Governance | Global Catalog management (CRUD + Media + Category + Parameter) |
| Content Governance | Content lifecycle management (Draft → Review → Published → Archived) |
| Supplier Capability Review | Review Offer/Organization (not manage supplier operations) |
| Demand Supervision | Supervise Demand/Matching/RFQ lifecycle |
| Audit Governance | AuditLog + WorkflowEvent monitoring |

### 3.2 NOT Admin

| Forbidden | Reason |
|-----------|--------|
| Seller Backend | Supplier = Capability Provider, not Store Owner |
| Supplier ERP | Platform governance, not supplier operations |
| Commerce Backend | VISNDT is not e-commerce |
| Transaction Management | Order/Payment/Inventory not in scope |

### 4.3 Lifecycle State

| Model | Status Field | Type | Current States |
|-------|-------------|------|----------------|
| Product | `status` | `String @default("DRAFT")` | ⚠️ **No formal enum** |
| Offer | `status` | `OfferStatus` enum | DRAFT, ACTIVE, INACTIVE, SUBMITTED, ACCEPTED, REJECTED, WITHDRAWN |
| Content | `status` | `ContentStatus` enum | DRAFT, REVIEW, PUBLISHED, ARCHIVED |
| Demand | `status` | `DemandStatus` enum | DRAFT, PUBLISHED, SUBMITTED, PROCESSING, CLOSED, CANCELLED |
| RFQ | `status` | `RFQStatus` enum | DRAFT, OPEN, RESPONDING, CLOSED, CANCELLED |

**Finding**: `Product.status` is a bare `String` field — no `ProductStatus` enum, no formal lifecycle states. `WorkflowEntityType` has no `PRODUCT` entry.

**Decision**: This is a **Future Candidate** for M19.4.x Product Lifecycle Governance Audit. NOT modified in this phase.
