## 4. M20.1 Planning Scope

### 4.1 M20.1.1 — Product Discovery Enhancement

**Current State**: Product list (`/products`) with keyword + category + parameter filters, URL sync, highlight text, filter chips, pagination. Product detail (`/products/[slug]`) with gallery, parameters (grouped), supplier list, inquiry flow, anchor navigation.

**Planned Enhancements**:

| Enhancement | Current Gap | Implementation | Impact |
|-------------|-------------|----------------|--------|
| Product Comparison | No side-by-side comparison | `ProductCompare` component (select 2-4 products, parameter matrix) | apps/web only |
| Product Card Visual Hierarchy | Flat card layout | Enhanced ProductCard with primary image, key params preview, category badge | apps/web only |
| Product Detail Information Architecture | Sequential sections | Tabbed/accordion layout for overview/specs/suppliers/documents | apps/web only |
| Parameter Display UX | Grouped list, no comparison context | Parameter comparison hints, unit display, range visualization | apps/web only |
| Product Gallery Enhancement | Basic image grid | Thumbnail navigation, zoom, lightbox | apps/web only |

**Constraint**: All frontend-only. No schema/API change. All data already available via existing GET /products, GET /products/:id.

### 4.2 M20.1.2 — Search Experience Unification

**Current State**: Product search via SearchBar + ProductFilter (keyword + category + parameterFilters). Content and Supplier search are separate domains. No cross-entity search.

**Planned Enhancements**:

| Enhancement | Current Gap | Implementation | Impact |
|-------------|-------------|----------------|--------|
| Unified Search Entry | Search only on product page | Global SearchBar in PublicHeader (searches Products + Content) | apps/web only |
| Search Type Tabs | No type distinction | All/Products/Knowledge/Solutions tabs in search results | apps/web only |
| Filter UX Enhancement | Basic filter chips | Collapsible filter sections, filter count badges, save filter state | apps/web only |
| Search Suggestion | No suggestions | Keyword autocomplete from product names + content titles | apps/web only (client-side) |
| Empty State Enhancement | Basic empty message | Contextual suggestions ("Try different keywords", "Browse categories") | apps/web only |
| Search Result Highlight | Keyword highlight exists | Enhanced highlight with context snippet | apps/web only |

**Constraint**: All frontend-only. Cross-entity search aggregation is client-side (parallel API calls to existing GET /products, GET /content/public). No new backend search endpoint.

### 4.3 M20.1.3 — Workspace Optimization

## 6. Development Sequence Recommendation

```
M20.1.1 Product Discovery Enhancement
        ↓
M20.1.2 Search Experience Unification
        ↓
M20.1.3 Workspace Optimization
        ↓
M20.1.4 Supplier Capability Showcase
        ↓
M20.1.5 Admin Operation Efficiency
```

**Rationale**:
1. Product Discovery (M20.1.1) is the highest-traffic public surface — most impactful first
2. Search Unification (M20.1.2) builds on product discovery pages, benefits from enhanced product cards
3. Workspace Optimization (M20.1.3) is the logged-in user experience — lower traffic but higher engagement
4. Supplier Showcase (M20.1.4) enhances supplier-facing pages, fewer pages but strategic
5. Admin Efficiency (M20.1.5) is internal tooling — lowest user-facing impact, optimized last
