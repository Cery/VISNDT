## 4. API Usage

| 端点 | 方法 | 认证 | 用途 | 调用位置 |
|------|------|------|------|----------|
| `GET /demands/my` | GET | JWT | 获取所有 Demand | `match.service.getAllMatches()` |
| `GET /demands/:id/matches` | GET | JWT | 获取每个 Demand 的 Matches | `match.service.getAllMatches()` |

### 调用链

```
/workspace/matches
  └─ match.service.getAllMatches()
       ├─ demand.service.getDemands()
       │    └─ GET /demands/my (JWT)
       │
       └─ for each demand:
            └─ lib/api/demands.getDemandMatches(id)
                 └─ GET /demands/:id/matches (JWT)
       │
       └─ Aggregate: flatten + annotate with demandTitle + sort by date
```

### 聚合策略

- 先获取所有 Demand（最大 50 条）
- 并行获取每个 Demand 的 Matches
- 合并所有 Match 数据，附加 `demandTitle`
- 按创建时间降序排列

### MatchScore

```
Score → 进度条 (0-100%) + 百分比文本
  ≥80% → emerald
  ≥50% → blue
  <50% → amber
  null/undefined → "—"
```

### MatchList

```
States:
  loading → 4× skeleton pulse
  empty   → "No matches yet" + description
  data    → MatchCard[] (demand link clickable)
```

### MatchCard

```

Click → /workspace/demands/[demandId]
```
