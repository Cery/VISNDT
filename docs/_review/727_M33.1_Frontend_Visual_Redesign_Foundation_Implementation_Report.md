## 4. Implementation Summary（逐 Foundation 层）

Execution Principle：**Contract Before Implementation**。全部改动依据 726 Contract 的对应 §（Surface Contract §7 / Typography Contract §5 / Container §8.1 / Spacing §4.5 / Focus §18 / Responsive §4.5）。

### 4.1 Surface Foundation
- **Before**：双端表面依赖硬编码/既有变量，无统一语义层（surface-0/1/2/elevated/overlay）。
- **Implemented**：`packages/design-tokens` 新增 `surfaceHierarchy`（复用既有色值 + rgba overlay，不新增品牌色/第二套色板）；Web `globals.css` 新增 `.surface-0/1/2/.surface-elevated`；Admin `index.css` 新增 `.vds-surface-*`。
- **Files**：`packages/design-tokens/src/index.ts`；`apps/web/src/app/globals.css`；`apps/admin/src/styles/index.css`。
- **Result**：双端一致 Surface 语义层，供 M33.2 消费；无新增色值、无第二套 Token System。

### 4.2 Typography Foundation
- **Before**：无统一 base 级标题层级基线（多依赖组件级 class）。
- **Implemented**：Web `globals.css` base 层新增 H1(. /2.25rem/1.15/700/-0.025em) H2(1.875/1.2/600/-0.02) H3(1.5/1.25/600/-0.015) H4(1.25/1.3/600) 四级基线。
- **Files**：`apps/web/src/app/globals.css`。
- **Result**：建立可复用 base 排版基线，对齐 726 Typography Contract 四级信息层级，不重构页面。

### 4.3 Container Foundation
- **Before**：无统一 content/wide/reading 容器宽度原语。
- **Implemented**：`design-tokens` 新增 `container`（content 1280 / wide 1480 / reading min760-max820）与 `responsivePadding`（mobile16/tablet24/desktop32）；双端 CSS 新增 `.vds-container*`（`max-width` content 1280 / wide 1480 / reading `min(820px,100%)`）；Web 新增单一事实源容器原语 `PageContainer.tsx`（消费 `container.width`）。
- **Files**：`packages/design-tokens/src/index.ts`；`apps/web/src/app/globals.css`；`apps/admin/src/styles/index.css`；`apps/web/src/components/common/PageContainer.tsx`（新增）。
- **Result**：1280/1480/760–820 基础规则可执行，供 M33 P0 页复用。

### 4.4 Spacing Foundation
- **Before**：双端无随 8px rhythm 的语义间距工具类。
- **Implemented**：Web `.vds-space-y-*(1/2/3/4/6/8)`；Admin `.vds-space-y-*(2/4/6/8)`（8px×n）。
- **Files**：`apps/web/src/app/globals.css`；`apps/admin/src/styles/index.css`。
- **Result**：8px rhythm 得到 Foundation 级应用。

### 4.5 Border / Focus Foundation
- **Before**：focus 状态依赖浏览器默认 / Tailwind 既有，非平台统一 focus-visible ring。
- **Implemented**：`design-tokens` 新增 `border.focus`（复用 primary #2563eb）；Web `:focus-visible{outline:2px solid hsl(var(--ring));outline-offset:2px;border-radius:6px}`；Admin `:where(.admin-layout,.ant-app) :focus-visible{outline:2px solid #2563eb}`。
- **Files**：`packages/design-tokens/src/index.ts`；`apps/web/src/app/globals.css`；`apps/admin/src/styles/index.css`。
- **Result**：Focus-visible Foundation 保留并可验证，未新增颜色。

### 4.6 Icon Foundation
- **Before**：Web 使用 `lucide-react`、Admin 使用 `@ant-design/icons`（既有运行时）。
- **Implemented**：**未新增任何 Icon Runtime 依赖**；复用既有 icon 运行时；未新增 emoji。
- **Files**：无新增依赖文件。
- **Result**：F10/F11 合规（未新增 Runtime Icon Dependency，Emoji P0 入口在本任务范围内未新增）。

### 4.7 Responsive Foundation
- **Before**：响应式多依赖既有 tailwind 断点，无统一 clamp 留白基线。
- **Implemented**：`.vds-container*` `padding-inline: clamp(16px, 4vw, 32px)`（Admin `clamp(16px,3vw,32px)`）——375/16 · 768~1024/中 · 1024+/32。
- **Files**：`apps/web/src/app/globals.css`；`apps/admin/src/styles/index.css`。
- **Result**：375/1440 无 Foundation 导致的横向溢出（见 §8 证据）。

### 4.8 Core Visual Primitive
- **Before**：无可复用容器原语。
- **Implemented**：`PageContainer.tsx`（`variant = content/wide/reading`，消费 `design-tokens.container.width`，clamp 留白）。仅建立原语，未大规模替换页面（属 M33.2/M33 P0 范围）。
- **Files**：`apps/web/src/components/common/PageContainer.tsx`（新增）。
- **Result**：单一事实源容器原语可执行。
