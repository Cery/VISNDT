## 3. Admin IA Before / After

### Before（技术/近义入口混排）

```
首页 · 运营中心 · 数据与监控(数据分析/业务分析/运营监控/审计智能) · 产品管理
内容中心(内容管理/标签管理/知识分类/知识条目/媒体中心)
产品询价 · 需求管理 · RFQ 管理 · 报价管理 · 匹配管理
用户管理 · 组织管理 · 参数管理(参数组/参数定义/分类管理/知识分类映射) · 通知管理 · 审计日志 · AI 数据准备
```

问题：入口命名偏技术型（内容管理/知识分类/知识条目）、参数与分类/知识映射混排、「组织管理」未体现供应商语义、媒体中心作为一级入口缺乏独立运营闭环。

### After（运营型目标结构）

```
首页                    → 首页 / 运营中心
产品中心                → 产品管理 / 产品分类 / 参数体系(参数组、参数定义)
业务中心                → 需求管理 / RFQ 管理 / 报价管理 / 产品询价 / 匹配管理
用户与供应商            → 用户管理 / 企业管理
内容中心                → 文章管理 / 知识库(知识条目、知识分类、知识分类映射) / 标签管理
数据与监控              → 数据分析 / 业务分析 / 运营监控 / 审计智能
系统管理                → 通知管理 / 审计日志 / AI 数据准备
```

要点：菜单层级精简、中文名称统一、无重复入口、无死链入口（所有项均映射至既有已注册路由）。
