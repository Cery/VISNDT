## 4. M13.3.1 Review — Atomic Upload-Create

### Objective

Eliminate the FileAsset orphan window created when a user uploads a file but closes the browser before creating the ProductMedia.

### Implementation

| File | Change |
|---|---|
| `product-media.service.ts` | Added `createWithUpload()` — upload + create + entityId update + rollback |
| `product-media.controller.ts` | Added `POST /products/:productId/media/upload` |
| `product-media.service.ts` (admin) | Added `createWithUpload()` multipart form data |
| `ProductMediaCreate.tsx` | Single-step upload (was two-step) |

### New Endpoint

| Method | Route | Auth | Description |
|---|---|---|---|
| `POST` | `/products/:productId/media/upload` | ADMIN | Upload file + create ProductMedia atomically |

### Flow

```
POST /products/:id/media/upload
  → fileAssetService.upload(file, userId)     // Create FileAsset
  → prisma.productMedia.create({...})          // Create ProductMedia
  → prisma.fileAsset.update({ entityId })      // Link entityId
  → SUCCESS: return ProductMedia with fileAsset
  → FAILURE: fileAssetService.delete(id)       // Rollback (DB + S3)
```
