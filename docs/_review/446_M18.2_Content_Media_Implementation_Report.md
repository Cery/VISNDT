## 4. Database Change

- **Model 新增**：`ContentMedia`（`id`/`contentId`/`fileAssetId?`/`type`/`caption?`/`altText?`/`sortOrder`/`createdAt`/`updatedAt`）
  - `content` 关系：`onDelete: Cascade`
  - `fileAsset` 关系：`fileAssetId` 可空
  - 索引：`@@index([contentId])`、`@@index([fileAssetId])`
- **Enum 新增**：`ContentMediaType`（`IMAGE` / `ATTACHMENT`）
- **Enum 扩展**：`FileEntityType` 新增 `CONTENT`
- **保持**：`Content.coverImageId` 继续作为封面（单封面与多媒体并存，互不冲突）
- **Content 模型**：新增反向关系 `media ContentMedia[]`（不影响现有字段）

## 5. Migration Details

- **Migration 名称**：`20260812104939_m18_2_content_media`
- **内容**：
  1. `ALTER TYPE "FileEntityType" ADD VALUE 'CONTENT'`
  2. `CREATE TYPE "ContentMediaType" AS ENUM ('IMAGE', 'ATTACHMENT')`
  3. `CREATE TABLE "content_media"`（含主键约束）
  4. `CREATE INDEX content_media_content_id_idx` / `content_media_file_asset_id_idx`
  5. 外键：`content_media_content_id_fkey`（`ON DELETE CASCADE`）、`content_media_file_asset_id_fkey`（`ON DELETE SET NULL`）
- **迁移方式**：因本地数据库不可达（Docker API 连接失败），采用 `prisma migrate diff` 离线生成等价迁移 SQL，确保 Migration 与 Schema 一致。

## 6. API Changes

### 新增 Admin 端点（`JwtAuthGuard + RolesGuard + Roles(ADMIN)`）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/content/:contentId/media` | 列表（public，排除 storageKey） |
| `GET` | `/content/:contentId/media/:id` | 详情（public，排除 storageKey） |
| `POST` | `/content/:contentId/media/upload` | 原子上传-create（multipart） |
| `PATCH` | `/content/:contentId/media/:id` | 更新 caption/altText/type/sortOrder |
| `DELETE` | `/content/:contentId/media/:id` | 删除媒体 + 级联 FileAsset + S3 |

### Public API 扩展
- `GET /content/public/:slug`：`publicContentSelect` 新增 `media` 关联（`id`/`type`/`caption`/`altText`/`sortOrder` + `fileAsset` 的 `id`/`fileName`/`mimeType`），向后兼容（新增可选字段）。
- 列表 `GET /content/public` 保持轻量（不含 media 数组）。

### 关键约束
- **storageKey 永不暴露**：Public 投影（`publicFileAssetSelect` / `publicContentSelect`）仅暴露 `id/fileName/mimeType/fileSize/fileType`，不含 `storageKey/entityId/uploadedBy`。

## 7. Admin Changes

- 内容编辑页新增「媒体管理」区块（`ContentMediaManager.tsx`）：
  - 上传：按 MIME 自动判别图片（IMAGE）/附件（ATTACHMENT）；
  - 列表：图片经签名 URL 预览，附件展示文件名/大小/类型；
  - 编辑：caption / altText / type / sortOrder；
  - 删除：级联删除 `FileAsset`（DB）+ S3 对象。
- 复用 `ProductMedia` 成熟模式（原子上传-create / 级联清理），避免脚手架重造。

## 8. Web Changes

- 内容详情页新增 `MediaGallery.tsx`：
  - 图片（IMAGE）：媒体画廊网格展示，支持 altText/caption；
  - 附件（ATTACHMENT）：附件下载列表，经预签名 URL 下载。
- 集成于 `/knowledge/[slug]` 详情页（`content.media`）。

## 9. Security Verification

**安全缺口修复**：`GET /files/:id/download` 增加实体发布状态校验。

- **校验链路**：`FileAsset` → `ContentMedia` → `Content.status`
- **校验规则**：
  - `entityType === CONTENT` 时，仅当关联 `Content.status === PUBLISHED` 允许公开下载；
  - `DRAFT` / `REVIEW` / `ARCHIVED` → `ForbiddenException`（拒绝）；
  - 文件未关联任何 Content → `ForbiddenException`（拒绝）；
  - 非 CONTENT 文件保持原有公开行为。
- **storageKey 保护**：Public 投影永不暴露 storageKey；Web 仅经预签名 URL 访问。
- **上传边界**：保持 ADMIN 保护 + MIME 白名单 + 10MB 限制。
