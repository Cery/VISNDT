## 6. BUYER/SUPPLIER/null 行为变化

修改前：

1. `BUYER` 用户可在已登录条件下访问这些 action 页面
2. `SUPPLIER` 用户也可在已登录条件下通过直链访问这些 Buyer 页面
3. `workspaceRole = null` 的已登录用户也可进入这些页面主体

修改后：

1. `BUYER` 用户保持可访问，页面 UI 与业务行为不变
2. `SUPPLIER` 用户会在页面入口被 `RoleGuard` 拒绝，不再继续渲染 Buyer 页面主体
3. `workspaceRole = null` 用户会在页面入口被 `RoleGuard` 拒绝，不再继续渲染 Buyer 页面主体

说明：

1. 本次复用现有 `RoleGuard` 行为，未修改其实现
2. 未使用 `workspaceRole ?? 'BUYER'`
3. 未使用 `workspaceRole || 'SUPPLIER'`
4. 未新增任何权限模型
