## Security Review

### User Management 安全链路

```
RequireAuth (Route Guard)
    ↓
URL: /users
    ↓
userService.getList()
    ↓
apiClient.get('/users')  ← JWT Bearer Token 注入
    ↓
Backend: @UseGuards(JwtAuthGuard, RolesGuard)
    ↓
Backend: @Roles(Role.ADMIN)
    ↓
UsersService.findAll()
```

### Organization Management 安全链路

```

    ↓

    ↓
Backend: @UseGuards(JwtAuthGuard, RolesGuard)
    ↓
Backend: @Roles(Role.ADMIN)
    ↓
OrganizationsService.findAll()
```

### 敏感数据检查

| 检查项 | 结果 | 说明 |
|---|---|---|

| passwordHash 是否在 API 响应中 | ⚠️ 存在 | 但前端类型安全排除，不渲染 |
