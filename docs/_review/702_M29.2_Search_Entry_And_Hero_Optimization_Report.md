## 3. Search Entry Changes

`GlobalSearchBar.tsx` 新增 `variant?: 'default' | 'hero'` 属性，在不新增第二套搜索逻辑的前提下，通过一个视觉变体提升 Hero 内搜索入口的权重：

- `variant='default'`（默认，Header / 结果页 Sticky 头沿用）：`h-11` / `text-sm` / 紧凑按钮。
- `variant='hero'`：输入框 `h-14 sm:h-16`、文本 `text-base`、输入内边距 `px-4`、提交按钮 `px-6 sm:px-7` + `shadow-industrial-lg`。

行为保持不变：

- `handleSubmit` → `router.push('/search?q=...&type=...')`（保留现有 query/type 参数）。
- `handleClear`、`showSuggestions`、`typeMenuOpen`、Enter 提交、清除按钮行为不变。
- 搜索域枚举不变：`all / product / supplier-product / knowledge / solution`（无 `supplier`）。
