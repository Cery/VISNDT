## 6. SupplierProduct Comparison Experience

- **入口**：Search SupplierProduct Tab → Capability Detail「供应商型号」区块勾选（`SupplierModelsSection`「加入对比」）→ 底部 `SupplierCompareBar`「开始对比」→ `/products/compare?ids=...&type=supplier-product&capability=...`。
- **六层信息层级**（`SupplierCompareTable`）：
  1. **Platform Capability** — 页首「正在比较的检测能力」蓝底锚点（"我在比较什么能力？"）
  2. **Supplier Organization** — 每列顶部「供应商：xxx」（"谁提供？"）
  3. **Brand / Series / Model** — 品牌+系列 + 型号（等宽字体）
  4. **Technical Parameters** — 按 ParameterGroup 分组 + 差异高亮（"型号有什么差异？"）
  5. **Commercial Summary** — 有效 Offer 数 / 价格区间 / 货币（"是否可询价？"）
  6. **Inquiry** — 每列「咨询此型号」展开表单（"下一步怎么办？"）
- **价格未置于 Capability 之前**；SupplierProduct 以「能力下型号」呈现，未显示为独立 Marketplace Listing。
- **Option B 决策（经运行时验证后冻结）**：共同关键参数 + 差异高亮。差异行琥珀底色 + 最优数值绿色标记，满足当前规模（≤7 型号），无需完整矩阵（Option C）。

## 7. Supplier Organization Identity

- 比较表每列明确显示：**供应商（Organization 名）/ 品牌 / 系列 / 型号** 四要素，非仅 Brand。
- **同 Brand 不同 Organization 可区分**：edge 验证 `org|series` distinct=7（中科|标准系列、锐视|高端系列、锐视|经济系列、明视|轻量系列、明视|基础系列、明视|标准高清系列、明视|高清智能系列）。
- **同 Brand 同 Org 多型号**：明视 4 型号均带组织名「明视工业检测设备有限公司-D5reg」，identity 一致无错位。
- **避免了 Brand = Supplier Organization 的错误理解**（每列「供应商：组织名」独立展示，品牌为二级信息）。

## 8. Parameter Comparison

- 数据源：`SupplierProductParameterValue`（覆盖值）经 capability 图 `parameterValues` 暴露。
- 实测 2–3 个存在不同参数值的型号（7 型号全参数覆盖，`models with >=3 params=7/7`）：
  - `image_resolution`：1280x720 / 1920x1080 / 2560x1440 / 3840x2160（4 档）
  - `working_length`：2m / 3m / 10m
  - `ie_ip_rating`：IP54 / IP65 / IP67 / IP68
- 参数名 / 平台默认 / 供应商覆盖值 / 差异：**清晰可理解**（参数名 + 单位 + 差异行高亮 + 最优值绿标）。

## 9. Commercial Summary

- 复用既有 `commercialSummary`：有效 Offer 数、价格区间（priceFrom~priceTo）、货币（CNY）、可询价状态。
- 实测：VX-6000C=42000 CNY / VX-6000-MAX=88000 CNY / VX-6000-PRO=68000 CNY，各 1 ACTIVE Offer；4 个无 Offer 型号显示「暂无可购」。
- **禁止 Paid / Sponsored / Commercial Ranking**：比较表仅信息呈现，价格不参与任何排序；排序保持能力/供应商展示顺序，无商业排名。

## 10. Inquiry Transition
