### 文件内覆盖场景

1. `Accepted Match -> POST /rfqs/from-match`
2. Buyer 发布 Targeted RFQ，使 Supplier 可提交响应
3. Supplier `POST /rfqs/:id/responses`
4. Supplier 调用 `POST /rfq-responses/:id/accept` / `reject` 返回失败
5. Buyer `POST /rfq-responses/:id/view`
6. Buyer `POST /rfq-responses/:id/accept`

## 5. 覆盖场景与验证点

### 5.1 Accepted Match -> Targeted RFQ

- 验证 `POST /rfqs/from-match` 返回 `201`
- 验证 RFQ 数据写入：
  - `sourceMatchId`
  - `targetOrganizationId`
  - `status = DRAFT`
- 验证 `WorkflowEvent`
  - `entityType = RFQ`
  - `action = CREATED`
  - metadata 包含 `demandId` / `sourceMatchId` / `targetOrganizationId`
- 验证 `Notification`
  - Supplier Admin 收到 `RFQ_UPDATE`
  - 标题为 `New RFQ Assigned`

### 5.2 Supplier submit RFQResponse

- 验证 `POST /rfqs/:id/responses` 返回 `201`
- 验证 RFQResponse 数据写入：
  - `status = SUBMITTED`
  - `reviewedBy = null`
  - `reviewedAt = null`
  - `decisionNote = null`
- 验证 Buyer 收到 `RESPONSE_UPDATE`
  - 标题为 `New RFQ Response`

### 5.3 Buyer view

- 验证 `POST /rfq-responses/:id/view` 返回 `201`
- 验证 RFQResponse 状态变更：
  - `status = VIEWED`
  - `reviewedBy = buyerUserId`
  - `reviewedAt != null`
  - `decisionNote = null`
- 验证 `WorkflowEvent`
  - `entityType = RFQ_RESPONSE`
  - `action = REVIEWED`
  - metadata 包含 `previousStatus = SUBMITTED`、`rfqId`、`demandId`、`buyerOrganizationId`、`supplierOrganizationId`、`targetOrganizationId`
- 验证 `view` 不产生额外 Supplier 决策通知

### 5.4 Buyer accept

- 验证 `POST /rfq-responses/:id/accept` 返回 `201`
- 验证 RFQResponse 状态变更：
  - `status = ACCEPTED`
  - `reviewedBy = buyerUserId`
  - `reviewedAt != null`
  - `decisionNote` 按请求体写入
- 验证 `WorkflowEvent`
  - `action = ACCEPTED`
  - metadata 包含 `previousStatus = VIEWED` 与 `decisionNote`
- 验证 `Notification`
  - Supplier Admin 收到 `RESPONSE_UPDATE`
  - 标题为 `Response Accepted`

### 5.5 Buyer reject

- 验证 `POST /rfq-responses/:id/reject` 返回 `201`
- 验证 RFQResponse 状态变更：
  - `status = REJECTED`
  - `reviewedBy = buyerUserId`
  - `reviewedAt != null`
  - `decisionNote` 按请求体写入
- 验证 `WorkflowEvent`
  - `action = REJECTED`
  - metadata 包含 `previousStatus = VIEWED` 与 `decisionNote`
- 验证 `Notification`
  - Supplier Admin 收到 `RESPONSE_UPDATE`
  - 标题为 `Response Rejected`
