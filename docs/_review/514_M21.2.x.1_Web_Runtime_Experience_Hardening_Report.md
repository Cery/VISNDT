## 3. Runtime Experience Changes

### 3.1 Loading States

**变更前**: 所有 17 条公开路由均无 `loading.tsx`，页面导航时无加载反馈。

**变更后**: 17 条路由全部新增 `loading.tsx`，统一使用 `Loading` 组件（旋转 spinner + 居中布局）。

**实现**: 每个 `loading.tsx` 遵循 Next.js App Router 原生机制，Server Component，复用 `@/components/common/Loading`。

### 3.2 Error Boundaries

**变更前**: 所有 17 条公开路由均无 `error.tsx`，TSX 异常时 Next.js 默认错误页。

**变更后**: 17 条路由全部新增 `error.tsx`，每个包含：
- 用户友好的错误描述（中文）
- 重试按钮（`reset()`）
- 返回导航按钮（`<Link>`）
- 警告图标（SVG）
- 不显示任何内部错误信息

**实现**: 每个 `error.tsx` 为 `'use client'` Client Component，遵循 Next.js `error.tsx` 规范。

### 3.3 EmptyState Enhancement

**变更前**: `EmptyState` 组件仅支持 `message`、`description`、`icon`。

**变更后**: 新增 `title` 和 `action` props。`action` 支持 `href`（渲染 Next.js Link）或 `onClick`（渲染 Button），用于空状态下的 CTA 引导。
