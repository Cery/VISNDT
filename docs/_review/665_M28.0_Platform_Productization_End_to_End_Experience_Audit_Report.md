## 6. Business Closed Loop — **VERIFIED（端到端真实运行时）**

核心业务闭环 **Demand → Match → RFQ → Supplier Response** 在真实运行时端到端打通：

```
Buyer 建 Demand (DRAFT 201)
  → 添加参数 resolution / data_interface / weight (各 201)
  → Publish (PUBLISHED 201)  → 触发确定性匹配
  → Match: 命中 "3DSCAN-Pro 结构光三维扫描仪" score=100，新增 DemandMatch
  → 状态链 PENDING→MATCHED→REVIEWED→ACCEPTED (各 200)
  → RFQ from-match (201, DRAFT) → publish (OPEN)
  → Supplier targeted RFQ: /workspace/supplier/rfqs 200，该 RFQ 可见
  → Buyer pending-decisions 200 count=2；buyer overview rfqTotal total=11
```

**重要实证**：配置无参数需求时匹配按设计跳过（`MatchingService` 在 demand.parameters.length===0 时返回 0 matches），**非缺陷**；一旦补全参数，确定性 `weighted_v1` 匹配正确命中 100 分。
