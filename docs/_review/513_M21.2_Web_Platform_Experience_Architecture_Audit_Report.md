## 13. Architecture Decision

**Decision**: **513_M21.2_Web_Platform_Experience_Architecture_Audit — PASS**

**Web Platform Experience Score: 68% (C+)**

**Key Findings**:

1. **Public Web**: 17 routes complete, good content coverage, but **missing loading/error states across all public pages** and **SEO is weak outside content detail pages**.

2. **Workspace**: Buyer and Supplier workspaces are functionally complete but **lack guided flows, onboarding, and mobile support**.

3. **Conversion**: The Content→Product→Inquiry→Demand→RFQ funnel is **structurally complete** but **CTAs are not contextual** and **no conversion tracking exists**.

4. **SEO**: Content pages have excellent SEO (OpenGraph + JSON-LD), but **Product pages lack JSON-LD entirely** and **Product model lacks SEO fields** (Schema gap, not frontend).

5. **Navigation**: Three-layer navigation (Discovery/Business/Workspace) is well-structured but **mobile navigation is basic**.

6. **Design System**: 40+ well-organized components but **no design tokens, no documentation, no shared primitives library**.

**Recommendation**: **Enter M21.2.x Development Phase** (Frontend Only, No Schema/API/Search Change).

**M21.2.x Scope**:
- Add loading.tsx to all 17 public routes (P0)
- Add error.tsx to all 17 public routes (P0)
- Add JSON-LD to product detail + homepage (P0)
- Add OpenGraph to all list pages (P0)
- Add breadcrumb JSON-LD (P1)
- Contextual CTA links (P1)
- Empty state components (P1)
