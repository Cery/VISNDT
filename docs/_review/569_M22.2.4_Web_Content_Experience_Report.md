### Component Changes

| Component | Type | Description |
| --- | --- | --- |
| ContentCard | New | Unified content card: cover image, type badge (color-coded), estimated read time, title, summary, tags (max 3 + overflow), publish date, author name |

### API Consumption

| API | Usage |
| --- | --- |
| GET /content/public | List pages (articles, knowledge, insights, solutions, tags) — added sort/order params |
| GET /content/public/:slug | Detail pages (articles/[slug], knowledge/[slug]) — existing usage |
| GET /api/assets/:id/file | ContentCard cover image + detail page cover image |

### User Experience Improvement

1. **Unified Content Cards**: All four content type list pages (articles, knowledge, insights, solutions) now use the same ContentCard component, providing consistent visual experience across the platform
2. **Cover Image Display**: Content detail pages (articles, knowledge) now show cover images, enhancing visual appeal
3. **Reading Time**: Estimated reading time displayed in both card and detail views, helping users gauge content length
4. **Tag Navigation**: Tag aggregation page now supports all four content types, improving content discovery
5. **Responsive Grid**: List pages use responsive 3-column grid (1 col mobile / 2 col tablet / 3 col desktop)
6. **Sort Support**: Content list API now supports sort/order parameters for flexible content ordering
