## 4. Deployment Command Reference

### 4.1 开发环境

```bash
# 启动所有服务
pnpm dev

# 仅启动 Backend
pnpm --filter @visndt/api dev

# 仅启动 Frontend
pnpm --filter @visndt/admin dev
```

### 4.2 生产构建

```bash
# 全量构建
pnpm build

# 仅 Backend
pnpm --filter @visndt/api build

# 仅 Frontend
pnpm --filter @visndt/admin build
```

### 4.3 数据库操作

```bash
# 开发环境迁移
pnpm db:migrate

# 生产环境迁移
pnpm --filter @visndt/database exec prisma migrate deploy

# 生成 Prisma Client
pnpm db:generate

# 查看数据库
pnpm db:studio
```

### 4.4 生产部署

```bash
# Windows
scripts\deploy.bat

# Backend 启动
node apps/api/dist/main

# Frontend 部署 (Nginx)
# 将 apps/admin/dist/ 部署到 Nginx 静态目录
```
