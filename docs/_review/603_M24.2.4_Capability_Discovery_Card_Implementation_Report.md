## 2. Implementation Summary

将 Product Center 产品列表卡片从「Listing Card」升级为「Capability Discovery Card」：

- 列表接口 `GET /products` 增加两个向后兼容字段：`primaryMedia`（单一主图）与 `keyParameters`（≤3 条核心参数）。
- 前端 `ProductCard` 渲染真实图片（`/files/:fileAssetId/download` 公开下载地址）与关键参数摘要，并保留既有名称 / 型号 / 分类 / 描述 / 比较入口。
- 空态降级：无图片 → 「暂无图片」，无关键参数 → 「暂无参数信息」，均不影响卡片整体渲染。

**确定性来源**：

```
ProductParameterValue → ParameterDefinition（keyParameters）
ProductMedia（mediaType=IMAGE, isPrimary→displayOrder）（primaryMedia）
```

- 关键参数排序：`ProductParameterDefinition.displayOrder`（单产品管理员编排顺序）→ `ParameterDefinition.name` asc → `parameterDefinitionId` asc；无 AI / 推荐算法。
- 主图：仅返回一个 `isPrimary` 优先、`displayOrder` 次之的 IMAGE 媒体，只暴露 `fileAssetId`，不回传完整媒体列表。

## 4. API Impact

- `GET /products` 端点 **保持不变**，入参契约不变。
- 响应列表项 **新增** 两个字段（向后兼容扩展，非 breaking change）：
