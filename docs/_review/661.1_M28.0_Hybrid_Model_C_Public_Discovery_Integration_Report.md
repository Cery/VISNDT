## 2. API Impact（Backend）

能力 = Capability Authority（Platform Product），保持不变。新增 DTO 均位于既有 `CapabilityDetailDTO` 家族，无新的数据库关系、无裸 Offer 列表。

### 2.1 新增 DTO — `CapabilityCommercialSummaryDTO`

位于 `apps/api/src/discovery/dto/capability-detail.dto.ts`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `offerCount` | `number` | 该 SupplierProduct 关联的 Offer 总数 |
| `activeOfferCount` | `number` | 其中 `status = ACTIVE` 的 Offer 数（商业可购数量） |
| `priceFrom` | `number|null` | ACTIVE Offer 价格区间下限（无则 null） |
| `priceTo` | `number|null` | ACTIVE Offer 价格区间上限（无则 null） |
| `currency` | `string|null` | 首个 ACTIVE Offer 的币种（无则回退任意 Offer） |

`CapabilitySupplierProductDTO` 同步扩展只读字段 `description` / `technicalDescription`（供应商型号技术描述，公开信息），以及 `commercialSummary`。

### 2.2 Handler 逻辑（`capabilities.controller.ts`）

分组后逐 SupplierProduct 计算 `commercialSummary`：

- 仅统计 `status === 'ACTIVE'` 的 Offer 用于可购数量与价格带；
- 价格取有效正数价并按数值排序得到 `[priceFrom, priceTo]`；
- 暴露的仅是「商业可购摘要（数量 + 价格带）」，绝不含 Draft / Review / Rejected 等治理内部数据。

### 2.3 API 契约（目标形状）

```json
{
  "platformProduct": { "id": "", "name": "", "categoryId": "" },
  "supplierProducts": [
    {
      "supplierProduct": {
        "id": "", "brand": "", "series": "", "modelNumber": "",
        "description": "", "technicalDescription": "",
        "status": "PUBLISHED",
        "organization": { "id": "", "name": "" },
        "commercialSummary": { "offerCount": 3, "activeOfferCount": 2,
                               "priceFrom": 1200.0, "priceTo": 2600.0, "currency": "CNY" }
      },
      "offers": []
    }
  ]
}
```

## 3. Frontend Impact（Web）

### 3.1 Capability Detail Page（产品详情页增强）

- 新增 `Supplier Models Section`（`SupplierModelsSection.tsx`）：以独立「供应商型号」Tab 呈现。
- 展示（每项 Supplier 型号）：
  - **Brand**（品牌）
  - **Series**（系列）
  - **Model Number**（型号）
  - **Technical Description**（技术描述/描述，公开字段）
  - **Commercial Availability**（商业可购状态）+ 价格带 + 币种
- 状态徽标：`activeOfferCount > 0` → 「可询价」；否则「暂无可购」。公开模型统一呈现为 **Approved Supplier Model**（仅 `PUBLISHED`）。
- 不展示：Draft / Review Status / Rejected Note / 治理内部数据（后端压根不下发）。

### 3.2 数据流

```
page.tsx (Server)
   → getCapabilityDetail(product.id)      // GET /capabilities/:id
   → capability.supplierProducts[]        // 仅 PUBLISHED
   → ProductDetailContent(supplierModels)
   → Tab「供应商型号」→ SupplierModelsSection
```

失败降级：Capability 拉取失败不影响产品详情页，`supplierModels` 置空并渲染空态。
