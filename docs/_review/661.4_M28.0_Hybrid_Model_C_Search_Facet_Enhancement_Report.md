## 4. Search Architecture Verification

**Search = Discovery Acceleration Layer**：本任务仅在 Search 层（`apps/api/src/search/**`）增加投影读取，不拥有业务模型。Search 只负责能力发现、参数过滤、供应商型号检索、公开信息聚合。

**Search != Marketplace Ranking**：未新增 SupplierStore / Shop / Ranking / 交易撮合。未对供应商排名做任何市场化处理。

**Search Non Responsibility 保持**：不负责报价决策、交易撮合、订单生成、支付流程、供应商排名交易化。
