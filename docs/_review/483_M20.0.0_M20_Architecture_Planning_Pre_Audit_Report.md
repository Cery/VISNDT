## 4. Current Architecture Snapshot

### 4.1 Product Model

```
Product = Platform Global Catalog
  ├── category: ProductCategory (tree, self-referencing)
  ├── parameterValues: ProductParameterValue[] (value + valueNumber)
  ├── parameterAssociations: ProductParameterDefinition[] (display order)
  ├── media: ProductMedia[] (FileAsset-backed)
  ├── offers: Offer[] (capability mapping)
  ├── demandMatches: DemandMatch[] (matching results)
  └── inquiries: Inquiry[]
```

### 4.2 Supplier Capability Model

```
Organization (Supplier Identity)
  └── Offer[] (Capability Mapping)
        └── Product (Capability)
  └── OrganizationMember[] (Shared capability access)
```

### 4.3 Search Model

```
Product Search: GET /products (keyword + categoryId + parameterFilters + status + sort + page)
Supplier Capability: GET /organizations/:id + GET /offers?organizationId=
Knowledge Search: GET /content/public (future planning)
Matching Search: Demand → DemandMatch (RFQ Domain)
```

### 4.4 Matching Model

```
Demand.publish() → match() → Candidate Products (ACTIVE + ACTIVE Offer + category filter)
  → ScoringService.calculateScore() (weighted parameter matching)
  → DemandMatch (matchScore + matchDetails JSONB)
  → PENDING → REVIEWED → ACCEPTED/REJECTED
  → RFQ (sourceMatchId) → RFQResponse → WorkflowEvent
```

### 4.5 Content Model

```
Content (ARTICLE | KNOWLEDGE | SOLUTION | INSIGHT)
  ├── media: ContentMedia[]
  ├── revisions: ContentRevision[]
  ├── coverImage: FileAsset?
  ├── status: DRAFT → REVIEW → PUBLISHED → ARCHIVED
  ├── scheduledPublishAt: DateTime?
  └── seo fields: seoTitle, seoDescription, seoKeywords
```

## 5. M20 Direction Assessment

### 5.1 Direction 1: Frontend Platformization — Priority 1

**M20 Definition**: `Frontend Platformization` = enhance platform usage experience without introducing new business models.

**Target**: Elevate VISNDT from "functional web application" to "polished platform experience".

#### Current State Assessment

| Dimension | Current State | M20 Target |
|-----------|---------------|------------|
| Product Discovery | Functional list + detail + parameter search | Enhanced browsing flow, visual hierarchy, comparison |
| Search Experience | keyword + category + parameter filters, URL sync | Unified search experience, cross-entity discovery |
| Supplier Capability | Public page + Product→Supplier link | Capability showcase, trust signals |
| Workspace | Functional dashboards (buyer/supplier) | Role-optimized workspace, task-driven UX |
| User Journey | Independent pages, manual navigation | Guided flows, contextual transitions |
| Admin Governance | 50 management pages, governance statistics | Operation efficiency, batch operations, governance insights |

#### Gap Analysis

| Gap | Description | Priority |
|-----|-------------|----------|
| **Product Comparison** | No side-by-side product parameter comparison | High |
| **Unified Navigation** | Cross-entity discovery (Product→Knowledge→Supplier) not seamless | High |
| **Workspace UX** | Dashboard is functional but not task-driven | High |
| **Responsive Design** | Mobile/tablet experience not optimized | Medium |
| **Loading Performance** | No skeleton loading on all pages; no progressive rendering | Medium |
| **Admin Efficiency** | Batch operations limited; no governance dashboards beyond statistics | Medium |
| **Supplier Trust** | No certification/verification badges; no capability completeness indicators | Medium |
| **Visual Design** | Functional but not polished; no design system | Low |

#### Development Scope

| M20.x Task | Scope | Type |
|------------|-------|------|
| M20.1 Product Discovery Enhancement | Product comparison, visual hierarchy, improved browsing | Frontend |
| M20.2 Search Experience Unification | Cross-entity search, improved filter UX, search suggestions | Frontend |
| M20.3 Workspace Optimization | Role-optimized dashboards, task-driven UX, quick actions | Frontend |
| M20.4 Supplier Capability Showcase | Trust signals, capability completeness, visual identity | Frontend |
| M20.5 Admin Operation Efficiency | Batch operations, governance dashboards, operation insights | Frontend |

**Constraint**: All M20.1-M20.5 are frontend-only. Zero Schema/API change. Backend Capability First.
