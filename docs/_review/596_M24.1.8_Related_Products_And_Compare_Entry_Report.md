## 7. Related Product Resolution

Deterministic, non-AI resolution implemented in `apps/api/src/products/products.service.ts` `findRelatedProducts(idOrSlug)`:

```
find Product (by UUID or slug) → categoryId
if no categoryId → return []  (never fall back to whole catalog)
else → findMany Product where:
  categoryId = product.categoryId
  status = 'ACTIVE'
  id != product.id
  orderBy: [createdAt desc, id asc]
```

Same-category-only basis. No AI / semantic / vector / parameter similarity / matching score.
