## 3. Event Architecture

### 3.1 Event Schema

```typescript
type ConversionEventType =
  | 'page_view'
  | 'product_view'
  | 'cta_click'
  | 'inquiry_start'
  | 'inquiry_submit';

interface ConversionEvent {
  event: ConversionEventType;
  source?: string;
  targetId?: string;
  metadata?: Record<string, unknown>;
  timestamp: string; // ISO 8601
}
```

### 3.2 Adapter Pattern

```
开发环境: ConsoleAdapter → console.log（仅 dev 模式）
生产环境: 通过 setTrackingAdapter() 替换为真实 Provider
```

### 3.3 Event Coverage

| Event | Trigger | Integration Point | Metadata |
|-------|---------|-------------------|----------|
| `product_view` | 产品详情页加载 | `products/[slug]/page.tsx` (TrackOnMount) | productName, category, model |
| `cta_click` | Content CTA 点击 | `ContentProductCTA.tsx` | source: content_{type}, label |
| `inquiry_start` | 选择供应商 | `SupplierInquirySection.tsx` | productId, productName, organizationName |
| `inquiry_submit` | 咨询提交成功 | `InquiryForm.tsx` | productName, offerId, organizationName |
