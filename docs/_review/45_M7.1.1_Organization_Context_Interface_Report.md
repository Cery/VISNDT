## 3. Type Definition

### 3.1 OrganizationContext Interface

```typescript
export interface OrganizationContext {
  userId: string;          // User.id from JWT sub
  organizationId: string;  // Primary organization from JWT
  role?: string;           // Resolved from OrganizationMember (optional)
}
```

### 3.2 Factory Function

```typescript
export function toOrganizationContext(
  user: { id: string; organizationId?: string | null },
  role?: string,
): OrganizationContext
```

Converts `AuthRequest['user']` (from `@CurrentUser()`) to `OrganizationContext`.

---

## 4. Usage Pattern

```typescript
// Controller
@Post()
@UseGuards(JwtAuthGuard)
async create(
  @Body() dto: CreateDto,
  @CurrentUser() user: AuthRequest['user'],
) {
  const ctx = toOrganizationContext(user);
  return this.service.create(dto, ctx);
}

// Service
async create(dto: CreateDto, ctx: OrganizationContext) {
  // ctx.userId → ownership
  // ctx.organizationId → org scoping
  // ctx.role → role-based logic
}
```
