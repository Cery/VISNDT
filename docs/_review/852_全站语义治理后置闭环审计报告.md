## 2. Canonical Baseline（规范基线，852 的判定权威）

- 状态：Product ACTIVE→已发布；User ACTIVE→已启用/正常；Offer ACTIVE→有效（非「活跃」）。同一枚举不同对象不同中文。
- fallback：未知 →「未知状态 / 未知类型」，禁止回退英文原值。
