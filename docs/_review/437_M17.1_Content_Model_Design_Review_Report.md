## 5. ContentStatus Workflow Decision

| 内容状态 | 迁移动作 | WorkflowAction 映射 | 校验 |
| --- | --- | --- | --- |
| DRAFT（草稿） | CREATE | CREATED | 初始状态 |
| REVIEW（审核中） | SUBMIT | SUBMITTED | 仅 DRAFT → REVIEW |
| REVIEW（审核通过） | REVIEW | REVIEWED | 仅 REVIEW → PUBLISHED |
| PUBLISHED（已发布） | PUBLISH | OPENED | 仅 REVIEW → PUBLISHED |
| ARCHIVED（已归档） | ARCHIVE | CLOSED | PUBLISHED → ARCHIVED |

**判定：生命周期与现有 WorkflowAction 完全兼容（不修改 WorkflowAction 枚举）。** 状态流转由后端 Domain Logic 强制校验（仅允许合法迁移）。复用现有 `WorkflowEvent`（entityId=contentId, operatorId=操作人, metadata={type,from,to}）与 Notification 回流。（APPROVED）

## 7. API Contract Review Result

### Public（公开，仅 PUBLISHED）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/content?type=KNOWLEDGE&page=1&pageSize=20` | 列表（已发布，按 type 过滤、分页） |
| GET | `/content/:slug` | 详情（已发布，按 slug） |

### Admin（ADMIN，全部状态）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/content` | 创建草稿（DRAFT） |
| PATCH | `/content/:id` | 更新内容 |
| POST | `/content/:id/submit` | 提交审核（→ REVIEW） |
| POST | `/content/:id/review` | 审核通过（→ REVIEWED） |
| POST | `/content/:id/publish` | 发布（→ PUBLISHED） |
| POST | `/content/:id/archive` | 归档（→ ARCHIVED） |
| GET | `/content` | 后台列表（全部状态） |
| GET | `/content/:id` | 后台详情 |

**权限边界判定**：Public 读接口匿名可访问（仅返回 PUBLISHED）；Admin 写接口 `@UseGuards(JwtAuthGuard, RolesGuard)` + `@Roles(Role.ADMIN)` + `@ApiBearerAuth()`，与产品域一致。

**DTO 设计方向判定**：遵循 existing pattern（class-validator + @nestjs/swagger），`@IsString` / `@IsOptional` / `@IsIn(['ARTICLE','KNOWLEDGE','SOLUTION'])`（type）、`@IsIn(['DRAFT','REVIEW','PUBLISHED','ARCHIVED'])`（status）；生命周期迁移用 `POST /:id/action`，避免 body 携带状态。

**状态流转限制判定**：服务端强制校验合法迁移，非法迁移返回 400/409。

**判定：API Contract 设计冻结（APPROVED）。**
