## 4. API Usage

| 端点 | 方法 | 认证 | 用途 | 调用位置 |
|------|------|------|------|----------|
| `GET /demands/my` | GET | JWT | Demand 列表 | `demands/page.tsx` |
| `GET /demands/:id` | GET | JWT | Demand 详情 | `demands/[id]/page.tsx` |
| `GET /demands/:id/matches` | GET | JWT | Demand 匹配数 | `demands/[id]/page.tsx` |

### 调用链

```
/workspace/demands
  └─ demand.service.getDemands()
       └─ lib/api/demands.getMyDemands()
            └─ apiClient → GET /demands/my

/workspace/demands/[id]
  ├─ demand.service.getDemand(id)
  │    └─ lib/api/demands.getDemand()
  │         └─ apiClient → GET /demands/:id
  └─ demand.service.getDemandMatches(id)
       └─ lib/api/demands.getDemandMatches()
            └─ apiClient → GET /demands/:id/matches
```
