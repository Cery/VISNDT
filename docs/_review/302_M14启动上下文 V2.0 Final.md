# 8.2 Supplier角色模型

当前数据库已存在：

```
User

Organization

OrganizationMember
```

需要纠正的是：

* `Organization.type` 当前是 `String` 字段，不是 enum
* `OrganizationMember.role` 当前也是 `String`
* API 权限侧已有 `Role` enum，但前端与组织上下文尚未完全统一

因此 M14 启动阶段的原则应为：

> 先复用当前 `Organization` / `OrganizationMember` / JWT 组织上下文完成入口设计，  
> 不在启动文档里把未来枚举迁移写成既定事实。

------

用户关系建议表述为：

```
用户(User)

        │

        ▼

组织成员(OrganizationMember)

        │

        ▼

组织(Organization)

        │

        ▼

角色上下文(Role / Organization Context)
```
