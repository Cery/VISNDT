### 2.3 CTA Behavior

**ContentCommercialCTA Component**:

- Accepts `type` prop: `'explore-products'` | `'submit-inquiry'`
- `explore-products`: Shows "探索工业检测设备" card with link to `/products`
- `submit-inquiry`: Shows "获取专业检测方案" card with link to `/products`
- CTA links to `/products` (product catalog), where users can find products and submit inquiries via existing InquiryForm
- Consistent visual design: gradient background, border, icon, responsive layout

**Placement Pattern** (content detail pages):

```
Article Content
  ↓
Commercial CTA Section  ← NEW
  ↓
"More from [type]" Footer
```

**Placement Pattern** (business/about pages):

```

  ↓
Commercial CTA Section  ← NEW
```
