## 4. WorkflowEvent Verification

- **Schema 是否修改**：否。未修改 `WorkflowEvent` 模型，未新增 `ApprovalHistory` / `Reviewer` / `ApprovalUser` / `ContentReviewer` 数据表。
- **查询方式**：`WorkflowEventsService.findContentTimeline()` 通过 `where { entityType: WorkflowEntityType.CONTENT, entityId: contentId }` 过滤，按 `createdAt` 升序返回，显式投影 `id / action / operator(id, name) / metadata / createdAt`。
- **Timeline 数据来源**：仅来自 `WorkflowEvent`（业务流程历史）。不读取 AuditLog（系统审计），不读取 ContentRevision（版本快照）。
- **Reviewer Record**：复用 `WorkflowEvent.operatorId → User`（`operator: { select: { id, name } }`），无独立 Reviewer 模型。

## 5. API Verification

- **新增接口**：`GET /content/:id/approval-timeline`（Admin Only）。
- **权限**：`@UseGuards(JwtAuthGuard, RolesGuard)` + `@Roles(Role.ADMIN)` + `@ApiBearerAuth()`。非 ADMIN 被拒绝（RolesGuard ADMIN 校验）。
- **返回结构**（示例）：

```json
[
  {
    "id": "uuid",
    "action": "SUBMITTED",
    "operator": { "id": "uuid", "name": "Admin" },
    "metadata": { "to": "REVIEW" },
    "createdAt": "2026-08-12T10:00:00Z"
  }
]
```

- **Query Rules**：仅查询 `WorkflowEntityType.CONTENT`，不返回 Demand / RFQ / Organization / Supplier 事件。

## 6. Admin Verification

- **组件**：`apps/admin/src/components/content/ContentApprovalTimeline.tsx`（antd Timeline）。
- **页面位置**：集成于 `apps/admin/src/pages/content/ContentEdit.tsx`「审核时间线」卡片。
- **展示字段**：Action（中文标签：创建/提交审核/审核通过/发布/归档）、Operator、Time、Status Transition（`metadata.to`）。
- **数据来源**：`contentService.getApprovalTimeline(contentId)` → `GET /content/:id/approval-timeline`。
- **UI 限制**：仅展示，无审批按钮 / 审批流程修改 / Reviewer 分配 / 多级审批。

## 7. Security Review

- 无公开接口（`@Roles(Role.ADMIN)` + `@ApiBearerAuth()`）。
- 无权限扩大（复用现有 RBAC，未新增 Role / Permission）。
- 无敏感字段泄露：投影仅含 `id/action/operator(id,name)/metadata/createdAt`，不返回 AuditLog、不返回 Revision 内容、不泄露 `storageKey`、不泄露用户邮箱等敏感信息。
- 职责边界保持：Timeline 仅来自 WorkflowEvent，绝不从 AuditLog 构造。
