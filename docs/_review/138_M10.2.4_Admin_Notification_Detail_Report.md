## Page Architecture

### Data Flow

```
NotificationDetail
    ↓
notificationService.getById(id) → GET /notifications/:id
    ↓
if UNREAD → notificationService.markRead(id) → PATCH /notifications/:id/read
    ↓
Refresh local state with updated notification
```

## Auto Read Logic

### Implementation

```typescript
const markedRead = useRef(false);

// After successful data load, auto-mark as read if UNREAD
useEffect(() => {
  if (pageState.status !== 'success') return;
  if (markedRead.current) return;       // Guard: only once
  if (pageState.data.status !== 'UNREAD') return;

  markedRead.current = true;
  notificationService.markRead(id!).then((updated) => {
    setPageState({ status: 'success', data: updated });
  });
}, [pageState, id]);
```

### Safety Mechanisms

| Mechanism | Purpose |
|-----------|---------|
| `useRef(false)` | Prevents duplicate calls — persists across renders |
| `markedRead.current` guard | Re-entrant check before API call |
| `status !== 'UNREAD'` guard | Skips if already READ |
| `.then()` chaining | Updates local state with fresh READ status from API |
