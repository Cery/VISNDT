## 4. Markdown Implementation

- **存储复用**：`Content.content`（TEXT）保持不变，直接承载 Markdown，零数据迁移。`Database State = No Change`。
- **渲染引擎**：`react-markdown` + `remark-gfm`，支持标题、列表、表格、引用、图片引用语法、链接。
- **安全**：Web 端 `skipHtml`（原始 HTML 不渲染，含 script/style/iframe），链接/图片协议白名单（http/https/mailto/tel/站内相对路径），拦截 `javascript:` 等危险协议。

## 5. Admin Enhancement

- **MarkdownEditor 组件**：受控组件（value/onChange），顶层 Segmented 在「编辑」与「预览」间切换；编辑为等宽 textarea，预览用 react-markdown + remark-gfm 渲染，并配套 `.markdown-preview` GFM 样式。
- **ContentForm 集成**：正文 `Form.Item name="content"` 渲染由 TextArea 升级为 `MarkdownEditor`，表单校验与提交逻辑不变。
- **INSIGHT 类型支持**：类型下拉新增「参数百科（Insight）」；列表类型筛选新增 INSIGHT；Admin 端类型定义（Create/Update/FormData）扩展 INSIGHT。
- **验证**：Admin 创建、编辑、Markdown 保存、Preview 展示均可用（`apps/admin` build exit 0）。

## 6. Web Rendering Enhancement

- **MarkdownRenderer 组件**：服务端渲染（Next App Router Server Component），`Content.content → Safe Renderer → HTML Output → Detail Page`。
- **接入页面**：`/knowledge/[slug]` 与 `/solutions/[slug]` 详情页正文由 `prose + whitespace-pre-wrap` 纯文本升级为 `MarkdownRenderer`。
- **SEO**：`generateMetadata()` 来源 `seoTitle / seoDescription / title / summary` 逻辑完整保留，未受影响。
- **排版**：启用 `@tailwindcss/typography` 的 `prose` 插件（原 `prose` 类此前未生效），Markdown 排版正确呈现。
- **验证**：`apps/web` build exit 0（27 静态页生成成功），无 XSS 风险点。
