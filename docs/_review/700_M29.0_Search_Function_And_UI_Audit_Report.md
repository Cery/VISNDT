## 4. Search Architecture Audit

```
Search UI（SearchPageContent / GlobalSearchBar）
   ↓
Search Client（apps/web/src/services/search.service.ts + lib/api/search.ts）
   ↓
Search API（GET /api/v1/search + GET /api/v1/search/context）
   ↓
Search Controller（search.controller.ts）
   ↓
Search Service（search.service.ts + search-context.service.ts）
   ↓
Prisma（product / supplier_product / knowledge_entry / content / solution / offer）
   ↓
Result Mapping（UnifiedDiscoveryResponse）
```

| 维度 | 实际状态 |
|---|---|
| 实际搜索入口 | Header GlobalSearchBar / SearchPage `/search`（URL 驱动 `q/type/page/category/fc/f_*/sb/ss/sh`） |
| Search API | `GET /api/v1/search`（UnifiedSearchDto：`q, page, pageSize, category, filters, brand, series, hasOffer`）；`GET /api/v1/search/context` |
| DTO | `UnifiedSearchDto`（class-validator：q 必填、page≥1、pageSize 1-50） |
| Query 参数 | `q / page / pageSize / category / filters(parameterId:value1,value2;paramId2:value3) / brand / series / hasOffer` 全部真实传递 |
| Pagination | 每实体独立分页（page/pageSize），URL 驱动、可深链 |
| Sorting | 各实体 `createdAt desc` 等确定性排序，前后端无排序冲突 |
| Filtering / Facet | 服务端 filter-before-pagination；`/search/context` 提供 relevantCategories / commonFilters / categorySpecificFilters；M28 增加 supplierProductFacets（brand/series/commercial）随 `/search` 返回 |
| Result Type | `products / supplierProducts / knowledge / content / solutions / suppliers` + `supplierProductFacets` |
| Ranking | 无显式打分模型；按实体确定性排序；无 AI/语义排序；无 Supplier 优先级 |
| Search Source | Prisma `contains + mode:insensitive`（LIKE 风格），无 tsvector / 外部搜索引擎 / 语义搜索（与 M20.1 Search FROZEN 一致） |
| Error Handling | 前端 ErrorState 组件；后端校验失败返回 4xx |

**Architecture: PASS**（与 580_ADR-001/002/003、M22.4.1 Unified Search、M24.1、M28 FROZEN 完全一致；无第二套 Search、无 Search Engine Rewrite、无新 Schema）。
