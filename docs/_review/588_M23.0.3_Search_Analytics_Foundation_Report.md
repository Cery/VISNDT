### 2.3 Event Contracts

#### SearchEvent

```typescript
interface SearchEvent {
  id: string;           // 唯一事件标识
  query: string;        // 搜索关键词
  source: SearchSource; // web | admin | api | public
  timestamp: Date;      // 搜索时间
  entityTypes: string[];// 搜索实体类型
  resultCount: number;  // 总结果数
  sessionContext?: {    // 会话上下文
    sessionId?: string;
    userId?: string;
    organizationId?: string;
  };
}
```

### 2.5 SearchController Analytics Hook

```typescript
async search(@Query() dto, @Req() req?) {
  const result = await this.searchService.search(...);
  // 非阻塞分析记录 — 不影响响应
  this.recordSearchAnalytics(dto.q, result, req);
  return result; // 响应契约不变
}
```

Analytics hook 通过 `fireAndForget` 模式执行：
- 搜索完成后立即释放响应
- 事件写入失败不抛出异常
- 不修改 UnifiedDiscoveryResponse 结构
