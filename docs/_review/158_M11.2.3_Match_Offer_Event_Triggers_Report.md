## 3. Event Implementation

### 3.1 Event Summary

| Event | Name | Trigger | Notify Target | Type | Method |
|:---:|------|---------|---------------|:---:|--------|
| **E6** | Match Completed | `demands.service.ts:rematch()` | Demand 创建者 | `DEMAND_UPDATE` | `create()` |
| **E7** | Match Status Changed | `demands.service.ts:updateMatchStatus()` | Demand 创建者 | `DEMAND_UPDATE` | `create()` |
| **E8** | Offer Created | `offers.service.ts:create()` | 组织管理员 | `RESPONSE_UPDATE` | `createForOrganization()` |

### 3.2 E6: Match Completed

```
rematch() → matchingService.match(id)
         → notificationsService.create({
             userId: demand.createdBy,
             type: DEMAND_UPDATE,
             title: "Matching Completed",
             message: "{matched} out of {totalCandidates} products matched for your demand",
             referenceType: "MATCH",
             referenceId: demandId
           })
```

### 3.3 E7: Match Status Changed

```
updateMatchStatus() → prisma.$transaction([...])
                   → fetch demand.createdBy + demand.title
                   → notificationsService.create({
                       userId: demand.createdBy,
                       type: DEMAND_UPDATE,
                       title: "Match Status Updated",
                       message: "Match status changed to '{status}' for demand '{title}'",
                       referenceType: "MATCH",
                       referenceId: matchId
                     })
```

### 3.4 E8: Offer Created

```
create() → prisma.offer.create()
         → notificationsService.createForOrganization(
             user.organizationId,
             {
               type: RESPONSE_UPDATE,
               title: "New Offer Created",
               message: "A new offer has been created in your organization",
               referenceType: "OFFER",
               referenceId: offer.id
             }
           )
```
