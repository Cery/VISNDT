## 4. JWT Payload 标准化

```
{
  sub: user.id,           // subject
  email: user.email,      // 邮箱
  name: user.name,        // 显示名 (nullable)
  organizationId: user.organizationId  // 组织ID (nullable)
}
```

- `generateToken()` 签名统一为对象参数
- `validateUser()` 接收完整 payload 并返回标准化 shape
- JwtStrategy.validate() 类型与 AuthService.validateUser() 参数一致
