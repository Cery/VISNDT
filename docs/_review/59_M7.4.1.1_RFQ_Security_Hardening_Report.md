## 1. Phase Overview

本阶段修复 RFQ / RFQResponse 模块中的身份可信问题。当前 RFQ 和 RFQResponse 的创建/更新端点缺少 JWT 认证守卫，且 `createdBy` 和 `organizationId` 字段由客户端直接传入，存在身份伪造风险。

### 修复目标

| 问题 | 修复方案 |
|------|----------|
| `CreateRfqDto.createdBy` 客户端传入 | 删除字段，从 JWT `CurrentUser.id` 获取 |
| RFQ Controller 无认证 | 添加 `@UseGuards(JwtAuthGuard)` + `@ApiBearerAuth()` |
| RFQResponse Controller 无认证 | 添加 `@UseGuards(JwtAuthGuard)` + `@ApiBearerAuth()` |
| `CreateRfqResponseDto.organizationId` 客户端传入 | 删除字段，从 JWT `CurrentUser.organizationId` 获取 |
| RFQ 更新无所有权验证 | 添加创建者/同组织验证 |
| RFQResponse 更新无所有权验证 | 添加同组织验证 |

### 约束遵守

- ✅ 不修改 `database/prisma/schema.prisma`
- ✅ 不创建 Migration
- ✅ 不修改 Auth Module（M6 Freeze）
- ✅ 不修改 JWT Payload
- ✅ 不修改 User Schema

## 4. Security Impact

### 4.1 修复的安全漏洞

| # | 漏洞 | 严重程度 | 修复前 | 修复后 |
|---|------|----------|--------|--------|
| S1 | RFQ `createdBy` 身份伪造 | 🔴 Critical | 客户端传入任意 userId | 从 JWT 签名提取，不可伪造 |
| S2 | RFQResponse `organizationId` 伪造 | 🔴 Critical | 客户端传入任意 orgId | 从 JWT 签名提取，不可伪造 |
| S3 | RFQ 创建无认证 | 🟡 High | 任意用户可创建 RFQ | 需要有效 JWT Token |
| S4 | RFQ 更新无认证 | 🟡 High | 任意用户可修改任何 RFQ | 需要 JWT + 所有权验证 |
| S5 | RFQResponse 创建无认证 | 🟡 High | 任意用户可创建响应 | 需要有效 JWT Token |
| S6 | RFQResponse 更新无认证 | 🟡 High | 任意用户可修改任何响应 | 需要 JWT + 同组织验证 |

### 4.2 新增安全验证

```
RFQ 创建：
  └── JwtAuthGuard 验证 Token 有效性
       └── createdBy = user.id（JWT sub）

RFQ 更新：
  └── JwtAuthGuard 验证 Token 有效性
       └── 所有权验证：
            ├── rfq.createdBy === user.id  → 允许
            └── rfq.demand.organizationId === user.organizationId → 允许

RFQResponse 创建：
  └── JwtAuthGuard 验证 Token 有效性
       └── organizationId = user.organizationId（JWT）
            └── 无 organizationId → 400 Bad Request

RFQResponse 更新：
  └── JwtAuthGuard 验证 Token 有效性
       └── 同组织验证：
            └── response.organizationId === user.organizationId → 允许
```

### 4.3 数据隔离验证

| 场景 | 验证结果 |
|------|----------|
| 未认证用户创建 RFQ | ❌ 401 Unauthorized |
| 未认证用户创建 RFQResponse | ❌ 401 Unauthorized |
| 用户 A 修改用户 B 的 RFQ | ❌ 400 Bad Request（不同 org） |
| 同组织用户修改 RFQ | ✅ 允许 |
| Org A 用户修改 Org B 的 RFQResponse | ❌ 400 Bad Request |
| 无组织用户创建 RFQResponse | ❌ 400 Bad Request |
