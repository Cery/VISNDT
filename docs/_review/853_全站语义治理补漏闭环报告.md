## 5. Fallback 修复

- **原则**：消除 `|| x` / `?? x` 将英文枚举原值回显给用户；未知值统一回退中文占位符（未知状态/未知类型/未知角色/未知）。
- 新增 `apps/web/src/lib/display-labels.ts` 集中映射：组织类型（供应商/采购方/管理员/成员）、组织状态、产品状态（已发布/已下架/草稿/审核中/已归档）、需求状态、产品型号状态。
- Fallback 示例：
  - `STATUS_LABEL_MAP[item.status] || '未知状态'`
  - `ORG_TYPE_LABEL[type] ?? '未知类型'`
  - `ORG_STATUS_LABEL[status] ?? '未知状态'`
  - `statusLabel[product.status] || '未知状态'`
- 覆盖 Admin 端 30+ 文件（UserList/ProductList/ProductDetail/UserDetail/OrganizationList/Detail/RfqDetail/RfqResponseDetail/DemandDetail/ContentEdit/KnowledgeEntryEdit/SupplierProductCreate 等）与 Web 端 8+ 文件（SupplierInfo/ProductDetailContent/RFQDetail/ProductCard/SupplierCapability/inquiry-context 等）。
