## 5. Business Asset Migration Details

### 5.1 Migration Strategy

Each page attempts to fetch a Content-managed ARTICLE by specific slug:
- `/business` → `getContentBySlug('business')`
- `/about` → `getContentBySlug('about')`

**If Content exists:** renders as a full Content detail page (Markdown + MediaGallery + Breadcrumb)

**If Content not found:** renders the preserved static fallback content (identical to original static pages)

### 5.2 Migration Benefits

- Zero breaking change — existing static content fully preserved
- Gradual migration — Admin can create ARTICLE content at any time
- Instant switch — creating ARTICLE with slug='business'/'about' immediately activates Content-managed render
- Full Content lifecycle — DRAFT/REVIEW/PUBLISHED/ARCHIVED workflow applies
- SEO metadata — dynamic `seoTitle`/`seoDescription` from Content model
