## 11. Findings

### Finding #1: Helmet Not Installed (MEDIUM)
- **Category**: Security
- **Description**: The NestJS application does not use the `@nestjs/helmet` (Helmet) middleware. Standard HTTP security headers are missing from API responses.
- **Impact**: Missing `X-Content-Type-Options`, `X-Frame-Options`, `X-XSS-Protection`, `Strict-Transport-Security`, `Content-Security-Policy`, and other security headers.
- **Recommendation**: Install `helmet` and `app.use(helmet())` in `main.ts` for production deployments.

### Finding #2: JWT_SECRET Default is Smoke Test Value (LOW)
- **Category**: Configuration
- **Description**: `docker-compose.yml` line 36: `JWT_SECRET: ${JWT_SECRET:-visndt-smoke-test-jwt-secret-2026}`. The default value is a predictable smoke-test string.
- **Impact**: If `JWT_SECRET` is not set in the production environment, JWTs are signed with a weak, predictable secret.
- **Recommendation**: Set `JWT_SECRET` to a strong random value (64+ characters) in the production environment. Remove the smoke-test default.

### Finding #3: POSTGRES_PASSWORD Default is Weak (LOW)
- **Category**: Configuration
- **Description**: `docker-compose.yml` line 10: `POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-visndt_dev}`. The default password is a development value.
- **Impact**: If `POSTGRES_PASSWORD` is not overridden in production, the database uses a weak password.
- **Recommendation**: Set `POSTGRES_PASSWORD` to a strong password in the production environment.

### Finding #4: Duplicate .env Files (INFO)
- **Category**: Configuration
- **Description**: `.env` and `.env.example` files exist in both the project root and `apps/api/` directory with identical content. The root `.env` is missing `JWT_SECRET` and `JWT_EXPIRES_IN` entries.
- **Impact**: Potential confusion about which `.env` file is authoritative. The root `.env` lacks critical JWT configuration entries.
- **Recommendation**: Consolidate to a single `.env` file at the project root, or clearly document the purpose of each. Add `JWT_SECRET` and `JWT_EXPIRES_IN` to the root `.env`.
