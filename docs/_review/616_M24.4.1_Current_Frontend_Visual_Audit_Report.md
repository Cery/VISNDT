## 6. Gap Analysis

### Current State

当前已经达到：

```
Experience Foundation（体验基座）
```

即：工业配色 Token、网格/光斑/阴影视觉语言、能力发现叙事结构、运营驾驶舱框架、统一运营组件（FilterPanel/PageToolbar/BatchActionBar/Export/Import）、完整 Empty/Loading/Error 状态均已建立。

### Missing Layer

尚未形成（识别到的缺口）：

- **Premium Visual Language（高级视觉语言）**：缺独立插画/图形体系、真实产品影像在目录层的接入、Hero 的影像化表达；微交互（micro-interaction）偏少。
- **Industrial Brand System（工业品牌体系）**：Web/Admin 两端的品牌一致性依赖渐变字体 + 蓝色 token，尚未形成系统化的品牌资产（图形、插画、语义色阶、栅格节奏规范）。
- **B2B SaaS Experience（B2B SaaS 体验）**：`/workspace` 为导航壳页，Buyer/Supplier 工作台 KPI 聚合、待办、数据驾驶舱感薄弱。
- **Capability Discovery Narrative（能力发现叙事）**：首页叙事已建立，但产品详情/目录层的能力参数故事化与「能力发现」价值递进仍可强化。
- **Operation Dashboard Intelligence（运营驾驶舱智能）**：Admin 图表为默认 recharts 样式，缺异常预警、趋势洞察、可行动信号。
- **Component Design System（组件设计体系）**：Admin 大量硬编码色值（红/绿/橙/紫等在 `valueStyle`、`PIE_COLORS` 中散落），未收敛为语义色彩 token；Form/Detail 页面的一致性治理未完成。
