## 1. Phase Overview

将 `Demand.category_id` 从临时 raw SQL 字段正式纳入 Prisma Schema，移除 `CategoryHelper` 类及其 raw SQL 依赖，消除技术债务 TD-1。

**Before**: `Demand.category_id` 存在于数据库但不在 Prisma Schema 中，通过 `CategoryHelper.$queryRawUnsafe()` 读取。

**After**: `Demand.categoryId` 正式定义为 Prisma 字段，`MatchingService` 通过 `demand.categoryId` 直接访问。
