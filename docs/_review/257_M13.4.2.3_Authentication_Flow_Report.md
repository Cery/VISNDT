## 4. Auth Flow

```
Visitor
  ↓
Login Page (/login)
  │  Email + Password
  ↓
auth.service.login()
  ↓
POST /auth/login
  ↓
{ accessToken, user }
  ↓
setToken(accessToken)     → localStorage: visndt_token
setCurrentUser(user)      → localStorage: visndt_user
  ↓
AuthProvider Context 更新
  │  token, user, isAuthenticated = true
  ↓
redirect → /dashboard
```

```
Visitor
  ↓
Register Page (/register)
  │  Email + Password + Name? + InviteToken?
  ↓
auth.service.register()
  ↓
POST /auth/register
  ↓
{ accessToken, user }
  ↓
setToken(accessToken)     → localStorage: visndt_token
setCurrentUser(user)      → localStorage: visndt_user
  ↓
AuthProvider Context 更新
  │  token, user, isAuthenticated = true
  ↓
redirect → /dashboard
```

```
Logout
  ↓
removeToken()             → 清除 visndt_token
removeCurrentUser()       → 清除 visndt_user
  ↓
AuthProvider Context 更新
  │  token = null, user = null, isAuthenticated = false
```

### AuthProvider 状态

| 属性 | 类型 | 说明 |
|------|------|------|
| `user` | `AuthUser \| null` | 当前用户信息 |
| `token` | `string \| null` | JWT access token |
| `isAuthenticated` | `boolean` | `!!token && !!user` |
| `isLoading` | `boolean` | 初始化加载中 |
| `login(email, password)` | `Promise<void>` | 登录 + 存储 + Context 更新 |
| `logout()` | `void` | 登出 + 清除存储 |
| `register(email, password, name?, inviteToken?)` | `Promise<void>` | 注册 + 存储 + Context 更新 |

### JWT 存储方式

| 存储键 | 内容 | 位置 |
|--------|------|------|
| `visndt_token` | JWT access token | localStorage |
| `visndt_user` | `{ id, email, name?, organizationId? }` | localStorage (JSON) |

- ❌ 不保存密码

## 5. Route Protection

### 受保护路由

| 路由 | 保护方式 | 未登录行为 |
|------|----------|------------|
| `/dashboard` | `AuthGuard` | redirect → `/login` |
| `/workspace` | `AuthGuard` | redirect → `/login` |

**AuthGuard 流程：**
```
AuthGuard
  ├─ isLoading → <Loading />
  ├─ !token || !user → router.replace('/login')
  └─ 已认证 → {children}
```
