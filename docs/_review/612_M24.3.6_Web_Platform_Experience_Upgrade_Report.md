## 8. Media Fallback Validation

`MediaImage` 组件实现三级 fallback，满足 610 媒体验证标准：

1. **FileAsset URL**：`fileAssetUrl(fileAssetId)` → `GET /files/:id/download`（生产：S3 Compatible Storage）。
2. **开发占位**：`placeholderImageUrl(seed)` → `https://picsum.photos/seed/{seed}/800/600`（仅 `NODE_ENV==='development'`）。
3. **空态**：生产无资产时渲染「暂无图片」占位框，不产生断图 / 空白 / UI 坍塌。

已集成至 `ProductCard`（列表主图）与 `ProductGallery`（详情画廊），`onError` 触发降级链路。
