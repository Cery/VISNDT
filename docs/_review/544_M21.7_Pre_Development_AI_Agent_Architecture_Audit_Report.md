### Design Principles

1. **AI Gateway**: Single entry point for all AI interactions, with JWT-based auth, rate limiting, and audit logging
2. **Agent Runtime**: Lightweight orchestration layer — Prompt Manager + Tool Registry + Conversation Manager
3. **Tool Layer**: Abstraction over Semantic Layer + Business APIs, exposing typed tool interfaces to the agent
4. **Semantic Layer**: Remains Internal Capability, consumed only through AI Gateway → Tool Layer
5. **Business APIs**: No changes needed — AI reads through existing API boundary
6. **Human-in-the-Loop**: All AI outputs are advisory. Business mutations require human confirmation
