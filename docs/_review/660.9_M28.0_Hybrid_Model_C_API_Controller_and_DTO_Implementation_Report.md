## 2. API Implementation Summary

### 2.1 SupplierProduct Controller（Admin 路由）

`apps/api/src/supplier-products/supplier-products.controller.ts`

- 类级 Guard：`JwtAuthGuard + RolesGuard`，`@Roles(Role.ADMIN)`，`@ApiBearerAuth()`。
- 权限保持 **Role.ADMIN**（当前阶段禁止 `Role.SUPPLIER`）。
- 组织上下文：`organizationId` **恒从认证用户上下文派生**（`user.organizationId`），禁止 DTO 接收。

| Method | Route | 说明 |
| --- | --- | --- |
| POST | `/admin/supplier-products` | 创建 DRAFT（能力绑定校验）；org 空则 BadRequest |
| GET | `/admin/supplier-products` | 按管理组织列出（status/page/pageSize） |
| GET | `/admin/supplier-products/:id` | 按管理组织读取单个 |
| POST | `/admin/supplier-products/:id/submit` | DRAFT → SUBMITTED（`user.id` 记录操作者写入 service） |
| POST | `/admin/supplier-products/:id/review` | SUBMITTED → REVIEWING |
| POST | `/admin/supplier-products/:id/approve` | REVIEWING → APPROVED |
| POST | `/admin/supplier-products/:id/reject` | REVIEWING → REJECTED（**必填 reviewedNote**，DTO + service 双校验） |
| POST | `/admin/supplier-products/:id/publish` | APPROVED → PUBLISHED |

### 2.2 SupplierProduct DTO

- **CreateSupplierProductDto**：`platformProductId / brand / series? / modelNumber / description? / technicalDescription? / applicationInfo?`（class-validator 校验，Swagger 文档化）。
- **RejectSupplierProductDto**：`reviewedNote`（`@IsNotEmpty`）；reject 必须有 reviewedNote。

### 2.3 Offer DTO Extension

`apps/api/src/offers/dto/create-offer.dto.ts` 扩展可选 `supplierProductId?`（`@IsUUID`）。

- 保持 `organizationId`（Service 从 user context 派生；DTO 不接收组织字段）。
- 旧 Offer（`supplierProductId=NULL`）仍可创建/查询（service `validateSupplierBinding` 对空值 no-op）。

### 2.4 Capability Discovery API

`apps/api/src/discovery/capabilities.controller.ts`

- Route：`GET /capabilities/:id`。
- 调用 `DiscoveryService.findCapabilityGraph(id)`，在 **transport 层** 将扁平结果重塑为 **CapabilityDetailDTO**（能力节点锚定、逐 supplierProduct 各自 offers[]）。

```typescript
{
  platformProduct,          // Capability Authority（Product）
  supplierProducts: [
    {
      supplierProduct,      // Supplier Model Entity
      offers: []            // 该型号自己的 Commercial Layer
    }
  ]
}
```

- **禁止暴露**：Prisma raw relation / 数据库 join 结构 / 裸 Offer List。
