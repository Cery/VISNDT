## 1. Phase Overview

**Purpose**: 补齐 Product Global Catalog 关联管理模块的权限边界。

**Background**: M7.2.1 Architecture Review 发现 4 个关联模块 (ProductCategories, ParameterGroups, ParameterDefinitions, ProductParameters) 的 POST/PATCH 端点完全开放，任何人都可以创建/修改平台产品知识数据。

**Strategy**: 仅 Controller 层添加 ADMIN Guard，不修改 Service 层业务逻辑，不修改数据模型。
