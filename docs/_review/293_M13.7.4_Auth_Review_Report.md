### 3.2 Login Flow (Step-by-step)

| Step | Actor | Action | Detail |
|------|-------|--------|--------|
| 1 | User | Submit login form | email + password |
| 2 | LoginPage | `useAuth().login(email, password)` | Via AuthProvider |
| 3 | AuthProvider | `apiLogin({ email, password })` | Via auth.service.ts |
| 4 | auth.service | `apiClient('/auth/login', POST)` | Via apiClient |
| 5 | apiClient | CSRF excluded for `/auth/login` | Whitelisted |
| 6 | apiClient | `fetch(url, { body, credentials: 'include' })` | Direct fetch |
| 7 | Backend | Validate credentials → set cookies | `access_token` + `refresh_token` |
| 8 | Backend | Return `{ data: { user: {...} } }` | HttpOnly cookies |
| 9 | auth.service | Return `ApiResponse.data` | `{ user: AuthUser }` |
| 10 | AuthProvider | `setUser(res.user)` | Updates context |
| 11 | LoginPage | `router.replace('/dashboard')` | Redirect on success |

### 3.3 AuthGuard Flow (Protected Routes)

| Step | Actor | Action | Detail |
|------|-------|--------|--------|
| 1 | User | Navigate to `/workspace/*` | Protected route |
| 2 | AuthGuard | Check `isLoading` | Show `<Loading />` spinner |
| 3 | AuthProvider | `getMe()` → `GET /auth/me` | On mount, cookie-based |
| 4 | Backend | Return user from JWT cookie | Or 401 if expired |
| 5 | AuthProvider | `setUser(currentUser)` | `isLoading = false` |
| 6 | AuthGuard | `isAuthenticated ?` | Yes → render children |
| 7 | AuthGuard | `!isAuthenticated` | → `router.replace('/login')` |

### 3.4 Token Refresh Flow

| Step | Actor | Action | Detail |
|------|-------|--------|--------|
| 1 | apiClient | Any API call returns 401 | Except `/auth/refresh` itself |
| 2 | apiClient | `tryRefreshToken()` | `POST /auth/refresh` (cookie-based) |
| 3 | Backend | Read `refresh_token` cookie | Validate + rotate |
| 4 | Backend | Set new `access_token` + `refresh_token` | HttpOnly cookies |
| 5 | apiClient | Refresh succeeded → retry original request | With same `...init` |
| 6 | apiClient | Refresh failed → throw `ApiError(401, 'Session expired')` | Caller handles |

### 3.5 CSRF Flow

| Step | Actor | Action | Detail |
|------|-------|--------|--------|
| 1 | apiClient | POST/PUT/PATCH/DELETE request | Check `CSRF_METHODS` |
| 2 | apiClient | `getCsrfToken()` | Fetch from cache or `GET /auth/csrf` |
| 3 | Backend | `GET /auth/csrf` | Set `csrf_token` cookie + return in body |
| 4 | csrf.ts | Cache token in memory | NOT localStorage — XSS-safe |
| 5 | apiClient | Set `X-CSRF-Token` header | Send with request |
| 6 | Backend | Validate `X-CSRF-Token` vs `csrf_token` cookie | Double Submit Cookie |

### 3.6 Excluded CSRF Paths

| Path | Reason |
|------|--------|
| `/auth/refresh` | Token refresh — no CSRF needed |
| `/auth/login` | Login — no session yet |
| `/auth/register` | Registration — no session yet |
| `/auth/csrf` | CSRF token fetch — circular dependency |
