### 3.1 DDL 应用（已确认落库）

| 列 | 类型 | 可空 | 默认 |
|----|------|------|------|
| `organization_id` | uuid | YES | — |
| `status` | FileAssetStatus (enum) | NO | `'ACTIVE'` |
| `deleted_at` | timestamp | YES | — |

`FileType` 新增 `SPEC_SHEET`/`ILLUSTRATION` 枚举值，`FileAssetStatus` 枚举已创建。

### 3.2 数据回填

迁移内建 `UPDATE file_asset ... FROM user` 回填 `organization_id`（`uploadedBy → User.organizationId`）。

> **数据现状**：`file_asset` 表当前 **0 行**（`product_media`/`content_media` 亦为 0），故回填为**空集 no-op**。回填断言公式与存量行一致性均成立（无行需回填）。未来媒体上传时，`upload` 服务将即时写入 `organizationId`，无需二次回填。
