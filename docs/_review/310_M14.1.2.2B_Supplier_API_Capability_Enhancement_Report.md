## 5. RFQ Available 查询逻辑

实现位置：

- [rfqs.service.ts#L80-L120](file:///F:/Desktop/VISNDT/VISNDT/apps/api/src/rfqs/rfqs.service.ts#L80-L120)

查询规则：

1. 默认状态过滤：
   - `OPEN`
   - `RESPONDING`

2. 若显式传入 `status`：
   - 使用传入状态值

3. 关键字匹配：
   - `keyword` 匹配 `demand.title`

4. 分页：
   - 使用 `SearchParamsDto`
   - 计算 `skip = (page - 1) * pageSize`
   - 使用 `take = pageSize`

5. 返回结构：
   - 保持领域模型嵌套，不拍平 `demand`

实际返回结构为：

```ts
{
  data,
  total,
  page,
  pageSize,
  totalPages
}
```

单项数据结构为：

```ts
{
  id,
  status,
  publishedAt,
  closedAt,
  createdAt,
  updatedAt,
  demand: {
    id,
    title,
    description,
    organizationId
  }
}
```

说明：

- 本次没有改动 Prisma schema
- 本次保持 Prisma 关系查询，通过 `RFQ -> Demand` 完成筛选与返回
