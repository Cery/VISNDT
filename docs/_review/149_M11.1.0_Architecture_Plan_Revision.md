## 1. Revision Reason

### 1.1 触发原因

原始 M11.1.0 Architecture Plan (`148_M11.1.0_Architecture_Plan.md`) 包含 **Module D: Notification Trigger Foundation**，该模块需要修改 4 个 Backend 文件（`notifications/`, `demands/`, `rfqs/`, `rfq-responses/`），涉及 3 个 Frozen 模块的解冻。

根据当前 VISNDT 冻结策略：
- Database: FROZEN
- Backend business modules: FROZEN (M8)
- Backend notifications: RE-FROZEN (M10.2.5)
- Backend admin: RE-FROZEN (M10.3.3)

**M11.1 应聚焦于 Admin Frontend 扩展，禁止默认修改 Frozen Backend。** Notification Trigger 作为独立能力应移至单独的 Enhancement 阶段。

### 1.2 修正要点

| 维度 | 原始 M11.1 Plan | 修正后 M11.1 Plan |
|------|:---:|:---:|
| Backend 变更 | 4 文件 (additive) | **0** |
| Backend Unfreeze | 需要 | **不需要** |
| Frozen Module 触碰 | 3 个模块 | **0** |
| Notification Trigger | 纳入 M11.1 Core | **移至独立 Enhancement** |
| M11.1 性质 | Frontend + Backend | **纯 Frontend** |
