## 1. Phase Overview

本阶段为 Product Parameter System 增加数据类型能力，为后续 M7.3.2 Numeric Range Filter 做准备。核心变更包括：

- 新增 `ParameterDataType` 枚举（STRING / NUMBER / BOOLEAN / ENUM）
- 将 `ParameterDefinition.dataType` 从 `String` 升级为枚举类型
- 为 `ProductParameterValue` 新增 `valueNumber Float?` 字段
- 新增复合索引 `@@index([parameterDefinitionId, valueNumber])`

### 发现

`ParameterDefinition.dataType` 字段已以 `String` 类型存在，本阶段将其升级为 `ParameterDataType` 枚举以获得类型安全。

## 3. Schema Changes

### 3.1 新增枚举：ParameterDataType

```prisma
enum ParameterDataType {
  STRING
  NUMBER
  BOOLEAN
  ENUM
}
```

### 3.2 ParameterDefinition.dataType 升级

| 属性 | 修改前 | 修改后 |
|------|--------|--------|
| 类型 | `String` | `ParameterDataType` |
| 默认值 | 无 | `@default(STRING)` |
| 映射 | `@map("data_type")` | 不变 |

**影响：** 旧参数数据自动归类为 STRING。新参数需指定 `dataType`，未指定时默认 STRING。

### 3.3 ProductParameterValue 新增字段

| 字段 | 类型 | 映射 | 说明 |
|------|------|------|------|
| `valueNumber` | `Float?` | `value_number` | 数值参数的数字表示 |

**用途示例：**
- 镜头直径: `value = "2.8mm"`, `valueNumber = 2.8`
- 分辨率: `value = "200万"`, `valueNumber = 200`
- 无关参数: `value = "LED"`, `valueNumber = null`

### 3.4 新增索引

```sql
CREATE INDEX "product_parameter_value_parameter_definition_id_value_numbe_idx" 
ON "product_parameter_value"("parameter_definition_id", "value_number");
```

**用途：** 为 M7.3.2 Numeric Range Filter（`valueNumber >= x AND valueNumber <= y`）提供索引支持。

## 4. Migration Details

### Migration 名称

`20260718180104_add_parameter_datatype_enhancement`

### Migration SQL

```sql
-- CreateEnum
CREATE TYPE "ParameterDataType" AS ENUM ('STRING', 'NUMBER', 'BOOLEAN', 'ENUM');

-- AlterTable: 将 data_type 列从 String 改为 ParameterDataType 枚举
ALTER TABLE "parameter_definition" DROP COLUMN "data_type",
ADD COLUMN "data_type" "ParameterDataType" NOT NULL DEFAULT 'STRING';

-- AlterTable: 新增 value_number 列
ALTER TABLE "product_parameter_value" ADD COLUMN "value_number" DOUBLE PRECISION;

-- CreateIndex: 数值参数复合索引
CREATE INDEX "product_parameter_value_parameter_definition_id_value_numbe_idx" 
ON "product_parameter_value"("parameter_definition_id", "value_number");
```

### 风险提示

⚠️ `data_type` 列会被 DROP 并重建，如果表中已有数据且值不在枚举范围内（如 'number' 小写），会导致数据丢失。建议在应用迁移前确认现有数据兼容性。
