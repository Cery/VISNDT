## 5. Current Product / SupplyProduct / Supplier Semantics

- **Product = Canonical Platform Object**（Capability Authority）。`platformProductId` 作为 1:N 供给关系挂点语义稳定。
- **SupplyProduct = Supplier-owned Commercial Product**，**未被重新解释为 Capability**；保持既有生命周期/状态机（`SupplierProductStatus` DRAFT/SUBMITTED/REVIEWING/APPROVED/PUBLISHED/REJECTED 未动）。
- **Supplier = Organization(type=SUPPLIER) 语义角色**，**不新增 Supplier 表**；供应商身份一律来自 `SupplierProduct.organizationId / organization`，**绝非 Offer.organizationId**。
- **SupplierContext** 为统一前端视图模型：`organizationId / name / publishedSupplyProductCount / relatedProductId / publishedStatus` + `models`。

## 6. Published Supply Asset Boundary

供应商可被发现（进入公开 Supplier Context）的充要条件：
- 存在 **≥1 个 `status='PUBLISHED'` 的 SupplyProduct**；
- 该 SupplyProduct 关联的 **Organization.type = SUPPLIER**。

后端强制边界：`apps/api/src/discovery/discovery.service.ts` `findCapabilityGraph` 默认 `statusFilter = SupplierProductStatus.PUBLISHED`（L49-51），`supplierProducts` 查询按 `platformProductId` + `status=PUBLISHED` 过滤（L53-58），有 `includeDrafts` 显式声明的才放开。

**本路径不要求存在 Offer / Inquiry / RFQ / 交易历史。** 零商业层依赖已确认。

## 7. Supplier Semantic Model Implementation

新增 `apps/web/src/lib/supplier-context.ts`（纯展示层 view model，非 Entity）：

- 接口族：`SupplierModelSpecContext` / `SupplierModelContext` / `SupplierContext` / `SupplierRelationshipContext`。
- `SupplierContext` 满足 §7 契约字段：`organizationId / name / publishedSupplyProductCount / relatedProductId / publishedStatus('PUBLISHED')`。
- `SupplierModelContext`：`id / slug / model（brand + series + modelNumber 拼接）/ brand / status / specifications / hasMedia`。
- `buildSupplierRelationshipContext(relatedProductId, supplierModels)`：确定性投影，按 `organizationId` 归并 suppliers，累计 `publishedSupplyProductCount`，`source='PUBLISHED_SUPPLIER_PRODUCT_ORGANIZATION'`。

**数据源纯净性**：仅读取 `supplierProduct.organization / parameterValues / media`；**零 Offer / RFQ / Transaction 读取**；不创建 Persistence Entity / Prisma Model / Migration / 表；不虚构 Supplier Database Record；supplier identity 一律来自 `PlatformProduct → Published SupplyProduct → Organization`。
