## Architecture Impact

- **Layer**: Frontend Admin (apps/admin/)
- **New Components**: `components/organization/` — follows existing `components/user/` pattern
- **Data Flow**:
  - Create: Page → OrganizationForm → organizationService.create() → apiClient → POST /organizations
  - Edit: Page → PageState (loading) → organizationService.getById() → OrganizationForm → organizationService.update() → apiClient → PATCH /organizations/:id
- **Pattern**: Mirrors M10.1.2 User Create/Edit exactly
- **No new dependencies added**

## Security Impact

- **Route Protection**: All new routes inside `<RequireAuth>` wrapper
- **JWT Injection**: apiClient interceptor automatically injects Bearer token
- **Backend Authorization**: `checkOrganizationAccess` + RBAC (ADMIN) enforced by Backend
- **No client-controlled organizationId**: OrganizationCreate/Edit do not pass organizationId from client
- **No bypass of RBAC**: Frontend pages only make API calls; Backend enforces authorization

## API Changes

- **No new APIs** added
- **No existing APIs** modified
- Uses existing Backend endpoints:
  - `POST /organizations` — via `organizationService.create()`
  - `PATCH /organizations/:id` — via `organizationService.update()`
  - `GET /organizations/:id` — via `organizationService.getById()` (Edit page load)
