## 3. SupplierProduct Demo Data Completion（D1）

### 3.1 Seed 脚本

新增 `database/seed_supplier_product.ts`（幂等 upsert，`npm run seed:supplier-product`）。

设计约束（严格来自现有 Schema，禁止伪造业务模型）：

```text
SupplierProduct.platformProductId / organizationId / brand / series / modelNumber / status
    ↓
SupplierProduct → Offer → Supplier Organization 真实关系
    ↓
Offer.productId = SupplierProduct.platformProductId
Offer.organizationId = SupplierProduct.organizationId
```

组织经供应商成员关系（`supplierUserEmail` → OrganizationMember）动态解析，不依赖硬编码组织名后缀。

### 3.2 数据现状（prisma 实查）

| 实体 | 数量 | Note |
| --- | --- | --- |
| SupplierProduct | **13** | 3 组织 × 7 平台产品 |
| SupplierProductMedia | **5** | 部分型号含媒体 |
| SupplierProductParameterValue | **13** | 部分型号含 Parameter Override |
| PUBLISHED SupplierProduct | **6** | 公开边界 |
| 绑定 SupplierProduct 的 Offer | **6**（offer_total=7） | 全部 ACTIVE |

组织分布：

```text
明视（mingshi）    5 条
锐视（ruishi）     5 条
中科（zhongke）    3 条
```

状态覆盖（全六档）：`PUBLISHED=6 / DRAFT=2 / SUBMITTED=2 / REVIEWING=1 / APPROVED=1 / REJECTED=1`。

不同 brand / series / modelNumber；部分型号含 Media；部分型号含 Parameter Override；6 个 PUBLISHED 型号绑定 ACTIVE Offer。

### 3.3 Data Chain Integrity

实查 6 条绑定 Offer 全部满足：

```text
offer.organizationId === SupplierProduct.organizationId
offer.productId       === SupplierProduct.platformProductId
SupplierProduct.status === PUBLISHED
```

**全 PASS**（禁止跨组织 / 跨能力伪造测试数据）。
