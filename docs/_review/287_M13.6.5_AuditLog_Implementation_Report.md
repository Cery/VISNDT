### 4.2 Query Parameters (GET /admin/audit-logs)

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `page` | number | No | Page number (default: 1) |
| `pageSize` | number | No | Items per page (default: 20, max: 100) |
| `entityType` | string | No | Filter by entity type (e.g., DEMAND, OFFER) |
| `action` | string | No | Filter by action (CREATE, UPDATE, DELETE, STATUS_CHANGE, LOGIN) |
| `operatorId` | string | No | Filter by operator user ID |
