## 1. Task Summary

**Objective**: 优化 Public Web 内容体系到产品发现之间的上下文连接，从单一 "Content → Product" 路径升级为 "Content → Contextual Product Discovery → Inquiry" 的用户体验路径。

**Before**:
```
Content（knowledge/solution/article/insight）
  ↓
Generic CTA（explore-products / submit-inquiry）
  ↓
/products
```

**After**:
```
Content（knowledge/solution/article/insight）
  ↓
Contextual CTA（内容类型感知的产品发现引导）
  ↓
/products（或 /products?categoryId=xxx）
  ↓
Inquiry
```

**Scope**: Frontend Only — 1 新增组件 + 4 页面修改，零 Schema/API/Migration 变更。
