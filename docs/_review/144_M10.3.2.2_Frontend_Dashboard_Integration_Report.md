## Data Flow

### Single Parallel Fetch

```typescript
Promise.all([
  dashboardService.getStats(),           // GET /admin/dashboard/stats
  notificationService.getUnreadCount(),   // GET /notifications/unread-count
  dashboardService.getActivities(),       // GET /admin/dashboard/activities    ← NEW
  dashboardService.getPending(),          // GET /admin/dashboard/pending       ← NEW
  dashboardService.getStatus(),           // GET /admin/dashboard/status        ← NEW
])
```

**All 5 API calls execute in parallel. No serial chaining.**

### Architecture Chain

```
Home.tsx
  ↓
dashboardService.getActivities() / getPending() / getStatus()
  ↓
apiClient.get()
  ↓
Backend Controller → Service → Prisma
```

**No direct apiClient usage in Home.tsx. No axios/fetch usage.**

## UI Components

### Pending Items Section

4 `Card` + `Statistic` components in a `Row`/`Col` grid:

| Card | Icon | Value | Color Logic |
|------|------|-------|-------------|
| Users Pending | `ExclamationCircleOutlined` | `pending.usersPending` | Orange if > 0 |
| Demands Pending | `FileSearchOutlined` | `pending.demandsPending` | Orange if > 0 |
| RFQ Pending | `ThunderboltOutlined` | `pending.rfqPending` | Orange if > 0 |
| Unread Notifications | `NotificationOutlined` | `pending.unreadNotifications` | Red if > 0 (clickable → /notifications) |

### Recent Activities Section

Single `Card` with `Timeline` component, 4 event categories:

| Category | Icon | Color | Content |
|----------|------|-------|---------|
| Users | `UserOutlined` | Blue | "New User Registered" + email + relative time |
| Demands | `FileTextOutlined` | Green | "New Demand Created" + title + status Tag + relative time |
| Matches | `LinkOutlined` | Orange | "New Match Generated" + score% + status Tag + relative time |
| Notifications | `BellOutlined` | Cyan | "Notification" + title + type Tag + relative time |

**Relative time display**: "Just now", "5m ago", "3h ago", "2d ago", or full date.

**Empty state**: `<Empty description="No recent activities" />` when all 4 arrays are empty.

### System Status Section

Two `Descriptions` blocks in a single `Card`:

| Block | Fields |
|-------|--------|
| System Health | Database (green Tag), API (green Tag), Last Updated (formatted datetime) |
| Entity Counts | Users, Organizations, Products, Demands, Matches |
