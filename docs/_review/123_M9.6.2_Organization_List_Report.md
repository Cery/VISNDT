## Architecture Impact

- **数据流**: `OrganizationList.tsx` → `organizationService.getList()` → `apiClient.get('/organizations')` → Backend
- **依赖**: 复用 `apiClient`，无新增外部依赖
- **模式**: 严格遵循 ProductList/DemandList/UserList 模板
- **搜索**: Client-side filter (Backend `GET /organizations` 无 search/filter 参数)

---

## Security Impact

- **无影响** — 路由在 `RequireAuth` 守卫下
- `GET /api/v1/organizations` 需要 ADMIN 角色，Backend 侧 `@Roles(Role.ADMIN)` 保护
- 认证链路完整: RequireAuth → JWT Token → Backend ADMIN Guard

---

## API Changes

- **无新增 Backend API** — 复用 `GET /api/v1/organizations` (ADMIN only)
- Frontend `organizationService.getList()` 映射 `GET /organizations?page=&pageSize=`
