## 5. Product Center V2 Architecture

### 5.1 产品列表页信息架构

```
Product Center
├── Category Navigation（分类树，categoryId）
├── Search Bar（keyword）
├── Dynamic Parameter Filter（动态参数筛选，ParameterDefinition 驱动 → parameterFilters）
├── Sort（sortBy/sortOrder）
├── Product Result Grid（产品卡片）
└── Pagination（page/pageSize）
```

**产品卡片规划**（基于 `Product / ProductMedia / ProductParameterValue / Offer`）：
- 主图（ProductMedia isPrimary）
- 产品名称
- 型号（model）
- 分类
- 核心参数摘要（取前 N 个 ProductParameterValue）
- 供应商数量提示（规划：`offers` 数量，展示「N 家供应」）

### 5.2 产品详情页信息架构

```
Product Detail
├── Overview（名称/型号/分类/描述/主图相册）
├── Media Center（ProductGallery + 文档/证书）
├── Technical Specification（ParameterGroup → ParameterDefinition → ProductParameterValue 动态渲染）
├── Certification / Documents（非 IMAGE 媒体）
├── Supplier Capability（Offer + Organization 列表，禁止公开价格）
└── Inquiry Entry（产品 → 选择供应商 Offer → 询价）
```

**参数展示要求**：必须按 `ParameterGroup → ParameterDefinition → ProductParameterValue` 分组动态渲染，**禁止硬编码** 管径 / 像素 / 长度 / 光源 / 视场角。

1. **询价自动取首个 Offer（高）**：改造为「选择供应商」涉及 InquiryForm 状态管理，需确保 offerId/organizationId 正确透传。
