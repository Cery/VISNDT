## 4. Workspace Experience Upgrade Result

`/workspace` 从「导航入口壳页面」升级为「B2B Industrial Platform Workspace Experience」，形成：

```
Identity
↓
Role Awareness
↓
Business Snapshot
↓
Pending Actions
↓
Quick Operations
↓
Dashboard Deep Link
```

体验链路（Before → After）：

- Before：`/workspace` 仅承担导航职责，用户进入后缺少业务状态感知、KPI 聚合、待处理事项中心与 SaaS 驾驶舱体验，需主动进入 Dashboard 才能获取业务信息。
- After：用户进入 Workspace 首先感知「我是谁 / 我在哪个角色 / 我的组织上下文」（Context First），其次看到业务快照 KPI（Data Second），最后明确下一步行动入口（Action Third）。

SaaS 体验原则（Context First → Data Second → Action Third）落地为三层：`WorkspaceIdentityBar`（身份/角色）→ 业务快照 + 待处理事项 → 快捷入口 + 工作台深链。

Workspace 定位保持「Business Entry Experience Layer」，非 Dashboard Replacement——保留 Dashboard Deep Link 作为完整工作台承接，实现体验过渡。

## 5. Buyer Workspace Result

`BuyerWorkspaceEntry`（采购方 / Demand Side）：

- **身份与角色**：`WorkspaceIdentityBar`（title=采购方工作空间，roleLabel=Buyer · 采购方，roleHint=需求发起侧（Demand Side），roleTone=cyan）。
- **业务快照（KPI）**：4 张 `StatCard`——需求（demandSummary.total + 状态分布）、询价（rfqSummary.total）、匹配（matchSummary.total + 状态分布）、待决策响应（responseSummary.pendingCount）。
- **待处理事项（Pending Actions）**：`BuyerActionSummary`（待处理供应商响应，count=待决策数量）+ 最近 2 条待决策响应的具体卡片（demand.title / supplierOrganization.name / 查看询价深链）。
- **快捷入口（Quick Operations）**：`BUYER_QUICK_ITEMS` 4 项——我的需求（/workspace/demands）、询价单（/workspace/rfqs）、匹配结果（/workspace/matches）、通知中心（/workspace/notifications）。
- **Dashboard Deep Link**：进入完整采购方工作台（/dashboard/buyer）。

数据源全部复用既有 `workspace.service`（`getBuyerWorkspaceOverview` / `getBuyerPendingDecisions`），零新增 Endpoint。

## 6. Supplier Workspace Result

`SupplierWorkspaceEntry`（供应商 / Capability Provider）：

- **身份与角色**：`WorkspaceIdentityBar`（title=供应商工作空间，roleLabel=Supplier · 供应商，roleHint=能力提供侧（Capability Provider），roleTone=amber）。
- **商机摘要（KPI）**：6 张 `StatCard`——待处理 RFQ（rfqSummary.total）、已提交响应（responseSummary.total）、匹配机会（matchSummary.total）、公开 RFQ（availableRfqs.total）、我的 Offer（offers.total）、未读通知（notificationSummary.unreadCount）。
- **响应进度（Pending Actions）**：3 格统计（已提交 / 处理中 / 已接受，按 `getSupplierWorkspaceResponses` 状态分组）+ 查看全部响应深链。
- **快捷入口（Quick Operations）**：`SUPPLIER_QUICK_ITEMS` 6 项——RFQ 机会、商机中心、我的响应、我的 Offer、企业资料、展示管理。
- **Dashboard Deep Link**：进入完整供应商工作台（/dashboard/supplier）。

数据源复用既有 `workspace.service`（`getSupplierWorkspaceOverview` / `getSupplierWorkspaceResponses`）、`offer.service`（`getOffers`）、`rfq.service`（`getAvailableRfqs`），零新增 Endpoint。
