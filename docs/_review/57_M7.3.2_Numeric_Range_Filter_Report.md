## 3. API Change Report

### `GET /products` — parameterFilters 扩展

#### 新模式：数值范围查询

| 参数 | 类型 | 说明 |
|------|------|------|
| `parameterFilters[0].parameterDefinitionId` | string | 参数定义 ID（必填） |
| `parameterFilters[0].valueMin` | number | 最小值（含） |
| `parameterFilters[0].valueMax` | number | 最大值（含） |

#### 示例请求

```
# 范围查询：镜头直径 2mm ~ 3mm
GET /products?parameterFilters[0].parameterDefinitionId=uuid-1&parameterFilters[0].valueMin=2&parameterFilters[0].valueMax=3

# 单边范围：分辨率 >= 100万
GET /products?parameterFilters[0].parameterDefinitionId=uuid-2&parameterFilters[0].valueMin=100

# 单边范围：工作长度 <= 5m
GET /products?parameterFilters[0].parameterDefinitionId=uuid-3&parameterFilters[0].valueMax=5

# 混合：精确匹配 + 范围查询
GET /products?parameterFilters[0].parameterDefinitionId=uuid-1&parameterFilters[0].valueMin=2&parameterFilters[0].valueMax=3&parameterFilters[1].parameterDefinitionId=uuid-4&parameterFilters[1].value=LED
```

## 4. Filter Logic

### 4.1 三种过滤模式

| 模式 | 条件 | 查询 |
|------|------|------|
| 精确匹配 | `value` 有值，无 `valueMin`/`valueMax` | `parameterValues.some({ parameterDefinitionId, value })` |
| 数值范围 | `valueMin` 或 `valueMax` 有值，无 `value` | `parameterValues.some({ parameterDefinitionId, valueNumber: { gte/lte } })` |
| 混合（禁止） | `value` 和 `valueMin`/`valueMax` 同时存在 | → `400 Bad Request` |

### 4.2 互斥校验

```typescript
if (hasValue && hasRange) {
  throw new BadRequestException(
    'value and numeric range (valueMin/valueMax) cannot be used together'
  );
}
```

### 4.3 值域校验

```typescript
if (valueMin > valueMax) {
  throw new BadRequestException(
    `valueMin (${valueMin}) must be <= valueMax (${valueMax})`
  );
}
```

### 4.4 多参数 AND 逻辑

```typescript
// 两个参数条件 AND 组合
[
  { parameterDefinitionId: 'diameter', valueMin: 2, valueMax: 3 },
  { parameterDefinitionId: 'resolution', valueMin: 100 },
]
// 转换为：
AND: [
  { parameterValues: { some: { parameterDefinitionId: 'diameter', valueNumber: { gte: 2, lte: 3 } } } },
  { parameterValues: { some: { parameterDefinitionId: 'resolution', valueNumber: { gte: 100 } } } },
]
```

## 5. Prisma Query Design

### 范围查询 Prisma 结构

```typescript
// valueMin=2, valueMax=3
{
  parameterValues: {
    some: {
      parameterDefinitionId: 'uuid-1',
      valueNumber: { gte: 2, lte: 3 },
    },
  },
}

// valueMin=100 (仅下界)
{
  parameterValues: {
    some: {
      parameterDefinitionId: 'uuid-2',
      valueNumber: { gte: 100 },
    },
  },
}

// valueMax=5 (仅上界)
{
  parameterValues: {
    some: {
      parameterDefinitionId: 'uuid-3',
      valueNumber: { lte: 5 },
    },
  },
}
```

### 索引利用

M7.3.1 已创建的复合索引 `@@index([parameterDefinitionId, valueNumber])` 直接支持范围查询，提供高效的索引扫描。
