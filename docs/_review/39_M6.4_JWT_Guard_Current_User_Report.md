## 3. Change Details

### 3.1 CurrentUser 装饰器

```typescript
// Before: 直接访问 req.user
async me(@Req() req: AuthRequest) {
  return ApiResponse.ok(req.user);
}

// After: 使用 @CurrentUser() 装饰器
async me(@CurrentUser() user: AuthRequest['user']) {
  return ApiResponse.ok(user);
}
```

- 基于 `createParamDecorator` + `ExecutionContext`
- 类型安全：返回 `AuthRequest['user']` 类型
- 可用于任何需要获取当前用户的 Controller

### 3.2 JwtPayload 统一接口

```typescript
export interface JwtPayload {
  sub: string;
  email: string;
  name: string | null;
  organizationId: string | null;
}
```

- JwtStrategy.validate() 使用 `JwtPayload`
- AuthService.validateUser() 使用 `JwtPayload`
- AuthService.generateToken() 使用 `JwtPayload`
- 三处类型签名完全一致
