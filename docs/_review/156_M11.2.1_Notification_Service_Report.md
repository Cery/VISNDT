## 3. Backend Impact

### 3.1 New Methods

#### `create(dto: CreateNotificationDto): Promise<Notification>`

- **功能:** 为指定用户创建一条通知
- **调用方:** 业务 Service (rfqs, rfq-responses, matching, offers, demands)
- **暴露方式:** 内部调用，不暴露 API

#### `createForOrganization(organizationId: string, dto: Omit<CreateNotificationDto, 'userId'>): Promise<Notification[]>`

- **功能:** 为组织中所有 ADMIN 成员创建通知
- **调用方:** 业务 Service (offers, matching)
- **暴露方式:** 内部调用，不暴露 API
- **容错:** 成员为空时返回 `[]`，不抛异常

### 3.2 Module Export

- `NotificationsModule` 现在导出 `NotificationsService`
- 其他 Backend 模块可以通过 `imports: [NotificationsModule]` 注入该 Service

### 3.3 Controller Impact

- **0 changes** — Controller 完全不修改
- 不暴露 `POST /notifications` 端点

| 维度 | 分析 |
|------|------|
