## 1. Phase Overview

本阶段在不修改 Prisma Schema、不创建 Migration、不影响 M7 已冻结模块的前提下，实现 Supplier 查询领域。Supplier 不创建独立 Model，采用现有架构的 View Layer 方案：

```
Organization(type='supplier')
        |
       Offer
        |
      Product
```

**核心原则：** Supplier 是 Organization 的视图，通过 Offer 模型间接关联 Product。

## 3. API Changes

### 3.1 新增端点

| # | 方法 | 路径 | 认证 | 说明 |
|---|------|------|------|------|
| 1 | `GET` | `/suppliers` | ❌ Public | 列出所有供应商组织（type='supplier'） |
| 2 | `GET` | `/suppliers/:id` | ❌ Public | 获取供应商详情（含产品数/Offer数/匹配数） |

### 3.2 端点详情

**GET /suppliers**

| 查询参数 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| `keyword` | string | 否 | 按名称搜索（模糊匹配） |
| `page` | number | 否 | 页码（默认 1） |
| `pageSize` | number | 否 | 每页数量（默认 20，最大 100） |

**返回：** `{ items: [{ id, name, type, offersCount }], total, page, pageSize }`

**GET /suppliers/:id**

**返回：** `{ id, name, type, status, productCount, offerCount, matchCount, createdAt, updatedAt }`

**GET /suppliers/:id/products**

| 查询参数 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| `page` | number | 否 | 页码 |
| `pageSize` | number | 否 | 每页数量 |

**返回：** `{ items: [{ id, name, model?, status, category, offerStatus, offerId }], total, page, pageSize }`

**GET /suppliers/:id/matches** 🔒 JWT

| 查询参数 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| `page` | number | 否 | 页码 |
| `pageSize` | number | 否 | 每页数量 |

**返回：** `{ items: [{ id, matchScore, matchStatus, demand, product, matchedAt?, reviewedAt? }], total, page, pageSize }`

**安全：** 当前用户 `organizationId` 必须等于目标 supplier ID，否则返回 403。

## 6. Architecture

### 6.1 查询链路

```
GET /suppliers
  └── Organization.where({ type: 'supplier' })
      └── _count: { offers: true }

GET /suppliers/:id
  └── Organization.findFirst({ id, type: 'supplier' })
      ├── _count: { offers, demands }
      └── offers → unique product count

GET /suppliers/:id/products
  └── Organization.findFirst({ id, type: 'supplier' })  ← 验证存在
      └── Offer.findMany({ organizationId })
          └── include: Product + Category

GET /suppliers/:id/matches
  └── Organization.findFirst({ id, type: 'supplier' })  ← 验证存在
  └── Ownership: user.organizationId === id              ← 403 如果不同
      └── DemandMatch.findMany({ offer.organizationId })
          └── include: Demand + Product
```

### 6.2 数据流

```
User Request
    │
    ▼
SuppliersController
    │
    ▼
SuppliersService ─── PrismaService ─── PostgreSQL
    │                    │
    │                    ├── Organization
    │                    ├── Offer
    │                    ├── Product
    │                    ├── ProductCategory
    │                    └── DemandMatch
    │
    ▼
SupplierResponseDto (type-safe response)
```
