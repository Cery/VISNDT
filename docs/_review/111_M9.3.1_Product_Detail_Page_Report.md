## Architecture Impact

- **数据流**: `ProductDetail.tsx` → `productService.getById(id)` → `apiClient.get('/products/:id')` → Backend
- **依赖**: 复用 `apiClient` 和 `productService`，无新增依赖
- **模式**: 遵循 Dashboard 模板: loading → error (Retry) → success
- **类型**: `ProductDetail` extends `Product`，新增 `parameterValues` 和 `media` 属性

---

## Security Impact

- **无影响** — 所有路由在 `RequireAuth` 守卫下，无新增公开端点
- Product Detail 页面通过 `productService.getById()` 调用 `GET /products/:id`（Backend 端点为 Public）
- 认证链路完整: RequireAuth → JWT Token → Backend

---

## API Changes

- **无新增 API** — 复用现有 `GET /api/v1/products/:id`
- Frontend `productService.getById()` 返回类型从 `Product` 扩展为 `ProductDetail`，以支持 `parameterValues` 和 `media`

- **Loading**: 居中 Spin
