## 7. Visual Design Audit（源码级视觉审计）

### 7.1 Design Token Utilization（Token 利用率）
- Web：Token 经 `tailwind.config.ts` 映射为 `bg-primary / text-industrial-cyan / shadow-industrial-md` 等工具类，47 文件实际消费 102 处 → **Token 应用具备系统性**。
- Admin：AntD `colorPrimary` + `StatusTag` + `CHART_PALETTE` 统一委托设计 token，10 文件直接消费 → **Token 后端单一事实源成立**。
- 残留：Admin 仍存在少量硬编码 hex / `>500kB` 主包（723 P3 既有项）；部分页面（如 dashboard C4 emoji 图标）未完全 Token 化。
- **评分：4 / 5**（Token 体系完备且被系统性消费，余量在「全站彻底去硬编码 + 统一 semantic 映射」）。

### 7.2 Typography（字体排印）
- 字体族：Inter + JetBrains Mono（design-tokens 定义；Web `--font-inter`/`--font-jetbrains-mono`）。
- 字号阶：xs 12 → 5xl 48；行高 tight/normal/relaxed；字重 400-700 均已在 token 层定义。
- 实际应用：正文/h1-h6 层级基本统一（Tailwind prose 覆写对齐 Neutral）；但页面级「标题-副题-正文-元信息」节奏在非内容页（列表/工作台/卡片）尚不一致，Hero 层级偏 Banner。
- **评分：3 / 5**（Token 定义完整 + 内容区良好；跨页面排版节奏仍需 M33 统一）。

### 7.3 Color（色彩）
- 品牌主色 #2563EB / Secondary #0EA5E9 / Accent #F59E0B 已冻结并与双端 token 对齐（720/721 已定级 ALIGNED）。
- 语义状态 success #10B981 / warning #F59E0B / error #EF4444 / info #0EA5E9 统一经 `STATUS_TONE` 确定性映射。
- 中性色阶 + 表面色（layoutBg/headerBg/siderBg/cardBg）冻结。
- 残留：少量页面（emoji、硬编码 hex）未彻底收敛；无全新 Semantics/Accent 使用体系。
- **评分：4 / 5**（色彩体系冻结且对齐，余量在品牌深色面/表面分层/语义增强）。

### 7.4 Component System（组件系统）
- Web：原子层（Card/Button/Tag/Badge）+ 业务组件（ProductCard / ProductGrid / MobileFilterDrawer / CompareBar / SearchResultCard / ContentCard）+ 品牌层（IndustrialBadge / SectionHeader / CapabilitySummary）。**无独立 packages/design-system**，组件为文件级复用。
- Admin：AntD（ConfigProvider）+ 定制（OperationCard / StatusTag / StatCard / SectionHeader / TrendChart / MediaFileCard / WorkflowTimeline）+ design-system token 兼容层。
- 一致性：语义色调、状态表达、空错态（EmptyState/ErrorState）已收敛；但 Web 与 Admin 为两套组件语汇（Tailwind vs AntD），跨端一致靠 token，不靠共享组件。
- **评分：3 / 5**（组件可用可复用，但缺统一可视组件契约 + 跨端语汇统一）。

### 7.5 Layout Composition（版式构成）
- Web：内容 max-width≈1200px main+aside（Content Detail）；产品网格 Desktop 3 列（M21.5/721 优化）；卡片密度在 721 已降低；Hero 为 Banner + CTA，非高级叙事式 Layout。
- Admin：Layout（Sider+Header+Content）标准化；Dashboard 分区 KPI/趋势/图表；运营中心五视图。
- 整体：结构清晰但偏「功能排布」，缺乏大片留白、视觉节奏与 Prefer Level 层级的构成感。
- **评分：3 / 5**（结构可用；构成层次与留白节奏需 M33 提升）。

### 7.6 Brand Expression（品牌表达）
- 平台名「工业检测能力发现平台 / VISNDT 工业运营中心」已统一；品牌色/Logo 渐变/工业徽标（IndustrialBadge）存在。

- **评分：3 / 5**（品牌身份成立；品牌强度与高级感需 M33 强化）。

### 7.7 Responsive Visual（响应式视觉）

## 9. Visual Redesign Direction（M33 设计方向，Direction Defined）

基于审计结论，为 M33 Visual Redesign 冻结方向（供 **M33 Visual Design Contract** 使用）：

### 9.1 Brand Direction
- **Industrial Precision（工业精密）** + **Technical Professional(技术专业)** + **Modern B2B**（现代企业级）
- 关键词锚点：精密 / 结构 / 数据 / 确定性；弱化电商/营销/消费感，强化检测能力发现平台的专业克制
- 品牌强度目标：识别度 HIGH + 高级感 MEDIUM-HIGH

### 9.2 Layout Direction
- 首页：Banner Hero → 能力叙事多区块（分类→能力→解决方案→流程→知识→供应商）重构成更层次（留白、Z 字节奏、读者动线）
- 功能页（列表/详情/工作台）：统一 `container` 宽度 + 区块级视觉节奏 + 卡片分层（surface-1/surface-2）
- Admin：运营中心保持「控制台效率」，强化「工业运营」视觉纵深

### 9.3 Surface / Color Direction
- 深化中性表面分层（layoutBg → cardBg → elevated）与边界（border color 梯级）
- 品牌色只作强点（primary CTA / 次级强调），避免大面积平铺
- 修复 KPI emoji → 统一图标组件（或 Symbol 系统）

### 9.4 Typography Direction
- 全站统一「标题/副题/正文/元信息」四级节奏，落地 720 TYPOGRAPHY 至所有非内容页

### 9.5 Component Direction
- 建立统一可视组件契约（Web 原子 + Admin AntD 定制同时被 Token 约束），无需新建 `packages/design-system`（保持冻结）
