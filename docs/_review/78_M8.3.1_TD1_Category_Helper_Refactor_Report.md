## 3. 技术债说明

### 3.1 债务来源

M8.3.1 中，`MatchingService.match()` 直接调用 `this.prisma.$queryRawUnsafe()` 读取 `demand.category_id`：

```typescript
// BEFORE (M8.3.1) — 技术债
let demandCategoryId: string | undefined;
try {
  const rows = await this.prisma.$queryRawUnsafe<
    Array<{ category_id: string | null }>
  >(`SELECT "category_id" FROM "demand" WHERE "id" = $1::uuid`, demandId);
  demandCategoryId = rows[0]?.category_id ?? undefined;
} catch {
  demandCategoryId = undefined;
}
```

**问题：**
1. **违反单一职责原则** — MatchingService 混入了数据访问层细节
2. **不可测试** — raw SQL 逻辑无法独立单元测试
3. **不可复用** — 其他模块需要读取 `category_id` 时无法复用
4. **耦合** — raw SQL 细节与匹配算法耦合

### 3.2 偿还方案

提取 `CategoryHelper` 服务，封装所有 raw SQL 逻辑：

```typescript
// AFTER (M8.3.1-TD1) — 偿还
const demandCategoryId = await this.categoryHelper.getDemandCategoryId(demandId);
```

## 4. Before / After 架构变化

### 4.1 架构图

**Before:**
```
MatchingService
  ├── prisma.$queryRawUnsafe(SELECT category_id...)  ← 内联 SQL
  ├── prisma.product.findMany(categoryFilter)
  └── scoring.calculateScore(...)
```

**After:**
```
MatchingService
  ├── categoryHelper.getDemandCategoryId(demandId)   ← 封装服务
  ├── prisma.product.findMany(categoryFilter)
  └── scoring.calculateScore(...)

CategoryHelper (独立服务)
  └── prisma.$queryRawUnsafe(SELECT category_id...)   ← 隔离 SQL
```
