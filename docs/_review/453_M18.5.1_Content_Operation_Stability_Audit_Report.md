## 6. Scheduler Reliability Audit

- **Trigger**：`ContentSchedulerService.scan()` 仅查询 `status=REVIEW AND scheduledPublishAt <= now()`，`setInterval` 60s 分钟级扫描，`onModuleInit` 启动 + `unref` 不阻塞退出。
- **Idempotency**：`running` 标志防重入；`transition()` 使用原子条件更新 `updateMany({ where: { id, status: from } })`，`count === 0` 视为已变更——并发/重复扫描下仅产生一次 OPENED + 一次 STATUS_CHANGE；发布成功自动清除 `scheduledPublishAt` 避免二次命中。
- **Failure Recovery**：单条发布失败 catch 记录日志不阻塞其他任务，下一轮扫描自动重试，不修改 `scheduledPublishAt`；`system@visndt.com` 系统身份保证 WorkflowEvent/AuditLog 可追踪。
- 场景矩阵：

| 场景 | 期望 | 设计满足 |
|---|---|---|
| REVIEW + 到期时间 | 自动发布 | ✅ |
| REVIEW + 未到时间 | 不发布（`lte: now` 不命中） | ✅ |
| DRAFT | 不触发（仅扫 REVIEW） | ✅ |
| 重复扫描 | 不重复发布（原子条件更新） | ✅ |
| 失败任务 | 下一轮可恢复（隔离 + 保留 scheduledPublishAt） | ✅ |
