## Architecture Impact

- **数据流**: `UserList.tsx` → `userService.getList()` → `apiClient.get('/users')` → Backend
- **依赖**: 复用 `apiClient`，无新增外部依赖
- **模式**: 严格遵循 ProductList/DemandList 模板: discriminated union 状态管理
- **搜索**: Client-side filter (Backend `GET /users` 无 search/filter 参数)

---

## Security Impact

- **无影响** — 路由在 `RequireAuth` 守卫下
- `GET /api/v1/users` 需要 ADMIN 角色，Backend 侧 `@Roles(Role.ADMIN)` 保护
- 前端不渲染 `passwordHash` 字段（User 类型中排除）
- 认证链路完整: RequireAuth → JWT Token → Backend ADMIN Guard

---

## API Changes

- **无新增 Backend API** — 复用 `GET /api/v1/users` (ADMIN only)
- Frontend `userService.getList()` 映射 `GET /users?page=&pageSize=`
