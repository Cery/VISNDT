## 4. Authentication Flow

### 4.1 Complete Auth Flow

```
User visits /home
  │
  ├── isAuthenticated === false
  │     └── RequireAuth → Navigate to /login (state: { from: "/home" })
  │
  └── User submits login form
        └── useAuth().login(email, password)
              └── auth.service.ts: login()
                    └── apiClient.post('/auth/login', { email, password })
                          │
                          ├── Request interceptor: (no token yet, skip)
                          │
                          └── Response:
                                ├── Success → authStore.setAuth(token, user)
                                │     └── Login page: navigate(state.from ?? '/home')
                                │
                                └── Error → show error message
```

### 4.2 Authenticated API Flow

```
User clicks "Products" → apiClient.get('/products')
  │
  ├── Request interceptor: inject Authorization: Bearer <token>
  │
  └── Response:
        ├── 200 → unwrap response.data → render
        └── 401 → authStore.clearAuth() → window.location.href = '/login'
```

## 5. Route Protection Architecture

### 5.1 RequireAuth Component

```typescript
function RequireAuth({ children }: RequireAuthProps) {
  const { isAuthenticated } = useStore(authStore);
  const location = useLocation();

  if (!isAuthenticated) {
    return <Navigate to="/login" state={{ from: location.pathname }} replace />;
  }

  return <>{children}</>;
}
```

### 5.2 Route Table

```
/login → Login (public, no guard)
/ → RequireAuth → AdminLayout (ALL children protected)
  ├── /home → Home
  ├── /products → Placeholder
  ├── /demands → Placeholder
  ├── /matching → Placeholder
  ├── /users → Placeholder
  └── /organizations → Placeholder
* → NotFound (public, no guard)
```

## 6. Axios Interceptor Changes

### 6.1 Request Interceptor

```typescript
apiClient.interceptors.request.use((config) => {
  const { accessToken } = authStore.getState();
  if (accessToken) {
    config.headers.Authorization = `Bearer ${accessToken}`;
  }
  return config;
});
```

| Feature | Before | After |
|---------|--------|-------|
| Token injection | Placeholder (no-op) | `Bearer <token>` from `authStore` |
| Token source | None | `authStore.getState().accessToken` |
| Hook usage | N/A | No React hook (direct store access) |

### 6.2 Response Interceptor

```typescript
apiClient.interceptors.response.use(
  (response) => response.data,
  (error) => {
    if (error.response?.status === 401) {
      authStore.getState().clearAuth();
      window.location.href = '/login';
    }
    return Promise.reject(error);
  },
);
```

| Feature | Before | After |
|---------|--------|-------|
| Success | Unwrap `response.data` | Unwrap `response.data` (unchanged) |
| 401 handling | None | `clearAuth()` + redirect to `/login` |
| Other errors | `Promise.reject(error)` | `Promise.reject(error)` (unchanged) |
| 401 loop prevention | N/A | `window.location.href` (full page reload, clears state) |

## 7. 401 Handling

### 7.1 Flow

```
API returns 401
  │
  ├── Response interceptor detects error.response.status === 401
  │
  ├── authStore.clearAuth()
  │     ├── accessToken → null
  │     ├── user → null
  │     └── isAuthenticated → false
  │
  └── window.location.href = '/login'
        └── Full page reload prevents stale state
```

### 7.2 Loop Prevention

| Mechanism | Detail |
|-----------|--------|
| `window.location.href` | Forces full page reload, clearing all React component state |
| `clearAuth()` before redirect | Ensures token is removed before re-render |
| `/login` is public | No RequireAuth guard on `/login` route |
