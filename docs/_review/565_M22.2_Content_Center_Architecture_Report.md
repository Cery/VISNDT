## Content Center Architecture Summary

### Content 定位

Content Center 定位为 VISNDT 平台的**知识资产层（Content Asset Layer）**，承载工业检测领域的行业知识、技术内容、解决方案和洞察文章。

```
VISNDT Platform Layers
    |
    ├── Product Information Layer (M19 COMPLETED)
    ├── Supplier Experience Layer (M22.1 CLOSED)
    ├── Business Collaboration Layer (M20 COMPLETED)
    ├── Content Asset Layer ← M22.2 (THIS STAGE)
    └── AI Intelligence Layer (M21.7 FROZEN)
```

Content Center 不是：
- CMS 替换
- 用户社区
- 内容 Marketplace
- Supplier 自建内容商城
- 社交平台

### 内容类型

| ContentType | 用途 | Web 路径 | 示例 |
| --- | --- | --- | --- |
| ARTICLE | 企业动态、行业新闻、技术趋势 | /articles | 公司新闻、行业报告 |
| KNOWLEDGE | 技术知识库、参数百科 | /knowledge | 检测原理、技术参数说明 |
| SOLUTION | 行业解决方案 | /solutions | 工业检测方案、应用案例 |
| INSIGHT | 行业洞察、深度分析 | /insights | 市场分析、技术展望 |

#### 关联模型

| 模型 | 用途 | 关键字段 |

### API 端点全量盘点

#### Admin API (JWT + ADMIN Role)

| Endpoint | Method | 用途 |
| --- | --- | --- |
| GET /content | GET | 列表查询（type/status filter + pagination） |
| POST /content | POST | 创建草稿 |
| PATCH /content/:id | PATCH | 更新内容（draft/review only） |
| GET /content/:id | GET | 获取单条内容 |
| GET /content/by-slug/:slug | GET | 按 slug 查询 |
| POST /content/:id/submit | POST | 提交审核（DRAFT → REVIEW） |
| POST /content/:id/review | POST | 审核通过（REVIEW → PUBLISHED） |
| *POST /content/:id/publish | POST | 发布（含定时发布） |
| *POST /content/:id/archive | POST | 归档（PUBLISHED → ARCHIVED） |

#### Public API (No Auth)

| Endpoint | Method | 用途 |
| --- | --- | --- |
| GET /content/public | GET | 已发布内容列表（type filter + pagination） |
| GET /content/public/:slug | GET | 按 slug 获取已发布内容 |
