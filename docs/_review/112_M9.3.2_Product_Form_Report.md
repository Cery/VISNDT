## Architecture Impact

- **组件复用**: `ProductForm` 共享组件，通过 props 控制 Create/Edit 模式
- **数据流**:
  - Create: `ProductCreate → ProductForm → productService.create()`
  - Edit: `ProductEdit → productService.getById() → ProductForm → productService.update()`
- **分类加载**: `ProductForm` 挂载时通过 `categoriesService.getList()` 加载分类列表
- **依赖**: 复用 `apiClient`，无新增外部依赖

---

## Security Impact

- **无影响** — 所有路由在 `RequireAuth` 守卫下
- Create/Edit 调用 Backend `POST /products` 和 `PATCH /products/:id`，均为 ADMIN 角色端点
- 认证链路: RequireAuth → JWT Token → Backend JwtAuthGuard + RolesGuard(ADMIN)

---

## API Changes

- **无新增 Backend API** — 复用现有端点
- 新增 Frontend Service: `categoriesService.getList()` → `GET /product-categories` (Public)

## Product Form 功能

### ProductForm 组件

| 字段 | 组件 | 验证 |
|---|---|---|
| name | Input | required |
| model | Input | optional |
| categoryId | Select | required, 动态加载分类 |
| status | Select | DRAFT/ACTIVE/INACTIVE |
| description | TextArea | optional |

### 状态管理

| 状态 | UI |
|---|---|
| Loading (categories) | 居中 Spin |
| Error (categories) | Alert + Retry + Back to List |
| Ready | Form 渲染 |
| Submitting | 提交按钮 loading |
| Submit Error | message.error() |
| Submit Success | message.success() + redirect /products |

### 路由配置

| 路由 | 组件 | 模式 |
|---|---|---|
| `/products` | ProductList | List |
| `/products/create` | ProductCreate → ProductForm | Create |
| `/products/:id/edit` | ProductEdit → ProductForm | Edit (预填充) |
| `/products/:id` | ProductDetail | Detail |
