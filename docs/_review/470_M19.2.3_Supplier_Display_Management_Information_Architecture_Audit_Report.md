## 4. Supplier Display Information Architecture

### 4.1 Page Structure

```
Supplier Display Management
│
├── 1. Display Overview (概览)
│   ├── Supplier Name + Type + Status
│   ├── Active Offer Count
│   ├── Product Coverage Count
│   ├── Category Coverage Count
│   ├── Display Completeness
│   └── Public Profile Quick Link
│
├── 2. Company Identity (企业身份)
│   ├── Organization Name
│   ├── Organization Type (中文标签)
│   ├── Organization Status (状态徽章)
│   ├── Registration Date
│   └── Member Count
│
├── 3. Capability Overview (能力概览)
│   ├── Supported Products (via Offer)
│   ├── Product Categories (via Offer → Product → Category)
│   ├── Active Offers (status = ACTIVE | SUBMITTED)
│   ├── Inquiry History (via Offer → Product → Inquiry)
│   └── RFQ Response History (via workspace API)
│
├── 4. Product Capability (产品能力)
│   ├── Products Supplier Can Provide (via Offer)
│   │   ├── Product Name
│   │   ├── Product Model
│   │   ├── Product Category
│   │   └── Offer Status
│   └── Product → Public Profile Link
│
├── 5. Offer Management (供应管理)
│   ├── Active Offers
│   │   ├── Title
│   │   ├── Description
│   │   ├── Status (editable)
│   │   └── Product Link
│   ├── Draft Offers
│   └── Create Offer (if applicable)
│
├── 6. Public Preview (公开预览)
│   ├── Link to /suppliers/[organizationId]
│   ├── Preview Card (reuse SupplierPublicProfile)
│   └── Preview Offer List (reuse SupplierOfferList)
│
└── 7. Display Completeness (展示完整度)
    ├── Frontend-Calculated Score (0-100%)
    ├── Completed Items (✓)
    └── Missing Items (○)
```

### 4.2 Semantic Positioning

| Term | Correct (M19.2.3) | Incorrect (Forbidden) |
| --- | --- | --- |
| 产品 | Products Supplier Can Provide | Supplier Products / Store Products |
| 关系 | Product → Offer → Organization | Product → Supplier |
| 供应商 | Capability Provider | Seller / Store Owner |
| 展示 | Display Management | Store Management |
