## Architecture Impact

### 数据流验证

```
ProductList    → productService.getList()    → GET /products
ProductDetail   → productService.getById()    → GET /products/:id
ProductCreate   → ProductForm → productService.create() → POST /products
ProductEdit     → ProductForm → productService.update() → PATCH /products/:id
ProductForm     → categoriesService.getList() → GET /product-categories
```

### 架构合规性

| 检查项 | 结果 |
|---|---|
| 页面不直接调用 axios | ✅ 全部通过 apiClient |
| 无循环依赖 | ✅ 单向: Page → Service → Client |
| 无新增状态管理 | ✅ 无新 Store |
| 组件复用 (ProductForm) | ✅ Create/Edit 共享 |
| 遵循 Dashboard 模板 | ✅ discriminated union 状态 |
