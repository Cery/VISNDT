## 6. API 对接细节

### 6.1 数据流
```
GET /products          → PaginatedResponse<Product>   → ProductGrid
GET /products/:id      → ProductDetail                → ProductDetailPage
GET /product-categories → PaginatedResponse<Category> → ProductFilter, CategoryGrid
POST /inquiries        → InquiryResponse              → InquiryForm (success)
```

### 6.2 响应处理
- `apiClient<T>()` 自动解包 `ApiResponse<T>` 格式
- 所有 API 函数返回 `res.data`（业务数据）
- 错误通过 `ApiError` 类抛出，包含 HTTP 状态码

### 6.3 数据获取策略
| 页面 | 策略 | 库 |
|------|------|-----|
| 首页 | Server-side fetch (SSR) | 直接调用 getProducts/getCategories |
| 产品列表 | Client-side fetch (CSR) | TanStack Query (useQuery) |
| 产品详情 | Server-side fetch (SSR) | 直接调用 getProduct |
| 分类浏览 | Client-side fetch (CSR) | TanStack Query (useQuery) |
| 关于我们 | Static | 无 API 调用 |

3. **Inquiry 表单**：`offerId` 和 `organizationId` 为后端必填字段，当前表单使用 productId 作为 fallback；后续需要 Offer 选择器完善
