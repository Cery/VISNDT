## 5. ESLint关联分析

检查文件：

- `apps/web/eslint.config.mjs`

配置内容核心为：

```ts
...compat.extends("next/core-web-vitals", "next/typescript"),
```

分析结论：

1. 当前 ESLint 继承了：
   - `next/core-web-vitals`
   - `next/typescript`
2. 这两组配置与 Next 15 项目本身是兼容的
3. 但其中包含的规则仍会对 `<head>` 中的 Google Fonts 链接给出 pages-router 风格提示

仓库内直接证据：

- `apps/web/src/app/layout.tsx` 在 `<head>` 中直接写入了：
  - `https://fonts.googleapis.com`
  - `https://fonts.gstatic.com`
  - Google Fonts stylesheet link

因此本次 lint warning 为：

```text
Custom fonts not added in `pages/_document.js` will only load for a single page.
```

审计判断：

- 该 warning 与 `layout.tsx` 中直接插入 Google Fonts 有直接关联
- 但它本身只是 lint warning，**不是本次有效 build 的失败原因**
- 当前 evidence 更支持“ESLint 规则文案沿用 pages router 语义”，而不是“Next 运行时真实缺失 `_document` 文件”
