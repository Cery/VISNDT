## Architecture Impact

- **数据流**: `DemandList.tsx` → `demandService.getList()` → `apiClient.get('/demands')` → Backend
- **依赖**: 复用 `apiClient`，无新增外部依赖
- **模式**: 严格遵循 M9.3 ProductList 模板: discriminated union 状态管理
- **组件复用**: Input.Search + Select + Table + server-side pagination

---

## Security Impact

- **无影响** — 路由在 `RequireAuth` 守卫下
- Backend `GET /demands` 为 Public 端点，contact info 由 Backend 根据 `contactVisible` 保护
- 认证链路完整: RequireAuth → JWT Token → Backend

## API Changes

- **无新增 Backend API** — 复用 `GET /api/v1/demands` (Public)
- Frontend `demandService.getList()` 映射 `GET /demands?keyword=&status=&sort=&page=&pageSize=`

## Demand List 页面功能

| 功能 | 组件 | 详情 |
|---|---|---|
| 搜索 | Input.Search | 搜索 title + description |
| 状态筛选 | Select | ALL / DRAFT / PUBLISHED / SUBMITTED / PROCESSING / CLOSED / CANCELLED |
| 排序 | Table sorter | publishedAt → sort=published, createdAt → sort=latest |
| 分页 | Table pagination | 服务端分页，10/20/50 |
| 重置 | Button | 清空搜索/筛选/分页 |

### 表格列

| 列 | 字段 | 格式化 |
|---|---|---|
| Title | title | 加粗 |
| Organization | organization.name | 无组织显示 "-" |
| Category | category.name | 无分类显示 "-" |
| Status | status | Tag 颜色: DRAFT=orange, PUBLISHED=green, PROCESSING=blue, CLOSED=default, CANCELLED=red |
| Published | publishedAt | Date 或 "-" |
| Created | createdAt | Date |

### 状态管理

- Loading → 居中 Spin
- Error → Alert + description + Retry
- Success → Table
