## 5. API Baseline

### 5.1 API Client Architecture

All API calls go through a single centralized `apiClient` function in [src/lib/api-client.ts](file:///F:/Desktop/VISNDT/VISNDT/apps/web/src/lib/api-client.ts).

**Key behaviors:**
- `credentials: 'include'` — HttpOnly cookie-based auth
- `X-CSRF-Token` header — Double Submit Cookie pattern for POST/PUT/PATCH/DELETE
- 401 → `POST /auth/refresh` → retry original request (once)
- Refresh deduplication via `isRefreshing` flag + shared `refreshPromise`
- `ApiError` class with HTTP status code

## 6. Auth Baseline

### 6.1 Architecture

```
┌──────────────────────────────────────────────────────────┐
│                   AUTHENTICATION FLOW                     │
├──────────────────────────────────────────────────────────┤
│                                                           │
│  APP MOUNT                                                │
│    │                                                       │
│    ▼                                                       │
│  AuthProvider.useEffect()                                  │
│    │  GET /auth/me (cookie-based, no manual token)         │
│    │                                                       │
│    ├─ 200 → setUser(user) → isAuthenticated = true         │
│    └─ 401 → setUser(null) → isAuthenticated = false        │
│    │                                                       │
│    ▼                                                       │
│  AuthGuard (wraps protected routes)                        │
│    │                                                       │
│    ├─ isLoading  → <Loading />                             │
│    ├─ !auth      → router.replace('/login')                │
│    └─ auth       → render children                         │
│                                                           │
│  LOGIN:  POST /auth/login  → setUser → redirect dashboard │
│  REGISTER: POST /auth/register → setUser → redirect dash  │
│  LOGOUT: POST /auth/logout → clearCsrfToken → setUser(null)│
│                                                           │
│  AUTO-REFRESH (transparent):                              │
│    Any 401 → POST /auth/refresh → retry original request   │
│                                                           │
└──────────────────────────────────────────────────────────┘
```
