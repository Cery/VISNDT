## 5. Authentication Verification

### Auth Flow

```
Mount → AuthProvider.useEffect → GET /auth/me (cookie-based)
  ├── Success → setUser + isAuthenticated=true
  └── Failure → user=null + isAuthenticated=false

AuthGuard
  ├── isLoading → <Loading />
  ├── !isAuthenticated → router.replace('/login')
  └── Authenticated → render children

Login → POST /auth/login → setUser
Register → POST /auth/register → setUser
Logout → POST /auth/logout → clearCsrfToken() → setUser(null)
```

### JWT & Cookie Security

| Check | Status | Detail |
|-------|--------|--------|
| JWT storage | ✅ PASS | HttpOnly cookies (no localStorage) |
| CSRF protection | ✅ PASS | Double Submit Cookie pattern |
| CSRF token storage | ✅ PASS | In-memory only (XSS-safe) |
| Refresh mechanism | ✅ PASS | 401 → `tryRefreshToken()` → retry once |
| Refresh dedup | ✅ PASS | `isRefreshing` flag + shared `refreshPromise` |
| Logout cleanup | ✅ PASS | Revokes refresh token + clears CSRF token |
| Credentials forwarding | ✅ PASS | `credentials: 'include'` on all requests |
| AuthGuard redirect | ✅ PASS | Unauthenticated → `/login` |
