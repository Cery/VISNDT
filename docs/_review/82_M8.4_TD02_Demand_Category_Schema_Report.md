## 1. Objective

解决 M8 Final Architecture Audit 中发现的 TD-1 技术债：

> "demand.category_id 不在 Prisma schema，通过 raw SQL 访问"

**Before**: `CategoryHelper` 使用 `$queryRawUnsafe` 读取 `demand.category_id`（字段不在 Prisma Schema 中）。

**After**: `Demand.categoryId` 正式纳入 Prisma Schema，`CategoryHelper` 使用 Prisma 类型化查询 `findUnique({ select: { categoryId: true } })`。

## 4. Code Refactor

### 4.1 CategoryHelper

**Before** (`$queryRawUnsafe`):
```typescript
async getDemandCategoryId(demandId: string): Promise<string | undefined> {
  try {
    const rows = await this.prisma.$queryRawUnsafe<
      Array<{ category_id: string | null }>
    >(`SELECT "category_id" FROM "demand" WHERE "id" = $1::uuid`, demandId);
    return rows[0]?.category_id ?? undefined;
  } catch (err) {
    this.logger.warn(`Failed to read category_id...`);
    return undefined;
  }
}
```

**After** (Prisma typed query):
```typescript
async getDemandCategoryId(demandId: string): Promise<string | undefined> {
  try {
    const demand = await this.prisma.demand.findUnique({
      where: { id: demandId },
      select: { categoryId: true },
    });
    return demand?.categoryId ?? undefined;
  } catch (err) {
    this.logger.warn(`Failed to read categoryId...`);
    return undefined;
  }
}
```

### 4.2 Key Differences

| Aspect | Before | After |
|--------|--------|-------|
| Query Method | `$queryRawUnsafe` | `findUnique` |
| Type Safety | Manual type assertion | Prisma-generated types |
| Column Name | `category_id` (raw) | `categoryId` (Prisma) |
| SQL Injection Risk | Low (parameterized) | None (Prisma ORM) |
| Schema Dependency | None (column may not exist) | Validated (Prisma Schema) |

### 4.3 MatchingService

No change to matching algorithm. `CategoryHelper.getDemandCategoryId()` is called with the same interface, only the internal implementation changed.
