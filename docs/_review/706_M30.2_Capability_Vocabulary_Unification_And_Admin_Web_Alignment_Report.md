**Status**: **IMPLEMENTED — Legal Transitions Only**

在 `DemandEdit.tsx` 中实现基于现有 Demand Service 状态转换规则的合法状态变更：

```typescript
const legalStatusOptions = (() => {
  const current = demand.status;
  // DRAFT → PUBLISHED
  // PUBLISHED → CLOSED / PROCESSING
  // PROCESSING → CLOSED
  // CLOSED / CANCELLED → 不可变更
  return allStatuses.filter((s) => {
    if (s.value === current) return false;
    if (s.value === 'PUBLISHED' && current === 'DRAFT') return true;
    if (s.value === 'CLOSED' && (current === 'PUBLISHED' || current === 'PROCESSING')) return true;
    return false;
  });
})();
```

状态变更通过两次 API 调用分别更新普通字段和状态字段，满足后端状态变更单独处理要求。
