## 5. Web Interaction Implementation

**实际变更（代码级验证）**

- `apps/web/src/app/globals.css`：新增统一 Reduced Motion 基础（`prefers-reduced-motion: reduce` → `animation/transition-duration: 0.01ms !important; animation-iteration-count: 1 !important; scroll-behavior: auto !important`），是 Web 端唯一动画降级入口；新增工具类 `.page-enter / .card-lift / .btn-press / .stagger-item / .hero-enter` 及对应 keyframes（`visndPageEnter / visndFadeUp / visndHeroFade`）。
- `apps/web/src/app/template.tsx`（新增，客户端组件）：对 children 包裹 `.page-enter`（opacity fade-in 0.28s ease-out），不改变布局 / 不产生 containing block，避免干扰 fixed 元素（CompareBar / Drawer）。
- `apps/web/src/components/common/Toast/index.tsx`（新增）：模块级 store（`toast.success/error/info/warning`）+ 单一 `ToastViewport`；语义色对齐 COLOR_SYSTEM（success #10B981 / error #EF4444 / info #0EA5E9 / warning #F59E0B）；`aria-live="polite"` + `role="status"`；自动消失 3500ms，最多 4 条；fixed 定位带安全区置于 CompareBar 上方。零第三方依赖。
- `apps/web/src/components/common/BackToTop.tsx`（新增）：滚动 >480px 显现，`scrollTo({ top:0, behavior:'smooth' })`（reduced-motion 下自动降级）；`aria-label="返回顶部"` + `btn-press`。
- `apps/web/src/app/layout.tsx`：挂载 `<ToastViewport />` 与 `<BackToTop />`。
- `apps/web/src/components/common/Pagination.tsx`：激活页码由 gradient 改为纯 `bg-primary`（对齐 721 主语义色）+ `shadow-industrial-sm`；三个导航按钮加 `btn-press` 按下反馈。
- `apps/web/src/components/products/ProductGrid.tsx`：每张卡片包裹 `.stagger-item` 并施加 inline `animation-delay`（`min(idx*0.04, 0.4)s`），实现 CSS stagger 轻入场。

**Web Interaction 结论：`PASS`**

## 7. Animation / Reduced Motion

- 全部新动画为 CSS（transition / transform / opacity / box-shadow / background-color / border-color / animation-keyframes），无 JS 动画循环，无重型动画运行时。
- 允许项：fade / slide-up / scale-lite / 卡片 hover 抬升 / focus 过渡 / drawer（沿用既有）/ 按钮 active 反馈 / stagger；禁止项（parallax / infinite loop / 高速扫描线 / 雷达扫描 / AI 光效 / 赛博朋克 / 过度模糊 / 大型动态背景 / 复杂 JS 循环）未引入。
- **Reduced Motion**：CDP `Emulation.setEmulatedMedia(prefers-reduced-motion: reduce)` 实测：`.page-enter` 的 `animation-duration` 由 ~0.28s 降为 **`1e-05s`（0.01ms）**，`animation-iteration-count = 1`，`scroll-behavior = auto`；hover/active/focus 状态仍保留，动画不作为唯一反馈。Web + Admin 两处均实现统一降级入口。

**Animation / Reduced Motion 结论：`PASS`**
