## 4. RoleGuard变化

原问题：

- `RoleGuard` 内部固定执行 `roles.includes('BUYER')`
- 导致所有用户都按 Buyer 判断

本次调整：

- 改为读取 `useAuth()` 中的 `user.workspaceRole`
- 使用 `const workspaceRole = user.workspaceRole ?? 'BUYER'` 进行安全兜底
- 继续保持原有组件接口：
  - `roles`
  - `children`
  - `fallback`

当前判断逻辑：

```ts
const workspaceRole = user.workspaceRole ?? 'BUYER';
const hasRole = roles.includes(workspaceRole);
```

结果：

- `RoleGuard(['BUYER'])` 可按真实角色判断
- `RoleGuard(['SUPPLIER'])` 可按真实角色判断
- `RoleGuard(['ADMIN'])` 可按真实角色判断
- 当 `workspaceRole` 缺失时，按 Buyer 处理，避免页面崩溃
