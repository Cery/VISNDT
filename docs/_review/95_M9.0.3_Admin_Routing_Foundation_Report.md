## 4. Routing Architecture

|------|-----------|---------|

| `/home` | `Home` | Home / dashboard page |
| `*` | `NotFound` | 404 catch-all |

### 4.2 Router Implementation

```
src/router/index.tsx
  └── createBrowserRouter

        ├── "/home" → Home
```
