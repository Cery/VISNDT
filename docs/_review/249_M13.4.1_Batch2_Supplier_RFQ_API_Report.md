## 3. RFQ Mine API

### Endpoint

```
GET /rfqs/mine
```

### Authentication

```
JWT (Bearer Token)
```

### Organization Scope

```
user.organizationId → demand.organizationId (关联查询)
```

### Implementation

```typescript
// rfqs.controller.ts
@Get('mine')
@UseGuards(JwtAuthGuard)
@ApiBearerAuth()
@ApiOperation({ summary: 'Get RFQs for current supplier organization' })
async findMine(@CurrentUser() user: AuthRequest['user']) {
  if (!user.organizationId) {
    return ApiResponse.ok({ data: [], total: 0 });
  }
  return ApiResponse.ok(await this.service.findMine(user.organizationId));
}

// rfqs.service.ts
async findMine(organizationId: string) {
  const [data, total] = await Promise.all([
    this.prisma.rFQ.findMany({
      where: {
        demand: {
          organizationId,
        },
      },
      orderBy: { createdAt: 'desc' },
      include: { demand: true, createdByUser: true },
    }),
    this.prisma.rFQ.count({
      where: {
        demand: {
          organizationId,
        },
      },
    }),
  ]);
  return { data, total };
}
```

### 设计说明

RFQ 模型无直接 `organizationId` 字段，通过 `RFQ → Demand → organizationId` 关联查询。Service 方法使用 `demand.organizationId` 过滤，确保只返回当前 Supplier Partner 组织相关的 RFQ。

## 4. RFQ Response Mine API

### Endpoint

### Authentication


### Organization Scope

```
user.organizationId → response.organizationId (直接过滤)
```

### Implementation

```typescript
// rfq-responses.controller.ts
@Get('rfq-responses/mine')
@UseGuards(JwtAuthGuard)
@ApiBearerAuth()
@ApiOperation({ summary: 'Get current organization RFQ responses' })
async findMine(@CurrentUser() user: AuthRequest['user']) {
  if (!user.organizationId) {
    return ApiResponse.ok({ data: [], total: 0 });
  }
  return ApiResponse.ok(await this.service.findMine(user.organizationId));
}

// rfq-responses.service.ts
async findMine(organizationId: string) {
  const [data, total] = await Promise.all([
    this.prisma.rFQResponse.findMany({
      where: { organizationId },
      orderBy: { createdAt: 'desc' },
      include: { rfq: true, organization: true, offer: true },
    }),
    this.prisma.rFQResponse.count({ where: { organizationId } }),
  ]);
  return { data, total };
}
```

### 设计说明

RFQResponse 模型已有 `organizationId` 字段，直接按 `where: { organizationId }` 过滤。只返回当前 Supplier Partner 组织提交过的报价记录。
