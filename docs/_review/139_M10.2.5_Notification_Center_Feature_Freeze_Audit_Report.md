### Security Model Verification

```typescript
// getAccessScope()
// ADMIN:  { organizationId } → filter by Notification.user.organizationId
// MEMBER: { userId }         → filter by Notification.userId

// validateAccess()
// 1. Own notification → always allowed
// 2. ADMIN + same org → allowed
// 3. Otherwise → ForbiddenException
```

| Scenario | Access | Mechanism |
|----------|--------|-----------|
| User views own notification | ✅ | `userId === notification.userId` |
| ADMIN views org member's notification | ✅ | `organizationMember.role === 'ADMIN'` + org match |
| User views another user's notification | ❌ | `ForbiddenException` |
| Cross-org access | ❌ | org mismatch → `ForbiddenException` |
