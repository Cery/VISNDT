## 4. Auth Type Design

### 4.1 AuthUser Interface

```typescript
export interface AuthUser {
  id: string;
  email: string;
  name?: string;
  role: string;
  organizationId?: string;
}
```

| Field | Type | Required | Purpose |
|-------|------|:---:|---------|
| `id` | `string` | Yes | User UUID |
| `email` | `string` | Yes | User email |
| `name` | `string` | No | Display name |
| `role` | `string` | Yes | Role (ADMIN, MEMBER) |

## 5. Zustand Auth Store Design

### 5.1 AuthState Interface

```typescript
interface AuthState {
  accessToken: string | null;
  user: AuthUser | null;
  isAuthenticated: boolean;
  setAuth: (token: string, user: AuthUser) => void;
  clearAuth: () => void;
}
```

### 5.2 State Transitions

```
Initial State:
  accessToken: null
  user: null
  isAuthenticated: false

After Login (setAuth):
  accessToken: "<jwt_token>"
  user: { id, email, role, ... }
  isAuthenticated: true

After Logout (clearAuth):
  accessToken: null
  user: null
  isAuthenticated: false
```

### 5.3 Store Architecture

```
src/stores/
├── app.store.ts     # AppState (sidebarCollapsed)
├── auth.store.ts    # AuthState (token, user, auth status)
└── index.ts         # Barrel export (appStore + authStore)
```
