
```text

└─ RoleGuard
   └─ SupplierPageContent
      ├─ useEffect/loadData()
```

- `AuthGuard -> RoleGuard -> SupplierRfqsContent`

- 错误角色用户会先被 `RoleGuard` 拦截
- 内容组件不会先 mount
- 内容组件内的 `useEffect` 不会在错误角色下先触发
