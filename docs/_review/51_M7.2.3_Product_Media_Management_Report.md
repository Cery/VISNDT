## 1. Phase Overview

**Purpose**: 为 Product Global Catalog 增加媒体资源管理能力，支持产品图片、技术文档、认证文件、产品资料等媒体资源。

**Strategy**: 复用已有 FileAsset 模型，新增 ProductMedia 桥接模型，实现 Product → ProductMedia → FileAsset 的媒体管理链路。FileAsset 负责文件存储信息，ProductMedia 负责媒体元数据（类型、排序、主图标记等）。

## 4. Data Model Design

### ProductMedia 模型

```
ProductMedia {
  id:           UUID      (PK)
  productId:    UUID      (FK → Product)
  fileAssetId:  UUID?     (FK → FileAsset, optional)
  mediaType:    FileType  (IMAGE | DOCUMENT | CERTIFICATE | OTHER)
  title:        String?
  description:  String?
  isPrimary:    Boolean   (default false)
  displayOrder: Int       (default 0)
  createdAt:    DateTime
  updatedAt:    DateTime
}
```

### 关系图

```
Product ──1:N── ProductMedia ──N:1── FileAsset (optional)
  │                                       │
  │ + media[]                             │ + media[]
  │                                       │
  ├── name, description, ...              ├── fileName, storageKey
  │                                       ├── mimeType, fileSize
  │                                       └── entityType, entityId
  └── ProductCategory
```

### 设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| FileAsset FK optional | 可选 | 允许先创建元数据，后关联文件 |
| 不删除物理文件 | ✅ | DELETE 仅删除 ProductMedia 记录，不删除 FileAsset |
| 不修改 Product 模型 | ✅ | Product 保持 Global Catalog 纯净 |
| 不增加 imageUrl 字段 | ✅ | 避免 Product 模型膨胀 |

## 5. API Change Report

### 新增接口

| 方法 | 路径 | 权限 | 描述 |
|------|------|------|------|
| GET | `/products/:productId/media` | Public | 获取产品媒体列表 (按 displayOrder 排序) |
| GET | `/products/:productId/media/:id` | Public | 获取媒体详情 |
| POST | `/products/:productId/media` | 🔒 ADMIN | 添加产品媒体 |
| PATCH | `/products/:productId/media/:id` | 🔒 ADMIN | 更新媒体信息 |
| DELETE | `/products/:productId/media/:id` | 🔒 ADMIN | 删除媒体关联 |

### 权限设计

| 角色 | GET | POST | PATCH | DELETE |
|------|-----|------|-------|--------|
| Public | ✅ | ❌ 401 | ❌ 401 | ❌ 401 |
| MEMBER | ✅ | ❌ 403 | ❌ 403 | ❌ 403 |
| ADMIN | ✅ | ✅ | ✅ | ✅ |
