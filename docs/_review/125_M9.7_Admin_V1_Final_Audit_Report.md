## 5. Security Final Audit

### 安全链验证

```
浏览器 URL
    │
    ▼
RequireAuth (Route Guard)
    ├── authStore.isAuthenticated → false → Navigate /login
    └── authStore.checkTokenExpiry() → expired → clearAuth
    │
    ▼
AdminLayout
    │
    ▼
Page Component
    │
    ▼
Service Layer
    │
    ▼
apiClient (Axios)
    ├── Request Interceptor: Bearer ${accessToken} ← authStore.getState()
    └── Response Interceptor: 401 → clearAuth + redirect /login
    │
    ▼
Backend
    ├── JwtAuthGuard (JWT 验证)
    ├── RolesGuard (RBAC 验证)
```
