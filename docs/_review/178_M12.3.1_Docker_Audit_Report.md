## 2. Backend 运行方式分析

| 项目 | 值 |
|------|-----|
| Runtime | Node.js >= 20.0.0 |
| 包管理 | pnpm >= 9.0.0 |
| 构建 | `nest build` (TypeScript → CommonJS) |
| 启动 | `node dist/main` |
| 端口 | 4000 (默认) |
| 数据库 | PostgreSQL (Prisma) |
| 依赖 | bcrypt, passport-jwt, @prisma/client |

### 构建流程

```
npm install -g pnpm
  ↓
pnpm install --frozen-lockfile
  ↓
pnpm db:generate
  ↓
pnpm --filter @visndt/api build
  ↓
node apps/api/dist/main
```
