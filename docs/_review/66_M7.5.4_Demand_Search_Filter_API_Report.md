## 4. Query Design

### 4.1 Keyword 搜索

```typescript
// Prisma OR 查询
{
  OR: [
    { title: { contains: keyword } },
    { description: { contains: keyword } },
  ]
}
```

- 使用 Prisma `contains` 进行子串匹配
- 不区分大小写（依赖 PostgreSQL 默认 collation）
- 与 status filter 通过 AND 组合

### 4.2 Status 过滤

```typescript
// 精确匹配
where: { status: DemandStatus }
```

- 支持所有 DemandStatus 枚举值
- 与 keyword 通过 AND 组合

### 4.3 Sort 排序

```typescript
const sortMap = {
  latest:    { createdAt: 'desc' },    // 最新创建
  updated:   { updatedAt: 'desc' },    // 最近更新
  published: { publishedAt: 'desc' },  // 最近发布
};
```

- 使用 Object Map 白名单，防止注入
- 非法值回退到 `latest`（createdAt desc）
- NULL 值（publishedAt 未设置）由 PostgreSQL 降序处理

### 4.4 Include 扩展

```typescript
include: {
  organization: true,                                    // 组织信息
  createdByUser: true,                                  // 创建者
  parameters: { include: { parameterDefinition: true } }, // 参数需求
  matches: { include: { product: { include: { category: true } } } }, // 匹配结果
}
```

### 4.5 联系方式保护

```typescript
// 在 findAll() 返回前对所有结果应用保护
const protectedData = data.map((d) => this.protectContactInfo(d));

// protectContactInfo 逻辑：
// contactVisible=false → contactPhone/contactEmail → '***'
// contactVisible=true  → 保留原值
```

### 4.6 Prisma 查询生成

```sql
-- 示例：keyword=内窥镜&status=PUBLISHED&sort=published&page=1&pageSize=20
SELECT * FROM "demand"
WHERE "status" = 'PUBLISHED'
  AND ("title" ILIKE '%内窥镜%' OR "description" ILIKE '%内窥镜%')
ORDER BY "published_at" DESC NULLS LAST
LIMIT 20 OFFSET 0;
```
