
### 4.2 Matching Algorithm

```
Demand.publish()
  │
  ├── 1. Load Demand + parameters
  ├── 2. Query candidates (ACTIVE products + ACTIVE offers + category filter)
  ├── 3. For each candidate: calculateScore()
  ├── 4. Filter by minMatchScore threshold
  ├── 5. Sort by score (desc), limit to maxMatchesPerDemand
  ├── 6. Batch upsert DemandMatch records
  └── 7. Return MatchResultDto
```

### 4.3 Scoring Engine

| Feature | Implementation |
|---------|---------------|
| Algorithm | Weighted (weighted_v1) |
| Default threshold | `minMatchScore: 30` |
| Max matches | `maxMatchesPerDemand: 50` |
| Category filter | CategoryHelper resolves category from demand/parameters |
| Candidate filter | Product status=ACTIVE + has ACTIVE offer |
| Parameter types | Range, exact, enum matching |
| Hard fail | Required parameters with no match → skip |

### 4.4 Assessment

**Score: 85/100** ✅

| Strengths | Gaps |
|-----------|------|
| Full scoring algorithm | Not in app.module.ts (only via DemandsModule) |
| Weighted scoring | No parameter weight customization |
| Category filtering | Hardcoded thresholds |
| Unit tests (category helper) | No scoring service unit tests |
| Upsert-based match creation | Match scoring details not persisted with individual scores |
