## 4. Optimization Details

### 4.1 Backend Query Optimization

| # | Optimization | Before | After | Impact |
|---|-------------|--------|-------|--------|
| B1 | Date Truncation | Prisma groupBy (broken for day/week/month) | `$queryRaw` + `DATE_TRUNC()` | Fixes G4, G6 |
| B2 | Dashboard Time Range | All-time only | `?from=&to=` optional params | Fixes G2 |
| B3 | Trend Memory | Load all 7-day events into JS memory | Single SQL with `COUNT(*) FILTER` + `DATE_TRUNC` | Fixes G1 |
| B4 | Entity Name Resolution | Top N shows UUIDs | Read-only JOIN with Product/Content tables | Fixes G3 |

### 4.2 Trend Query Optimization

```sql
-- Before: Load all events into memory, group in JS
SELECT event, created_at FROM conversion_event WHERE created_at >= $1;

-- After: Single SQL aggregation with DATE_TRUNC
SELECT
  to_char(DATE_TRUNC('day', created_at), 'YYYY-MM-DD') AS date,
  COUNT(*) FILTER (WHERE event = 'PAGE_VIEW')::int AS page_views,
  COUNT(*) FILTER (WHERE event IN ('PRODUCT_VIEW', 'PRODUCT_FILTER'))::int AS product_views,
  COUNT(*) FILTER (WHERE event = 'CONTENT_VIEW')::int AS content_views,
  COUNT(*) FILTER (WHERE event = 'SEARCH')::int AS searches,
  COUNT(*) FILTER (WHERE event IN ('INQUIRY_START', 'INQUIRY_SUBMIT'))::int AS inquiries,
  COUNT(*) FILTER (WHERE event = 'CTA_CLICK')::int AS cta_clicks
FROM conversion_event
WHERE created_at >= $1 AND created_at <= $2
GROUP BY DATE_TRUNC('day', created_at)
ORDER BY date ASC;
```

### 4.3 Entity Name Resolution

```
Before:
  TopProductsTable: 产品ID = UUID (e.g. "a1b2c3d4-...")
  TopContentTable:  内容ID = UUID

After:
  Backend: resolveEntityNames() → Product.findMany() / Content.findMany()
  TopProductsTable: 产品名称 = Actual product name
  TopContentTable:  内容标题 = Actual content title
```

### 4.4 Admin UI Enhancement

```
Before:
  - No time range control (always all-time / 7-day trend)
  - No refresh capability
  - Top N shows UUIDs

After:
  - RangePicker (Ant Design) with optional from/to
  - Refresh button with loading state
  - Top N shows real entity names (from backend resolution)
```
