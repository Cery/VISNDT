## 2. Permission Architecture Changes

### 2.1 Architecture Before (508)

- JWT Payload 不含 Role 信息
- 后端 `RolesGuard` 通过 `OrganizationMember.role` 检查权限（ADMIN / MEMBER）
- 前端 `auth.service.ts` 硬编码 `role: 'ADMIN'`
- 前端无任何权限控制组件
- Admin 路由无权限守卫

### 2.2 Architecture After (509)

```
AdminRole (4 levels)
    |
PermissionDef (17 keys)
    |
usePermission Hook
    |
├── PermissionGuard (wrap children)
├── PermissionButton (disable with tooltip)
└── RoleCapabilityCard (display role info)
```
