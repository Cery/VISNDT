## 2. Current Product Architecture

### 2.1 Product Domain 全貌

```
Product Category (树形)
    │
    ├── Product (Global Catalog)
    │       │
    │       ├── ProductParameterValue (参数值)
    │       │       └── ParameterDefinition
    │       │               └── ParameterGroup
    │       │
    │       ├── ProductParameterDefinition (参数关联)
    │       │
    │       └── Offer (Organization-owned)
    │               │
    │               └── Organization
    │
    └── FileAsset (entityType=PRODUCT, 未集成)
```

## 4. Data Model Review

### 4.1 Product (Prisma Model)

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| id | Uuid | ✅ | PK |
| categoryId | Uuid | ✅ | FK → ProductCategory |
| name | String | ✅ | 产品名称 |
| model | String? | ❌ | 型号 |
| description | String? | ❌ | 描述 |
| status | String | ✅ | DRAFT (default) |
| createdAt | DateTime | auto | 创建时间 |
| updatedAt | DateTime | auto | 更新时间 |

**Relations**: category (ProductCategory), parameterValues (ProductParameterValue[]), parameterAssociations (ProductParameterDefinition[]), offers (Offer[])

### 4.2 ProductCategory (Prisma Model)

| Field | Type | Description |
|-------|------|-------------|
| id | Uuid | PK |
| name | String | 分类名称 |
| slug | String (unique) | URL slug |
| parentId | Uuid? | FK → self (树形) |

**Relations**: parent (self), children (self[]), products (Product[])

### 4.3 Parameter System (5 Models)

```
ParameterGroup (参数组，如 "光学参数")
  └── ParameterDefinition (参数定义，如 "分辨率", code, dataType, unit, required)
        ├── ParameterOption (预设选项，如 "1080p", "4K")
        └── ProductParameterValue (产品实际值)

ProductParameterDefinition (产品-参数关联，含 displayOrder)
```

### 4.4 Offer (桥接层)

| Field | Description |
|-------|-------------|
| organizationId | FK → Organization |
| productId | FK → Product |
| @@unique([organizationId, productId]) | 每个组织对每个产品仅一个 Offer |

## 5. Architecture Gap Analysis

### 5.1 安全缺口 (🔴 Critical)

| # | Module | 端点 | 缺口 | 建议 |
|---|--------|------|------|------|
| G1 | ProductCategories | POST/PATCH | 无 Guard | M7.2.2 添加 ADMIN Guard |
| G2 | ParameterGroups | POST/PATCH | 无 Guard | M7.2.2 添加 ADMIN Guard |
| G3 | ParameterDefinitions | POST/PATCH | 无 Guard | M7.2.2 添加 ADMIN Guard |
| G4 | ProductParameters | POST | 无 Guard | M7.2.2 添加 ADMIN Guard |

### 5.2 功能缺口 (🟡 Medium)

| # | 缺口 | 影响 | 建议 |
|---|------|------|------|
| F1 | 无产品图片/媒体管理 | 无法展示产品外观 | M7.2.3 集成 FileAsset |
| F2 | 无产品搜索/筛选 | 仅支持分页列表 | M7.2.4 添加 search/filter API |
| F3 | 无产品状态流转 | status 字段无 workflow | M7.2.5 添加 status transition |
| F4 | 无产品审计 | 无修改记录 | M7.7 阶段处理 |
| F5 | 无产品版本管理 | 修改即覆盖 | 未来 M8+ |

### 5.3 设计合理性 (✅ Strengths)

| # | 优势 | 说明 |
|---|------|------|
| S1 | Global Catalog 设计 | Product 不与 Organization 耦合，适合 Marketplace |
| S2 | 树形分类 | ProductCategory.parentId 支持多级分类 |
| S3 | 参数体系完整 | 5 模型支持 group→definition→option→value 全链路 |
| S4 | Product→Offer→Organization | 清晰的归属链路，Offer 层做 org 绑定 |
| S5 | M:N 参数关联 | ProductParameterDefinition + ProductParameterValue 双表设计 |

## 6. NDT 行业适配性分析

### 6.1 工业内窥镜产品

| 需求 | 当前支持 | 缺失 |
|------|---------|------|
| 产品型号 (model) | ✅ Product.model | — |
| 探头直径参数 | ✅ ParameterDefinition | — |
| 工作长度参数 | ✅ ParameterDefinition | — |
| 分辨率参数 | ✅ ParameterDefinition | — |
| 产品图片 | ❌ | FileAsset 未集成 |
| 认证证书 | ❌ | FileType.CERTIFICATE 未使用 |

### 6.2 NDT 检测设备

| 需求 | 当前支持 | 缺失 |
|------|---------|------|
| 多分类 (超声/射线/涡流) | ✅ ProductCategory 树形 | — |
| 技术参数体系 | ✅ ParameterGroup + Definition | — |
| 设备能力描述 | ✅ Product.description | 详细规格需 Parameter |
| 检测标准参数 | ✅ ParameterDefinition | — |

### 6.3 整体评估

**当前 Product Domain 已具备 NDT 产品目录的基础能力。** 参数体系可以灵活表达工业内窥镜和 NDT 设备的技术规格。主要缺口在于媒体管理（产品图片）和搜索/筛选能力。
